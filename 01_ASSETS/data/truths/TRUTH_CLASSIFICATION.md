# ZONGYUAN-ROOT 真值分类分级规范 V1.0

## 六类真值（type）
| 类型 | 说明 | 示例 |
|------|------|------|
| axiom | 公理（不可改） | 元极恒一公理、三态收敛公理 |
| theorem | 定理（可推导） | 三态自洽定理、稳态收敛定理 |
| rule | 元规则（需审批） | MR-01三态闭环、MR-02三端锁档 |
| standard | 标准（可增量） | 视觉标准、工程标准 |
| config | 配置（可编辑） | 服务配置、API配置 |
| ip_asset | IP资产 | 角色定妆、场景基准 |

## 四级锁档（level）
| 级别 | 名称 | 修改权限 | 说明 |
|------|------|----------|------|
| L0 | 公理层 | 禁止修改 | 宇宙客观规律、本源公理 |
| L1 | 法则层 | 需元极恒一审批 | 元法则、元宪法、核心规则 |
| L2 | 规则层 | 管理员可增量补丁 | 工程标准、业务规则 |
| L3 | 配置层 | 操作员可编辑 | 服务配置、参数、阈值 |

## 真值状态（status）
- FROZEN: 已固化，禁止覆盖
- ACTIVE: 活跃使用中
- PENDING: 待审批
- DEPRECATED: 已废弃
