# 昆仑洞天短剧 · 配音台词模板（DRM-PIPE V1.3）

> 每条台词结构：`角色 / 情绪 / 台词 / 时长 / 音效提示`。
> 台词须与分镜表 `sfx` 字段对齐；无台词镜头只标音效。

## 一、单条台词结构（照此填充）

```
【台词 001】
角色：九天玄女·战争形态
情绪：肃穆杀伐、沉稳威严
台词："归墟将启，凡人退避——此封印，本宫重立。"
时长：6s（语速沉稳，尾音压沉）
音效提示：句中战鼓一击，尾字随披风猎猎
```

字段说明：

| 字段 | 说明 |
|---|---|
| 角色 | 须与角色设定库一致（含形态，如"战争形态"） |
| 情绪 | 见下方角色口吻表，同角色跨集情绪基调统一 |
| 台词 | 简体中文，短句、可配音、无违规内容 |
| 时长 | 与对应分镜 duration 匹配（5–15s） |
| 音效提示 | 环境音/配乐/卡点提示 |
