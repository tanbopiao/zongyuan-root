# 昆仑洞天短剧 · 素材包目录规范（DRM-PIPE V1.3）

> 每集打包为一个可交付 ZIP。ZIP 内结构固定，"一键量产引擎"与下游归档按此结构消费。

## 一、ZIP 内目录结构

```
昆仑洞天_EPXX_<集标题>_素材包/
├── 01_分镜表/
│   ├── 分镜表_EPXX.json        # 机器可读（含 validation 校验字段）
│   └── 分镜表_EPXX.md          # 人读表格
├── 02_关键帧提示词/
│   └── 关键帧提示词集_EPXX.txt  # 每条【KF-NNN】一段，长兵器镜头标注铁律
├── 03_配音台词/
│   └── 配音台词脚本_EPXX.txt
├── 04_素材清单/
│   └── 素材清单_EPXX.json       # 每文件路径+SHA256+校验结果
└── README.md                    # 集级说明：项目/集号/角色/时长/校验结论
```

## 二、文件命名规则

| 项 | 规则 | 示例 |
|---|---|---|
| 集号 | `EP` + 两位数字 | `EP01` |
| 分镜表 | `分镜表_<集号>.{json,md}` | `分镜表_EP01.json` |
| 关键帧 | `关键帧提示词集_<集号>.txt` | `关键帧提示词集_EP01.txt` |
| 配音 | `配音台词脚本_<集号>.txt` | `配音台词脚本_EP01.txt` |
| 素材清单 | `素材清单_<集号>.json` | `素材清单_EP01.json` |
| 关键帧编号 | `KF-` + 三位序号 | `KF-004` |
| 分镜编号 | `S<集号>-` + 三位镜号 | `S01-004` |
| 禁止 | 空格、中文标点入文件名（目录名可含中文） | — |

## 三、素材清单（manifest）JSON 结构

```json
{
  "episode": "EP01",
  "title": "归墟封印",
  "did": "DID-BR-000002",
  "omega": "Ω₀⊂⊙∞⊂Ω",
  "totalShots": 12,
  "totalDurationSec": 112,
  "files": [
    {"path": "01_分镜表/分镜表_EP01.json", "sha256": "大写十六进制", "check": "pass"},
    {"path": "02_关键帧提示词/关键帧提示词集_EP01.txt", "sha256": "...", "check": "pass"}
  ],
  "validatorSummary": {"pass": 0, "warn": 0, "fail": 0}
}
```

## 四、打包硬约束

- 仅在本目录产出文件，不修改/不发布任何页面 HTML。
- 校验器 `fail` 项 > 0 时，素材清单 `validatorSummary.fail` 必须如实记录，不得清零蒙混。
- UTF-8 编码，中文目录名保留，文件名不含空格与中文标点。
