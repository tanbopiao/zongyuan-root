# 昆仑洞天短剧 · 关键帧提示词模板（DRM-PIPE V1.3）

> 本模板为**不可省略的前置约束块**。每条关键帧提示词 = ①内容描述 + ②风格锁定块 +（手持长兵器时）③结构铁律块。
> 校验器 `drama_validator.py` 对②③④做硬性检查：缺锁定项 → warn；命中④红线 → **fail（reject，不降级）**。

## ① 内容描述（按镜头自填）

`[角色形态], [场景描述], [动作/状态], [光影效果]`

- 角色形态必须锚定角色设定库（同角色跨镜不得漂移）。
- 未知存在/凶兽只露局部（如"魔族爪尖局部探出"），**不露全貌**。

## ③ 长兵器硬编码结构铁律块（凡手持长兵器·矛/枪/戟/棍/戈/长刀，强制全文照抄，不可省略）

> 以下为昆仑天元法则 V1.2 原文（KUNLUN-LAW-L0-003-V1.2 / metalaw.KEYFRAME-STRUCTURE-DRIFT-FIX-001），**逐字照抄，不得改写字序**：

```
【结构铁律·V1.2强制】长兵器几何连续完整,禁断裂/分段/凭空多生成;
矛尖与人物头部强制安全空域,禁穿插/重叠/刺头;
双手握持同一根矛杆,手指-手腕-小臂-肩部形成连续力学握持关系,接触点光影匹配;
武器延伸动线不切割人物主体剪影,矛尖落于独立空域或延伸至画面边界外;
能量光效仅作叠加照射层,禁止覆盖/融合/扭曲武器实体几何;
武器-手部-角色遮挡/接触阴影/环境反光全局光源统一。
```

**三级判定**：
- 高危（武器与头部重叠/穿插/刺头）→ 直接重绘 = **fail**
- 预警（武器距头部 <8% 画面高 / 铁律关键短语缺失）→ 自动调整 = **warn**
- 通过（结构完整、光影统一、四条关键短语齐全）→ 放行 = **pass**

校验器识别的四条关键短语（缺一即降级）：`几何连续` / `安全空域` / `双手握持` / `光效不覆盖实体`。

## ④ 人体结构绝对禁止法则（红线 = 校验器硬性 reject，fail 级）

```
【人体结构绝对禁止法则】
- 禁止角色面部雄性化、狰狞化（须为纯净女相/肃穆神性，英武亦可，绝无狰狞雄性）；
- 禁止神女/残魂形象恐怖化、鬼魅化（半透明光影即可，肃穆神性，非厉鬼怨灵）；
- 禁止任何血腥画面（伤口/血液/断肢/飞溅），一律以能量碰撞与光效表达；
- 禁止丢失右下角溯源标识 Ω₀⊂⊙∞⊂Ω；
- 未知存在/凶兽只露局部，不露全貌。
```

> 说明：提示词中以**否定式保护语**出现上述词（如"绝不狰狞雄性化""不露全貌不血腥"）属于正确写法，校验器做否定语境识别，**不计为 fail**；只有裸命中（无否定修饰）才判 fail。
