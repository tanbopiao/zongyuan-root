## 二、单镜字段表

| 字段 | 类型 | 约束 |
|---|---|---|
| shot_id | 字符串 | `S{集号}-{三位镜号}`，全镜连续不跳号 |
| chapterBeat | 枚举 | 章节节拍：起/承/转/合（3-5 节拍） |
| desc | 字符串 | 场景+人物+动作+光影；未知存在/凶兽**只露局部不露全貌** |
| duration | 整数秒 | **5–15 秒**（超界 fail） |
| kfPrompt | 字符串 | 完整关键帧提示词（含风格锁定块；长兵器镜头含结构铁律块） |
| vPrompt | 字符串 | 视频运动描述，快切卡点，禁慢镜头/长留白 |
| sfx | 字符串 | 环境音+配乐+台词 |
| transition | 枚举 | **硬切 / 闪白 / 快切**（禁慢淡入淡出/溶解/渐隐渐显） |
| hasWeapon | 布尔 | 是否手持长兵器（矛/枪/戟/棍/戈/长刀） |
| validation.bodyCheck | pass/fail | 人体结构红线（fail 级，不可降级） |
| validation.weaponLevel | pass/warn/fail/NA | 长兵器三级判定 |
| validation.characterRule | pass/fail | 角色元规则隔离 |
| validation.aspect | 固定 | `9:16竖屏` |
| validation.traceMark | present/missing | 右下角 Ω₀⊂⊙∞⊂Ω |

## 三、章节节拍（一集 3–5 拍）

```
节拍1 起：开场定调（环境/未知存在局部/压迫感建立）
节拍2 承：主角登场（形态锁定/动机）
节拍3 转：冲突爆发（长兵器动作/能量光效高潮）
节拍4 合：封印/收束（灵纹归位/角色复位）
节拍5 尾：定格剪影（溯源标识渐显，画面定格）
```
