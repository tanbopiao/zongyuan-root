# zongyuan-src

本目录存放 ZONGYUAN-ROOT 体系工程源码，按子目录平铺。已剔除 `__pycache__/` 与 `*.pyc` 编译缓存。

## 子目录说明

| 子目录 | 用途 |
|---|---|
| kernel/ | 元极恒一自治体系内核：负责开机引导、Lv10 模式加载、四层框架（元宪法/元公理/元法则/元规则）常驻与心跳通信 |
| truth-engine/ | 全域真值生成引擎 V3.0：基于 SM-BS 映射执行真值提炼、漂移量化、冲突消解与纯度评分 |
| cte-engine/ | CTE 三位一体适配器引擎：CausalToTruth / TruthToEvolution / EvolutionToCausal 三适配器流转与闭环预激活 |
