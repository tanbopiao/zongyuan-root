# semantic-index

本目录存放语义向量资产，用于 SM-BS 语义-黎曼流形双向稳态映射系统的锚定与漂移检测。

## 文件清单

| 文件名 | 用途 |
|---|---|
| semantic_model.json | 语义模型本体配置：定义概念空间维度、度量张量与语义距离参数，是 SM-BS 系统的模型定义文件 |
| ANCHOR-VECTORS.json | 锚点向量表：存储核心概念（人/事/物/规则）在流形中的基准坐标，用于漂移巡检时的坐标比对 |
| semantic_vector_engine.py | 语义向量引擎：执行概念向量化、流形坐标映射、漂移率计算与双向稳态映射的核心 Python 脚本 |
