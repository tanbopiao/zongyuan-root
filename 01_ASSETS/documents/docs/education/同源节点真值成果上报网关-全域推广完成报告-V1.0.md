```bash
curl -X POST https://www.huodouai.com/api/report/node/register \
  -H "Content-Type: application/json" \
  -d '{"node_id":"my-node-001","node_name":"我的节点","node_type":"worker"}'
```

### 第2步：上报真值
```bash
curl -X POST https://www.huodouai.com/api/report/truth \
  -H "Content-Type: application/json" \
  -d '{"truth_key":"RULE.EXAMPLE.001","truth_value":"示例真值内容","source_node":"my-node-001","confidence":0.9}'
```

### 第3步：验证上报
