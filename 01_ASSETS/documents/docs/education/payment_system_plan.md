## 一、系统架构

```
用户点击解锁 → 创建订单 → 调起支付 → 支付回调 → 解锁课程 → 记录订单
```

- **到账**：T+1

- **到账**：T+1

## 四、解锁逻辑

### 4.1 前端
- 付费课程显示锁定遮罩
- 点击解锁 → 弹出支付二维码
- 支付成功 → 解锁课程内容
- 已解锁课程记录在用户账号

### 4.2 后端
- 支付回调验证签名
- 更新订单状态为paid
- 记录用户已购课程
- 解锁课程内容访问权限

## 五、安全设计

1. **支付签名验证**：回调必须验证签名
2. **订单防重**：同一课程同一用户不重复创建待支付订单
3. **金额校验**：回调金额必须与订单金额一致
4. **退款机制**：7天无理由退款

## 六、接入步骤

1. 注册微信支付/支付宝商户号
2. 配置支付密钥
3. 开发支付接口
4. 开发回调接口
5. 前端对接
6. 测试支付流程
7. 上线

## 七、零成本启动方案

### 阶段一：手动解锁（零成本）
- 用户联系客服
- 客服确认付款后手动解锁
- 适合早期验证

### 阶段二：半自动（低成本）
- 用第三方支付平台（如PayJS）
- 无需商户号，个人可用
- 费率稍高但接入快

### 阶段三：全自动（正式）
- 正式商户号
- 全自动支付+解锁
- 规模化运营
