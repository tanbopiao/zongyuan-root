## 一、目的

将AI短剧生产从"手工抽卡"升级为标准化工业流水线，确保：
- 单部成本可控（6.6-7万元 vs 真人40-80万）
- 质量可复现（关键帧一致性≥90%）
- 周期可预测（单部7-14天）
- 合规可追溯（100%备案+AI双标识）

## 二、6节点标准化流程

### 节点1：剧本开发（Day 1-3）

**输入**：题材方向 / IP设定 / 平台要求
**输出**：分集大纲 + 分镜表 + 台词本

| 步骤 | 操作 | 验收标准 |
|---|---|---|
| 1.1 | 题材选型（参考热门题材榜） | 选定1个主题材+1个副题材 |
| 1.2 | 分集大纲（每集2-3分钟，80-100集） | 剧情节拍完整，每集有钩子 |
| 1.3 | 分镜表拆分（每集15-25镜） | 镜号/画面/时长/提示词/音效齐全 |
| 1.4 | 台词本导出 | 角色台词与旁白分离 |

**成本**：人工 0.5-1人天 × 800元/天 = 400-800元

---

### 节点2：角色与风格锁定（Day 2-4，与节点1并行）

**输入**：角色设定 / 风格基准
**输出**：角色定妆图 × N + 风格参考板

| 步骤 | 操作 | 验收标准 |
|---|---|---|
| 2.1 | 角色设定表（外貌/服饰/兵器/性格） | 每个角色≥3个角度描述 |
| 2.2 | 角色定妆图生成（Seedream 5.0） | 每角色3-5张，选定1张基准 |
| 2.3 | 风格参考板制作 | 黑金暗纹+国风仙侠+伦勃朗光影 |
| 2.4 | 长兵器结构铁律校验（如适用） | 高危→重绘，预警→调整，通过→放行 |

**成本**：算力 200元 + 人工 0.5人天 = 600元

---

### 节点3：关键帧批量生成（Day 4-8）

**输入**：分镜表 + 角色定妆图 + 风格参考板
**输出**：全部分镜关键帧（80-120张/集）

| 步骤 | 操作 | 验收标准 |
|---|---|---|
| 3.1 | 提示词模板填充（角色+场景+动作+光影） | 每镜1条完整prompt |
| 3.2 | 批量生成（Seedream 5.0，2K分辨率） | 每镜抽卡3-5次，选最优 |
| 3.3 | 角色一致性校验 | 同一角色跨帧相似度≥85% |
| 3.4 | 不合格帧重绘（抽卡冗余×8） | 废片率≤30% |
| 3.5 | 右下角溯源标识植入 Ω₀⊂⊙∞⊂Ω | 100%帧覆盖 |

**关键帧提示词模板**：
```
[角色形态], [场景描述], [动作/状态], [光影效果],
黑金暗纹风格, 国风仙侠写实厚涂, 史诗创世氛围,
UE5.7全局光追, 8K超清, 博物馆馆藏质感, 浮雕立体感,
伦勃朗光影, 9:16竖屏, 右下角Ω₀⊂⊙∞⊂Ω
```

**成本**：算力 1200元（含8倍抽卡冗余）+ 人工 1人天 = 2000元

---

### 节点4：视频合成（Day 7-10）

**输入**：关键帧序列 + 视频提示词
**输出**：全部分镜视频片段（每段5-10秒）

| 步骤 | 操作 | 验收标准 |
|---|---|---|
| 4.1 | 图生视频（Seedance 2.5，5秒/段） | 运动自然，无明显畸变 |
| 4.2 | 多段拼接（硬切/闪白快转） | 节奏卡点，禁用慢淡入淡出 |
| 4.3 | 帧率与分辨率统一（1080×1920，24fps） | 全片一致 |
| 4.4 | 废片重生成（运动畸变/角色漂移） | 重生成率≤20% |

**成本**：算力 560元 + 人工 0.5人天 = 960元

---

### 节点5：音频与后期（Day 9-12）

**输入**：视频片段 + 台词本 + 配乐方向
**输出**：成片（含配音/音效/配乐/字幕）

| 步骤 | 操作 | 验收标准 |
|---|---|---|
| 5.1 | AI配音（角色音色分离） | 口型同步，情感匹配 |
| 5.2 | 音效设计（环境音/动作音/转场音） | 5.1声道兼容 |
| 5.3 | 配乐制作/授权（卡点节奏） | BGM与画面节奏匹配 |
| 5.4 | 字幕压制（简体中文，安全区） | 不遮挡关键画面 |
| 5.5 | AI内容显式标识（片头/片尾） | "本片由AI生成"字样≥3秒 |

**成本**：算力 200元 + 人工 1人天 = 1000元

---

### 节点6：合规备案与交付（Day 11-14）

**输入**：成片 + 全部制作素材
**输出**：备案通过 + 多平台交付包

| 步骤 | 操作 | 验收标准 |
|---|---|---|
| 6.1 | AI内容隐式标识嵌入（C2PA/数字水印） | 100%帧可检测 |
| 6.2 | 三类备案材料生成（广电总局令第16号） | 一类/二类/三类按需提交 |
| 6.3 | 平台上线包制作（红果/抖音/快手） | 各平台格式+封面+简介 |
| 6.4 | 元秩序归档（四层结构化+SHA256确权） | 资产ID+Merkle哈希+DID确权 |
| 6.5 | 全局台账更新 | 根哈希重算，链路连续 |

**成本**：人工 1人天 + 备案费（三类约300-500元/部）= 1100-1300元

## 四、质量门禁（每节点必须通过）

| 门禁 | 检查项 | 通过标准 | 不通过处理 |
|---|---|---|---|
| QG1 | 剧本完整性 | 每集有钩子，剧情无逻辑断层 | 退回节点1 |
| QG2 | 角色一致性 | 跨帧相似度≥85% | 重绘不合格帧 |
| QG3 | 长兵器结构 | 无断裂/穿插/刺头 | 强制重绘 |
| QG4 | 视频运动质量 | 无明显畸变/漂移 | 重生成 |
| QG5 | 音画同步 | 口型误差≤100ms | 重新配音 |
| QG6 | AI标识完整性 | 显式+隐式双标识100%覆盖 | 补标识后重新导出 |
| QG7 | 备案合规 | 材料齐全，分类正确 | 补充材料 |

## 六、故障约束（全局强制）

1. 禁止慢淡入淡出转场，仅用硬切/闪白/快切
2. 禁止角色形象跨帧漂移（一致性<85%必须重绘）
3. 禁止长兵器结构断裂/穿插/刺头（三级判定）
4. 禁止无AI标识内容上线（显式+隐式双标识）
5. 禁止未备案作品分发（三类备案100%覆盖）
6. 禁止9:16以外画幅（竖屏强制）
