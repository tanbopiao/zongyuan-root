## 一、机制总览

### 1.1 机制定义

**物理基底自动补全机制（PBACM）**是物理仿真元规则体系的**智能补全层**，它解决物理仿真中的"不完整输入"问题：当用户输入一个不完整的物理场景（缺少质量、缺少约束、缺少力、缺少初始条件等）时，系统能够基于物理定律、常识推理、上下文推断，自动补全缺失的物理基底，使物理系统达到"可仿真、可推理、可演化"的完整状态。

> **类比**：就像代码编辑器的自动补全功能，物理基底自动补全是物理仿真编辑器的"物理自动补全"。

### 1.2 为什么需要自动补全

| 问题 | 说明 | 自动补全的价值 |
|------|------|--------------|
| **输入不完整** | 用户往往只描述部分物理属性，遗漏大量必要参数 | 自动推断缺失参数，降低输入门槛 |
| **物理知识门槛高** | 完整描述一个物理系统需要深厚的物理知识 | 基于物理定律自动补全，用户无需精通物理 |
| **仿真初始化复杂** | 物理仿真需要大量初始条件和边界条件 | 自动生成合理的初始条件和边界条件 |
| **场景描述模糊** | 用户用自然语言描述物理场景，信息不精确 | 将模糊描述转化为精确的物理参数 |
| **多物理场耦合** | 多物理场仿真需要考虑大量耦合关系 | 自动识别并补全物理场间的耦合关系 |

### 1.4 补全流程

```
用户输入（不完整物理场景）
    ↓
①输入解析：解析场景描述，提取已知物理要素
    ↓
②缺失检测：对比完整物理基底模板，识别缺失项
    ↓
③补全推理：基于物理定律+常识+上下文，推断缺失项
    ↓
④补全生成：生成完整的物理基底（属性/约束/参数/定律）
    ↓
⑤验证优化：物理一致性验证，冲突检测，参数优化
    ↓
⑥输出：完整可仿真的物理系统 + 补全说明 + 置信度
```

### 2.2 物理基底完整度评估

| 完整度等级 | 缺失要素数 | 可仿真性 | 补全需求 |
|-----------|-----------|---------|---------|
| **完整** | 0个 | ✅ 可直接仿真 | 无需补全 |
| **基本完整** | 1-2个次要要素 | ⚠️ 可仿真但精度有限 | 建议补全 |
| **部分完整** | 3-5个要素 | ❌ 不可直接仿真 | 必须补全 |
| **严重缺失** | 6-8个要素 | ❌ 无法仿真 | 深度补全 |
| **几乎空白** | 9-10个要素 | ❌ 完全无法仿真 | 全量补全 |

## 三、缺失检测机制

### 3.1 缺失检测方法

| 检测方法 | 说明 | 适用场景 |
|---------|------|---------|
| **模板对比法** | 将输入与完整物理基底模板对比，识别缺失字段 | 结构化输入 |
| **物理定律推导法** | 基于物理定律推导必要参数，检查是否缺失 | 半结构化输入 |
| **仿真可执行性检测** | 尝试运行仿真，检测哪些参数缺失导致错误 | 代码/脚本输入 |
| **语义分析法** | 分析自然语言描述，识别隐含的物理要素和缺失项 | 自然语言输入 |
| **依赖关系分析法** | 分析物理要素间的依赖关系，推导间接缺失项 | 复杂系统 |

### 3.2 缺失项分类

| 缺失类型 | 说明 | 补全难度 | 示例 |
|---------|------|---------|------|
| **必要参数缺失** | 仿真必须的参数，缺失则无法运行 | 低（有标准值） | 重力加速度g、时间步长dt |
| **材料属性缺失** | 物体的材料属性，影响仿真结果 | 中（需推断材料） | 弹性模量、泊松比、摩擦系数 |
| **初始条件缺失** | 系统的初始状态，影响演化路径 | 中（需合理假设） | 初始位置、初始速度 |
| **边界条件缺失** | 系统的边界约束，影响仿真范围 | 中（需推断边界） | 固定边界、自由边界、周期性边界 |
| **外力缺失** | 作用于系统的外力，影响运动状态 | 高（需推断受力） | 重力、风力、驱动力 |
| **约束缺失** | 物体间的约束关系，影响自由度 | 高（需推断连接） | 铰链、滑动、固定连接 |
| **物理定律缺失** | 适用的物理定律，影响仿真模型 | 高（需判断适用域） | 经典力学/量子力学/相对论 |
| **多物理场耦合缺失** | 多物理场间的耦合关系 | 极高（需深度分析） | 流固耦合、热固耦合、电磁耦合 |

## 四、补全推理机制

### 4.1 五大补全推理方法

#### 方法一：物理定律推导法

**原理**：基于物理定律和公式，从已知参数推导未知参数。

**示例**：
- 已知物体质量m和加速度a → 推导合力F=ma
- 已知物体密度ρ和体积V → 推导质量m=ρV
- 已知弹簧劲度系数k和形变量x → 推导弹力F=-kx
- 已知电压U和电阻R → 推导电流I=U/R

**适用场景**：有明确物理公式关联的参数补全

#### 方法二：物理常识库匹配法

**原理**：从物理常识库中匹配常见场景的标准参数值。

**常识库分类**：

| 常识库类别 | 内容示例 |
|-----------|---------|
| **材料属性库** | 钢/铝/铜/木/橡胶/玻璃的密度、弹性模量、泊松比、摩擦系数 |
| **物理常量表** | 重力加速度g、光速c、普朗克常数h、玻尔兹曼常数k、真空介电常数ε₀ |
| **标准环境参数** | 标准大气压、室温、空气密度、水的密度、粘度 |
| **常见场景模板** | 自由落体、抛体运动、单摆、弹簧振子、碰撞、圆周运动 |
| **单位换算表** | 国际单位制、英制单位、常用单位换算因子 |

**适用场景**：常见物理场景的标准参数补全

#### 方法三：上下文推断法

**原理**：基于场景描述的上下文信息，推断隐含的物理参数。

**推断维度**：

| 上下文维度 | 推断内容 | 示例 |
|-----------|---------|------|
| **场景类型** | 适用的物理定律和模型 | "天体运动"→万有引力+牛顿力学 |
| **物体描述** | 材料属性和形状 | "钢球"→钢的密度+弹性模量+球形 |
| **环境描述** | 环境参数和外力 | "在地球上"→重力g=9.8m/s² |
| **动作描述** | 初始条件和外力 | "从高处落下"→初始速度=0，受重力 |
| **约束描述** | 约束类型和参数 | "用绳子悬挂"→铰链约束+不可伸长绳 |
| **时间描述** | 仿真时长和时间步长 | "观察10秒"→仿真时长=10s |
| **精度要求** | 离散化精度和容差 | "精确仿真"→小时间步长+高精度求解器 |

**适用场景**：自然语言/半结构化描述的物理场景

#### 方法四：物理一致性约束法

**原理**：基于物理一致性约束（守恒定律、不等式约束、边界约束），推断参数的合理范围。

**一致性约束**：

| 约束类型 | 约束内容 | 推断应用 |
|---------|---------|---------|
| **守恒约束** | 质量守恒、动量守恒、能量守恒 | 推断未知质量/速度/能量 |
| **不等式约束** | 速度≤光速、温度≥绝对零度、摩擦系数≥0 | 限定参数合理范围 |
| **边界约束** | 物体不穿透、约束不违反、能量不溢出 | 推断边界条件 |
| **稳定性约束** | 仿真稳定条件（CFL条件、收敛条件） | 推断时间步长/网格尺寸 |
| **量纲约束** | 物理量量纲一致性 | 校验和推断参数单位 |

**适用场景**：参数范围推断和物理一致性校验

#### 方法五：机器学习预测法

**原理**：基于大量物理仿真数据训练的机器学习模型，预测缺失参数。

**预测模型**：

| 模型类型 | 预测内容 | 训练数据 |
|---------|---------|---------|
| **参数回归模型** | 预测缺失的物理参数值 | 历史仿真场景+完整参数 |
| **场景分类模型** | 分类物理场景类型，匹配模板 | 场景描述+场景标签 |
| **材料识别模型** | 从物体描述识别材料属性 | 材料描述+材料属性 |
| **约束推断模型** | 推断物体间的约束关系 | 场景描述+约束标注 |
| **物理场耦合预测** | 预测多物理场耦合关系 | 多物理场仿真数据 |

**适用场景**：复杂/模糊场景的智能补全

### 4.2 补全推理优先级

当多种补全方法可用于同一缺失项时，按以下优先级选择：

| 优先级 | 方法 | 置信度 | 说明 |
|--------|------|--------|------|
| **P0** | 物理定律推导法 | 95-100% | 有明确公式推导，结果确定 |
| **P1** | 物理常识库匹配法 | 85-95% | 标准参数值，适用常见场景 |
| **P2** | 上下文推断法 | 70-85% | 基于上下文合理推断，有不确定性 |
| **P3** | 物理一致性约束法 | 60-80% | 限定合理范围，需进一步确定 |
| **P4** | 机器学习预测法 | 50-80% | 数据驱动预测，依赖训练数据质量 |

## 五、补全生成与验证

### 5.1 补全结果生成

补全推理完成后，生成完整的物理基底，包含：

| 输出项 | 说明 |
|--------|------|
| **完整物理基底** | 十大要素全部填充的完整物理系统定义 |
| **补全项清单** | 所有被补全的项目列表，标注原值（空）和补全值 |
| **补全方法标注** | 每个补全项使用的补全方法（定律推导/常识匹配/上下文推断等） |
| **置信度评估** | 每个补全项的置信度（0-100%），整体补全置信度 |
| **物理一致性报告** | 补全后系统的物理一致性验证结果 |
| **可仿真性确认** | 确认补全后系统可直接运行仿真 |
| **用户可调整项** | 标注哪些补全项用户可能需要调整（低置信度项） |

### 5.2 物理一致性验证

补全完成后，必须通过物理一致性验证：

| 验证项 | 验证内容 | 验证方法 |
|--------|---------|---------|
| **量纲一致性** | 所有物理量量纲正确，公式两边量纲一致 | 量纲分析 |
| **守恒性验证** | 初始状态满足质量/动量/能量守恒 | 守恒量计算 |
| **不等式约束** | 所有物理量满足物理不等式（速度≤c等） | 范围检查 |
| **约束可行性** | 所有约束可同时满足，无过约束/矛盾约束 | 约束求解测试 |
| **仿真稳定性** | 时间步长和网格尺寸满足稳定性条件 | CFL条件/收敛性分析 |
| **边界完整性** | 边界条件完整，无未定义边界 | 边界扫描 |
| **初始条件合理性** | 初始条件物理合理，无奇点/不连续 | 初始状态检查 |

### 5.3 冲突检测与消解

补全过程中可能出现冲突，需要检测和消解：

| 冲突类型 | 说明 | 消解策略 |
|---------|------|---------|
| **参数冲突** | 不同补全方法给出不同参数值 | 按优先级选择高置信度方法，或取加权平均 |
| **约束冲突** | 补全的约束与已有约束矛盾 | 优先保留用户明确指定的约束，调整补全约束 |
| **定律冲突** | 不同物理定律适用域重叠导致矛盾 | 判断场景适用域，选择最匹配的物理定律 |
| **守恒冲突** | 补全参数导致守恒量不守恒 | 调整补全参数使守恒量守恒，或标注非守恒过程 |
| **边界冲突** | 补全的边界条件相互矛盾 | 重新推断边界条件，或增加过渡区域 |

## 六、典型补全场景示例

### 6.1 场景一：自由落体

**用户输入**："一个球从100米高处落下"

**已知要素**：
- 物质基底：球（形状已知，材料/质量未知）
- 运动基底：初始位置高度100m（初始速度未知）
- 空间基底：隐含三维空间（坐标系未知）

**缺失检测**：
- 空间基底：坐标系、维度、参考系
- 时间基底：时间步长、仿真时长
- 物质基底：球的质量、密度、材料、半径
- 力基底：重力（隐含但未明确）、空气阻力
- 运动基底：初始速度（隐含为0）
- 约束基底：地面约束（隐含）

**自动补全**：

| 缺失项 | 补全值 | 补全方法 | 置信度 |
|--------|--------|---------|--------|
| 坐标系 | 笛卡尔坐标系，y轴向上，原点在地面 | 上下文推断 | 90% |
| 重力加速度 | g=9.8m/s²，方向向下 | 常识库匹配 | 98% |
| 初始速度 | v₀=0（从静止释放） | 上下文推断 | 85% |
| 球的质量 | m=1kg（默认值） | 常识库匹配 | 70% |
| 球的半径 | r=0.1m（默认值） | 常识库匹配 | 65% |
| 球的材料 | 钢（默认材料） | 常识库匹配 | 60% |
| 空气阻力 | 忽略（默认） | 上下文推断 | 80% |
| 地面约束 | 弹性碰撞，恢复系数0.8 | 常识库匹配 | 75% |
| 时间步长 | dt=0.01s | 物理一致性（稳定性） | 85% |
| 仿真时长 | t=10s（足够落地+反弹） | 上下文推断 | 80% |

**补全后系统**：完整可仿真的自由落体系统，整体置信度82%

### 6.2 场景二：弹簧振子

**用户输入**："一个弹簧上挂着一个物体，拉一下然后松开"

**自动补全要点**：
- 推断弹簧劲度系数k（默认100N/m）
- 推断物体质量m（默认1kg）
- 推断初始位移（"拉一下"→默认0.1m）
- 推断初始速度（"松开"→初始速度=0）
- 补全重力、弹簧力、阻尼（默认忽略）
- 补全约束（弹簧上端固定）
- 推断仿真时长（默认10s，足够观察几个周期）

### 6.3 场景三：两球碰撞
