# [MIS]-豆包手机端简易教程-v1.0-20250313

## 一、下载安装

### 安卓系统

1. 打开手机 “应用商店”。
2. 搜索 “豆包”。
3. 点击豆包应用图标旁的 “安装”，等安装完成，在桌面点击图标即可打开。

### iOS 系统

1. 进入手机的 App Store。
2. 搜索 “豆包”。
3. 点击 “获取”，按提示验证指纹、面容 ID 或输入 Apple ID 密码，安装后在主屏幕找到图标启动。

## 二、功能使用

### 便捷输入

1. **语音输入**：打开豆包应用，点击输入框右侧麦克风图标，清晰说出需求，如 “写工作周报，包含本周业绩、问题与下周计划”，说完点击完成或稍等，豆包会将语音转文字并生成内容。
2. **快捷提问模板**：输入框下方有 “写邮件”“写文案” 等模板选项。若写请假邮件，点击 “写邮件” 模板，按提示补充请假原因、时长等，豆包生成规范邮件。

### 文档与内容处理

1. **文档撰写**：向豆包描述工作内容、成果、问题等，如 “过去一周负责项目 B，完成部分任务，成果 [具体成果]，遇到 [问题]，写工作总结”，豆包生成文档，可在应用内查看或复制到其他软件编辑。
2. **内容提取与概括**：把长文章或文档粘贴到输入框，指令 “概括要点”，如粘贴行业报告，豆包会提炼主要事件、结论等。

### 智能问答

1. **日常工作问题**：可问工作流程、业务操作等问题，如 “报销流程怎么走”“怎么提高客户转化率”，豆包依据知识储备解答。
2. **行业知识**：询问行业动态、政策等，如 “当前电商行业新趋势”“行业最新税收政策”，豆包整合信息呈现行业前沿内容。

### 个性化设置

1. **历史记录查看**：在个人中心或设置选项里找到 “历史记录”，可查看之前与豆包的交互记录，方便回顾。
2. **偏好设置**：在设置页面，可调整回答语言风格（正式、简洁等），设置是否接收推送通知。

### 工作相关功能

1. **工单处理**：有客户投诉等工单时，向豆包描述详情，如 “客户反馈产品 [型号] 质量问题，购买时间 [具体时间]，要求退款补偿，生成处理方案”，豆包给出包含话术、排查流程等的方案。
2. **工作汇报编写**：负责项目有成果需汇报，向豆包说明，如 “负责 [项目名称]，过去阶段完成 [任务 1]、[任务 2]，成果 [成果 1]、[成果 2]，问题 [问题 1]、[问题 2]，写月度汇报”，豆包生成结构清晰的汇报。
3. **工作速览**：面对多项工作任务，输入任务清单，如 “今天工作有会议、报表、客户跟进、资料准备，梳理重点和顺序”，豆包依紧急、重要程度分析并给出优先级和执行要点。
4. **工作要点总结**：完成工作任务后，对豆包说，如 “完成产品推广活动，形式 [具体形式]，参与人数 [X]，成本 [X] 元，效果好，总结要点”，豆包从策划、执行等方面提炼关键要点。
5. **工作流程优化**：对现有工作流程不满，向豆包描述，如 “公司采购流程从需求到验收，环节衔接不畅，周期比同行长 [X]%，优化流程”，豆包提供如简化环节、加强沟通等优化建议。
