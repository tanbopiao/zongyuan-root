# [MIS]-ima知识库使用指南-v1.0-20250725

想轻松玩转 ima 知识库？这份指南帮你快速上手，高效获取所需信息：

**一、轻松进入知识库**

打开公司内网浏览器，登录项目管理系统后，在首页顶部菜单栏的 “工具中心” 或 “资源库” 里找到 “ima 知识库”，点击就能进入。要是经常用，还能把它设为浏览器书签，下次直接点书签就能打开，省时又方便。

**二、精准找到你要的内容**

- 知道大概关键词？在知识库首页顶部的搜索框输入，比如 “工单提交规范”，点搜索图标，相关文章就会按匹配度出来。
- 不清楚关键词但知道领域？看左侧分类目录，像 “工单管理”“系统操作指南” 这些，点进去逐层找，准能找到。
- 想缩小范围？搜索结果页面能按 “发布时间”“浏览量” 排序，也能按 “图文教程”“视频讲解” 等内容类型筛选，快速锁定目标。

**三、灵活操作和利用内容**

进入文章详情页，能调大字体、切换夜间模式，阅读更舒适。看到重要内容，选中后用右侧 “笔记” 功能记下来，或者点顶部五角星图标收藏，方便以后看。文章有附件的话，点 “下载” 就能存到本地；想分享给同事，点 “分享” 生成链接或选联系人发送就行（对方得有权限哦）。部分重要文档能看历史版本，点页面底部 “版本记录”，更新时间和内容变化一目了然。

**四、遇到问题这样解决**

发现文章有错、过时或说不清？点详情页底部 “我要反馈”，选类型、写说明提交，管理员 3 个工作日内会处理回复。没找到想要的内容？点首页右下角 “在线咨询” 告诉管理员你的需求，他们会帮忙找或记录下来后续更新。提示 “无访问权限” 的话，联系本部门负责人申请，或让负责人找管理员开通。
