## 视频脚本

### 第1节：AI图像生成技术概览（7分钟）

**旁白**：欢迎来到AI图像生成课程。2026年，AI图像生成已经从实验室走进了千家万户，从产品图到海报，从角色设计到艺术创作，AI正在重塑视觉内容的生产方式。

**画面**：展示AI生成图片的前后对比，从草图到成品。

**旁白**：目前主流的AI图像工具有四款：Seedream、Midjourney、DALL-E和Stable Diffusion。它们各有侧重：Seedream擅长中文提示词和东方美学；Midjourney艺术感最强；DALL-E精确理解文字；Stable Diffusion可本地部署。

**字幕**：Seedream | Midjourney | DALL-E | Stable Diffusion

### 第2节：提示词编写技巧（10分钟）

**旁白**：提示词是AI图像生成的核心。一个好的提示词应该包含四个要素：主体、风格、细节和参数。

**画面**：提示词结构拆解动画。

**旁白**：主体描述你要画什么，风格决定整体调性，细节补充具体元素，参数控制画面比例和质量。例如："一只橘猫，水彩风格，坐在窗台上，阳光透过窗帘，8K高清，16:9"。

**实操演示**：
- 基础提示词 vs 优化提示词对比
- 权重调整演示（::1.5, ::0.5）
- 负面提示词使用（避免模糊、变形、多余手指）

### 第3节：产品图与海报生成（10分钟）

**旁白**：商业场景中，最常用的是产品图和海报生成。电商产品图过去需要摄影棚，现在用AI只需要30秒。

**实操演示**：
- 生成产品图：描述产品→选择场景→生成→局部修改
- 设计海报：确定主题→选择风格→生成→调整文字位置

### 第4节：人像与角色生成（8分钟）

**旁白**：人像生成是技术难点。2026年的AI已经能生成非常逼真的人像，但要注意：AI生成的人像不能冒充真人，这是伦理底线。

**实操演示**：
- 风格化角色设计
- 多角度一致性保持
- 常见问题修复（手指、面部不对称）

### 第5节：图像编辑与后期（7分钟）

**旁白**：生成只是第一步，编辑才是关键。AI图像编辑工具可以做背景移除、风格迁移、超分辨率、局部重绘。

**实操演示**：
- 一键移除背景
- 照片转油画风格
- 低分辨率图片放大4倍
- 局部擦除与修复

### 第6节：商业应用与版权（5分钟）

**旁白**：最后讲商业应用和版权。AI生成图片用于商业场景时，要注意三点：一是确认工具的商用授权条款，二是不要生成侵犯他人肖像权的内容，三是AI生成内容建议标注"AI辅助创作"。

## 教材文档

### 一、提示词模板库

**产品图模板**：
```
[产品名称]，[材质/颜色]，放置在[场景]中，
[光线描述]，[背景描述]，商业摄影风格，
8K高清，产品居中，45度角，--ar 3:4
```

**海报模板**：
```
[主题]海报，[风格：赛博朋克/国风/极简]，
主色调[颜色]，[核心视觉元素]，
文字区域留白，现代设计感，--ar 16:9
```

**角色设计模板**：
```
[角色描述]，[风格：动漫/写实/水墨]，
全身立绘，白色背景，[服装细节]，
[表情/姿态]，高质量，--ar 2:3
```

### 三、练习题

**练习1**：用AI生成一张产品图，描述你的产品并选择合适场景。
**练习2**：写一个100字以内的海报提示词，生成一张活动海报。
**练习3**：对比同一主体用3种不同风格生成的效果。
**练习4**：用AI图像编辑工具移除一张图片的背景。
**练习5**：将一张普通照片转换为艺术风格。
**练习6**：生成一个角色的正面和侧面视图，保持一致性。

### 四、常见问题

**Q：AI生成的图片能直接商用吗？**
A：要看工具的授权条款。Seedream、Midjourney付费版通常允许商用，但免费版可能有限制。建议使用前查看最新授权协议。

**Q：为什么AI生成的手总是有问题？**
A：手部结构复杂，是AI图像生成的常见短板。可以通过负面提示词（"extra fingers, deformed hands"）或后期局部修复来解决。

**Q：如何保持角色一致性？**
A：使用参考图功能（image-to-image），或固定seed值，或使用角色专属的LoRA模型。
