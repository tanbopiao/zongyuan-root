## 工业化标准流程（SOP）

### 第一阶段：剧本开发（Day 1-2）
1. **主题确定**: 基于元极恒一世界观，确定剧集主题和核心冲突
2. **分集大纲**: 12集/季，每集3-5分钟，明确每集起承转合
3. **人物设定**: 角色外观/性格/能力/关系/成长弧线
4. **世界观构建**: 时空背景/势力分布/规则体系/核心矛盾

### 第二阶段：分镜设计（Day 3-4）
1. **分镜表生成**: 每集30-50个镜头，含景别/运镜/时长/台词
2. **关键帧提示词**: 每个镜头生成Seedream/MiniMax提示词
3. **角色一致性校验**: 多镜头角色形象一致性检查
4. **风格统一**: 国风电影级色调/光影/构图统一

### 第三阶段：视频生成（Day 5-7）
1. **关键帧生成**: Seedream 5.0生成关键帧图片
2. **视频生成**: MiniMax H3/Seedance 2.0生成视频片段
3. **配音台词**: TTS生成角色配音，匹配口型
4. **配乐音效**: 国风BGM+环境音效+特效音

### 第四阶段：后期制作（Day 8-9）
1. **剪辑合成**: 片段拼接+转场+节奏调整
2. **调色校色**: 统一色调，电影级调色
3. **字幕制作**: 双语字幕，特效字幕
4. **质量审核**: 画面/音频/剧情/一致性全面审核

### 第五阶段：归档发布（Day 10）
1. **元秩序归档**: SHA256哈希确权+eFuse固化+Merkle-DAG追加
2. **多平台发布**: 抖音/快手/视频号/B站/小红书
3. **数据回收**: 播放量/点赞/评论/完播率数据回收
4. **真值沉淀**: 生产经验→真值库→知识图谱→下一轮优化
