## 一、系统架构

```
用户访问 → 登录/注册 → JWT Token → 访问课程 → 进度同步
```

## 二、登录方式

### 2.1 推荐方案：第三方登录（零成本快速启动）
- **微信扫码登录**：用户量最大，体验最好
- **飞书登录**：企业用户方便
- **手机号验证码登录**：通用方案

### 2.2 备选方案：账号密码
- 邮箱+密码
- 适合PC端

## 三、用户表结构

```
user_id: 用户ID（唯一）
nickname: 昵称
avatar: 头像
phone: 手机号
email: 邮箱
wechat_openid: 微信openid
created_at: 注册时间
last_login: 最后登录时间
purchased_courses: 已购课程列表
learning_progress: 学习进度记录
```

## 四、学习进度同步

### 4.1 本地存储（当前）
- localStorage记录学习进度
- 优点：零成本，无需后端
- 缺点：换设备不同步

### 4.2 云端同步（升级后）
- 登录后进度同步到云端
- 多设备同步
- 已购课程跨设备可用

## 五、权限控制

### 5.1 免费课程
- 所有登录用户可访问
- 未登录也可预览

### 5.2 付费课程
- 已购买用户可访问
- 未购买显示锁定遮罩
- 支付后自动解锁

## 六、接入步骤

### 阶段一：本地模式（零成本）
- localStorage记录进度
- 无需后端
- 适合早期验证

### 阶段二：轻量登录
- 微信扫码登录
- 进度云端同步
- 用Serverless/低代码后端

### 阶段三：完整系统
- 完整用户系统
- 多端同步
- 数据分析

## 七、安全设计

1. **密码加密**：bcrypt哈希存储
2. **Token安全**：JWT+过期时间
3. **接口鉴权**：每个API验证Token
4. **数据隔离**：用户只能看自己的数据
