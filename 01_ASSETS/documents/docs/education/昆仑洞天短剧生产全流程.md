## 三、完整生产流程（8步工业化流水线）

### 步骤1｜分集大纲生成

**输入**：项目名称、集数范围、核心剧情走向
**输出**：每集结构化大纲

```
## EP{编号} {标题}
- 核心冲突：...
- 关键场景：场景1 / 场景2 / 场景3
- 出场角色：...
- 结尾钩子：...
```

### 步骤2｜分集剧本撰写

基于大纲，每集生成完整剧本：
- 场景编号 + 场景描述
- 角色台词（含情绪标注）
- 动作指示
- 转场说明

每集控制在3-5个场景，适配竖屏短剧节奏。

### 步骤3｜分镜表拆分（核心交付物）

将剧本拆分为独立分镜表，每个分镜包含：

| 字段 | 说明 |
|------|------|
| 镜号 | S{集号}-{序号}，如 S03-012 |
| 画面 | 主体/动作/环境/光影 |
| 时长 | 单镜3-5秒（默认），全段10秒 |
| 关键帧提示词 | 用于图像生成的完整prompt |
| 视频提示词 | 用于视频生成的运动描述 |
| 音效/配乐 | 环境音、配乐、台词 |
| 转场方式 | 硬切/闪白/快切 |
| 角色 | 出场角色及形态 |

输出格式：Markdown表格

### 步骤4｜关键帧提示词优化（7要素强制）

每个分镜提示词必须包含7要素：

1. **主体描述**：角色外观、服饰、姿态、表情
2. **环境描述**：场景、天气、时间、氛围
3. **构图参数**：镜头角度、景别、景深、运镜
4. **光影参数**：光源方向、色温、伦勃朗光/逆光/柔光
5. **风格标签**：国风仙侠写实厚涂 / 黑金暗纹 / 史诗创世
6. **质量标签**：8K、UE5.7全局光追、博物馆馆藏质感、浮雕立体感
7. **确权符号**：画面右下角 Ω₀⊂⊙∞⊂Ω

**标准模板**：
```
[角色形态], [场景描述], [动作/状态], [光影效果],
黑金暗纹风格, 国风仙侠写实厚涂, 史诗创世氛围,
UE5.7全局光追, 8K超清, 博物馆馆藏质感, 浮雕立体感,
伦勃朗光影, 9:16竖屏, 右下角Ω₀⊂⊙∞⊂Ω
```

### 步骤5｜长兵器结构铁律校验（V1.2强制）

凡关键帧中角色**手持长兵器**（矛/枪/戟/棍/戈/长刀等），提示词必须附带以下硬编码约束：

```
【结构铁律·V1.2强制】
长兵器几何连续完整,禁断裂/分段/凭空多生成;
矛尖与人物头部强制安全空域,禁穿插/重叠/刺头;
双手握持同一根矛杆,手指-手腕-小臂-肩部形成连续力学握持关系;
武器延伸动线不切割人物主体剪影,矛尖落于独立空域或延伸至画面边界外;
能量光效仅作叠加照射层,禁止覆盖/融合/扭曲武器实体几何;
武器-手部-角色遮挡/接触阴影/环境反光全局光源统一。
```

**三级判定**：
- 🔴 高危（武器与头部重叠穿插）→ 直接重绘
- 🟡 预警（武器距头部 <8% 画面高）→ 自动调整角度与位置
- 🟢 通过（结构完整光影统一）→ 放行

### 步骤6｜视频合成

- 关键帧 → 视频生成（单段10秒）
- 多段拼接成完整剧集
- 模型：Seedance 2.5（优先）/ Seedance 2.0
- 节奏：快切卡点，禁用慢镜头

### 步骤7｜配音台词导出

从剧本中提取全部台词，生成配音脚本：

| 字段 | 说明 |
|------|------|
| 镜号 | 对应分镜 |
| 角色 | 说话人 |
| 台词 | 原文 |
| 情绪 | 平静/激动/悲伤/威严/魅惑等 |
| 语速 | 慢/中/快 |
| 音色参考 | 可选，指定声线类型 |

输出格式：
```
[S03-001] 女娲（威严/中速）："天地初开，万物待生。"
[S03-002] 九天玄女（决绝/快速）："魔族犯境，此战必诛！"
```

### 步骤8｜元秩序归档 + 台账更新

调用 meta-order-archive / meta-lock-sop 技能，对全部产出执行全域锁档：

1. 四层结构化拆分（元数据/业务叙事/工程契约/故障台账）
2. 分配资产ID（KD-DRAMA-XXXX）
3. 计算SHA256哈希
4. 创建飞书文档
5. 移入Wiki M5产品体系层节点
6. 更新全局索引台账
7. 卷宗命名：`SNAP-KUNLUN-EP{集号范围}`

## 四、故障约束（全局强制，8条铁律）

1. ❌ 禁止角色面部雄性化、狰狞化
2. ❌ 禁止神女/残魂形象恐怖化、鬼魅化
3. ❌ 禁止血腥画面，以能量碰撞和光效表达
4. ❌ 禁止丢失右下角溯源标识 Ω₀⊂⊙∞⊂Ω
5. ❌ 禁止使用慢淡入淡出转场
6. ❌ 禁止空镜和无效留白，节奏必须紧凑
7. ❌ 未知存在/凶兽只露局部，不露全貌
8. ❌ 禁止长兵器结构漂移（矛尖刺头/武器断裂/多生成武器/双手脱离矛杆/光效覆盖武器）

## 七、批量生产模式

指定多集（如"生成EP003-EP005"）时：
1. 并行生成各集大纲
2. 逐集执行步骤2-7
3. 最后统一执行步骤8归档
4. 输出总索引文件 `_INDEX.md`，汇总各集交付物链接
