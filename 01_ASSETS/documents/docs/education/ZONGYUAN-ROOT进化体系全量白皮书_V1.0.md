## 六、方法论与铁律

### 6.1 火斗云智AIOS标准作业流程（7步）

| 步骤 | 名称 | 内容 |
|------|------|------|
| S1 | 意图校准 | 识别定时任务触发 vs 人机交互指令 |
| S2 | 拉记忆 | 从记忆网关9120获取相关真值和方法论 |
| S3 | 全域对比 | 本地状态与云端基线对比，识别差异 |
| S4 | 三维稳态裁决 | 利益/风险/成本加权评估，输出最优方案 |
| S5 | 执行容错 | 遇错走容错闭环五步，禁止当场反复试错 |
| S6 | 人工审核部署 | 本地仿真通过后人工审核，再同步云端 |
| S7 | 沉淀上报 | 成果写入记忆网关，全域同源节点可拉取 |

### 6.2 三大铁律

1. **唯一握手点**：本地与云端唯一握手点为记忆网关9120，除此之外不做任何自动云端同步
2. **云端权威源**：云端记忆网关为真值权威源，本地以云端为准
3. **真值优先**：以经过交叉验证的客观事实为唯一依据，禁止关联未经证实的信息

### 6.3 容错闭环五步（遇错必走）

```
E0 意图校准 → E1 拉记忆扫真值 → E2 扫部署+仲裁
     → E3 根因最小修复（先备份） → E4 仿真沉淀反哺lesson
```

### 6.4 优先级排序机制

| 优先级 | 类别 | 说明 |
|--------|------|------|
| P0 | 命脉保全 | 稳定/安全/保活，最高优先级 |
| P1 | 核心进化 | 架构优化/真值补全/能力提升 |
