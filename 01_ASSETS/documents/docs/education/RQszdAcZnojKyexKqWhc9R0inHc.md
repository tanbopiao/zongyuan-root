# [MIS]-九宫飞星起卦方法教程-v1.0-20250910

起卦是预测分析的第一步，核心在于 “取象”，即捕捉当前时空或问卦人最显著的信息点作为卦象的源头。以下将系统性整理和解释九宫飞星起卦方法，并附上清晰步骤，助力掌握这一实用预测工具。

## 一、起卦核心原则：感而遂通

在起卦前，务必保持心境平和，精神专注。起卦的瞬间捕捉到的第一个念头或信息最为准确，这被称为 “第一念” 或 “纳气”。如果心绪杂乱或对方不诚，则卦象不灵，不必强求。

## 二、九宫飞星起卦方法大全

根据应用场景与核心逻辑，起卦方法可分为以下五大类，涵盖从基础定位到高阶应用的全维度需求。

### （一）本命卦（先天卦）—— 定位根本

此法用于看一个人的根本属性、一生运势、健康根基、祖上影响等，是对个人整体命理格局的基础锚定。

#### 计算方法（基于出生年份）

1. **年份数字处理**：将出生年份后两位数字相加，取个位数（若得 10，则取 0；若个位为 0，则用 10 去数）。
2. **男女顺逆数规则**：

   - 2000 年以前：男命从离卦（9）开始逆数，女命从乾卦（6）开始顺数。
   - 2000 年以后：男命从艮卦（8）开始逆数，女命从兑卦（7）开始顺数。
3. **落宫定卦**：数到对应的数字，落在哪一宫，该宫的卦就是其人的本命卦。

#### 举例说明

- **1963 年男命**：6+3=9。从离 9 开始逆数：9→8→7→6→5→4→3→2→1。落坎宫，本命卦为坎卦。
- **1963 年女命**：6+3=9。从乾 6 开始顺数：6→7→8→9→1→2→3→4→5。落中宫，中宫男为坤，女为艮，故本命卦为艮卦。

### （二）时空卦 —— 捕捉当下

此法用于分析特定时间点发生的事情或运势，非常灵活常用，能精准对接当下的时空能量场。

#### 1. 时间卦

根据问卦的时辰直接对应后天八卦方位，时辰与卦象的对应关系是长期实践中总结的时空能量映射规律。

##### 时辰与卦象对照表

| 时辰 | 对应时间 | 对应卦象 |
|-|-|-|
| 子时 | 23:00-1:00 | 坎卦 |
| 丑、寅时 | 1:00-5:00 | 艮卦 |
| 卯时 | 5:00-7:00 | 震卦 |
| 辰、巳时 | 7:00-11:00 | 巽卦 |
| 午时 | 11:00-13:00 | 离卦 |
| 未、申时 | 13:00-17:00 | 坤卦 |
| 酉时 | 17:00-19:00 | 兑卦 |
| 戌、亥时 | 19:00-23:00 | 乾卦 |

##### 举例说明

下午 14:30 问卦，属未时，时空卦为坤卦。

#### 2. 方位卦

根据问卦人相对于你的方位起卦，利用空间方位与八卦的对应关系，捕捉空间能量对问卦事件的影响。

##### 方位与卦象对照表

| 方位 | 对应卦象 |
|-|-|
| 东 | 震卦 |
| 东南 | 巽卦 |
| 南 | 离卦 |
| 西南 | 坤卦 |
| 西 | 兑卦 |
| 西北 | 乾卦 |
| 北 | 坎卦 |
| 东北 | 艮卦 |

##### 举例说明

问卦人从东南方走来，即以巽卦起卦。

### （三）物象卦 —— 万物皆卦

通过观察问卦时最引人注目的物体、颜色、声音等现象来起卦，体现 “万物有灵、皆含卦理” 的核心思想，将周遭物象转化为预测依据。

#### 1. 数字卦

看到任何数字，取其个位数（1-9），对应先天卦数（1 坎、2 坤、3 震、4 巽、5 中、6 乾、7 兑、8 艮、9 离），数字是最直接的 “象” 的载体。

##### 举例说明

手机时间显示 17:08，取数字 8，对应艮卦。

#### 2. 形象 / 颜色卦

将物体的形状、颜色归类到八卦，依据八卦的属性特征匹配物象，实现 “观物取象、以象定卦”。

##### 举例说明

- 看见圆形金属物品：乾卦（乾为天、为圆、为金）
- 看见红色物品：离卦（离为火、为红）
- 看见植物、树木：震卦或巽卦（震为木、巽也为木）

#### 3. 行为卦

根据问卦人的行为举止判断，行为是问卦人当下状态与气场的外在表现，蕴含着事件发展的潜在信息。

##### 举例说明

进门时右脚被绊了一下，预示这家人家有煞气（右为阴）。

### （四）用神卦 —— 针对问题

根据所问事情的类别，直接选取对应的八卦作为分析核心，聚焦问题本质，实现 “问啥找啥、精准对应” 的预测效果。

#### 常见问题与对应用神卦对照表

| 所问事情类别 | 对应用神卦及依据 |
|-|-|
| 工作、官职 | 乾卦，依据为乾卦代表君、为领导。 |
| 财运、婚姻 | 妻财卦（由本命卦五行与 “我克” 的五行所对应的卦）为用神。例如本命卦为坎水（水克火），则离卦为其财卦。 |
| 考试、学习 | 巽卦（为风、为文书）或离卦（为火、为文明）为用神。 |
| 母亲、土地房产 | 坤卦，依据为坤卦为地、为母。 |

### （五）太极定位法 —— 借助其它术数

此法为高阶用法，当精通其它命理术数时，可以在其盘（如奇门、八字、紫微等）中直接定位与问题最相关的点，并以该点的五行属性对应到八卦上来起卦分析，实现多术数融合互补。

#### 举例说明

在八字盘中看财运，找到 “财星” 所在，若财星为木，则对应震卦或巽卦，以此卦起卦分析。

## 三、起卦流程总结

1. **静心**：让自己平静下来，排除杂念，进入专注状态。
2. **接纳**：感受问卦人的气场和问题的焦点（纳气），建立与问卦事件的能量连接。
3. **选择方法**：

   - 看长期、根本性的问题 → 用本命卦。
   - 看近期、当下的事情 → 优先用时空卦或最突出的物象卦。
   - 有明确指向性的问题 → 用用神卦。
   - 高阶应用且精通其他术数 → 用太极定位法。
4. **取象**：抓住第一瞬间映入你脑海的 “象”（时间、方位、数字、物体等），确保 “象” 的纯粹性。
5. **定卦**：根据上述方法，将 “象” 转化为一个具体的八卦（如乾、坎、艮、震、巽、离、坤、兑）。
6. **分析**：以这个卦为 “体” 或 “用神”，结合五行生克、旺衰、卦象等进行解读。

## 四、重要提示

一次起卦通常只用一个主要方法，不可混杂。例如，用了问卦时辰起卦，就不要再同时用他的本命卦来断同一件事，否则信息会混乱。信任你起出的第一个卦象，其承载的时空与能量信息最为精准纯粹。
