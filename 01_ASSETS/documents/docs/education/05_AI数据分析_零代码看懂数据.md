## 三、教材文档

### 第一章 AI数据分析基础

#### 1.1 AI数据分析的定义
AI数据分析是指利用人工智能技术，对结构化和非结构化数据进行清洗、分析、可视化和洞察提取的过程。它降低了数据分析的技术门槛，使非技术人员也能从数据中获取价值。

#### 1.2 可分析的数据类型
| 类型 | 示例 | AI分析能力 |
|------|------|-----------|
| 表格数据 | Excel、CSV | 统计、趋势、对比、预测 |
| 文本数据 | 评论、问卷、记录 | 分类、情感、主题提取 |
| 时序数据 | 销售、流量、监控 | 趋势、季节性、异常检测 |
| 混合数据 | 表格+文字描述 | 综合分析、关联发现 |

#### 1.3 两种分析层次
1. **描述性分析**：发生了什么？（数据汇总、趋势描述）
2. **诊断性分析**：为什么发生？（归因分析、根因定位）

#### 1.4 数据分析五步法
```
明确问题 → 准备数据 → AI分析 → 验证结果 → 输出洞察
```

**关键原则**：好的问题比好的数据更重要。在分析之前，先问自己："我想从数据中知道什么？这个答案能指导什么行动？"

#### 1.5 数据准备规范
| 规范项 | 好的做法 | 差的做法 |
|--------|----------|----------|
| 表头 | "销售额(元)"、"用户ID" | "col1"、"A列" |
| 单位 | 统一为元，表头注明 | 混合元/万元/美元 |
| 日期 | "2026-01-15" | "1/15"、"一月中" |
| 背景 | 说明时间范围、业务线 | 无上下文 |

### 第二章 数据清洗与整理

#### 2.1 缺失值处理策略
| 策略 | 适用场景 | 风险 |
|------|----------|------|
| 删除行 | 缺失比例<5%，随机缺失 | 可能丢失重要信息 |
| 均值/中位数填充 | 数值型数据，缺失比例适中 | 可能降低数据方差 |
| 前后值插值 | 时序数据，连续缺失少 | 可能制造虚假趋势 |
| 标记为"未知" | 类别型数据 | 增加一个类别 |

#### 2.2 异常值识别方法
1. **统计法**：超出均值±3倍标准差
2. **业务法**：超出业务合理范围（如年龄>150）
3. **趋势法**：与前后数据点差异过大
4. **AI综合判断**：结合统计和业务语义

#### 2.3 格式统一清单
- 日期：统一为 YYYY-MM-DD
- 金额：统一为纯数字，注明单位
- 百分比：统一为 0.XX 或 XX%，不要混用
- 文本：去除首尾空格，统一大小写规则
- 编码：统一为 UTF-8

#### 2.4 AI分类应用场景
- 用户评论：正面/负面/中性 + 具体标签
- 销售记录：按产品/渠道/地区分类
- 工单记录：技术问题/账户问题/功能建议/其他
- 调研问卷：按主题自动归类

### 第三章 趋势分析与洞察

#### 3.1 同比环比计算公式
```
同比增长率 = (本期值 - 去年同期值) / 去年同期值 × 100%
环比增长率 = (本期值 - 上期值) / 上期值 × 100%
```

**解读原则**：
- 同比看长期趋势，消除季节性影响
- 环比看短期变化，敏感度高
- 两者结合使用，避免误判

#### 3.2 趋势预测三要素
1. **趋势成分**：长期上升/下降/平稳
2. **季节成分**：周期性波动（如节假日效应）
3. **随机成分**：不可预测的波动

**预测置信度**：短期预测（1-3期）可信度较高，长期预测（>6期）仅供参考。

#### 3.3 归因分析框架
```
总指标变化
├── 子指标A贡献（XX%）
│   ├── 因素A1（XX%）
│   └── 因素A2（XX%）
├── 子指标B贡献（XX%）
│   ├── 因素B1（XX%）
│   └── 因素B2（XX%）
└── 其他因素（XX%）
```

#### 3.4 对比分析维度
- 时间对比：本期 vs 上期，今年 vs 去年
- 空间对比：地区A vs 地区B，门店1 vs 门店2
- 类别对比：产品A vs 产品B，渠道1 vs 渠道2
- 目标对比：实际 vs 目标，实际 vs 行业基准

### 第四章 数据可视化与报告

#### 4.1 图表选择决策树
```
你想展示什么？
├── 变化趋势 → 折线图 / 面积图
├── 分类对比 → 柱状图 / 条形图
├── 占比关系 → 饼图 / 环形图（≤5类）
├── 相关性 → 散点图 / 气泡图
├── 分布情况 → 直方图 / 箱线图
├── 层级关系 → 树状图 / 旭日图
└── 地理分布 → 地图 / 热力图
```

#### 4.2 可视化四原则
1. **一图一观点**：每张图只传达一个核心信息
2. **标注关键数据**：重要数字直接标注，不让读者猜
3. **颜色有含义**：用颜色突出重点，区分类别，不是装饰
4. **去除冗余**：去掉不必要的网格、3D效果、装饰元素

#### 4.3 数据报告五段式
| 段落 | 内容 | 篇幅 |
|------|------|------|

## 六、练习题与答案

### 练习题1：方法匹配
**题目**：以下分析需求分别适合哪种分析方法？
1. 本月销售额为什么下降了？
2. 下个月销售额大概是多少？
3. 产品A和产品B哪个表现更好？
4. 本月和上月相比增长了多少？

**答案**：
1. 归因分析
2. 趋势预测
3. 对比分析
4. 同比环比分析

### 练习题2：图表选择
**题目**：以下数据展示需求分别适合什么图表？
1. 展示12个月的销售额变化趋势
2. 展示三个产品类别的销售额占比
3. 展示5个地区的销售额对比
4. 展示广告投入和销售额的关系

**答案**：
1. 折线图
2. 饼图或环形图
3. 柱状图
4. 散点图

### 练习题3：提示词编写
**题目**：请写出一个提示词，让AI对一份用户增长数据做归因分析。数据包含：总用户数、新用户数、活跃用户数、流失用户数，最近一个月总用户增长放缓。

**答案**：
"以下是一份用户增长数据，最近一个月总用户增长放缓。请做归因分析：1.将总用户增长拆解为新用户增长和流失减少两个维度 2.计算每个维度的贡献度 3.定位主要原因 4.给出2-3条可能的业务原因和改进建议。数据：[粘贴]"
