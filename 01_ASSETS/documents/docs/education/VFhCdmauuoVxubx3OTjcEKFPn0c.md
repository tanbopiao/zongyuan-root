## 五、甲方权利与义务

### （一）权利

1. 对乙方的劳务技能、工作质量、出勤情况进行监督、检查和考核，对不符合要求的，有权要求乙方整改；对屡教不改或严重违反协议约定的，有权解除本协议。
2. 根据施工需要合理安排乙方的工作任务，对乙方的违规操作行为有权予以制止和纠正。
3. 按照本协议约定扣除乙方应承担的费用及相应罚款。

### （二）义务

1. 为乙方提供符合国家安全标准的施工场地、必要的施工工具及设备（具体以《甲方提供工具设备清单》为准），并对工具设备的安全性负责。
2. 对乙方进行岗前安全教育培训、技术交底及施工现场管理制度培训，确保乙方熟悉操作规程及安全注意事项。
3. 为乙方提供符合国家标准的劳动保护用品（如安全帽、安全带、工作服、手套等），并监督乙方正确使用。
4. 按照本协议约定按时、足额支付乙方劳务报酬，不得克扣、拖欠。
5. 依法为乙方购买工伤保险；若甲方自愿为乙方购买人身意外伤害保险的，保险费用由 [甲方 / 乙方 / 双方按比例] 承担，保险权益归乙方所有。
6. 尊重乙方的人格尊严，不得歧视、虐待乙方，保障乙方的合法权益。

## 六、乙方权利与义务

### （一）权利

1. 要求甲方提供符合安全标准的施工条件、必要的劳动保护用品及约定的劳务报酬。
2. 拒绝甲方提出的违章指挥、强令冒险作业等违反法律法规及协议约定的要求。
3. 依法享受休息休假权利及法定节假日加班报酬。
4. 发生工伤事故时，有权要求甲方协助处理，并依法享受工伤保险待遇。

### （二）义务

1. 严格遵守国家法律法规及甲方的施工现场管理制度、安全操作规程，服从甲方管理人员的合理调度和安排。
2. 熟练掌握劳务岗位所需技能，按要求完成劳务任务，确保工作质量和进度。
3. 正确使用甲方提供的施工工具、设备及劳动保护用品，妥善保管个人工具及甲方交付的财物，如有损坏或丢失，应照价赔偿。
4. 按时上下班，不得迟到、早退、旷工；请假需按甲方规定履行审批手续。
5. 自觉维护施工现场的文明施工秩序，不得在施工现场打闹、酗酒、赌博、吸毒，不得擅自离岗或串岗。
6. 向甲方提供真实有效的身份证、特殊工种操作证（如涉及）等个人资料；若个人信息发生变更，应及时通知甲方。

## 七、工伤处理与医疗保障

1. 乙方在提供劳务期间因工作原因受到事故伤害的，应立即通知甲方，甲方应在 24 小时内将乙方送往定点医疗机构救治，并在 3 日内向社会保险行政部门提出工伤认定申请。
2. 乙方的工伤保险待遇按《工伤保险条例》及国家、地方相关规定执行；若甲方未为乙方购买工伤保险，乙方的工伤赔偿费用由甲方全额承担。
3. 乙方因非工伤原因患病或受伤的，医疗费用由乙方自行承担；甲方可根据实际情况给予适当的人道主义帮助。

## 八、协议的解除与终止

1. 经甲乙双方协商一致，可以书面形式解除本协议。
2. 乙方有下列情形之一的，甲方有权单方解除本协议，且不支付经济补偿：

   - 试用期内被证明不符合录用条件的；
   - 严重违反甲方施工现场管理制度或安全操作规程的；
   - 严重失职、营私舞弊，给甲方造成重大经济损失（单次损失超过\_\_\_\_\_\_元）的；
   - 被依法追究刑事责任的；
   - 同时与其他用人单位建立劳务关系，对完成甲方工作任务造成严重影响的。
3. 甲方有下列情形之一的，乙方有权单方解除本协议：

   - 未按照本协议约定及时足额支付劳务报酬的；
   - 未提供符合安全标准的施工条件或必要的劳动保护用品的；
   - 违章指挥、强令冒险作业危及乙方人身安全的。
4. 本协议期满、约定的劳务任务完成或出现法律规定的其他终止情形时，本协议自动终止。
5. 协议解除或终止后，乙方应在\_\_\_\_日内办理工作交接手续，归还甲方提供的工具、设备及相关资料；甲方应在乙方办理完毕交接手续后\_\_\_\_日内结清剩余劳务报酬。
