# 本源智能普惠教育体系 部署说明 V1.1

> 本文档指导将本源智能普惠教育全自动闭环体系部署到官网/服务器，包含环境准备、代码部署、官网页面部署、API服务启动、数据初始化、验证测试、持续迭代等完整流程。

**V1.1更新**：新增Flask API服务层（8大类40+接口）、官网实时数据面板、API服务测试（25项）。核心引擎完全向后兼容，升级仅需新增API服务依赖。

---

## 一、部署概览

### 1.1 部署架构
```
用户浏览器
    ↓ HTTPS
官网落地页（静态HTML）+ API网关
    ↓
Python 后端服务（Flask/FastAPI）
    ↓
六大引擎模块（知识图谱/内容生产/自适应学习/师资培育/评估/演化）
    ↓
JSON文件存储（可升级至MySQL/Redis/向量数据库）
```

### 1.2 部署清单
| 组件 | 说明 | 部署方式 |
|------|------|----------|
| 官网落地页 | index.html 展示页 | 静态文件部署（Nginx/CDN） |
| API服务 | Python后端，提供REST接口 | WSGI/ASGI服务（Gunicorn/Uvicorn） |
| 数据存储 | 知识图谱/学习者/教师等数据 | JSON文件（初期）→ 数据库（后期） |
| 日志系统 | 运行日志/错误日志 | 文件日志 + 可选ELK |

### 1.3 最低硬件要求
- CPU：2核
- 内存：2GB
- 磁盘：10GB（含数据+日志）
- 系统：Linux（Ubuntu 20.04+ / CentOS 7+）

## 四、官网落地页部署

### 4.1 静态页面部署（Nginx方式）

将 `deploy/web/index.html` 复制到网站根目录：
```bash
sudo mkdir -p /var/www/auto-edu
sudo cp deploy/web/index.html /var/www/auto-edu/
```

配置Nginx：
```bash
sudo nano /etc/nginx/sites-available/auto-edu
```

写入配置：
```nginx
server {
    listen 80;
    server_name edu.yourdomain.com;  # 替换为你的域名

    root /var/www/auto-edu;
    index index.html;

    # 静态页面
    location / {
        try_files $uri $uri/ =404;
    }

    # API反向代理（后续启动API服务后启用）
    # location /api/ {
    #     proxy_pass http://127.0.0.1:5000;
    #     proxy_set_header Host $host;
    #     proxy_set_header X-Real-IP $remote_addr;
    # }
}
```

启用配置并重启：
```bash
sudo ln -s /etc/nginx/sites-available/auto-edu /etc/nginx/sites-enabled/
sudo nginx -t  # 测试配置
sudo systemctl restart nginx
```

### 4.2 验证页面访问
浏览器访问 `http://edu.yourdomain.com`，应看到官网落地页。

### 4.3 HTTPS配置（推荐）
```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d edu.yourdomain.com
```

## 五、API服务部署（可选，后续迭代）

### 5.1 创建API服务入口
在 `src/` 目录下创建 `api_server.py`（V1.1版本将内置，此处为部署参考）：

```python
from flask import Flask, jsonify, request
from main import AutoEduSystem

app = Flask(__name__)
system = AutoEduSystem()
system.initialize_demo_data()
system.deploy()

@app.route('/api/v1/system/status', methods=['GET'])
def system_status():
    return jsonify({"code": 0, "message": "success", "data": system.get_system_status()})

@app.route('/api/v1/knowledge/stats', methods=['GET'])
def knowledge_stats():
    return jsonify({"code": 0, "message": "success", "data": system.kg.get_graph_stats()})

@app.route('/api/v1/system/evolve', methods=['POST'])
def evolve():
    result = system.evolution.run_full_evolution_cycle()
    return jsonify({"code": 0, "message": "success", "data": result})

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

### 5.2 安装API依赖
```bash
source venv/bin/activate
pip install flask gunicorn
```

### 5.3 启动API服务
```bash
# 开发模式
python3 src/api_server.py

# 生产模式（Gunicorn）
gunicorn -w 2 -b 0.0.0.0:5000 --timeout 120 src.api_server:app
```

### 5.4 配置Systemd服务（开机自启）
```bash
sudo nano /etc/systemd/system/auto-edu-api.service
```

写入：
```ini
[Unit]
Description=Auto Edu API Service
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/huodou/auto-edu
Environment="PATH=/opt/huodou/auto-edu/venv/bin"
ExecStart=/opt/huodou/auto-edu/venv/bin/gunicorn -w 2 -b 127.0.0.1:5000 --timeout 120 src.api_server:app
Restart=always

[Install]
WantedBy=multi-user.target
```

启动并设置开机自启：
```bash
sudo systemctl daemon-reload
sudo systemctl start auto-edu-api
sudo systemctl enable auto-edu-api
sudo systemctl status auto-edu-api
```

### 5.5 验证API
```bash
curl http://127.0.0.1:5000/api/v1/system/status
# 应返回系统状态JSON
```

#!/bin/bash

## 十一、常见问题

### Q1: 运行 `python3 src/main.py` 报错 `ModuleNotFoundError`
A: 确保在项目根目录运行，且已创建 `__init__.py` 文件。检查目录结构是否完整。

### Q2: 官网页面访问404
A: 检查Nginx配置的root路径是否正确，`index.html` 文件是否存在于该目录。

### Q3: API服务启动后无法访问
A: 检查端口5000是否被占用：`netstat -tlnp | grep 5000`；检查防火墙是否开放端口。

### Q4: 数据文件很大（root_archive.json）
A: ROOT根库归档文件会持续增长，属于正常现象。定期备份即可，不影响系统运行。

### Q5: 如何重置系统数据
A: 删除 `data/` 目录下所有文件，重新运行 `python3 src/main.py` 即可重新初始化。
