# [MIS]-ima知识库使用教程-v1.0-20250725

1. **进入知识库**：打开项目管理系统，在首页菜单栏找到 “ima 知识库” 入口，点击即可进入。
2. **查找内容**：在知识库首页的搜索框中，输入你想查询的关键词（如工单处理流程、常见问题等），点击搜索按钮，系统会展示相关的知识内容。也可通过左侧分类导航栏，按分类查找所需信息。
3. **查看与使用**：找到目标内容后，点击进入即可阅读详细信息。若有需要，可对内容进行收藏、下载或分享给同事。
4. **问题反馈**：若未找到所需内容，或发现知识信息有误、滞后，可点击页面底部的 “反馈” 按钮，填写反馈内容提交，后台会及时处理并更新。
