## 视频脚本

### 第1节：AI编程助手概览（6分钟）

**旁白**：2026年，写代码的方式已经彻底改变了。你不需要从零开始敲每一行，只需要用自然语言描述你想要什么，AI就能帮你生成代码。

**画面**：演示从"我要一个待办事项应用"到完整代码的过程。

**旁白**：主流工具有四款：Cursor、GitHub Copilot、通义灵码和Trae。Cursor是AI原生编辑器；Copilot在IDE中自动补全；通义灵码国产免费；Trae适合中文用户。

### 第2节：提示词与需求描述（10分钟）

**旁白**：让AI写代码的关键是把需求说清楚。一个好的需求描述包含四个要素：功能、输入、输出、边界条件。

**实操演示**：
- 差的描述："帮我写个计算器"
- 好的描述："用Python写一个计算器，支持加减乘除，输入是两个数字，输出是计算结果，除数不能为0"
- 错误信息反馈：把报错信息完整复制给AI

### 第3节：常见编程任务（10分钟）

**旁白**：零基础用AI编程，从三个最简单的任务开始：写网页、数据处理、自动化工具。

**实操演示**：
- 写一个个人主页HTML
- 批量重命名文件脚本
- 调用天气API

### 第4节：调试与排错（8分钟）

**旁白**：AI生成的代码不一定一次就对。当出现错误时，把完整的错误信息复制给AI，它能帮你定位问题。

**实操演示**：
- 出现报错→复制错误信息→AI修复
- 代码审查：让AI解释它生成的代码

### 第5节：项目实战（10分钟）

**旁白**：我们用AI从零开始做一个待办事项应用。

**实操演示**：
1. 描述需求
2. AI生成HTML+CSS+JS
3. 测试运行
4. 迭代添加功能

### 第6节：学习路径（5分钟）

**旁白**：AI编程不代表不需要学习。基础逻辑、调试思维、安全意识仍然重要。建议先用AI做出东西建立信心，再逐步学习核心概念。

## 教材文档

### 一、需求描述模板

```
【功能】用[语言/工具]做一个[功能描述]
【输入】[用户输入什么]
【输出】[期望输出什么]
【边界】[有什么限制/特殊要求]
```

**示例**：
```
【功能】用Python写一个文件批量重命名工具
【输入】一个文件夹路径和新文件名前缀
【输出】文件夹内所有文件按前缀+序号重命名
【边界】不修改子文件夹，支持图片文件
```

### 二、常见错误类型

| 错误类型 | 表现 | 解决方法 |
|----------|------|----------|
| 语法错误 | 代码运行直接报错 | 把错误信息给AI |
| 逻辑错误 | 代码能跑但结果不对 | 描述期望vs实际差异 |
| 依赖错误 | 缺少库 | 让AI告诉你安装命令 |
| 路径错误 | 文件找不到 | 确认文件位置 |

### 三、练习题

**练习1**：让AI写一个个人主页HTML页面。
**练习2**：用AI写一个批量文件重命名脚本。
**练习3**：故意制造一个错误，让AI帮你修复。
**练习4**：让AI解释一段它生成的代码。

### 四、常见问题

**Q：零基础真的能用AI编程吗？**
A：能做小工具和简单网页。复杂系统仍需要学习基础概念。

**Q：AI写的代码安全吗？**
A：不要直接复制运行不理解的代码。让AI解释关键部分，检查是否有安全风险。
