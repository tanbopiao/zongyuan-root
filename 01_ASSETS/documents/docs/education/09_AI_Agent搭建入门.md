## 第一章：什么是AI Agent

### 1.1 从对话到行动

ChatGPT是你问它答，Agent是你说目标，它自己拆步骤、调工具、执行、检查结果。

**核心区别**：
- 对话AI：你说一句，它答一句
- Agent：你给目标，它自主完成整个流程

### 1.2 Agent的核心能力

一个完整的Agent具备：
1. **规划**：把大目标拆成小步骤
2. **工具调用**：会用搜索、代码、API等工具
3. **记忆**：记住之前做过什么
4. **反思**：做错了会自己修正

### 1.3 应用场景

- 自动写周报：收集数据→分析→写初稿→发给你审
- 自动做调研：搜索→整理→写报告
- 自动客服：理解问题→查知识库→回答

## 第二章：Agent核心架构

### 2.1 大脑（LLM）

负责理解和决策的核心。可以是GPT-4、Claude、豆包等。

### 2.2 规划模块

把"写一篇市场分析"拆成：
1. 搜索市场数据
2. 整理竞品信息
3. 分析趋势
4. 写报告
5. 检查格式

### 2.3 工具集

Agent能调用的工具：
- 联网搜索
- 代码执行
- 文件读写
- API调用
- 数据库查询

### 2.4 记忆系统

- **短期记忆**：当前对话上下文
- **长期记忆**：存在数据库里的历史经验

## 第三章：用Coze/Dify搭建Agent

### 3.1 准备工作

1. 注册Coze或Dify账号
2. 选择模型
3. 确定Agent要做什么

### 3.2 第一步：写人设提示词

```
你是一个市场分析助手。你的任务是：
1. 根据用户提供的行业关键词，搜索相关市场数据
2. 整理出市场规模、主要玩家、趋势分析
3. 输出结构化的分析报告
```

### 3.3 第二步：配置工具

添加"联网搜索"工具，让Agent能查最新数据。

### 3.4 第三步：测试调试

- 输入测试问题
- 看Agent是否按预期步骤执行
- 调整提示词优化效果

### 3.5 第四步：发布

- 发布到飞书/微信/Web
- 让真实用户使用
- 收集反馈持续优化

## 第四章：实战案例——自动周报Agent

### 4.1 需求

每周五自动收集本周工作数据，生成周报初稿。

### 4.2 实现步骤

1. **数据源**：连接项目管理工具API
2. **提示词**："根据以下数据生成本周工作周报，包括完成事项、进行中、下周计划"
3. **输出格式**：Markdown
4. **触发方式**：每周五下午自动执行

### 4.3 效果

- 原来写周报1小时 → 现在10分钟（审核修改）
- 数据自动收集，不会遗漏
- 格式标准化

## 第五章：多Agent协作

### 5.1 为什么需要多Agent

单个Agent能力有限，复杂任务需要分工：
- 调研Agent：负责搜集信息
- 写作Agent：负责整理输出
- 审核Agent：负责检查质量

### 5.2 协作方式

- **串行**：A做完给B，B做完给C
- **并行**：A和B同时做不同部分，C汇总

### 5.3 实战场景

写一份行业报告：
1. 调研Agent搜索10篇文章
2. 数据Agent整理关键数据
3. 写作Agent汇总成报告
4. 审核Agent检查事实准确性

## 第六章：常见问题与最佳实践

### 6.1 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| Agent不按步骤做 | 提示词不清晰 | 写更具体的指令 |
| 调用工具失败 | 工具配置错误 | 单独测试工具 |
| 输出质量差 | 模型能力不足 | 换更强的模型 |
| 忘记之前的信息 | 上下文窗口满了 | 加长期记忆 |

### 6.2 最佳实践

1. **任务要具体**：不要说"帮我做个研究"，要说"帮我搜索2026年AI教育市场规模，整理成表格"
2. **一步步来**：先让Agent做简单任务，确认没问题再加复杂度
3. **人在环路**：关键决策让人审核，不要全自动化
4. **持续优化**：每次用了记录哪里不好，改提示词
