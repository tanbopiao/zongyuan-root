## 四、永恒自治模式（V1.1.1 本次核心新增）

### 4.1 设计理念

永恒自治模式是系统的**顶层调度内核**，实现"无需人工干预，系统自主感知、自主决策、自主执行、自主归档"的闭环运行。所有自治行为严格服从元宪法五大公理，受三维稳态算子约束，重大变更强制人工闸口，连续失败自动熔断。

### 4.2 5步固定闭环

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ Step1    │───▶│ Step2    │───▶│ Step3    │───▶│ Step4    │───▶│ Step5    │
│ 感知采集 │    │ 稳态仲裁 │    │ 任务分发 │    │ 执行+自检│    │ 归档沉淀 │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
     │                                                                │
     └──────────────────── 永久循环 ◀───────────────────────────────┘
```

**Step1 感知采集**：自动拉取全链路信号——系统状态、知识图谱统计、内容产出、学习数据、师资数据、评估结果、演化状态、风险信号。

**Step2 稳态仲裁**：
- 元宪法公理校验（五大公理强制校验，违反直接拒绝）
- 三维稳态评分（利益40%/风险35%/成本25%）
- 重大变更人工闸口（教材版本大改/体系规则修改/大规模资源分发）
- 自动执行判定（score≥70自动执行，50-70轻量执行，<50暂缓）

**Step3 任务分发**：将批准任务下发到对应模块（知识图谱/内容引擎/评估/演化/资源均衡）。

**Step4 执行+自检**：模块执行任务，自动单元自检；失败自动回滚（轻量任务）；连续失败3次触发熔断。

**Step5 归档沉淀**：哈希确权，写入ROOT双库，生成审计日志，全程不可篡改。

### 4.3 核心组件

| 组件 | 功能 |
|------|------|
| AutonomyConfig | 自治配置（轮询间隔/风险阈值/熔断/稳态权重/公理校验） |
| SteadyStateArbiter | 三维稳态仲裁器（利益40%/风险35%/成本25%） |
| MetaAxiomValidator | 元宪法公理校验器（五大公理强制校验） |
| AutonomyTask | 自治任务对象（类型/优先级/预估评分/状态流转） |
| EternalAutonomyOrchestrator | 永恒自治调度器（5步闭环+熔断+人工闸口+审计） |

### 4.4 安全机制

1. **元宪法公理校验**：所有自治任务必须通过五大公理校验，违反直接拒绝
2. **分级权限**：轻量任务自动执行，重大变更强制人工审核
3. **熔断回滚**：连续失败3次自动暂停自治循环，轻量任务失败自动回滚
4. **风险阈值**：任务预估风险超过30%暂停自动执行，提交人工审核
5. **全程审计**：所有自治行为记录审计日志，哈希确权，不可篡改

### 4.5 配置文件

`config/autonomy_config.yaml` 包含：
- 基础运行配置（轮询间隔300秒/无限循环/轻量任务自动执行）
- 风险与熔断配置（风险阈值0.3/连续失败3次熔断）
- 稳态决策权重（利益40%/风险35%/成本25%）
- 启用模块配置（6大引擎全部启用）
- 审计与日志配置
- 元宪法公理校验（五大公理永久生效，不可关闭）

## 六、V1.3 视频教学内容生产通道（本次核心新增，对接短剧流水线）

### 6.1 通道定位

视频教学内容生产通道是教育系统与**昆仑洞天短剧工业化流水线（drama-pipeline）**的对接通道，实现从知识点到教学视频的全链路自动化生产。通道将教育系统的知识图谱、教材内容与短剧流水线的分镜表生成、关键帧提示词、视频生成能力打通，形成教育视频工业化生产能力。

### 6.2 6步工业化流水线

```
知识点 → ①教学脚本 → ②分镜表 → ③关键帧 → ④视频规格 → ⑤配音 → ⑥归档交付
         (脚本生成器)  (分镜生成器) (提示词生成) (短剧流水线) (台词提取) (双库归档)
```

| 步骤 | 模块 | 核心功能 | 输出 |
|------|------|----------|------|
| ① 脚本生成 | TeachingScriptGenerator | 知识点→5环节教学脚本（导入/讲解/演示/问答/总结），四学段分层 | 结构化教学脚本 |
| ② 分镜表生成 | EduStoryboardGenerator | 脚本→教育风格分镜表，每环节2-3镜头，含画面/时长/提示词/音效/转场 | 短剧流水线兼容分镜表 |
| ③ 关键帧准备 | 通道内置 | 提取所有镜头关键帧提示词，教育风格（清新明亮/现代简约/科技感） | 关键帧提示词列表 |
| ④ 视频生成 | 对接短剧流水线 | 分镜表转换为drama-pipeline格式，可直接输入storyboard_generator.py | 视频规格+短剧兼容格式 |
| ⑤ 配音准备 | 通道内置 | 提取完整旁白台词，分环节配音脚本，含语音风格和BGM建议 | 配音台词脚本 |
| ⑥ 归档交付 | VideoAssetManager | 6类资产（脚本/分镜/关键帧/视频/音频/缩略图）双库归档+哈希确权+台账 | 资产清单+哈希确权 |

### 6.5 短剧流水线对接方式
