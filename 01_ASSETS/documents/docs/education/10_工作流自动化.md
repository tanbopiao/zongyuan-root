## 第一章：什么是工作流自动化

### 1.1 为什么要自动化

每天80%的时间在做重复的事：整理表格、回邮件、写周报、发通知。这些事不需要创造力，但占了大量时间。

**工作流自动化**就是把这些重复步骤串起来，让AI自动跑。

### 1.2 自动化的价值

| 场景 | 手动时间 | 自动化后 |
|------|----------|----------|
| 整理客户反馈 | 2小时/天 | 5分钟 |
| 写周报 | 1小时/周 | 10分钟 |
| 数据报表 | 3小时/周 | 自动生成 |
| 邮件分类回复 | 1小时/天 | 自动处理 |

### 1.3 自动化vs Agent

- **工作流**：固定步骤，按流程走（适合确定性任务）
- **Agent**：灵活决策，自己判断（适合不确定性任务）

## 第二章：常见自动化工具

### 2.1 低代码自动化

- **Zapier**：连接500+应用，可视化拖拽
- **Make**：更灵活，适合复杂流程
- **飞书多维表格自动化**：国内用户首选

### 2.2 AI增强自动化

- **Coze工作流**：AI节点+工具节点
- **Dify工作流**：LLM编排+RAG
- **n8n**：开源自托管

### 2.3 选择建议

| 需求 | 推荐 |
|------|------|
| 简单连接两个应用 | Zapier |
| 需要AI处理 | Coze/Dify |
| 数据敏感要私有化 | n8n |
| 飞书生态内 | 飞书自动化 |

## 第三章：搭建第一个自动化流程

### 3.1 场景：新客户邮件自动处理

**流程**：
1. 收到新邮件 → 2. AI判断意图 → 3. 分类（咨询/投诉/合作）→ 4. 生成回复草稿 → 5. 发给你审核

### 3.2 步骤

1. **触发**：新邮件到达
2. **AI节点**：分析邮件内容，提取关键信息
3. **条件分支**：
   - 咨询类 → 查知识库 → 生成回答
   - 投诉类 → 标记优先级 → 通知相关人员
   - 合作类 → 记录到CRM → 约时间
4. **输出**：发送通知给你

### 3.3 优化

- 先跑一个月，看哪些处理得好，哪些需要人工
- 越来越多的自动处理，人工只处理异常

## 第四章：实战——内容生产自动化流水线

### 4.1 流程

选题 → 大纲 → 初稿 → 配图 → 排版 → 发布

### 4.2 自动化设计

1. **选题Agent**：每天早上搜索热点，推荐3个选题
2. **写作Agent**：根据选题生成大纲和初稿
3. **配图Agent**：根据内容生成配图
4. **审核Agent**：检查事实和质量
5. **发布**：自动发布到公众号/小红书

### 4.3 人在环路

- 选题人审核选哪个
- 初稿人修改后发布
- 越来越成熟后自动化程度提高

## 第六章：自动化最佳实践

### 6.1 从简单开始

不要一开始就搞复杂自动化。先挑一个最痛的点，跑通了再扩展。

### 6.2 人在环路原则

关键环节一定要人审核。特别是对外发送、花钱、删除数据这类操作。

### 6.3 持续优化

每周看一次自动化运行日志：
- 哪些流程经常出错？
- 哪些步骤可以更智能？
- 哪些新场景可以加进来？
