## 三、不可篡改硬约束（6条铁律）

1. **镜头分片**：仅允许 5s / 10s；输出固定 1080×1920 24fps
2. **校验前置**：先校验，后执行，禁止先执行后拦截
3. **故障隔离**：单镜头/单算子异常仅隔离局部，不摧毁整任务、不摧毁服务
4. **调度策略**：免费优先；付费调用强制人工确认
5. **资产确权**：所有资产全链路SHA256哈希，Merkle-DAG锁档归档；失败样本隔离，禁止污染进化库
6. **熔断闸门**：熔断S0/S1风险触发，系统不可自动恢复，必须人工闸门放行
