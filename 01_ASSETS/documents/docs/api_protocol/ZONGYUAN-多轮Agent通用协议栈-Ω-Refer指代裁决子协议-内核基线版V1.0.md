## 二、Ω-Refer 指代裁决子协议规范

### 2.1 核心术语定义

- **EID（Entity Unique ID）**：全局实体唯一标识，会话域内不可重复；每一个被 Agent 引用的对象（文件、查询结果、工具返回项、任务子节点、历史回答条目）分配 EID。
- **Ref 指针**：`ref:EID`；代词、二次引用、"上一个/第二条/它"全部翻译为此指针，禁止裸代词在跨 Agent、跨轮次报文中流转。
- **TruthRootHash**：本轮状态集合 Merkle 根哈希，写入报文头部，作为真值锚点。
- **StateVersion**：单调递增版本号，用于并发冲突判定、快照回退。
- **DID-Sig**：DID 主体签名，绑定 OBS 七域权责拓扑，完成身份、权限、操作单元绑定。

### 2.2 Ω-Refer 标准报文头部（强制携带，仲裁层优先解析）

```json
{
  "Ω_PROTO_VER": "1.0",
  "DID": "did:zongyuan:xxx",
  "DID_Sig": "base85签名串",
  "TruthRootHash": "sha256 merkle根",
  "StateVersion": 17,
  "RefSet": [
    {"eid": "E-00128", "entity_type": "tool_result", "label": "上一次查询返回列表"},
    {"eid": "E-00129", "entity_type": "sub_task", "label": "文件导出任务"}
  ],
  "ConflictPolicy": "reject/merge/rollback",
  "FuseMask": ["loop", "param_invalid", "permission_deny"]
}
```

- **RefSet**：本报文所有依赖实体引用集合；仲裁层校验 EID 是否在当前会话真值账本中存在，EID 不存在直接熔断。
- **FuseMask**：接入全局元规则熔断开关，联动 **META-RULE-012 配额稳态**（定时任务配额稳态保护元规则）与 **META-RULE-018 死循环熔断**（逻辑回环熔断元规则）。

### 2.3 指代消解流程（硬裁决链路，顺序不可颠倒）

1. 用户原始输入送入 Ω-Refer 仲裁前置器
2. 前置器识别自然语言指代，检索本地 Ref 账本，解析生成 RefSet；无法解析出有效 EID → 直接返回澄清回执，**不送入 LLM**
3. 组装协议头，绑定 TruthRootHash、StateVersion、DID 签名
4. 报文下发：先经仲裁校验层，再进 LLM 推理/工具调度层
5. 工具返回新实体 → 分配新 EID，追加写入 RefSet，更新 Merkle-DAG，生成新版本哈希
6. 用户否定结果、要求重来：依据 StateVersion 执行快照回退，恢复上一版 Ref 账本

**关键区分**：
- 旧方案：LLM 自己猜指代、补参数（软逻辑，易漂移）
- 本方案：仲裁层先锁定实体集合，LLM 仅在已锁定 EID 集合范围内做业务推理

### 2.4 并发状态冲突仲裁原语

三种策略由报文 `ConflictPolicy` 声明，协议原生支持，不依赖业务代码：

1. `reject`：检测同一 EID 并发写，直接拒绝后发请求，返回冲突错误
2. `rollback`：自动丢弃后发变更，回退至稳定版本
3. `merge`：仅支持无冲突字段合并；冲突字段标记分歧，触发人工接管

所有变更写入 Merkle-DAG，每条变更节点携带时间、操作主体 DID、变更前/后快照哈希，可完整审计溯源。

### 2.5 参数校验子原语（绑定 EID 实体元描述）

每个 EID 附带实体 Schema 描述：字段名、类型、值域、白名单约束。工具调用参数生成后，仲裁层对照 EID 绑定 Schema 强校验，参数越界、类型不匹配、权限不足直接熔断，阻断非法参数流向工具。

## 三、上层协议适配改造（四层协议栈升级）

> 版本注记：SAMP/StateMesh、语义压缩上下文协议、AEP 执行控制层随本版**首次定义并纳入基线**（无更早入仓初版）；A2A 通信层承接 V2.3 白皮书十协议族第 5 族（`/v1/a2a/kunlun/dispatch` LIVE）。

### 3.1 通信层（A2A）

A2A 仅承载业务 payload；A2A 消息 body 外层必须包裹 Ω-Refer 头部信封。外部异构 Agent 接入时，如不支持 Ω-Refer，自动降级为兼容模式（仅限信息查询，不允许长任务工具调用），降级模式标记高风险标签。

### 3.2 状态管理层（SAMP / StateMesh）

状态存储单元不再是自由 JSON，而是 Merkle-DAG 叶子节点；状态同步时携带 TruthRootHash，接收方校验哈希一致性，哈希不匹配判定状态篡改/传输异常，拒绝加载。

### 3.3 上下文管理层（语义压缩协议升级）

- 压缩输出产物必须保留完整 RefSet 与 EID 映射表
- 摘要文本只是面向 LLM 的可读视图，**真值权威源为 Ref 账本 + Merkle 树**
- 镜像态校验：压缩摘要生成后，仲裁层用镜像态反向核验摘要与原始 RefSet 真值一致性，摘要失真则丢弃、拒绝使用

### 3.4 执行控制层（AEP）

AEP 执行循环（SENSE→REASON→PLAN→ACT→OBSERVE）每步入参、出参都走 Ω-Refer 信封封装；ACT 动作执行前强制触发参数 Schema 校验、权限拓扑校验。

## 四、框架适配器规范（解耦依赖，框架无感）

1. 所有框架（LangGraph/AG2/CrewAI 等）仅实现协议适配器，框架 API 变更不修改 Ω-Refer 仲裁协议定义
2. 适配器职责：把框架内部状态对象映射为 EID 实体、监听框架事件、回写 Ref 账本；**适配器损坏 ≠ 内核裁决逻辑失效**
3. 最小适配器接口：
   - `ref_resolve(text) → RefSet | null`
   - `state_commit(RefSet, payload) → StateVersion, TruthRootHash`
   - `state_rollback(StateVersion)`
   - `verify_fuse(FuseMask)`

## 五、熔断与权责拓扑集成

Ω-Refer 头部 DID 签名与 OBS 七域权责拓扑联动：

- 每一个 EID 实体绑定最小访问权限标签
- 跨域引用 EID 时，权责拓扑裁决权限；越界直接熔断——与权限越界治理资产（META-LAW-007 中枢主窗口星型协同架构法则）同源闭环
- 所有熔断事件写入全局审计日志，日志条目本身纳入 Merkle-DAG 存证，不可篡改

> **待补注记**：「OBS 七域权责拓扑」为本版新引术语，仓内暂无七域清单真值；七域划分须与 META-LAW-007 权限域对齐后以附录 A 追加，**在此之前禁止自行编造域清单**。
