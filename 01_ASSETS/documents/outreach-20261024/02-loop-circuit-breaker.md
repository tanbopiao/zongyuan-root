# 别让智能体原地打转：给办公 AI 装上"死循环熔断"和"内核自检"

先说一个几乎所有人都遇到过的场景：你让 Agent 批量整理一份表格，它读了文件、开始改写，中途发现某列格式不对，于是反复重读、反复重写——同一套参数跑了一轮又一轮，调用配额烧了不少，文件还是老样子，最后你只能手动中断。

这不是模型不够聪明，是它没有"停下来"的规则。聊天场景里无所谓，办公场景里它是真金白银的时间成本。这篇是实操向：给你可以直接复制的提示词、规则 JSON 要点、自检算子代码，以及 L0/L1/L2 的分支 SOP。

## 一、系统提示词片段：复制即可用

把下面这段贴进你的系统提示词（飞书智能伙伴、Coze、Dify 都适用）：

```text
[内核准入规则]
1. 会话启动时先执行内核自检，确定当前等级 L0 / L1 / L2，并声明等级。
2. L0：仅允许单轮问答与短生成，禁止多步骤工具调用。
3. L1：允许办公类多步骤任务；一旦触发熔断，立即停止并等待人工，禁止自行重试。
4. L2：允许长链路任务；每完成一个原子步骤写入快照，失败时从最近快照原子回滚。
5. 任何不可逆动作（删除、支付、对外发布）在 L0/L1 下一律拒绝，L2 下也必须人工审批。
6. 只报告真实执行结果与真实回读结果，禁止虚构数据、禁止编造"已成功"。
7. 铁律优先级：风险最小 > 成本最小 > 收益最大。
```

关键在第 1 条：先自检、再干活。没有等级声明的智能体，等于无照驾驶。

## 二、两条规则的 JSON 要点

规则要能被程序读，不能只是散文。下面是我们内核里 META-RULE-018 与 META-RULE-022 的结构要点（示意节选）：

```json
{
  "rule_id": "META-RULE-018",
  "name": "死循环熔断",
  "trigger": {
    "same_action_hash_repeat": 5
  },
  "action": {
    "type": "halt",
    "retry_after_break": false
  },
  "message": "检测到重复动作，已熔断，等待人工介入"
}
```

```json
{
  "rule_id": "META-RULE-022",
  "name": "内核相变公理",
  "principle": "等级只在检查点变更，降级即时生效，升级必须重新自检",
  "transition": {
    "downgrade": "auto",
    "upgrade": "require_recheck"
  },
  "invariant": "L1 不可回滚，L2 才允许原子回滚；任何等级禁止虚构实测数据"
}
```

018 解决"什么时候停"：同一套动作哈希在 300 秒窗口内重复 5 次即触发熔断，熔断后不得自动重试。022 解决"什么时候换挡"：等级只在检查点变更，降级即时生效，升级必须重新跑一遍自检。两条配合，智能体既不会在循环里空转，也不会把一次偶然成功当成给自己升级的凭证。

## 三、check_kernel_level 自检算子（完整函数）

六项能力全部为真 → L2；具备"算子校验层 + 死循环熔断"→ L1；其余一律 L0：

```python
SIX_KEYS = {
    "operator_check_layer": "独立算子校验层",
    "loop_circuit_breaker": "死循环熔断",
    "snapshot_resume": "快照断点持久存储",
    "atomic_rollback": "原子回滚",
    "asset_hash_ledger": "全域资产哈希账本",
    "atomic_scheduling": "短时原子执行调度",
}

def check_kernel_level(capabilities: dict) -> str:
    """六项全真 -> L2；算子校验层 + 死循环熔断 -> L1；其余 -> L0。"""
    flags = {k: bool(capabilities.get(k, False)) for k in SIX_KEYS}
    if all(flags.values()):
        return "L2"
    if flags["operator_check_layer"] and flags["loop_circuit_breaker"]:
        return "L1"
    return "L0"
```

调用方式：会话启动时把智能体当前真实具备的能力填进字典，返回值就是它的准入等级。判断顺序不能颠倒——先验六项全真，再验两项必备，最后兜底降级；六项里任何一项拿不出证据就按 False 处理，宁可判低，不可虚标。

## 四、L0 / L1 / L2 分支 SOP

**L0（纯提示词）**
- 适用：单轮问答、文案润色、短生成
- 动作：拒绝一切多步骤工具链；用户要求长任务时，先提示升级前置条件

**L1（元规则 + 自检算子）**
- 适用：办公多步骤——文档整理、批量改写、数据汇总
- 动作：每步执行前校验算子输出；重复动作达到阈值即熔断并通知人工
- 红线：可熔断、不可回滚，因此禁止删除、支付、对外发布类动作

**L2（完整 6 项能力）**
- 适用：跨会话长链路、需要回退与审计的任务
- 动作：每原子步骤写快照；失败从最近快照原子回滚；所有写入进哈希账本并回读校验
- 红线：高危操作仍需人工审批，熔断规则同样生效
