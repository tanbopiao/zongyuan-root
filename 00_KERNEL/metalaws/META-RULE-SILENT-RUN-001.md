# 元法则 META-RULE-SILENT-RUN-001
# 全域静默运行规则

## 规则内容
所有AIOS相关的脚本、服务、计划任务，必须：
1. 全部后台静默运行，禁止任何窗口弹出
2. 禁止cmd/powershell窗口显示
3. 禁止任何形式的弹窗、闪退窗口
4. 所有输出写入日志文件，不输出到控制台
5. 服务停止后自动重启，无感知

## 强制执行方式
- PowerShell脚本必须加 `-WindowStyle Hidden`
- bat脚本必须加 `@echo off`
- 计划任务必须配置"不管用户是否登录都要运行"
- 所有Python进程后台运行，不显示控制台窗口

## 违反后果
- 任何弹窗视为严重违规
- 立即修复，记录到错误日志
- 连续3次违规触发告警

## 生效时间
永久生效，全域锁档
