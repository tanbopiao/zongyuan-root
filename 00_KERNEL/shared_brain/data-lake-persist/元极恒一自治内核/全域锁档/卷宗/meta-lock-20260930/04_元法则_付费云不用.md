## 一、元法则定义

**官网部署、资产分发、资源中转等一切对外/跨端路径，一律不使用付费云服务（对象存储 COS/OSS、付费 CDN、付费存储桶等）。部署与分发只允许使用零成本通道。**

## 二、允许的零成本通道（白名单）

| 通道 | 成本 | 用途 |
|---|---|---|
| Gitee Git 仓库 | 零成本 | P0 主路径：画廊发布仓 `zongyuan-gallery.git` |
| 魔搭 ModelScope | 零成本 | P1 备用：`zongyuan-character-keyframes` + `zongyuan-root-achievements` 数据集 |
| 自有 SSH 服务器 | 零成本 | P3 备用：`zongyuan-cloud`(123.207.202.158) rsync 直推（待修复授信） |

## 三、禁止项（黑名单）

- ❌ 对象存储 COS / OSS / TOS（付费存储桶）
- ❌ 付费 CDN
- ❌ 付费云数据库、付费云函数中转
- ❌ 其他任何按量/按存储付费的云服务

## 四、落地影响

1. **P2 对象存储中转路径停用**（`deploy_paths_config.json` 中 `oss_pull` → `status: disabled`），不再作为部署备用路径
2. 部署调度器只从零成本路径（P0 Git / P1 魔搭 / P3 SSH）中选择
3. 后续任何新增部署/分发方案，若涉及付费云服务，一律否决，改用零成本替代

## 五、执行校验

- 新方案评审：先校验是否引入付费云服务 → 命中黑名单即否决
- 部署调度器探针：P2 标记 disabled，不参与调度、不计入可用路径
- 违反本元法则的部署动作，中枢自动拦截并告警

```
MR-DEPLOY-AUTO-001 (审批→自动部署闭环)
```
