# SOP-SITE-OPERATIONS-001 ｜ 官网安全操作与本地仿真先行 SOP
版本：v1.0 ｜ 依据：META-VISUAL-STANDARD-001 v2.0（VS-8~11） ｜ 锚定：DID-BR-000002

## 一、操作分级
| 级别 | 内容 | 执行 |
|---|---|---|
| 白名单·增量 | 新增导航按钮（导航条/抽屉）、主页新增简介区块+跳转按钮、部署新页面（新文件名）；不删不改原内容 | 自动执行（须过仿真门） |
| 禁止 | 删除/替换原有内容、推倒重构、覆盖 immutable 锁档资产 | 一律人工审批，禁止自动 |
| 提取 | 只读解锁提取视觉标准（不改内容，提取后立即重锁） | 允许 |

## 二、本地仿真先行（强制流程）
1. `site_sim.py --download <name>`：下载线上原版为只读基准
2. `--apply`：本地副本应用增量（锚点唯一断言 + 幂等，防止误插/重复）
3. `--diff`：校验只增不改（删除/替换行 > 0 → 拒绝）
4. `--simulate`：shot.py 渲染自检（桌面+移动截图，确认未破坏布局/视觉）
5. 全部通过 → 才可进入部署；未过仿真门禁止上线

## 三、部署纪律
- 新页面：新文件名发布，scp 前 immutable 探测（asset_publish.py 已内置拒绝门）
- 锁档文件确需增量变更：人工审批 → 解锁 → 应用仿真通过的增量 → 重锁 → 线上验收 → 审计
- 部署后：HTTP 200 验收 + 审计 + 网关上报 + 锁档留痕

## 四、验收判定
- 仿真报告：新增行 N、删除行 0、渲染自检无错误 ✓
- 线上：变更点生效 + 原页面其余内容与线上原版 diff 为空 ✓
- 审计：site.ops.<name>.<ts>|ok

## 五、范围
本 SOP 覆盖 huodouai 系官网（www.huodouai.com 文档根 /www/wwwroot/huodouai.com）与元极恒一/昆仑洞天同系页面；aios 等其他站点独立管理，不得混改。
