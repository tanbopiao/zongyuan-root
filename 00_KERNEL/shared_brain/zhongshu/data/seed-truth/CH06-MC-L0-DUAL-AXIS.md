# 第 6 章 · MC×L0 双轴拦截协议（Dual-Axis Interception Protocol）

**引用种子**：S6（自感≠真值，双轴分离根）· S8（不可绕过 L0 校验节点）· S14（MC 校准硬约束）
**版本**：v5.0 · 对齐 L0 根 Merkle `94dd5ec5…`

## 6.1 双轴定义

| 轴 | 载体 | 职能 | 来源种子 |
|---|---|---|---|
| 真值轴 | L0 全局根 + 租户子 L0 | 判定"这条不可错"：不可绕过、不可改写 | S6/S7/S8 |
| 自感轴 | MC（元认知校准） | 判定"我可能错"：置信度、ECE、过自信惩罚 | S6/S14 |

**核心定理**：两条轴在语义上不可合并。自感轴的输出（置信度/反思）永远不能升级为真值轴的输入（L0 条款）；真值轴的判定永远不能由自感轴代答。

## 6.2 拦截时序（请求 → 双轴判定 → 放行/拦截）

```
请求 R
  │
  ▼
① L0 校验门（不可绕过, S8）
  │  校验 R 涉及的全部条款 ∈ L0 且未被反转
  │  违反 → REJECT + 审计留痕
  ▼
② MC 校准门（S14）
  │  计算 P_conf, ECE; 越界过自信 → 惩罚
  │  P_conf < τ_conf → 降级/拒绝交付
  ▼
③ 双轴交叉判定
  │  A) 自感说"可能错" ∧ L0 说"不可错" → 放行 L0, 记录自感偏差(不合并)
  │  B) 自感说"确定" ∧ L0 说"不可错" → 正常放行
  │  C) L0 无条款覆盖 → 禁止放行(缺校验即拦截), 走 L0 增补审批
  ▼
④ 结果留痕（append-only）
  │  log = {request, l0_check, mc_calib, cross_verdict, seq}
  │  写 HASH-LEDGER + 审计
  ▼
  放行 / 拦截（REJECTED → recycled + 审计）
```

## 6.3 协议规则（可直接落代码）

| 规则 | 内容 | 种子 |
|---|---|---|
| R1 | 任何 L1–L5 调用链入口必须过 L0 校验节点，缺省即 REJECT | S8 |
| R2 | MC 置信输出不得写入 L0 条款，L0 条款不得引用 MC 置信 | S6 |
| R3 | MC 校准损失 = 交叉熵 + λ₁·ECE + λ₂·越界过自信惩罚（越界：P_conf>阈值 且 实际错误） | S14 |
| R4 | 双轴判定冲突（自感 vs L0）时，L0 优先；自感偏差记入校准日志用于 MC 自改进 | S6/S11 |
| R5 | RSI 可改进 MC 参数与 workflow（R2 范围内），禁止触碰 L0 条款与 Ω | S11 |
| R6 | 所有拦截/放行结果 append-only 留痕，违规 z 一律 recycled | S18 |

## 6.4 与五柱的接线

- **MI**：探针输出（Ω 投影）→ 仅供自感轴参考，不进入 L0 校验链（S5/S13）
- **SFMP**：语义单元 z 下发前过 R1/R6（L0 校验 + 留痕），原始上下文永不出域（S12/S18）
- **RSI**：自改进动作受 R5 约束，改进对象仅限 MC 层（S11）
- **MC**：承载自感轴全流程，校准质量受 S14 硬约束
