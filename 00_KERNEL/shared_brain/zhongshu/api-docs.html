外部系统接入指南（真值 API 生态）

三步接入，任何系统可成为体系同源节点：
步骤动作说明
1 注册向仲裁中枢登记节点身份分配 node_id（如 EXT-SYS-001）+ 自治层级 + 能力通道，写入节点注册表
2 上报POST 真值X-DID: DID-BR-000002 单头 + key 命名空间（建议 <系统>.<事件>.<时间戳>）+ value 事件字段

# Python 外部系统接入示例
import json, urllib.request
def report_truth(key, value):
    req = urllib.request.Request("https://www.huodouai.com/api/report/truth",
        data=json.dumps({"key": key, "value": value}).encode(),
        headers={"X-DID": "DID-BR-000002", "Content-Type": "application/json"})
    r = json.loads(urllib.request.urlopen(req, timeout=10).read().decode())
    assert r.get("message") == "真值写入成功"
    return r["truth_count"]

# 上报事件
tc = report_truth("ext-sys-001.order.20261003",
    {"event": "order_sync", "system": "外部系统示例", "orders": 128, "at": "2026-10-03"})
print("真值条目:", tc)
