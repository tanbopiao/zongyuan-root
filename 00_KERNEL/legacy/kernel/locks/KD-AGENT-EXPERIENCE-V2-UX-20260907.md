智能体体验中心V2.0体验优化升级锁档凭证

基于全网同类产品（Coze扣子/GPT Store/AI Agent UX白皮书）调研，完成10大体验优化：

【首页布局优化】
- 精选横幅：40+智能体/6领域/5模型/全部免费
- 分类标签：带数量统计，高阶智能置顶
- 排序功能：默认/热门/名称三种排序

【智能体卡片升级】
- 添加使用次数（模拟数据，后续接真实统计）
- 添加评分（⭐4.5-4.9）
- 添加徽章：🔥热门/NEW新/PRO高阶
- 能力标签展示（3个核心能力）
- 卡片悬停动效（上浮+阴影+边框）

【对话体验升级】
- 思考中动画（三点跳动+文字提示）
- 消息淡入动画
- 建议追问按钮（每条回答后3个建议）
- 错误恢复三要素：具体原因+描述+重试按钮
- 新对话按钮（清空历史重新开始）

【搜索功能】
- 顶部全局搜索框
- 支持名称/描述/标题/能力标签搜索
- 实时搜索结果

【用户引导】
- 首次访问新手引导弹窗（4步使用指南）
- localStorage记录已展示状态
- 每个智能体配备快捷提问

【分享功能】
- 分享智能体链接（?agent=ID参数）
- 自动复制到剪贴板
- 通过URL参数直接打开指定智能体对话

【移动端优化】
- 响应式布局（768px断点）
- 移动端隐藏模型选择器
- 全屏对话面板
- 紧凑卡片布局

【技术优化】

- 语义化HTML结构
- 动画性能优化（transform/opacity）
- 无障碍支持（aria-label/title）
