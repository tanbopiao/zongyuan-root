# 普通用户体验版工作台 P0基础版 · 锁档

## 一、产品定位
- 名称：AI体验工作台（通用版）
- 目标用户：普通用户/体验者/潜在客户
- 核心场景：AI对话、写作助手、工具体验
- 部署路径：/experience/
- 设计原则：轻量、简洁、开箱即用、无政务门槛

## 二、P0基础版功能清单
1. 智能对话（核心）
   - 对接政务API chat端点（/gov-api/api/gov/chat）
   - 支持多模型选择（5个模型：zhipu/doubao/kimi/qwen/hunyuan）
   - 打字指示器动画
   - 代码块格式化渲染

2. 对话管理
   - 新建对话/切换对话/删除对话
   - 对话历史本地持久化（localStorage）
   - 自动生成对话标题（第一条消息）
   - 最多保留50条历史对话

3. 快捷提问
   - 6个常用场景卡片（写邮件/解释概念/写代码/旅行建议/文字润色/问题分析）
   - 一键发送预设问题

4. 模型切换
   - 5个模型可选（免费+免费额度）
   - 模型状态实时显示
   - 切换提示Toast通知

5. 个人中心
   - 对话导出（TXT格式）
   - 清空当前对话
   - 对话历史管理

6. 响应式设计
   - 桌面端：侧边栏+主内容区
   - 移动端：抽屉式侧边栏+底部输入
   - 适配768px/480px断点

## 三、技术架构
- 前端：纯HTML+CSS+JS（无框架依赖）
- 样式：CSS变量驱动，暗色主题
- 数据：localStorage本地持久化
- AI对接：复用政务API chat端点（避免重复开发后端）
- 文件结构：
  - /experience/index.html（4.8KB）
  - /experience/css/style.css（9.7KB）
  - /experience/js/app.js（12KB）
