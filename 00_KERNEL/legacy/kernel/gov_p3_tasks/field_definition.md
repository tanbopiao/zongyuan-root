## 导入操作指引

1. 新建多维表格，创建上面定义的全部字段；
2. 使用 `gov_p3_task_import.csv` 文件导入；
3. 导入完成后，设置视图：按优先级分组 / 阶段分组两个看板视图；
4. 任务状态改为「全域锁档」时，自动触发P3阶段完成事件。

## 配套自治规则

1. 高危工单设置截止日期提醒；
2. 全部8条任务全部标记锁档，触发P3阶段完成事件；
3. 每个算子完成后独立哈希锁档，最终整体全域Merkle-DAG归档。
