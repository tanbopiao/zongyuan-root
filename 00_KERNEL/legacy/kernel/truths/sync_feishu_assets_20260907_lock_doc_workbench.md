## 三、六维扫描巡检SOP

**六维扫描维度：** 进度 / 质检 / 回滚 / 归档 / 角色一致性 / 元规则漂移

**完整闭环工作流程：**

1. **开工初始化**
   - 加载工作台配置，恢复窗口布局
   - 调取本次任务对应的基准母版卷宗、元规则
   - 在台账新建任务记录，填写时间戳与任务目标

2. **迭代执行**
   - 产出物第一时间保存到对应业务目录
   - 草稿测试全部放在`06_临时草稿`，验证通过再移入正式目录

3. **强制巡检环节（每一轮产出后必须执行）**
   - 进度：任务目标是否达成
   - 质检：格式、画面、参数合规性
   - 回滚：是否存在可回滚快照，漂移过大直接回退
   - 归档：文件路径正确
   - 角色一致性：对比基准母版，识别视觉漂移
   - 元规则漂移：校验输出是否违背公理元规则
   - 异常写入多维表格异常清单，标记风险等级

4. **锁档归档**
   - 全部校验通过，生成快照存入`07_备份快照`
   - 云盘同步，更新台账锁档标记

5. **收工流程**
   - 清理临时草稿，无用测试样本删除
   - 记录未完成事项，写入台账
   - 输出本次会话简短简报
