### 3.2 核心引擎调用链溯源

**部署闭环调用链**（4算子串行）:  
AutoCheck(预检) → Deploy(部署) → APICall(验证) → HashLock(锁档)

**巡检闭环调用链**（手动栈遍历）:  
MerkleDAGWalk(遍历快照) → AutoCheck(批量检查) → HashLock(锁档结果)

**AI调用确权链**（aios_gateway算子）:  
用户请求 → aios_gateway算子  
├── 计算model_hash（模型版本哈希）  
├── 计算prompt_hash（输入内容哈希）  
├── 调用AI Proxy → 模型推理  
├── 计算output_hash（输出内容哈希）  
├── 三哈希写入调用日志  
└── 返回结果+三哈希凭证

**漂移检测涌现链**（drift_detect算子）:  
系统状态采样 → 基线对比 → 漂移检测  
├── 有用涌现 → 记录到学习进化引擎 → 可能成为新算子  
├── 有害幻觉 → 触发告警 → 回滚到上一稳定版本  
└── 未知 → 进入L-1观察池 → 人工/自动判定
