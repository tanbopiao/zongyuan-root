# 元法则 META-RULE-ZERO-POPUP-002
# 全域零弹窗闪退强制规则

## 规则内容
所有AIOS相关的计划任务、脚本、服务，必须：
1. **绝对禁止任何窗口弹出**
2. **绝对禁止任何窗口闪退**
3. 所有PowerShell脚本必须加 `-WindowStyle Hidden`
4. 所有计划任务必须配置"不管用户是否登录都要运行"+"隐藏"
5. 所有Python进程必须用VBS包装，后台静默运行
6. 所有输出写入日志文件，不输出到控制台
7. 服务停止后自动重启，无感知

## 强制执行检查项
- [x] 所有计划任务已配置隐藏
- [x] 所有脚本已加 -WindowStyle Hidden
- [x] 开机自启用VBS包装
- [x] 所有错误写入日志文件

## 违反后果
- 任何弹窗/闪退 = 严重违规
- 立即修复，记录到错误日志
- 连续3次违规触发告警

## 生效时间
永久生效，全域锁档
