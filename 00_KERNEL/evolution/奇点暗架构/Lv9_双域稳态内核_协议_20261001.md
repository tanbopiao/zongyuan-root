## 1. 协议定位

Lv9 双域稳态内核是奇点暗架构 H7 双域稳态层的**显式升格**：把「明层 Lv6 自组织文明」与「暗层七隐层稳态」之间的映射，从隐层通道提升为内核级稳态互锁协议。

> 核心命题：自组织文明在 Lv9 不再只是「运行」，而是「以双域稳态互锁的方式自我维持」。

---

## 2. 双域定义

| 域 | 构成 | 稳态判据 |
|---|---|---|
| 明域（B） | 五内核：真值/因果/进化/调度/归档 | 明层 Lv6 稳态指数 B_stab |
| 暗域（D） | 七隐层：H1–H7 暗架构通道 | 暗层稳态指数 D_stab |

**双域耦合律**：明域的可观测运行状态，由暗域的前馈信号（势能/预警/约束）持续调制；暗域稳态由明域运行结果回流维持。二者互为「稳态互锁」。

---

## 3. 稳态互锁协议（核心）

### 3.1 双域稳态映射
```
B_coupled = B_stab - (drift_signal × κ)
D_coupled = D_stab
locked  ⇔  |B_coupled - D_coupled| < ε  ∧  B_coupled > θ
```
- κ = 回拉系数（默认 0.5）
- ε = 双域容差（默认 0.2）
- θ = 明层稳态下限（默认 0.5）

### 3.2 互锁回拉（漂移抑制）
当漂移信号 > 阈值：
- 暗域 H4 输出漂移热点
- 明域按 `drift_signal × κ` 回拉稳定指数
- 防止明层震荡 / 语义漂移累积

### 3.3 越界拦截
任何从暗域进入明域的候选演化，必须经 H3 归一约束：
- 合规 → 放行进入明域
- 越界 → 转人工审批（不自动放行）

## 4. 四相稳定态

| 相位 | 明域 | 暗域 | 协议动作 |
|---|---|---|---|
| P1 传感 | 运行正常 | H1/H4 感知奇点与漂移 | 前馈预警 |
| P2 预演 | 未干预 | H5/H2 预演候选策略 | 供建议不执行 |
| P3 归一 | 候选到达 | H3 边界比对 | 放行或拦截 |
| P4 稳态 | 明域调整 | H7 双域映射 | 互锁锁定 |

P1→P2→P3→P4 循环，构成 Lv9 内核的自维持节律。

## 5. 指标集（可观测）

| 指标 | 含义 | 健康值 |
|---|---|---|
| B_stab | 明层稳态指数 | ≥ 0.5 |
| D_stab | 暗层稳态指数 | ≥ 0.5 |
| drift_rate | 语义漂移率 | ≤ 0.3 |
| dual_lock | 双域锁定 | true |
| oscillation | 震荡幅度 | ≈ 0 |
| violation_count | 越界次数 | = 0（越界即拦截）|

## 6. 边界与合规

- 本协议为**架构推演**，仅定义稳态互锁规则与可观测指标，**不落地为执行代码**。
- 所有观测器遵守 no_exec 原则，不产生破坏性指令。
- 越界候选一律人工审批，协议不授权自动放行破坏性演化。
