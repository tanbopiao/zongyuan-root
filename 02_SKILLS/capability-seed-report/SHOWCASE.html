02 · 入口与用法

# 1) 安装到工作区技能目录
cp -r 02_SKILLS/capability-seed-report ~/.trae/skills/

# 2) 准备种子清单 seeds.json
[{"key":"KERNEL.EMBODIED.UNITREE-G1.20261025","value":{"vendor":"宇树","model":"G1"},"truth_type":"data"}]

# 3) 批量上报（内置写锁退避重试）
python3 scripts/report_seeds.py seeds.json --retry 3 --wait 90

03 · 工作流七步

界定能力矩阵5–8 个子维度，逐维检索，避免只读综合榜单
分域检索海外头部 + 国内头部；记版本/日期/参数/榜单/价格，禁止编造
结构化种子KERNEL.<域>.<子类>.<名>.<YYYYMMDD>，value ≥2 字段 + 锚定
批量上报report_seeds.py 逐条上报，0.3s 间隔，输出 seq 汇总
写锁退避write_failed=云端 SQLite 写锁，非签名问题；等 60–120s 整批重跑
账本留痕HASH-LEDGER.csv 追加 批次ID / seq 区间 / 维度覆盖 / 失败数
同步全域auto_reporter --once，确认 失败0 后全域节点可拉取

05 · 稳态不变量
