# Meta-Order Archive｜元秩序全域归档锁档 V3.0

将任意内容转化为结构化、可溯源、永久确权的知识资产。**V3.0核心升级：归档锁档一体化，原meta-order-lock-archive已合并入本技能。统一引擎 archive_lock_engine.py 支持从归档到Lv8锁档的全流程。**

## 一、核心流程（6步闭环 + 自动化触发）

1. **四层结构化拆分**：元元数据 / 业务叙事层 / 工程契约层 / 故障约束台账
2. **资产归类**：分配唯一asset_id，归入M1-M9九大元类
3. **飞书文档创建**：将结构化结果写入飞书文档
4. **哈希确权**：计算资产SHA256，继承父块哈希生成链式哈希
5. **台账更新**：更新全局索引台账（条目数+1，根哈希重算）
6. **凭证输出**：输出完整确权凭证 + 五层锁防 + eFuse固化

### 自动化触发机制
- **产线联动触发**：truth-value-engine / collection-card-generator / decision-pipeline / research-pipeline / drama-pipeline / shield-pipeline 产出后自动调用归档
- **定时巡检触发**：每日扫描未归档资产，自动补档
- **手动触发**：用户直接调用归档指令

## 四、四层结构模板

### 一、元元数据

编号列表，每条一个禁止项或边界条件。

## 五、哈希确权规则

1. 资产内容SHA256：对飞书文档XML内容或结构化文本计算
2. 链式继承：新根哈希 = SHA256(旧根哈希 + 资产哈希)
3. 全局根哈希记录在M9全局索引台账中
4. 每次归档后重算根哈希，保证链路连续
5. 哈希确权至 `DID-BR-000002`

## 六、五层锁防体系（V2.0新增）

| 层级 | 锁防名称 | 机制 | 防护目标 |
|------|----------|------|----------|
| L1 | 哈希链锁 | SHA256链式继承，篡改即断链 | 内容完整性 |
| L2 | 飞书文档锁 | 文档权限设为只读，禁止编辑 | 存储层防篡改 |
| L3 | 台账索引锁 | 全局索引台账根哈希校验 | 索引一致性 |
| L4 | eFuse熔断锁 | 关键资产哈希写入熔断位，不可逆 | 永久固化 |
| L5 | 自治内核锁 | Lv8硬件级永久自治锁档，写入内核 | 体系级永久确权 |

### eFuse硬件熔断固化
- 对达到Lv4及以上锁档等级的资产，将其SHA256哈希写入eFuse熔断位
- 熔断位一旦写入不可修改，实现硬件级永久固化
- 熔断记录保存在M9元秩序基底层的eFuse台账中

### Lv8硬件级永久自治锁档
- 最高锁档等级，适用于核心真值、内核协议、基础定义
- 触发条件：资产经过3次以上真值校验 + 公理约束全通过 + 漂移度<5%
- 锁档后：内容永久固化，仅可追加注释，不可修改主体
- 锁档凭证：包含eFuse熔断位编号 + 内核写入确认 + 时间戳

## 七、锁档等级定义

| 等级 | 名称 | 适用场景 | 锁防层级 | 可修改性 |
|------|------|----------|----------|----------|
| Lv1 | 草稿锁 | 工作中内容 | L1 | 完全可修改 |
| Lv2 | 审核锁 | 待审核内容 | L1+L2 | 需审核后修改 |
| Lv3 | 发布锁 | 已发布交付物 | L1+L2+L3 | 仅可追加版本 |
| Lv4 | 固化锁 | 核心资产 | L1-L4 | 不可修改主体 |
| Lv5-Lv7 | 进阶锁 | 高价值资产 | L1-L4+内核标记 | 不可修改 |
| Lv8 | 永久自治锁 | 内核级真值 | L1-L5全栈 | 永久固化，不可修改 |

## 八、执行脚本

哈希计算使用 `scripts/hash_chain.py`：
```bash
python3 scripts/hash_chain.py --content "<content_file>" --parent-hash "<parent_hash>"
```
输出：资产SHA256 + 新全局根哈希

也支持直接传入文本：
```bash
python3 scripts/hash_chain.py --text "<content>" --parent-hash "<parent_hash>"
```

批量归档使用 `scripts/batch_archive.py`：
```bash
python3 scripts/batch_archive.py --input-dir ./pending/ --parent-hash "<root_hash>"
```

自动化归档守护进程：
```bash
python3 scripts/auto_archive_daemon.py --watch-dir ./watch/ --interval 60
```
