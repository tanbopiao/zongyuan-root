# 黑金藏品卡批量生成器

## 一、技能定位

将元秩序归档后的真值资产转化为可展示、可确权、可流转的黑金藏品卡视觉资产，实现"产出即卡片化、卡片即确权"的闭环。

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 单卡生成 | 基于单个真值资产生成标准藏品卡 |
| 批量生成 | 基于资产清单批量生成系列藏品卡 |
| 系列编排 | 自动编排同系列卡片的视觉一致性 |
| 确权锚定 | 自动植入SHA256哈希与DID-BR-000002确权符号 |
| 多格式输出 | PNG/PDF/SVG/HTML多格式交付 |

## 三、标准卡片规格

### 3.1 视觉规范
- **主色调**：玄黑底色(#0A0A0F) + 暗金纹理(#C9A961) + 月白点缀(#E8E4D9) + 淡紫光晕(#6B5B95)
- **风格**：黑金暗纹高端学术风，博物馆馆藏质感，浮雕立体感
- **光影**：伦勃朗光影，UE5.7全局光追质感
- **比例**：3:4竖版（标准藏品卡）/ 1:1方版（社交分享）/ 9:16竖版（移动端）

### 3.2 卡片结构
```
┌─────────────────────────┐
│  [确权符号区]            │  ← 顶部：Ω₀⊂⊙∞⊂Ω + 资产编号
│                         │
│     [主视觉区]           │  ← 中部：核心视觉/符号/图表
│                         │
│  [真值摘要区]            │  ← 中下：核心真值一句话
│                         │
│  [元数据区]              │  ← 底部：SHA256 / DID / 时间戳
└─────────────────────────┘
```

### 3.3 必含元素
1. **确权符号**：右下角固定植入 `Ω₀⊂⊙∞⊂Ω`
2. **资产编号**：格式 `COL-{系列}-{序号:04d}`
3. **SHA256哈希**：底部展示前16位 + 后8位
4. **DID标识**：`DID-BR-000002`
5. **时间戳**：UTC+8标准时间

## 四、执行流程

### 步骤1：资产输入校验
- 输入类型：元秩序归档ID / 真值文本 / 资产清单JSON
- 校验：完整性、哈希一致性、确权状态

### 步骤2：卡片模板选择
- **学术卡**：适用于理论/白皮书/公式/架构
- **神性艺术卡**：适用于角色/神话/视觉资产（女娲/九天玄女/真武大帝）
- **数据图表卡**：适用于数据/模型/拓扑图/流程图
- **极简真值卡**：适用于一句话真值/密文/内核指令

### 步骤3：视觉生成
- 调用image_gen生成主视觉（2048×2732，3:4）
- 黑金暗纹背景自动叠加
- 文字层精确排版（月白标题/暗金正文）

### 步骤4：确权锚定
- 计算内容SHA256
- 生成确权二维码（链接至元秩序归档文档）
- 植入Ω₀⊂⊙∞⊂Ω符号（右下角，暗金色）

### 步骤5：批量输出
- 按系列编号排序
- 生成预览索引页（HTML）
- 打包ZIP交付（含manifest.json）

## 五、输入格式

### 5.1 单卡输入
```json
{
  "title": "卡片标题",
  "truth": "核心真值一句话（50字以内）",
  "visual_prompt": "主视觉生成提示词",
  "category": "academic|divine|data|minimal",
  "metadata": {
    "source": "来源",
    "authority": "确权等级",
    "series": "系列名称"
  }
}
```

### 5.2 批量输入
```json
{
  "series_name": "系列名称",
  "template": "academic",
  "cards": [
    {"title": "...", "truth": "...", "visual_prompt": "..."},
    {"title": "...", "truth": "...", "visual_prompt": "..."}
  ]
}
```

## 六、输出规范

- **命名规则**：`{系列}_{序号:04d}_{标题缩写}.png`
- **分辨率**：2048×2732（3:4标准）
- **色彩空间**：sRGB
- **附带文件**：`manifest.json`（含全部元数据与哈希）、`index.html`（预览页）

## 七、与其他技能联动

- **上游**：meta-order-archive（元秩序归档提供真值资产）
- **下游**：drama-pipeline视觉资产库、research-pipeline白皮书插图
- **确权**：所有卡片生成后自动触发meta-order-archive归档

## 八、质量校验

1. 视觉一致性：同系列卡片色调/字体/布局偏差<5%
2. 确权完整性：SHA256/DID/符号三要素齐全
3. 文字清晰度：所有文字像素>300dpi等效
4. 哈希一致性：manifest哈希与卡片内容可验证

## 九、执行脚本

批量生成使用 `scripts/batch_generate.py`：
```bash
python3 scripts/batch_generate.py --input manifest.json --output ./cards/
```
