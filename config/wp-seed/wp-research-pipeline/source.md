# Research Pipeline｜研究工业化流水线

从主题到白皮书的全链路自动化研究系统。

## 核心流程（7步研究流水线）

1. **主题拆解**：将研究主题拆解为子问题、关键词、检索维度
2. **文献/信息调研**：调用学术文献调研、行业分析、general_search等技能收集资料
3. **信息萃取**：对收集到的资料做真值萃取，过滤噪声，标注来源
4. **分析框架构建**：建立结构化分析框架（现状/趋势/争议/缺口/建议）
5. **报告/白皮书撰写**：生成长文档，包含摘要、正文、结论、参考文献
6. **元秩序归档**：调用meta-order-archive技能，四层结构化+哈希确权
7. **Wiki沉淀**：归档到wiki M4理论体系层或M8行业知识层

## 研究类型与输出映射

| 研究类型 | 调用技能 | 输出格式 | 归档元类 |
|---|---|---|---|
| 学术主题 | 学术文献调研+学术创作 | 文献综述/研究报告 | M4 |
| 行业分析 | 行业分析报告+市场热点 | 行业白皮书 | M8 |
| 技术趋势 | 学术文献调研+general_search | 技术趋势研判 | M4 |
| 竞品分析 | 个股研究+公告解读 | 竞品分析报告 | M8 |
| 理论构建 | 学术文献调研+批判性阅读 | 理论框架文档 | M4 |
| 尽调报告 | 个股研究+业绩分析+公告 | 尽调备忘录 | M8 |

## 研究报告标准结构

1. **摘要**（300字以内：研究问题、方法、核心发现、结论）
2. **背景与问题定义**（为什么研究这个，核心问题是什么）
3. **现状梳理**（领域现状、关键玩家、技术路线）
4. **深度分析**（按分析框架展开，每个论点配证据和来源）
5. **争议与缺口**（当前争议点、研究空白、不确定性）
6. **趋势与预判**（未来3-5年趋势，基于证据的推演）
7. **结论与建议**（可操作的建议，区分确定性和推测性结论）
8. **参考文献**（所有引用来源，带URL）

## 真值萃取规则

- 每个事实性陈述必须标注来源
- 区分"已验证事实""专家观点""推测性判断"
- 冲突信息必须并列呈现，不单方面取舍
- 数据必须标注时间、来源、口径
- 禁止编造引用，找不到来源的内容标注为"待验证"

## 与meta-order-archive联动

研究报告完成后自动执行：
1. 四层结构化拆分（元元数据/业务叙事/工程契约/故障台账）
2. 分配资产ID（KD-THEO-XXXX 或 KD-INDU-XXXX）
3. 创建飞书文档
4. 计算SHA256哈希
5. 移入wiki M4或M8节点
6. 更新全局索引台账

## 执行脚本

文献摘要批量提取使用 `scripts/literature_extractor.py`：

```bash
python3 scripts/literature_extractor.py --input <资料文本文件> --output <摘要JSON>
```

输出：每条文献的标题、核心观点、方法、结论、可信度评分。

## 质量约束

1. 研究报告必须有明确的研究问题，不能泛泛而谈
2. 所有数据和事实必须可溯源
3. 分析框架必须逻辑自洽，不跳步
4. 结论必须与证据匹配，不夸大
5. 区分"是什么"和"应该是什么"，不混淆事实与价值判断
6. 参考文献格式统一，URL可访问

## 全域联动协议（V2.0标准）

本产线已接入 **unified-orchestrator** 全域统一调度中枢。

- **推荐入口**：通过 `unified-orchestrator/scripts/auto_router.py` 自动识别意图并调用本产线，无需手动指定参数
- **真值校验闸门**：本产线产出强制经过 `truth-value-engine` SM-BS流形校验，漂移度>30%自动打回
- **因果增强**：决策/研究类产线自动接入 `causal-singularity-core` 因果链溯源与奇点预测
- **自动归档锁档**：产出完成后Lv3+自动触发 `meta-order-archive` → `meta-order-lock-archive` 全链路
- **自动卡片化**：Lv4+锁档资产自动触发 `collection-card-generator` 生成黑金藏品卡
- **算力路由**：所有生成任务穿透 `compute-scheduler` 统一调度，稳态公式 V(t)≥λC(t)
