## 正文

### 一、真值分级去重（对应Mem0分层蒸馏）
1. L1宪法级（元法则/同源协议/内核铁律/安全基线）：**只读，禁止合并、禁止删除、禁止替换**，仅可版本递增锁档。
2. L2业务级（短剧流水线/API配置/节点部署/业务真值）：可**相似合并**、可**冲突替换**，替换后旧版归档非删除。
3. L3运维级（日志/心跳/自监控/临时状态）：**静默去重清理**，去重不留痕，降低检索噪声。

### 二、合并替换规则（对应Mem0 update/merge决策）
1. **相似合并(merge)**：新真值与库中已有真值语义相似/同义/可补全 → 合并为一条更完整事实，保留双方Merkle溯源。
2. **冲突替换(replace)**：新真值与旧真值冲突（如偏好/决策变更）→ 新值覆盖旧值，旧值移入归档区，**不物理删除**。
3. **全新新增(add)**：与库中无重叠 → 直接新增。
4. 合并/替换判断依据：语义相似度 + 实体匹配 + 时间衰减（多信号），禁止仅凭文本字面判断。

### 三、多信号召回过滤
1. 真值检索按 语义向量 + 实体匹配 + 会话作用域 + 时间衰减 综合排序，只返回最相关，过滤冗余。
2. 检索、迭代、锁档全部按分级权重执行，优先召回L1宪法真值。

### 四、溯源与审计（M1/M3约束）
1. 任何合并/替换必须写入账本：旧值SHA + 新值SHA + 合并/替换决策 + 时间 + DID。
2. 被替换的旧真值归档保留（非删除），可随时回溯。
3. 去重全程不破坏Merkle-DAG溯源链与锁档凭证。
