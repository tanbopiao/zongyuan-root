## 一、流水线总览（7 阶段 + 3 道质量门）

```
阶段1 剧本规划 → [Q1 内容审核] → 阶段2 分镜脚本 → [Q2 分镜评审]
→ 阶段3 关键帧生成 → [Q3 视觉合规] → 阶段4 视频生成
→ 阶段5 音频生成 → 阶段6 音视频合流 → 阶段7 归档部署
```

---

## 二、各阶段详细架构（含输入输出格式）

### 阶段1：剧本规划
| 项 | 说明 |
|---|---|
| 输入 | 题材/世界观/角色设定/章节大纲 |
| 输出 | 完整剧本（分章节/分场景，每场景含：场景号/时间/地点/人物/动作/台词） |
| 工具 | 人工创作 + AI 辅助（doubao-book-writer） |
| 约束 | L0 天元法则（纯东方/乌黑长发/禁白发/无外来元素） |
| 质量门 Q1 | 内容审核：世界观一致性/角色设定合规/价值观正向 |

### 阶段2：分镜脚本
| 项 | 说明 |
|---|---|
| 输入 | 剧本 |
| 输出 | 分镜表 JSON（镜头号/章节/画面描述/台词/时长/景别/运镜） |
| 工具 | doubao-shortvideo-writing 技能 |
| 输出格式 | `storyboard.json`（每条：shot_id/chapter/description/dialogue/duration/shot_type/camera） |
| 质量门 Q2 | 分镜评审：镜头数合理/时长分配/视觉可实现性 |

### 阶段3：关键帧生成
| 项 | 说明 |
|---|---|
| 输入 | 分镜脚本 + 角色设定 |
| 输出 | 关键帧图片（1152x2048 竖版 JPG）+ 缩略图（540px webp） |
| 工具 | image_gen（Seedream） |
| 规则 | 纯东方神女/乌黑长发/玄黑鎏金/溯源标识/无白发/无外国人 |
| 命名规范 | `KD-章节-IMG-序号.jpg`（如 KD-01-IMG-01.jpg） |
| 质量门 Q3 | 视觉合规：黑发/东方/无外来元素/分辨率达标 |

### 阶段4：视频生成
| 项 | 说明 |
|---|---|
| 输入 | 关键帧图片 + 分镜描述 |
| 输出 | 视频片段（15s MP4，H.264） |
| 工具 | image_to_video（Seedance 2.0 Mini） |
| 规则 | 单条生产/禁止批量/用户指令触发/断点续传 |
| 命名规范 | `KD-章节-episode.mp4`（如 KD-01-awakening.mp4） |
| 额度管理 | 近 7 天额度限制，失败自动登记断点，恢复后续传 |

### 阶段5：音频生成
| 项 | 说明 |
|---|---|
| 输入 | 台词/旁白文本 |
| 输出 | 音频文件（WAV/MP3，16kHz） |
| 工具 | text_to_audio_plus / edge-tts |
| 通道 | 服务器轻量音频通道（/tts/generate） |
| 角色音色 | 按角色配置音色（神女/旁白/配角） |
| 命名规范 | `KD-章节-audio-序号.wav` |

### 阶段6：音视频合流
| 项 | 说明 |
|---|---|
| 输入 | 视频片段 + 音频 + 字幕文本 |
| 输出 | 成片（MP4，1080x1920） |
| 工具 | byted-mediakit-editing（ffmpeg） |
| 功能 | 字幕压制/音量调整/转场/片头片尾 |
| 验收 | 音画同步/字幕清晰/音量平衡/无黑边 |

### 阶段7：归档部署
| 项 | 说明 |
|---|---|
| 输入 | 成片 + 元数据 |
| 输出 | 作品库 + 锁档 + 部署上线 |
| 工具 | full_pipeline.py + git push + cron pull |
| 流程 | 资产入库 → Merkle 锁档 → 真值上报 → Gitee 推送 → 云端 pull → Nginx 对外 |
| 验收 | 线上可访问/数据一致/哈希校验通过 |

## 三、异常处理与重试机制

| 异常场景 | 处理方式 |
|---|---|
| 图片生成失败 | 重试 1 次 → 仍失败登记断点 → 后续补生成 |
| 视频额度耗尽 | 自动登记断点 → 额度恢复后从断点续传 |
| 音频生成失败 | 切换备用通道（edge-tts → 本地 TTS） |
| ffmpeg 合流失败 | 检查输入文件完整性 → 重试 → 仍失败换参数 |
| Gitee push 失败 | 检查凭证 → 重试 → 仍失败改本地备份 |
| 云端 pull 失败 | 检查 git remote → 手动触发 → 仍失败登记断点 |
| 线上 404 | 检查文件路径 → 确认 pull 成功 → 仍失败查 Nginx |
