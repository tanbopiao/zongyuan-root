## 二、使用流程

```
1. 按 templates/剧本模板.md 写剧本
2. 按 templates/分镜模板.json 拆分镜
3. 按 templates/提示词模板.md 生成关键帧
4. 用关键帧生成视频
5. 生成音频并合流
6. 按 samples/格式 整理作品库数据
7. 部署到线上
```
