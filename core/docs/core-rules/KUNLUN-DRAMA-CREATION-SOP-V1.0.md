## 二、多智能体分工（火斗云智自治体系）

1. **剧本Agent**：读取世界观真值，生成分集大纲、对白、场景描述；校验剧情一致性，规避世界观冲突。
2. **分镜Agent**：剧本拆分为镜头，输出镜头描述、运镜、光影、构图、角色姿态；输出关键帧Prompt。
3. **美术资产Agent**：角色三视图、场景概念图、关键帧；严格锁定角色形象，防止人脸/外形漂移。
4. **视频生成Agent**：基于关键帧，使用免费模型生成片段；优先控制资源消耗，遵循MR-007资源稳态元法则。
5. **剪辑合成Agent**：拼接片段、字幕、配乐；输出成片，计算资产SHA256。
6. **asset_archiver.py归档Agent**：CDN链接拉取资产、本地归档、上报网关、推送云端飞书目录。

```
世界观真值读取 → 分集剧本撰写 → 分镜拆解 → 关键帧生成 → 视频片段生成 → 成片剪辑 → SHA256哈希固化 → asset_archiver.py归档 → CDN静态资源托管 → 全域锁档 → 网页预览入库
```
