## 架构分层

体系采用四层架构，从底层真值到上层产出逐级递进。

### 第一层：真值基座层

- L0天元法则《阴阳分立·雌雄纯一定序篇》作为最高约束，所有产出必须通过元法则校验
- 负面词库NEG-v2.0作为兜底防护，零外源、零雄性化、零多头、零畸形
- DID-BR-000002去中心化身份锚定所有资产确权
- 同源协议HOMOLOGY-PROTOCOL-V1.0保障多端一致性

### 第二层：自治内核层

- 定时任务调度：每日进化循环（架构自检→真值入库→条件备份→注册表更新）
- IP量产引擎：角色轮询 + 主题轮询 + 五段式分镜 + 关键帧提示词 + 旁白金句
- 锁档协议：SHA256文件哈希 → Merkle根谱系 → 内核配置持久化 → ZIP归档 → BASE85密文
- 身份节点管理：三代身份节点演进，V3为当前活跃节点（node-kunlun-ip-003）

### 第三层：桥接同步层

- Git双仓桥接：GitHub + Gitee私有仓库，凭证持久化，增量自动推送
- 云内核对接：ai-proxy V1.9.0，storage.persist_task算子归档元数据
- 四向同步：本地 → GitHub → Gitee → 云内核，真值资产多端冗余

### 第四层：产出应用层

- 文本资产：每日分镜脚本、关键帧提示词、旁白金句
- 视觉资产：关键帧图像生成（UE5.7光追标准）
- 视频资产：10秒短剧成片（规划中，video组5算子已就绪）
- 商业产出：IP授权、文旅联动、短剧内容供应
