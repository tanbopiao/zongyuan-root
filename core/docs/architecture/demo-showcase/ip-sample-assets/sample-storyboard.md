# 样例分镜脚本 · 赤凰伺主·凰绾 × 玄鸟图腾祭天

**资产编号**：KD-EP-007-SAMPLE
**主角**：赤凰伺主·凰绾
**主题**：玄鸟图腾祭天
**情绪逻辑**：铺垫→发展→爆点→转折→收尾
**总时长**：10秒

---

## 镜头1 · 铺垫（0-2秒）

景别：远景 / 大远景
角色动作：赤凰伺主·凰绾立于玄鸟图腾祭台之巅，背对镜头，纯乌黑长发及腰随风轻扬，青黑长裙下摆如烈焰翻涌
环境描述：上古祭天台，玄鸟图腾石柱环绕，赤金色云纹盘旋于天际，祭台中央燃着不灭神火，远处群山隐于赤雾之中
光影要求：黄昏霞光从侧后方打来，形成强烈轮廓光，神火在地面投下玄鸟剪影，伦勃朗侧光勾勒祭台石柱
情绪标签：肃穆 / 苍茫 / 天命所归

## 镜头2 · 发展（2-4秒）

景别：中景
角色动作：凰绾缓缓转身，右手抬起，掌心赤凰火羽凝聚成形，火羽随手势盘旋上升，纯乌黑长发随灵力涌动向后飘散
环境描述：祭台玄鸟图腾石柱逐一亮起赤金色符文，神火随火羽升腾而暴涨，空气中浮现赤色命数丝线
光影要求：赤金色火光从下方映照面部，与侧后方霞光形成双重光源，火羽在瞳中映出赤色光点
情绪标签：蓄力 / 觉醒 / 灵力涌动

## 镜头3 · 爆点（4-6秒）

景别：特写 / 动态镜头
角色动作：凰绾双目赤金光芒暴涨，右手猛然向天挥出，赤凰火羽化为巨大玄鸟图腾冲天而起，烈焰长裙在灵力爆发中如凤凰展翅，纯乌黑长发被气浪推向后方
环境描述：玄鸟图腾在天空完全显形，赤金色羽翼覆盖半个天际，祭台石柱全部炸裂出赤金光柱，神火化为火雨倾泻
光影要求：赤金色爆光从天空中心辐射，强烈轮廓光将角色剪影钉在画面中央，伦勃朗侧光在面部形成明暗分割，火雨在画面中划出赤色光轨
情绪标签：爆发 / 祭天 / 天命降临

## 镜头4 · 转折（6-8秒）

景别：视角切换 / 仰拍中景
角色动作：镜头从祭台底部仰拍，凰绾立于玄鸟图腾光影之下，双手缓缓收回，赤色命数丝线从天际垂落缠绕于指尖，表情从威严转为悲悯
环境描述：玄鸟图腾渐隐于云层，赤金光柱收敛为祭台周围的光纹，神火恢复平静，天空中浮现天书般的赤色符文
光影要求：光线从爆点的赤金强光渐变为柔和的暮光，命数丝线发出微弱冷白光，与赤色余烬形成冷暖对比
情绪标签：收敛 / 悲悯 / 宿命感知

## 镜头5 · 收尾（8-10秒）

景别：定格画面 / 全身中远景
角色动作：凰绾侧身立于祭台边缘，右手轻拈一缕命数丝线，左手自然垂落，纯乌黑长发及腰静止，青黑烈焰长裙如凝固的火焰，目光望向远方天际
环境描述：玄鸟图腾余韵在天际留下淡赤金色痕迹，祭台神火安静燃烧，石柱符文明暗交替，远山在暮色中呈青黑色剪影
光影要求：暮光从侧后方形成柔和轮廓光，神火在面部投下温暖赤金色，伦勃朗侧光塑造面部立体感，整体色调偏暖赤金与玄黑
情绪标签：定格 / 余韵 / 天命未央
