## 镜头1 · 铺垫（0-2秒）

- **镜头编号**：S08-01
- **时长**：0-2秒
- **景别**：远景 / 大远景
- **角色动作**：赤霞司命·绯灵汐立于天书剑封印石台之前，背对镜头，纯乌黑长发及腰静止如墨瀑，青金长裙下摆微微飘动，赤红眼瞳在阴影中隐约发光
- **环境描述**：上古封印密室，石壁上刻满天书符文，中央石台悬浮一柄被赤金色锁链缠绕的古剑，剑鞘上流转着青色命数丝线，四周烛火无风自动
- **光影要求**：青金色冷光从石台下方透出，与烛火暖光形成冷暖交织，伦勃朗侧光勾勒角色剪影，天书符文在石壁上发出微弱赤金色光
- **情绪标签**：肃穆 / 封印 / 宿命将至

## 镜头2 · 发展（2-4秒）

- **镜头编号**：S08-02
- **时长**：2-4秒
- **景别**：中景
- **角色动作**：绯灵汐缓缓转身，右手抬起指向石台，赤红色命数丝线从指尖射出，缠绕上天书剑的锁链，纯乌黑长发随灵力涌动向后飘散，赤红眼瞳光芒渐盛
- **环境描述**：天书符文随命数丝线逐一亮起，赤金色锁链开始震动崩解，古剑剑鞘发出青色嗡鸣，密室空气中浮现赤霞流云
- **光影要求**：命数丝线发出赤红色光芒映照面部，与石台青金色冷光形成双重光源，符文亮起的光在墙面流动
- **情绪标签**：蓄力 / 解封 / 灵力涌动

## 镜头3 · 爆点（4-6秒）

- **镜头编号**：S08-03
- **时长**：4-6秒
- **景别**：特写 / 动态镜头
- **角色动作**：绯灵汐双目赤金红光暴涨，右手猛然回拉，天书剑锁链全部崩断，古剑冲天而起悬浮于她头顶，她伸手握住剑柄，纯乌黑长发被剑气推向后方，青金长裙如赤霞翻涌
- **环境描述**：天书剑完全启封，剑身绽放青金色剑芒，赤金色符文从剑身飞出环绕角色，石壁符文全部炸裂出光柱，密室顶部被剑芒击穿，赤霞流云从缺口涌入
- **光影要求**：青金色剑芒从天空中心辐射，强烈轮廓光将角色剪影钉在画面中央，伦勃朗侧光在面部形成明暗分割，赤金色符文在画面中划出光轨
- **情绪标签**：爆发 / 启封 / 天命出鞘

## 镜头4 · 转折（6-8秒）

- **镜头编号**：S08-04
- **时长**：6-8秒
- **景别**：视角切换 / 仰拍中景
- **角色动作**：镜头从石台底部仰拍，绯灵汐持天书剑立于光柱之中，剑尖缓缓垂下，赤色命数丝线从剑身流向她的指尖，表情从威严转为悲悯，仿佛看到了剑中封印的宿命
- **环境描述**：剑芒渐敛为青金色光晕，赤金色符文收敛为剑身纹路，光柱消散为密室中的光尘，石壁上残留的天书符文明暗交替
- **光影要求**：光线从爆点的青金强光渐变为柔和的暮光，命数丝线发出微弱赤红光，与青金色余烬形成冷暖对比
- **情绪标签**：收敛 / 悲悯 / 宿命感知

## 镜头5 · 收尾（8-10秒）

- **镜头编号**：S08-05
- **时长**：8-10秒
- **景别**：定格画面 / 全身中远景
- **角色动作**：绯灵汐侧身持天书剑立于石台边缘，剑尖触地，左手轻拈一缕赤色命数丝线，纯乌黑长发及腰静止，青金长裙如凝固的赤霞，目光望向剑芒击穿的缺口外的天际
- **环境描述**：天书剑余韵在剑身留淡青金色光芒，密室烛火恢复平静，石壁符文明暗交替，缺口外可见暮色中的远山青黑色剪影
- **光影要求**：暮光从缺口侧后方形成柔和轮廓光，烛火在面部投下温暖赤金色，伦勃朗侧光塑造面部立体感，整体色调偏暖赤金与玄黑
