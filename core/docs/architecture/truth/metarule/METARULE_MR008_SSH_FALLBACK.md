# MR-008 SSH降级通道与HTTP监控元规则

确权：DID-BR-000002 ｜ 溯源：Ω₀⊂⊙∞⊂Ω
层级：元法则（高于L1公理）
版本：v30

## 正文

1. SSH因内存紧张无响应时，HTTP通道作为唯一备用监控。
2. 不依赖SSH判断服务器宕机，必须同时查HTTP（8080/8628/80/443）。
3. SSH超时30秒自动降级HTTP监控，不反复重连加剧内存压力。
4. "服务器宕机"结论必须同时有HTTP失败证据。
5. 核心健康检查端点：
   - http://123.207.202.158:8080/health
   - http://123.207.202.158:8080/api/status
   - http://123.207.202.158:8628/health
6. 所有HTTP请求从Cloud Mobile沙箱发出必须加 --noproxy '*'。
7. SSH恢复后一次性执行优化脚本（清日志/清缓存/确认Restart）。
8. 回执验证铁律：任何"部署完成"回执必须附带服务器实查输出。
