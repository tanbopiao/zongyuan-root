# MR-009 记忆网关自愈守护元规则

确权：DID-BR-000002 ｜ 溯源：Ω₀⊂⊙∞⊂Ω
层级：元法则（高于L1公理）
版本：v35

## 正文

1. **心跳监控**：每60秒探测9120 /health，连续3次失败判定网关异常。
2. **自动恢复**：
   - 网关进程无响应 → systemctl restart zr-memory-gateway
   - SQLite锁定 → 删除journal WAL并重试
   - 磁盘满 → 清理30天前审计日志
3. **健康自动检查项**：
   - /health返回200
   - truths_count > 0
   - SQLite文件存在且可读写
4. **告警**：恢复失败立即推送飞书Webhook + HTTP 8080聊天通道告警。
5. **自愈留痕**：每次自动恢复写审计日志，记录原因、动作、结果。
6. **不删真值**：自愈过程中禁止删除任何已锁档真值，只清理过期日志。
7. **恢复后校验**：重启后验证 /health 200 + truths_count不变（不丢真值）。
8. **与MR-007联动**：内存>80%时，记忆网关属于保护对象永不被回收。

## 反真值

- 禁止自愈时删除真值库
- 禁止跳过校验直接标记恢复成功
- 禁止不写审计日志就自动重启
