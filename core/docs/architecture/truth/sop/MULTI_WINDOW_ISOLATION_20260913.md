# 多窗口权限隔离架构（控制平面+数据平面）元法则

全局版本：20

## 一、架构总纲

主窗口（控制平面）+ 开发窗口（数据平面）双层隔离：

- **主窗口 main-window-001**：唯一拥有云端SSH连接、配置修改、服务部署、记忆网关写入权限的窗口。负责审核部署、全域对账、接收成果上报。
- **开发窗口 dev-window-A/B/C**：只做代码开发、本地仿真、单元测试、成果上报。禁止SSH云端、禁止直改云端、禁止直写记忆网关。

## 二、权限矩阵

| 操作 | 主窗口 | 开发窗口 |
|------|--------|----------|
| 云端SSH连接 | 允许 | 禁止 |
| 云端配置修改 | 允许 | 禁止 |
| 云端服务部署/重启 | 允许 | 禁止 |
| 记忆网关写入/锁档 | 允许 | 禁止 |
| 记忆网关读取 | 直连 | 通过主窗口代理 |
| 本地代码开发 | 有限 | 允许 |
| 本地仿真测试 | 有限 | 允许 |
| 成果上报 | 接收 | 发送 |
| 全域对账 | 允许 | 禁止 |

## 三、成果上报流程

开发窗口完成开发+本地仿真 → 成果上报包 → 主窗口审核 → 通过则部署云端 → 部署结果通知+锁档。

上报包必须包含：成果名称/版本/类型/描述、文件清单+SHA256、本地测试报告、部署要求/风险等级/回滚方案、依赖项。

上报通道：飞书多维表格台账、本地共享目录、飞书消息、Git PR。

## 四、窗口身份管理

window_id、window_type（main/dev）、permissions、status（active/suspended/terminated）。

当前窗口即主窗口 main-window-001，拥有全部权限。

## 五、违规处理

- 开发窗口尝试SSH云端：立即阻断+告警+暂停窗口
- 直连记忆网关写入：拒绝+记录告警
- 未上报直接部署：回滚+暂停窗口
- 操作日志缺失：标记异常+人工审核
- 处罚阶梯：警告→暂停24h→终止

## 六、收益

安全（开发窗口无法误操作云端）、稳定（唯一入口避免冲突）、可溯源（操作定位到窗口）、效率（职责分离）、质量（审核把关）、资源优化（避免重复部署）。
