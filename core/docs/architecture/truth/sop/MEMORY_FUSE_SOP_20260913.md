# 内存阈值熔断与资源置余SOP

快照：ZONGYUAN-SNAP-20260913-MEMORY-THRESHOLD-FUSE-SOP
确权：DID-BR-000002 ｜ 溯源：Ω₀⊂⊙∞⊂Ω
锁档：Lv10

---

## 一、阈值定义

- 预警：70%
- 硬熔断：80%
- 极端兜底：90%
- 采样：每2秒，连续5次超阈值才触发（防抖）

## 二、分级处置

### Level1 预警（≥70%）
1. dr_resource_monitor写审计事件，推送告警main-window-001
2. 自动清理临时缓存、过期快照、非关键日志
3. 拒绝新普通台账任务，运行中任务允许完成
4. 带DID签名的高危任务仍可调度
5. 回落至65%以下自动解除

### Level2 硬熔断（≥80%）
1. 暂停所有新任务（含高危）
2. 关停非核心业务负载（API业务、统计进程）
3. 清理全部临时缓存和中间结果
4. 保护对象禁止关停：dr_resource_monitor、auto_violation_detect、9120真值库、审计日志、节点心跳
5. 回落至70%后进入恢复校验（真值库/Merkle/心跳）
6. 校验通过自动恢复，失败持续冻结告警

### Level3 极端兜底（≥90%）
1. 保留核心守护进程，强杀所有非必要用户态程序
2. 冻结文件写入，审计日志仅内存缓冲
3. 全局紧急审计快照防真值丢失

## 三、L1铁律

1. 熔断目标：保护内核/审计/安全/心跳，牺牲业务层
2. 熔断不修改L1公理、不删锁档快照
3. 熔断全过程审计永久存入9120
4. 恢复前必须完成资产完整性校验

## 四、常驻进程

dr_resource_monitor：CPU/内存/磁盘采样、分级熔断、回收、审计、告警、恢复校验。
