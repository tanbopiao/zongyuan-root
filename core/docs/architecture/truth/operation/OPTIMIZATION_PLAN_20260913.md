## 二、优化方案（按优先级）

### P0：内存治理（立即执行，零成本）

**问题**：221MB可用，随时可能OOM。

**措施**：
1. **确认drama-api的systemd Restart配置**：
   - 确保 `Restart=always`、`RestartSec=3`
   - 这比主备双进程更省内存，挂了3秒自动拉起
2. **识别并停止非必要常驻进程**：
   - 当前10+个python3进程，逐个确认必要性
   - 停掉近期未使用的实验性gateway
3. **清理日志释放磁盘缓存**：
   - `find /opt/ZONGYUAN-ROOT/logs -name "*.log" -size +50M -truncate -s 0`
4. **不新增任何常驻服务**：直到内存升级

**预期收益**：释放300-500MB可用内存

### P1：真实高可用（替代虚报的主备）

**问题**：drama-api单实例，挂了就断。

**务实方案**（不增加第二个进程）：
1. systemd watchdog：进程卡死自动kill重启
2. 简单健康巡检脚本：crontab每分钟检查8628，挂了自动systemctl restart
3. 日志保留最近100行崩溃记录，便于排查

**为什么不上真双实例**：可用内存221MB，再起一个python进程直接OOM。

### P2：回执验证机制（防虚报）

**问题**：窗口报告"已完成"但实际未落地。

**措施**：
1. 所有"部署完成"回执必须附带**服务器实际验证输出**（systemctl status / ss -tlnp / curl health）
2. 主窗口在台账审核时，必须SSH验证实际状态后才标记"已验收"
3. 引入"回执可信度"标记：已验证/待验证/未通过

### P3：版本对齐

- 本地v27的静默值守状态推送到云端
- 云端注册表更新到v27
- truth文件同步

### P4：硬件升级（长期）

**根本解决方案**：
- 2GB→4GB内存
- 升级后：再做主备双实例、压测、更多服务
- 成本：腾讯云轻量服务器升配约+50元/月
