## 一、部署相关

### Q1：部署需要什么环境？
**A：** 
- Python 3.8+
- Linux服务器（Ubuntu/CentOS/OpenCloudOS均可）
- 至少1GB内存、10GB磁盘
- 可访问外网
- 运行 `python3 scripts/env_check.py` 自动检测

### Q2：部署失败，提示"git pull失败"怎么办？
**A：** 
1. 检查服务器网络是否正常
2. 检查Git仓库地址是否正确
3. 手动执行 `git pull` 看具体错误
4. 如果是权限问题，确认Git凭证已配置

### Q3：部署完成后访问页面404？
**A：** 
1. 检查Nginx配置，确保文件路径正确
2. 检查文件权限：`chmod 644 /path/to/file.html`
3. 检查Nginx是否有SPA路由重写规则
4. 确认域名解析正确指向服务器IP

### Q4：支持Docker部署吗？
**A：** 
当前版本提供手动部署方式，Docker镜像正在开发中（阶段2交付）。
手动部署请参考《部署手册》。

### Q5：如何升级到新版本？
**A：** 
```bash
cd /opt/ZONGYUAN-ROOT
git pull origin main
# 如需重新部署web文件
cp showcase-page/differential_capabilities_v2.html /www/wwwroot/www.huodouai.com/diff.html
```

## 二、授权与密钥相关

### Q6：我的API密钥泄露了怎么办？
**A：** 
1. 立即到对应平台重置密钥
2. 在.env文件中更新新密钥
3. 重启服务生效
4. 检查日志是否有异常调用

### Q7：DID是什么？在哪里获取？
**A：** 
DID是你的节点身份标识，格式如 `DID-BR-000002`。
首次使用时联系管理员分配，或通过握手接口自动注册。

### Q8：共享密钥怎么保管？
**A：** 
- 密钥保存在.env文件中，不要提交到Git
- 不要分享给第三方
- 建议定期更换
- 如怀疑泄露，立即更换

## 四、技术问题

### Q13：同源协议是什么？
**A：** 
同源协议是火斗云智定义的多节点通信协议，用于不同智能体节点之间安全通信。
包含6种报文类型（握手/请求/响应/心跳/确认/锁档），HMAC-SHA256签名验证。

### Q14：什么是Merkle-DAG？
**A：** 
Merkle-DAG是一种哈希链结构，每个文件都有SHA256哈希，所有哈希组成有向无环图。
任何文件被篡改，哈希链就会断裂，系统自动告警。

### Q15：什么是漂移抑制？
**A：** 
AI系统运行久了会逐渐偏离原始设定，这叫"漂移"。
我们的三重漂移抑制引擎会自动检测并纠正：
1. 哈希校验：配置文件是否被篡改
2. 结构校验：系统结构是否完整
3. 语义校验：模型输出是否偏离设定

### Q16：eFuse熔断是什么？
**A：** 
eFuse是一种硬件级熔断机制，关键配置一旦写入就永久锁定，无法修改。
类似芯片的熔丝，烧断后就不能再改了。

## 六、常见报错

| 报错 | 原因 | 解决方法 |
|------|------|---------|
| `E_AUTH_401` | 鉴权失败 | 检查DID和密钥是否正确 |
| `E_SIGNATURE_INVALID` | 签名错误 | 检查签名计算方式 |
| `E_TIMEOUT_408` | 请求超时 | 检查网络，重试 |
| `E_RATE_429` | 限流 | 降低请求频率 |
| `git pull失败` | 网络/权限 | 检查网络和Git凭证 |
| `403 Forbidden` | 权限不足 | 检查文件权限和Nginx配置 |
| `502 Bad Gateway` | 后端服务未启动 | 检查后端服务是否运行 |
