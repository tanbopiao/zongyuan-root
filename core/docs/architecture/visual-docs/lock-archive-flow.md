## 验证方式

任何第三方可通过以下方式验证资产真实性：

1. 重新计算文件SHA256，与manifest.json中记录比对
2. 串联所有文件哈希计算Merkle根，与记录比对
3. 串联所有批次Merkle根计算全域根哈希，与内核配置比对
4. 全部一致则资产未被篡改，确权有效
