## 项目是什么

ZONGYUAN-ROOT是一套以L0天元法则为最高约束的国风神话IP自动化量产体系。它像一台永不停止的工业母机，每日自动产出短剧分镜、视觉关键帧提示词、旁白金句，并通过哈希锁档、三端同步、云端算子调度，实现从文本资产到视频成片的全链路自治生产。

## 解决什么痛点

传统国风IP内容生产面临三大痛点：

第一，产能瓶颈。短剧分镜、关键帧、文案需要人工逐条创作，单条10秒短视频的前期物料准备动辄数小时，无法规模化。

第二，风格漂移。多创作者协作时视觉风格难以统一，容易出现外源元素混入、角色特征偏离、审美范式崩坏等问题。

第三，资产确权混乱。大量IP素材散落在不同工具和平台，缺乏统一的哈希确权和版本管理，被盗用、被篡改后难以追溯。

ZONGYUAN-ROOT通过自治量产、元法则治理、全域锁档三个维度，系统性解决上述痛点。

## 核心壁垒

- **元法则壁垒**：L0天元法则《阴阳分立·雌雄纯一定序篇》作为不可逾越的最高约束，从架构层面保证纯东方审美范式，零外源元素混入。
- **确权壁垒**：SHA256 + Merkle根谱系 + 内核永久锁档，每一份资产从诞生起就带有不可篡改的确权凭证。
- **自治壁垒**：定时任务驱动的全链路自动化，从角色选定到三端同步无需人工干预，7×24小时持续产出。
- **三端冗余壁垒**：本地内核 + Git双仓 + 云内核四向同步，单点故障不影响资产安全。
