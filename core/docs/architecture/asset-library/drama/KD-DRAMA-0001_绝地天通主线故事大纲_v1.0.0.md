## 世界观基底
上古时代，天地相通，人神混居，昆仑为众神居所。凡间欲望泛滥，邪魔借天地通道穿行于人间与神界，秩序崩坏。众神在昆仑召开瑶池集会，商议重新划定天地边界。主线核心：秩序校准，隔绝人神通道，守护人间与神界各自的平衡。

### 主要登场核心角色
西王母：昆仑执掌者，主持绝地天通仪式。
女娲：创世始祖，见证天地边界重铸。
太阴月神：执掌太阴法则，夜晚与魂灵秩序。
九天玄女：天道信使，传递神谕，征战镇邪。
赤华玄媱、凰绾、绯灵汐：诸神麾下神女。
山海经异兽萌宠：昆仑守护生灵。

## 故事分幕
### 第一幕：墟境异动（EP00-EP02）
天地裂隙不断出现，墟境混沌力量溢出，凡间灾祸频发。西王母感知异动，开启昆仑天门，召集众神赶赴瑶池集会。众神研判危机，确认旧有的人神通道已经不可继续维持。

### 第二幕：众神远征探测墟境（EP03-EP06）
九天玄女带队，开启墟境探测启封任务，深入混沌裂隙探查本源。各路神女分头行动，镇压溢出的混沌魔物。见证上古遗留的破碎神迹，回望远古天地相通时代的记忆。

### 第三幕：绝地天通仪式（EP07-EP12）
瑶池举行盛大仪式，众神合力。以符文法阵、玄鸟之力作为媒介，铸造天地隔绝屏障。断开通天的通道，划定神界居昆仑，凡人居于大地，互不侵扰。

### 第四幕：新秩序时代（EP13之后）
天地两界界限稳固。神明不再随意行走人间，但依旧默默守护苍生。留下传说与遗迹，罗定八景、文塔印象园等人间遗迹，成为神话在凡间的残留印记。
