PIPELINE

量产流水线

01

角色与主题选定

从4位核心角色和6大场景主题中轮询选定当日组合，校验前3日不重复，确保产出多样性。

02

五段式分镜生成

按铺垫→发展→爆点→转折→收尾情绪逻辑，生成10秒短剧分镜，每镜含编号、时长、景别、动作、环境、光影、情绪七维度。

03

关键帧提示词生成

为爆点帧和收尾帧各生成标准化提示词，强制基准参数确保视觉统一：纯乌黑长发、九头身、9:16竖屏、UE5.7光追、Portra400胶片。

04

旁白金句创作

文言文/半文白风格，15-30字，蕴含天道/秩序/宿命/力量主题，适合作为短视频画外音收尾。

05

全域锁档确权

SHA256文件哈希 → Merkle根谱系 → 内核永久锁档 → ZIP归档 → BASE85密文 → 巡检日志，九步闭环不可篡改。

06

三端同步归档

Git提交 → GitHub推送 → Gitee推送 → 云内核persist_task归档，真值资产四向同步，闭环完成。
