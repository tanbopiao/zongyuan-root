## 一、核心结论
归档链路 = 七层依赖叠加。当前环境七层全具备；其他地方缺的不是单一样东西，而是「钥匙（凭据）+ 地图（知识）+ 手（工具链）」组合。唯一真正环境无关的是公网通道——通道人人可通，缺的是谁有资格、谁会走、拿什么工具走。

## 二、七层依赖拆解（按可复制性排序）

### ① 通道层（公网可达）——环境无关
- drama.huodouai.com 域名 + 9120/API 端点公网放行，任何设备有网即达
- 不是"这里行、别处不行"的原因

### ② 凭据层（钥匙）——最硬缺口
- 有效 Token（ZR-CAPTURE-2026-OMEGA-d04bb54ba2a55a7d，2026-09-13 轮换）
- 节点身份注册（local-dev-001）+ DID-BR-000002 绑定
- 无 Token/身份 → 通道通也被 401 拒

### ③ 知识层（地图）——次硬缺口
- 端点清单、桶语义、上报格式、manifest 规范、SOP V1.0、四端流程
- 全部本地实测固化；新节点未学即等于无

### ④ 工具层（手）
- lark-cli（飞书）、Playwright+chromium（解析快速对话视频直链）、ffprobe/sha256sum/curl/python
- 普通豆包对话无 Bash 执行权 → 有钥匙也动不了手

### ⑤ 环境层（场地）
- 工作任务模式 = 虚拟机 + 磁盘 + 网络出口 + Bash
- "工作任务"与"快速对话"的本质差别：快速对话只有生成能力，无执行沙箱

### ⑥ 权限层（门禁）
- 飞书云盘文件夹权限、上传接口授权、Base 台账访问、审批定义（当前待建）
- 换账号/换租户即失效

### ⑦ 约定层（规则）
- DID+Ω 确权、回执不作真值、四端独立核验——纯文档可复制，需主动导入

## 三、环境对照
- 当前任务环境：七层全具备（审批定义待建为唯一部分缺口）
- 新云电脑/新节点：缺凭据+知识+工具 → 全部可补齐（上岗教育体系分发）
- 普通豆包对话：缺环境（无执行沙箱）+工具 → 结构性缺失，只能走工作任务
- 外部设备/手机：缺凭据+知识+工具+环境+权限 → 基本不可用，仅作上传入口
- 云端其他账号：缺凭据+权限 → 等凭据与授权分发
