## 二、优化方案（三层递进）

### 第一层：短期 — 调度规则优化（零成本，立即可落地）

#### 2.1 截止日优先仲裁规则
同优先级项目冲突时，**截止日更近的项目优先**。
- P02（9-20）vs P04（9-30）→ P02优先分配提示词组
- P04降级使用视觉B + 智能补位（用智谱GLM-4-Flash辅助提示词初稿）

#### 2.2 闲置资源自动补位
调度器增加"次优匹配"逻辑：
- 主资源满载时，自动匹配技能重叠度≥1的次优资源
- 例：P04缺提示词资源 → 智谱GLM-4-Flash承担提示词初稿生成
- IMA知识库自动承担所有项目的RAG检索环节，释放人工

#### 2.3 负载均衡阈值
- 单资源并行负载≥80%时，调度器拒绝新项目分配
- 触发告警：需要扩容或降低项目并行数

### 第二层：中期 — 资源池重构（1-2周）

#### 2.4 创意资源扩容
- **火山豆包Pro**：新增Key3（已有b63e56d0）作为第三实例，max_parallel从2→3
- **提示词组**：拆分为"提示词初稿"（智谱承担）+ "提示词精修"（人工组）双层
- **视觉组**：新增视觉关键帧C，分担P04短剧量产线工作量

#### 2.5 闲置资源激活
- 合规锁档组：自动接入所有项目的最终交付环节（哈希校验+飞书归档）
- IMA知识库：作为所有项目的默认检索后端，不再单独排项目
- 百度网盘：自动作为所有项目的成品备份存储，不再单独排项目

#### 2.6 职能池弹性扩展
| 职能组 | 当前容量 | 优化后 | 扩容方式 |
|--------|----------|--------|----------|
| 模型工程组 | 3模型×2-3并行 | 3模型×3并行 | 已有Key，仅调参 |
| 视觉组 | 2人×1并行 | 3人×1并行 | 新增1个视觉资源 |
| 提示词组 | 1组×2并行 | 2层×2并行 | 智谱承担初稿层 |
| 运维组 | 1组×2并行 | 1组×2并行 | 已够 |
| 合规组 | 1组×2并行 | 自动接入所有项目 | 零扩容 |

### 第三层：长期 — 调度算法升级（1个月）

#### 2.7 酉空间任务分配（对接前述酉矩阵理论）
- 将每个项目的技能需求向量化
- 资源能力向量化
- 用酉变换做最优匹配，替代当前贪心算法
- 保证全局资源利用率最大化

#### 2.8 预测性调度
- 基于历史项目周期，预测资源释放时间
- 提前预留资源，避免临时争抢
- 对接每小时巡检算子，实时更新负载

#### 2.9 冲突自动裁决引擎
- 输入：冲突资源 + 两个项目
- 输出：分配方案 + 理由
- 裁决权重：截止日40% + 项目优先级30% + 资源历史利用率30%
