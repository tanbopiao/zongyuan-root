## 一、视觉范式基线（硬约束）

### 1.1 人物形象
- 主角：纯东方神女形象
- 发色：必须黑色，禁止白发、灰发
- 人种：仅东方审美，禁止外国人种元素
- 服饰：东方古风，禁止西方服饰
- 建筑：东方古风建筑，禁止西方建筑

### 1.2 风格统一
- 画风：国风岩彩/水墨风格
- 色调：暖金+黛蓝+朱砂红为主色
- 画质：电影级4K
- 比例：9:16竖屏（短视频）/ 16:9横屏（电影级）

### 1.3 禁止元素
- ❌ 白发
- ❌ 外国人
- ❌ 西方服饰
- ❌ 西方建筑
- ❌ 外来审美元素

## 二、资产命名规范

### 2.1 命名格式
```
KUNLUN-{TYPE}-{STORY}-{SCENE}-{SEQ}-{VERSION}
```

### 2.2 类型代码
| 代码 | 类型 |
|------|------|
| KEY | 关键帧 |
| VIDEO | 视频成片 |
| AUDIO | 音频 |
| PROMPT | 提示词 |
| CHAR | 角色立绘 |
| BG | 背景图 |

### 2.3 示例
- `KUNLUN-KEY-XIHE-SCENE01-V001`
- `KUNLUN-VIDEO-XIHE-SCENE01-V001`
- `KUNLUN-AUDIO-XIHE-BGM-V001`

## 三、矩阵职能池定义

### 3.1 五大职能池

| 职能池 | 职责 | 资源 |
|--------|------|------|
| 视觉设计池 | 关键帧、角色立绘、背景图 | Seedream 5.0 Pro |
| 提示词工程池 | 提示词设计、优化、测试 | 智谱GLM-4-Flash |
| 视频生产池 | 短剧成片、运镜、特效 | Seedance 2.0 Mini |
| 音频生产池 | BGM、配音、音效 | seed-audio |
| 运维合规池 | 审核、锁档、归档、漂移检测 | 本地巡检脚本 |

### 3.2 项目-资源映射
每个项目（短剧/视频）从五大职能池分配资源：
- 视觉设计池 → 关键帧
- 提示词工程池 → 提示词
- 视频生产池 → 成片
- 音频生产池 → 音频
- 运维合规池 → 审核锁档

---

## 四、短剧生产流水线

### 4.1 六阶段流程
1. 剧本创作 → 提示词工程池
2. 关键帧生成 → 视觉设计池
3. 视频生成 → 视频生产池
4. 音频合成 → 音频生产池
5. 审核校验 → 运维合规池
6. 锁档归档 → 运维合规池

### 4.2 质量门禁
- 关键帧：视觉范式校验（无白发/无外国人/纯东方）
- 视频：角色一致性校验（多帧对比）
- 音频：人声清晰度校验
- 成片：整体风格一致性校验
