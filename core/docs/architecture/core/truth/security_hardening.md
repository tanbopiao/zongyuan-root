## 一、边界防护

### 1.1 fail2ban 暴力破解防护
**作用：** 自动封禁多次尝试登录失败的IP，防止SSH/密码暴力破解攻击。

**配置要点：**
- 监控SSH登录失败日志
- 阈值：5分钟内失败3次 → 封禁IP 24小时
- 白名单：本机IP、已知可信IP不封禁
- 日志路径：/var/log/fail2ban.log

### 1.2 防火墙规则
- 仅开放必要端口：80/443/22
- 8077记忆网关：仅127.0.0.1内网访问
- 8080业务网关：IP白名单限制
- 其他端口：默认拒绝

### 1.3 IP白名单
| 服务 | 白名单策略 |
|------|-----------|
| 8077记忆网关 | 仅127.0.0.1 |
| 8080业务网关 | 可信IP段 |
| /console/ | 仅管理员IP |
| SSH | 密钥认证，禁用密码登录 |

## 二、身份与权限安全

### 2.1 三级权限模型
- **L0理论基座**：全量真值读写，锁档确权，冲突仲裁
- **L1-L3业务层**：受限读写，受Lv6权限约束
- **L4执行层**：仅执行，无真值修改权

### 2.2 认证机制
- 节点间：mTLS双向证书 + JWT短期令牌
- API调用：X-API-Key 认证
- 管理后台：Basic Auth + IP白名单

### 2.3 审计要求
- 所有写操作必须记录审计日志
- 日志包含：操作人、时间、内容、来源IP、结果
- 审计日志不可修改，仅可追加

---

## 三、数据安全

### 3.1 API密钥管理
- 有效密钥：保留路由，正常使用
- 无效密钥：封存隔离，不参与调度
- 密钥存储：.env文件，权限600，禁止提交Git
- 轮换策略：每90天轮换一次

### 3.2 资产加密
- 敏感资产：AES-256加密存储
- 传输：HTTPS/TLS 1.3
- 备份：加密后异地备份

### 3.3 防篡改
- 所有资产：SHA256哈希校验
- 关键配置：eFuse硬件熔断固化
- 版本控制：Git双远程镜像

## 四、告警收敛

### 4.1 告警分级
| 级别 | 触发条件 | 处置 |
|------|---------|------|
| P0 严重 | eFuse熔断/哈希链断裂 | 立即通知+自动回滚 |
| P1 高危 | 重度漂移/越权访问 | 5分钟内通知 |
| P2 中危 | 中度漂移/服务异常 | 30分钟内通知 |
| P3 低危 | 轻度漂移/性能告警 | 每日汇总 |

### 4.2 收敛规则
- 同一问题5分钟内只告警一次
- 低危告警合并为每日摘要
- 告警去重：相同错误码只计一次
