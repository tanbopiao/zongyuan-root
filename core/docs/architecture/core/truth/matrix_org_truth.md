## 核心公理
矩阵架构 = 职能线（纵向专业能力池） × 项目线（横向业务交付目标）双维交叉。
员工同时受职能经理（管标准/能力）和项目经理（管任务/排期）双维管理。

## 三种形态
- 弱矩阵：职能经理主导，项目经理仅协调权（小项目起步用）
- 平衡矩阵：双经理权责对等，共同考核（中型项目）
- 强矩阵：项目经理主导预算/人事（大型高优项目）

## 火斗云智落地映射
纵向职能池：模型工程组 / 提示词资产组 / 视觉关键帧组 / 运维内核组 / 合规锁档组
横向项目实例：太阴月神PV / 九天玄女EP05 / RAG知识库工程 / 短剧量产线

## 核心收益
1. 专业人才复用，资源利用率高
2. 跨部门协同天然打通，适配多模态复合项目
3. 项目结束人员退回资源池，组织弹性强

## 核心约束
1. 双重汇报易指令冲突，需全局优先级调度
2. 权责边界需明确，避免推诿
3. 需配套双维绩效考核

## 落地决策
采用弱矩阵起步 → 逐步升级平衡矩阵
配套：全局资源调度表 + 项目优先级元规则 + 双维绩效
