## 一、核心原理真值
集成学习 = 训练多个有差异的弱学习器，聚合其输出，抵消单一模型的偏差/方差缺陷，获得更强更稳的预测。
弱学习器定义：性能略高于随机猜测的模型（浅层决策树、简单线性模型等）。

## 二、误差三分真值（针对性削弱）
1. 方差（Variance）：对训练噪声过拟合、预测波动大 → Bagging 系随机误差相互抵消，降方差。
2. 偏差（Bias）：模型能力不足欠拟合 → Boosting 系迭代学习残差，降偏差。
3. 固有噪声：数据自带，集成无法消除，只能减少模型层错误。

## 三、三大范式真值
1. Bagging（自助聚合）：有放回采样多份子集 → 各训一模型 → 投票/均值聚合。降方差、抑过拟合。典型：随机森林（叠加特征采样增多样性）。
2. Boosting（提升）：串行训练，后模型学前面全部模型的错误样本，修正残差 → 加权组合。降偏差，弱模型逐步变强。典型：AdaBoost / XGBoost / LightGBM。
3. Stacking（堆叠）：两层架构——第一层多个异构模型（树/SVM/线性），输出作新特征；第二层元模型学习融合权重。兼顾偏差方差，提上限。

## 四、多样性前提真值
集成增益的前提：基础模型必须存在合理差异（样本不同/特征不同/类型不同/初始化不同）。输出完全一致则集成无增益。

## 五、与 ZONGYUAN-ROOT 架构映射
- 矩阵调度器（异构算子并行）≈ Bagging：多 Agent 独立计算，稳态裁决聚合
- 学习进化机制（失败教训回流、规则增强）≈ Boosting：逐轮修正体系残差
- 多维稳态决策算子（收益/成本/风险裁决）≈ Stacking 元学习器：融合多源信号出最终决策
- 多样性保障 ≈ 多智能体分工/异构模型通道，防止同质化失效

## 六、工程红线
1. 无多样性不集成：基模型同质时禁止宣称精度提升
2. 噪声不可消：报告必须区分模型误差与固有噪声
3. 集成复杂度有成本：收益<成本时回退单模型
4. 决策必须可溯：聚合权重与基模型输出留痕（Merkle-DAG）
