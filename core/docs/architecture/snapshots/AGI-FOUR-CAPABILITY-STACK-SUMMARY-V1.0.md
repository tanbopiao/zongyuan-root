## 二、四层能力定位
1. 语言认知层（大脑）：理解、推理、拆解任务、构建逻辑世界观。解决：看懂目标、生成方案。短板：无落地能力、存在幻觉。
2. 多模态具象层（视觉载体）：将抽象逻辑、剧本、世界观转化为图像、视频、视听资产。解决：从思维到可视成品。短板：易风格漂移、无自我校验标准。
3. 算子执行层（手脚）：代码、调度、算力调用、文件处理、自动化工程落地。解决：把方案跑通、量产、入库。短板：无自主思考，只能被动执行。
4. 记忆溯源稳态层（良知&底盘）：真值记忆、哈希确权、规则锁档、冲突检测、经验沉淀。解决：根治幻觉、防止漂移、维持长期自洽。短板：不主动生产，只负责校准与稳态固化。
