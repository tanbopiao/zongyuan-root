## 一、为什么 V1.0 不通用（3 个绑定）
1. 绑定工具执行：curl/握手/上报是豆包侧能力，纯文本模型无法执行
2. 绑定资源访问：aka 链接/云服务器只有能联网的模型可读
3. 绑定系统标识：registry/快照是本系统内部状态，其他模型无感知

## 二、通用化三大优化
1. **能力自报**：模型先声明「能执行代码/能联网/纯文本」，按能力走对应分支
2. **链路降级**：握手→上报可降级为「文本真值报告」，学习可降级为「粘贴手册」
3. **规则抽象**：把命令改为行为约束（铁律+汇报格式），任何模型都能遵守
