核心原则：新鲜感 = 已建立规则 × 规则被打破/重新解释的次数

## 一、核心公式
观众觉得新鲜，不是因新设定多，而是因"以为懂这个世界了，然后发现自己错了"。
保鲜关键动作：建立规则 → 让观众相信规则 → 打破或重新解释规则。

## 二、七条保鲜法则（永久执行）
1. 冰山留白：只展示世界10%，每集只揭一层真相，其余留作悬念
2. 视角切换：同一事件从反派/灵族/战魂等视角复述，世界观立体化
3. 设定带代价：每层新能力必须付出代价（记忆/寿命/情感/反噬），拒绝廉价力量
4. 历史纵深：让现在事件成为过去回声；观众视为史实的设定后期可被证明为谎言或被重新解释
5. 环境即角色：场景随情绪/状态变化（密林变色、浮空山呼吸、法阵记忆来访者）
6. 密度呼吸感：小集（情感）与大集（世界观展开）交替，禁止连续抛设定
7. 角色成长解锁新地图：认知提升→视野打开→新区域解锁（青丘→三界→墟境→鸿蒙）

## 三、60集三层递进反转骨架
- 第一层（1-12）：以为封印是保护 → 13-24 发现是囚禁
- 第二层（25-36）：以为敌人在墟境 → 37-48 发现堕渊伪神只是棋子
- 第三层（49-60）：以为创世是终点 → 60集发现创世是被设计的轮回，鸿蒙之上还有更古老秩序

## 四、每集生成前自检三问（至少中两问）
1. 这一集是否让观众对世界产生新的疑问？
2. 是否重新解释或动摇了某个旧设定？
3. 结束时世界是否比开播时多一个未解之谜？

三问全不中 = 消耗性一集，须重写。
