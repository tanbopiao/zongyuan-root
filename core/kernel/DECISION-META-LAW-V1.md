# 决策元法则 · 标准公式 V1.0
> 来源：云端母本 kernel.html | 固化：2026-10-11 | DID-BR-000002 | Ω₀⊂⊙∞⊂Ω

## 公式
```
P = 0.3U − 0.4R − 0.3C
```
- U = 收益（Utility）| R = 风险（Risk，权重最高）| C = 成本（Cost）
- **P ≥ 0.7** → 立即自愈校准（执行）
- **P < 0.3** → 强制回滚纯净母版（熔断）
- 0.3 ≤ P < 0.7 → 审慎评估/人工审批

## 与稳态评估的关系
- 四维稳态评分（自洽/冲突/资源/风险）用于体系进化门槛（≥80）
- 决策元法则 P 用于单次操作的自愈/回滚判定（操作级）
- 两者互补：体系级稳态 + 操作级决策
