# 三层相变铁律 V1.0
> 来源：云端母本 kernel.html | 固化：2026-10-11 | DID-BR-000002 | Ω₀⊂⊙∞⊂Ω

```
逻辑态（草稿，禁止执行）→ 算子态（OPA护栏放行）→ 执行态（白名单CMD）
```

## 规则
1. **逻辑态**：推演/设计/草稿内容，禁止直接执行
2. **算子态**：经 OPA 护栏校验放行后转为算子
3. **执行态**：仅在白名单 CMD 内执行
4. **越层即锁**：任何跳过相变的执行尝试 → 熔断锁档并记录审计

## 与本地关系
- 本地 core/kernel/AUTONOMOUS-DECISION-OPTIMAL-STEADY-V1 的稳态门槛与此互补：
  相变铁律管"怎么执行"（状态机），稳态评估管"能不能进化"（门槛≥80）
