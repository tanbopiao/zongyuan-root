API 文档

公开接口规范：试用网关智能路由 · DAL 部署仲裁 · 记忆网关真值上报。所有接口均要求 X-DID 身份头。

POST

试用网关 · 智能路由

官网试用通道核心接口：体系内问题（知识卡/真值库/语义向量）毫秒级本地直答，体系外问题自动转发外部推理，外部不可用时降级本地 1.5B。
POST https://www.huodouai.com/try/chat Headers: Content-Type: application/json · X-DID: DID-BR-000002
请求体
{"messages":[{"role":"user","content":"什么是联邦记忆池"}]}
响应体
{
  "ok": true,
  "reply": "联邦记忆池（SFMP）是ZONGYUAN-ROOT的多节点语义记忆同步系统…",
  "source": "knowledge-card | semantic | ark-external | local-1.5b-fallback",
  "elapsed_ms": 0,
  "锚定": "Ω₀⊂⊙∞⊂Ω"
}
字段说明取值
source回答来源，标识命中层级knowledge-card 知识卡 0ms
semantic 语义向量检索 ~0.5s
ark-external 外部推理 ~30s
local-1.5b-fallback 应急降级
elapsed_ms响应耗时毫秒
限流每 IP 10 分钟 5 次超出返回 429
GET

DAL 部署仲裁层 · 健康检查

DAL（Deployment Arbitration Layer）是云端原子发布仲裁网关：X-DID 动态认证、软链原子发布、一键回滚、配置片段校验、端口池分配。健康检查公开可读。
GET https://www.huodouai.com/dal/health
响应体
{"ok": true, "service": "dal-gateway", "version": "V2.0", "port": 18900, "锚定": "Ω₀⊂⊙∞⊂Ω"}
POST

DAL 部署仲裁层 · 原子发布

节点通过统一客户端 dal-deploy 发起部署/回滚/配置/端口分配/工单投喂，由 DAL 仲裁执行并记账。
POST https://www.huodouai.com/dal/deploy Headers: Content-Type: application/json · X-DID: DID-BR-000002
请求体（动作示例）
{"action": "deploy", "target": "products.html", "content": "<html>…</html>"}
{"action": "rollback", "target": "products.html"}
{"action": "port_alloc", "app": "try-gateway"}
{"action": "inbox_push", "key": "…", "value": {"directive_action": "…"}}
支持动作
action说明
deploy软链原子发布（版本化，可回滚）
rollback一键回滚上一版本
confignginx 配置片段合并（-t 校验失败自动回滚）
port_alloc / port_release / port_register:18xxx 端口池分配与管理
did_register / did_revoke节点密钥 ↔ DID 注册表联动
inbox_push / inbox_ack执行种子工单投喂与确认
POST

记忆网关 · 真值上报

全网真值共识的唯一写入通道：节点将提炼的结构化真值（L0 种子）上报记忆网关，供云端仲裁引擎扫描消费。
POST https://www.huodouai.com/api/report/truth Headers: Content-Type: application/json · X-DID: DID-BR-000002
请求体（规范要点）
{
  "key": "命名空间.key（禁止 truth- 前缀；执行种子用 KERNEL.EVOLUTION.DIRECTIVE. 前缀）",
  "value": {"结构化JSON对象（必须为对象，字符串将被拒）"},
  "truth_type": "meta_law|rule|config|decision|data|creative|risk|protocol|unknown",
  "did": "DID-BR-000002"
}
响应体
{"ok": true, "truth_count": 5211, "seq": 5312, "event_id": "truth-…"}
错误含义
401缺少/错误 X-DID 头
value_must_be_objectvalue 必须是 JSON 对象
empty_value_rejected旧 content/truth_value 顶层字段已失效
