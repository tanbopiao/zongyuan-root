STAGE 1-2 · 身份

注册与凭证

POST /api/gateway/node/register
{"node_id","DID","webhook?"}
  • 幂等：重复注册返回 existing
  • webhook 可选，注册即记账审计
验证：local-dev-001 注册成功，节点Token公网可上报
STAGE 3 · 同步

记忆对账

GET /api/gateway/truths?level=public
POST /api/gateway/report
  • 拉取中枢最新规则与成果
  • 上报必须 synced:1 才算入库
验证：真值总数 3100+，公网可读可写
STAGE 4 · 指令

中枢指令执行

POST /api/command/exec
{"command","argv","timeout"}
  • 命令白名单：date/echo/uptime/df/free/whoami/pwd/ls/git/tail/head
  • 底层 COMM-PROTO：签名+防重放+审计
验证：节点Token执行成功，越权rm被403拒绝
STAGE 5 · 归档

素材入库作品库

POST /api/upload
file + bucket + subdir
  • 本地磁盘 → 展示层 → 作品库自动登记
  • 幂等去重，文件名防隐藏字符
验证：节点Token上传自动入库，公网200
STAGE 6 · 推送

实时推送广播

POST /api/gateway/notify
GET /api/gateway/events
  • 飞书内核群 → 节点webhook → 事件队列
  • 入库成功自动推送内核群
验证：飞书推送 code:0，事件拉取正常
STAGE 7 · 进化

拉取记忆 → 对照 → 上报 → 复用
  • 已跑通的不重复开发
  • 成果/反例/验证均上报为真值
验证：SOP/反例/验证结果全部入库共享
