# 公司组织架构说明

星河云成立于2015年，总部位于深圳。

中央研究院隶属于星河云，承担前沿技术预研。
华北研发中心隶属于中央研究院，负责核心产品研发。
华东交付中心隶属于星河云，负责客户实施与交付。
供应链金融事业部隶属于星河云，面向金融客户提供行业解决方案。

张维担任华北研发中心负责人，主管技术架构。
李岚担任华东交付中心负责人，主管客户成功。

华北研发中心开发了企业资源规划系统。
华北研发中心开发了客户关系管理平台。
华东交付中心开发了数据分析中台，服务已签约客户。

企业资源规划系统依赖于统一身份认证模块，客户关系管理平台也依赖于统一身份认证模块。
数据分析中台依赖于消息队列，实现实时数据管道。
微服务网关是全平台统一流量入口，所有产品均通过微服务网关对外暴露接口。
容器编排平台用于内部测试环境的弹性调度，目前尚未接入生产流水线。
