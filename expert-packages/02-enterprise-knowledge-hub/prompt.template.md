# 企业知识中枢专家 · 提示词模板

## 场景 1：多部门知识库统一检索
> 公司知识分布在法务、研发、HR 三个部门目录：`{legal_dir}`、`{rd_dir}`、`{hr_dir}`，原文各自保留不集中迁移。请：1) 以部门节点标识 `{node_id}`、归属身份 `{did}` 对三个目录分别执行知识条目入库并构建统一索引账本 `{ledger_path}`；2) 用关键词 `{keyword}` 执行跨部门检索；3) 输出命中条目清单（部门/路径/哈希前缀/时间/标签），并对非同源调用方演示拒绝访问。要求：条目不可变、同路径冲突须标注。

## 场景 2：法务/合同文档归档
> 法务目录 `{legal_dir}` 新增一批合同与审批流程文档。请执行：1) 入库并生成 SHA256 条目索引，标签含 `legal` 与文件类型；2) 运行契约校验：重算哈希验证不可变性、输出 schema 错误与冲突清单；3) 导出索引池摘要（条目数/部门/最近更新/冲突数）供审计。要求：归档后旧条目不删除，后续修订生成新条目。

## 场景 3：研发经验沉淀复用
> 研发团队每次故障复盘/最佳实践产出到 `{rd_dir}`。请建立可复用的知识沉淀闭环：1) 对该目录构建索引，标签含 `rd`、`postmortem`、`playbook`；2) 新员工/值班同学输入问题关键词 `{keyword}`，经 DID 同源校验后跨历史条目检索，定位可复用经验；3) 若同一路径出现新复盘版本，执行冲突消解：新版本保留、旧版本标记 conflict 但保留溯源。要求：只返回元信息，原文按需受控拉取。
