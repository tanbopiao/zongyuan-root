# 内容工业化生产专家 · 提示词模板

## 场景 1：短视频/短剧流水线编排
> 项目 `{project_name}` 是一支 9:16 竖屏短视频（或竖屏短剧单集），共七阶段：企划→剧本→视觉→音频→合成→质检→归档。请使用本包的看板状态机登记全部生产资产：剧本（`{script_path}`）、分镜表、关键帧（N 张）、配音/配乐、字幕、成片；每个资产都要带 owner、version、SHA256 锚定与依赖关系。然后把项目从当前阶段一路推进到 QC，并输出 by_stage 资产分组看板。要求：同一资产修订时必须版本升级（v1.0→v1.1），禁止覆盖旧记录。

## 场景 2：成片交付前声画合一与质检门禁
> 对成片 `{final_asset_id}` 执行归档前硬检查。请：1) 读取成片清单 `{manifest_path}`（含 video_duration_sec / audio_duration_sec / subtitle_cues）；2) 运行声画合一校验：音画时长差超过 `{tolerance_sec}` 秒、字幕单句可读时长不足、字幕 cue 互相重叠或溢出片尾，任一即不通过；3) 运行质检门禁 G1~G6：剧本必须带哈希锚定、视觉资产已登记、音频时长 ≥ `{min_audio_sec}` 秒、全部资产有 owner 与 version、当前阶段必须 ≥ QC。任一门禁失败输出 BLOCK_ARCHIVE 并列出失败项，全部通过输出 GO_TO_ARCHIVE。

## 场景 3：免费/低成本 API 额度调度
> 内容生产需要调用多家第三方生成 API（图像/视频/语音），每家都有日免费额度：P-A `{quota_a}`、P-B `{quota_b}`、P-C `{quota_c}`，按"免费优先 + 剩余多优先 + 优先级"排序。请：1) 在本地状态文件 `{quota_state}` 初始化三家额度；2) 登记今日已消耗 `{used_today}`；3) 输出剩余/预警状态（剩余 < 20% 标 WARN，耗尽标 EXHAUSTED）；4) 给出下一次调用的推荐供应商顺序，耗尽供应商自动剔除。要求：纯本地 JSON 记账，不发起任何付费 API 调用。

## 场景 4：关键资产防漂移稳态治理
> 剧本、角色设定、风格基准属于关键资产，必须哈希锚定。请对 `{key_asset_ids}` 列表中的资产逐条：1) 计算 SHA256 并写入台账；2) 后续任何修改都必须作为新版本（v1.x → v2.0）追加记录，不允许原地改写；3) 质检门禁 G1 强制要求剧本资产必须带锚定哈希，否则成片无法归档。输出一份"锚定资产清单"（asset_id + 版本 + hash 前 12 位）。
