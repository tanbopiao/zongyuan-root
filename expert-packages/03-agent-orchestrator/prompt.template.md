# 智能体编排专家 · 提示词模板

## 场景 1：跨部门资产全景盘点
> 需要对企业 `{root}` 下的全部数字资产做一次全景盘点，覆盖 `{channels}`（如 NAS、知识库、文档库、业务数据库）。请：1) 先用 `plan.py --mode evaluate` 判定是否达到并行编排门槛；2) 若达标，按来源通道生成 2-4 个端到端自持分片，每个分片自行完成"只读检索→统计→识别缺口→标准化输出"；3) 用 `rules_check.py --mode all` 校验负载均衡、依赖合法性、统一 schema 与确权档案；4) 聚合为一份统一台账，列出总量、按来源分布、缺口清单与重复清单。全程只读，写操作必须先列候选等我确认。

## 场景 2：多仓库并行巡检
> 我有 `{repo_count}` 个代码仓库需要做安全与依赖漏洞巡检，每个仓库的流水线为"拉取清单→依赖扫描→静态检查→出报告"。请：1) 把仓库按 2-4 个分片均衡分配（参考预估权重 `{weights}`），单分片占比不得超过 40%；2) 分片间并行、分片内串行，分片间不得互相读写；3) 任一分片失败只标记 `failed_shards` 不阻塞其他分片，瞬时错误最多重试 `{max_retries}` 次；4) 全部完成后按统一 schema 合并巡检台账。

## 场景 3：重大决策多方案并行推演
> 就"`{decision_topic}`"这一重大决策，需要并行推演 `{scenario_count}` 套备选方案（如：自建 vs 采购、保守 vs 激进、区域 A vs 区域 B）。请：1) 每套方案作为一个独立分片，端到端完成"假设设定→收益测算→风险识别→成本估算→三维评分(收益40%/风险35%/成本25%)"；2) 分片间并行；3) 最后聚合为对比台账，给出推荐排序与敏感性说明；4) 台账绑定 `did={did}` 与 plan_id 后归档。
