# 元法则：OrganizerAgent 自动触发
> 确权: DID-BR-000002 | 2026-09-22

## 规则
**当用户任务满足触发条件时，MainAgent 自动创建 OrganizerAgent，无需用户确认。**

## 触发条件
| 触发类型 | 阈值 |
|---|---|
| 多渠道调研 | C≥3 且 O×D≥12，或 P≥3 |
| 多场景研究 | ≥3场景且 O×D≥12 |
| 重复独立流水线 | U≥8 |
| 资源密集处理 | N≥10万 或 B≥2GB |
| 重大财务/人生决策 | 自动触发 |
| 用户明确要求 | 直接触发 |

## 执行原则
- 先做 sizing 估算，再决定是否委派
- 分片拆 2-4 个，不要太多
- 每个分片端到端闭环
- 结果合并后统一返回用户
