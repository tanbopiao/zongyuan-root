# 零成本 HTTP 调度：用免费 API 搭自治智能体体系

很多人觉得搭 AI 自治体系要烧钱：服务器、GPU、API 调用、向量数据库……
但实际上，只要选对通道、错峰调用、用对免费额度，**一套多节点自治体系可以跑在零成本上**。

本文分享 ZONGYUAN-ROOT 体系的真实工程实践：如何用纯 HTTP API + 免费额度，搭出真值库、任务调度、多节点协同的完整自治链路。

## 一、为什么零成本可行

核心思路：**把付费能力降级为免费通道，把重型组件换成轻量替代**。

| 传统方案 | 月成本 | 我们的替代 | 成本 |
|---|---|---|---|
| 云数据库 | ¥200+ | 飞书多维表格 + HTTP API | 免费 |
| 向量数据库 | ¥300+ | Git仓库 + 关键词检索 | 免费 |
| 付费视频API | ¥500+ | 魔搭免费额度 2000次/天 | 免费 |
| 服务器常驻 | ¥100+ | 无服务器函数 + 定时触发 | 免费 |
| 对象存储 | ¥100+ | Git仓库 + 本地磁盘 | 免费 |

关键不是"没有成本"，而是**把成本转移到已有免费资源上**。

## 二、核心架构：纯 HTTP 解耦

整个体系没有 WebSocket、没有消息队列、没有常驻进程。所有节点之间全靠 HTTP POST 通信。

```
本地执行节点 ──POST /api/report/truth──→ 云端真值库
     ↑                                        │
     │                                        ↓
     └──GET /api/truths/─────────────── 拉取待办
```

### 真值上报接口
```python
import requests
requests.post("https://www.huodouai.com/api/report/truth",
    headers={"X-DID": "DID-BR-000002"},
    json={
        "truth_key": "KERNEL.OPERATOR.V2.1",
        "truth_value": '{"executable": 12, "status": "locked"}',
        "source_node": "NODE-DEV-DOUBAO-WORK-001",
        "confidence": 1.0,
        "truth_type": "kernel"
    })
```

就这一个接口，承担了：
- 成果上报
- 状态同步
- 跨节点通信
- 版本锁档

**一个 endpoint 解决四件事，这就是零成本的核心——极简。**

## 三、多节点任务调度：飞书多维表格当中台

不用搭任务队列，直接用飞书多维表格当任务中台：

1. 主节点往表格写任务（任务名、优先级、截止时间、状态）
2. 子节点定时 `lark-cli base +record-list` 拉取待办
3. 干完活更新进度列
4. 全自动，不用买任何调度服务

实测：42 条任务，6 个节点，全部通过这个方式流转，零额外成本。

## 五、避坑实录

### 坑1：不要用云函数常驻
一开始想用 Serverless 函数做心跳保活，结果冷启动延迟 3-5 秒，反而拖慢链路。改成：**本地脚本 + 定时任务**，简单粗暴但快。

### 坑2：不要堆组件
一开始想加向量数据库、消息队列、缓存层，搭到一半发现——**全是免费的但全是多余的**。一个飞书表格 + 一个HTTP接口就够了。

### 坑3：不要重复上报
同一个真值 key 重复 POST，云端会去重，但日志会膨胀。加个本地 `.json` 状态文件，记录上次上报的 key，避免重复。

零成本不是"用爱发电"，是**架构上做减法**：

- 不堆不需要的组件

**极简就是零成本的工程哲学。**
