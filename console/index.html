API文档

📚 快速开始

火斗云智AIOS API完全兼容OpenAI接口规范，您可以直接使用OpenAI SDK或任何兼容工具。

# Base URL
https://api.huodouai.com/v1
# 认证方式
Authorization: Bearer YOUR_API_KEY
# 支持的模型
huodou-7b (7B决策大脑)
huodou-0.5b (自研轻量模型)
huodou-pro (智能路由，自动选最优)
💻 Python示例
from openai import OpenAI client = OpenAI( api_key="YOUR_API_KEY", base_url="https://api.huodouai.com/v1" ) response = client.chat.completions.create( model="huodou-pro", messages=[ {"role": "user", "content": "你好，请介绍一下火斗云智AIOS"} ], temperature=0.7, max_tokens=512 ) print(response.choices[0].message.content)
🌐 cURL示例
curl https://api.huodouai.com/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer YOUR_API_KEY" \ -d '{ "model": "huodou-pro", "messages": [{"role": "user", "content": "你好"}], "temperature": 0.7 }'
