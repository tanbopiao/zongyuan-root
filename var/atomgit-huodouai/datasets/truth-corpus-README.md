## 简介

## 核心特色

1. **真实来源**：全部语料来自已部署的 ZONGYUAN-ROOT 体系（非生成式模板堆砌）
2. **工程可复现**：每条规则含明确触发条件与执行边界，可直接落地
3. **体系化**：公理→法则→规则→提示词四层递进，构成完整约束链
