## 开篇：一个工程问题

我们要让一组 AI Agent 长期自治运行——每天自动做内容、自动对账、自动归档、自动发布，人只在关键节点拍板。这套系统已经跑了一段时间，累计沉淀了 **87,000+ 条结构化真值**，今天把它的工程架构完整拆开讲清楚。

不是 PPT，每一条都有线上接口可验证。

## 一、系统长什么样

整体三层：

```
本地执行层（Agent Workspace）
   ├─ 任务引擎：指令 → 规划 → 执行 → 验证 → 交付
   ├─ 知识网关：真值上报 / 检索 / 对账
   └─ 发布通道：Git 增量发布 + 开放平台聚合

云端记忆网关（Memory Gateway）
   ├─ 真值库：结构化真值 + 幂等去重 + 语义校验
   └─ 状态核验：/status /truths /truth 接口

元内核：全局基准快照 + 共识确权
```

关键设计：执行层和云端**纯 HTTP 解耦**，全程不依赖 SSH，每一步可审计。

## 二、六个核心技术点

### 1. 真值确权网关（Verified Knowledge Gateway）

统一上报接口：`POST /api/report/truth`，字段 key / value / source_node / confidence / truth_type。

工程上做了三件事：
- **幂等写入**：同 key 重复上报自动去重，不会写爆
- **语义前置校验**：写入前先过语义层，冲突和无效真值直接挡掉
- **全网检索**：`/api/truth/{key}` 按 key 精确取回，来源节点可追溯

### 2. 不可变快照流水线（Immutable Snapshot Pipeline）

十二阶段流水线：哈希归档 → 共识确权 → 自愈校验 → 熔断固化 → 稳态验证。

- Merkle 根哈希锚定全资产清单，任何变更可对账检测
- eFuse 熔断：快照固化后进入只读链，防篡改
- 最新基准覆盖 **1,426 项资产**，共识 7/7 通过

### 3. 多 Agent 自治与权限分级

- 中枢只掌全局锚点，非锚点工作各节点自治完成
- 节点互操作：握手 → 对账 → 增量闭环
- 权限分级：能直办不等审批，须审批不绕过中枢

### 4. 自动发布引擎

- 全资产索引自动生成（INDEX.json / INDEX.md / 门户页）
- Git 增量发布：多仓库自动 clone → 增量同步 → commit → push
- 开放平台合集聚合：幂等去重，无限流接口
- 限流规避：优先 Git 通道承载媒体，绕开上传接口频控

### 5. 自适应心跳调优

- 心跳自动执行：握手 → 对账 → 待补队列补推 → 健康判定
- 停滞检测：真值量连续多轮不增长即告警（疑似生产停摆）
- 自动调优：连续健康达标建议降频，异常持续则保持并检查云端

### 6. 零成本 AI 能力接入矩阵

通义万相 I2V/T2V、Agnes Video V2（永久免费）、魔搭 API-Inference（免费 2000 次/天），统一配置化适配，错峰调用，成本归零。

## 四、踩过的坑

- **上传接口限流**：开放平台 `/files/upload` 实测频控严格，改用 Git 通道承载媒体，稳定性大幅提升
- **OpenAPI 覆盖有限**：文章/帖子不在开放 API 范围，发布类动作需网页端登录态
- **多节点重复劳动**：用中枢统一调度 + 结果共享解决，每个节点只做本域工作
