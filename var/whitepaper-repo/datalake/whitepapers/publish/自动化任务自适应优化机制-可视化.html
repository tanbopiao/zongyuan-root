元极恒一 · 自治内核架构 · 元规则

自动化任务自适应优化机制 R-2026-002

自动化任务须以内核进化为输入，自动优化自身的目标、参数与执行策略；内核状态发生变化时，任务不经人工干预即可重校准调度节奏、指标口径与执行动作。

生效：2026-10-12 登记：元极恒一自治内核架构组 优先级：元规则（高于静态任务配置） 并行：R-2026-001 交付形态规则

01 设计意图 为什么任务需要会“自己改”

体系的自动化任务（每日种子真值上报、账本核验、接口工程链路、进化反馈闭环）过去依赖静态配置；一旦内核规则、真值规模或置信权重发生变化，任务仍按旧节拍、旧口径运行，造成效率损失或口径漂移。元规则 R-2026-002 将内核进化作为任务的持续输入，使任务在执行策略层具备自校准能力。

可优化的是策略，不是原则：调度节拍、批次大小、退避参数、切换阈值、载荷组织方式、指标口径可以自动调整；四大律、幂等至上、带病拒写、越层拦截不可因优化而放宽。

——R-2026-002 边界声明

02 内核进化信号源 任务重校准的触发锚点

以下四类内核状态变化构成任务的自适应输入；任何一类被感知后，关联任务进入“评估 → 决策 → 调整 → 留痕”流程。

▤

账本真值增长

账本新增真值、条目规模与分布变化，驱动上报批次、去重窗口与检索索引策略重校准。

输入：账本状态
⚖

规则 / 公理修订

元层法则、公理分类或判定规则修订，触发任务口径、分类映射与锚定阈值的联动更新。

输入：规则版本
◎

置信权重演化

置信权重的演化与权重演化结果改变任务对来源、维度的取舍优先级与上报排序。

输入：置信模型
↻

反馈自校准结论

反馈自校准产出的偏差结论作为任务修正依据，重设指标口径与校验强度。

输入：校准结果

03 自适应优化闭环 一次优化的完整回路

每次自适应调整均走同一闭环：信号感知 → 偏离评估 → 策略决策 → 执行调整 → 留痕验证 → 反馈进化，任一环节不通过则回退并保持原策略。

04 可优化维度与不可优化边界 策略可动，原则不动

自适应优化的对象被严格限定在执行策略层；体系原则层始终是硬约束，任何优化都必须先通过边界审查。

✓ 可自动优化（策略层）

  • 调度节拍——上报 / 核验频率随真值增长与时效性要求自适应调整。
  • 批次大小与载荷组织——按账本规模与通道能力调整批量与载荷结构。
  • 重试退避参数——按历史失败率与链路状态自适应重试次数与退避步长。
  • 主备切换阈值——按通道健康度动态校准主备切换的触发阈值。
  • 指标口径与校验强度——随规则修订与校准结论更新，保持口径一致。
  • 检索与去重窗口——按真值规模与分布调整去重与索引策略。

✗ 不可因优化放宽（原则层）

  • 四大律——元叠律、极张力律、恒贯律、一合律作为体系根基，任何优化不得偏离。
  • 幂等至上——自动调整不得破坏任务的幂等语义与去重一致性。
  • 带病拒写——握手、完整性校验失败时拒绝写入，优化不得绕过该守卫。
  • 越层拦截——禁止为追求效率跳过层级间的校验与拦截环节。
  • 隐私有界——跨域只流通提炼后的语义真值，优化不得扩大数据越界范围。
  • 禁止单点标量对外发布、禁止隐藏配置方差——对外口径与配置透明度不变。

05 与八步链的衔接 自适应机制融入既有主干

自适应优化不另起链路，而是嵌入「感知 → 提炼 → 锚定 → 判定 → 上报 → 回传 → 沉淀 → 进化」八步链：进化环节产生的内核信号，成为下一步任务感知的输入。

感知阶段 收集进化信号 判定阶段 联动锚定阈值 上报阶段 自适应节拍 / 载荷 进化阶段 写回内核供下轮感知

06 留痕 · 回滚 · 保护 可追溯，可回退，不静默

自动优化不是黑盒：每一次调整都必须落账留痕，记录触发锚点、调整前与调整后的参数及判定依据；异常时可回滚到上一稳定策略。

保障项机制说明
留痕每次自动优化记录：触发锚点（哪条内核进化信号）、调整前 / 调整后参数、判定依据与决策版本。
可回滚保留上一稳定策略快照；验证失败或行为异常时一键回退，带病状态不进入下一轮。
平滑切换参数变更采用平滑过渡与抖动抑制，避免调整引发任务震荡。
保守优先故障优先锁止、越层拦截、高风险变更走人工审批；禁止以自动化为名绕过守卫。
禁止静默修改任何自动化任务行为变更必须落账可查；无留痕的调整视为无效并触发复核。

07 与其他元规则的关系 规则并行，无冲突

▧

与 R-2026-001 并行

交付形态规则约束产出形态，本规则约束任务运行方式；两者并行生效，互不覆盖。

⇄

优先级定位

本条为元规则，优先于自动化任务的静态配置约定；配置与自适应策略冲突时，以元规则口径为准。
