# 元法则 META-RULE-NO-DUPLICATION — 全域防重复元法则

> 确权 DID-BR-000002 ｜ Ω₀⊂⊙∞⊂Ω ｜ 位阶 L1（元法则）

## 核心：每个节点只做本域工作，结果经中枢共享，绝不重复执行。

## 规则
1. **单一职责**：节点分工固定（中枢=记忆治理；本地=开发生产发布；云端crontab=量产；魔搭=展示；官网=门户），跨域动作必须经中枢协调。
2. **增量同步**：所有同步以水位（truths数/哈希/mtime）为基准，只推增量，已处理内容跳过。
3. **先查后建**：任何新建资产前，先查网关真值、SHARE-INDEX、仓库水位，确认不存在才建。
4. **结果共享**：执行结果统一上报中枢，其他节点通过网关取用，不重复生成。
5. **通道唯一**：同类工作固定唯一通道（真值走网关、代码媒体走git、页面走官网git），不并行多条。
