## 一、定位与核心公理

企业生产数据（ERP/MES/WMS/SCADA/数据库/API/文件/消息队列）**不直接流入模型**，统一经标准化数据网关处理后再供 Agent 使用：

```
企业生产侧 → 采集适配层 → 标准化数据网关 → 实体引用协议层 → Agent 协议栈
```

网关是**唯一边界控制点**：Agent 不直连业务库，只拿到带稳定引用标识与校验哈希的标准化实体视图。

## 二、网关能力（对外口径）

1. **稳定实体标识**：工单/产线/批次/设备/质检单按业务主键获得全局稳定标识，跨轮次、跨 Agent 引用不漂移
2. **Schema 约束校验**：字段类型、单位、值域、枚举白名单在网关把关，越界数据不进入 Agent 链路
3. **快照与校验哈希**：每次数据读取生成带校验哈希的快照视图，可验证完整性与时效
4. **行级权限过滤**：按调用方身份自动过滤厂区、产线与敏感成本字段，越界在网关层拦截
5. **拉取与订阅双模式**：按需查询 + 事件推送（产线状态、报警、质检结果）

## 三、三种接入路径

| 路径 | 机制 | 适用 |
|---|---|---|
| 业务 API 对接 | 标准化 OpenAPI → 网关适配（鉴权/转实体/标识/封包/缓存） | ERP、MES 自研、SaaS 平台 |
| 数据库 CDC 增量 | binlog 变更捕获 → 消息队列 → 网关增量更新视图 | 实时产线、报警、库存 |
| 文件/报表导入 | 目录监听/办公软件推送 → 解析清洗 → 批量注册视图 | 离线周报、盘点 |

## 四、稳态与安全边界

- **只读原则**：模型链路只读视图/快照，写回生产业务系统一律走独立人工审批流程
- **敏感隔离**：财务、成本、工艺配方独立权限域，不进入普通 Agent 可见范围
- **时效保护**：快照带有效期，过期自动失效并强制刷新，防止旧数据误导生产决策
- **审计闭环**：数据读取与引用动作全量记入不可篡改审计日志，可追溯到具体身份与快照版本

## 五、能力边界（诚实声明）

- 本版为对接方案与网关视图公开，不含内核哈希存证与权限裁剪实现细节
- 实时性取决于接入路径（CDC 实时 / API 准实时 / 文件离线），离线数据默认标记，不单独支撑高风险生产决策
