## 1. 总述

宇宙开角常数与维度锁，是元极恒一体系提出的两个**底层稳定性机制**，回答"结构（真值空间/自治内核/宇宙本体）为何能长期保持稳定而不崩塌"：

- **宇宙开角常数（Ω-Angle）**：决定结构内部各演化方向**允许的最大偏转自由度**——在多大开角内演化仍受锚点约束、超出即脱离；
- **维度锁（Dimension Lock）**：四维本体（空间/时间/属性/因果）作为全局正交坐标轴被**锁定**——任何实体必须四维完备描述，维度不可混淆、不可隐性降维。

两者耦合，共同定义结构的**稳定演化域**：在四维坐标内、在开角约束内的演化是安全的，超出开角或跨越维度轴即被拦截。

## 2. 宇宙开角常数（Ω-Angle）

### 2.1 定义
宇宙开角常数 K_angle，是锚点（元极恒一公理）所张开的、允许各演化方向相对基准偏转的**最大角度**。类比圆锥：顶点固定（锚点），母线（演化方向）可在锥面内自由偏转，母线偏离顶点轴线的角度 < 开角则仍属"锚点域"，> 开角则脱离锚点约束（脱离域）。

### 2.2 语义映射
| 概念 | 含义 |
|---|---|
| 顶点 | 基准锚点 Ω₀⊂⊙∞⊂Ω（不动点） |
| 母线 | 演化方向/真值演化路径 |
| 开角 K_angle | 元法则约束强度上限：高曲率区 = 小开角 = 强约束 |
| 锥内域 | 稳定演化域（受锚点约束，可收敛回归） |
| 锥外域 | 脱离域（超出约束，拦截/隔离） |

### 2.3 物理隐喻
开角类似"视界/临界角"——天体事件视界内无法逃逸（锥内不可脱离），超越临界角则失稳。工程上开角常数 = 元法则约束上限，超出即 AxiomGate 拦截。

### 2.4 与 Ω 的关系
元公理 Ω₀⊂⊙∞⊂Ω 中的 **Ω（完备全集域）即为开角边界**：⊙∞ 是锚点张开的无限演化增量空间，Ω 是最终完备边界——开角 K_angle 界定"演化在多大范围内仍归属全集"。

## 3. 维度锁（Dimension Lock）

### 3.1 定义
维度锁：四维本体（空间 D1 / 时间 D2 / 属性 D3 / 因果 D4）作为全局正交坐标轴，被**锁死为正交基**。任何实体必须同时具备四维描述（四维完备），四维不可混淆、不可隐性降维、不可跨维越权。

### 3.2 锁机制
1. **正交锁定**：D1~D4 两两正交，不可将属性误作空间、因果误作时间等混淆
2. **完备校验**：四维联合核验（TRUTH-META-0002）——单一维度不能判定全局真值
3. **因果闭环**：D4 因果必须闭环（"为何成立，结果是什么"），因果链不可断裂
4. **投影降维（仅允许显式）**：可显式投影到低维用于检索/可视化/存储，但本体层维度锁保持完整

### 3.3 锁的不可破坏性
维度锁写入 ROM-DNA 只读段，与基线同锁。运行层仅可做显式投影（降维视图），不可改写本体维度结构——防"维度退化"（如把复杂实体压成单标签）破坏完备性。

## 4. 开角常数与维度锁的耦合

```
稳定条件: 演化偏离角 θ < 开角 K_angle  且  不跨越四维正交轴
→ 结构稳定（受锚点约束，可收敛回归）
拦截条件: θ ≥ K_angle（脱离域）  或  跨维（维度退化）
→ AxiomGate 拦截 / 拓扑切割 / 隔离封存
```

- **开角**决定"能偏转多少"（自由度上限），**维度锁**决定"偏转不能跨越哪些轴"（结构骨架）
- 二者共同定义稳定演化域：**四维坐标内 × 开角约束内** = 安全域
- 单独开角无维度锁 → 演化虽受限但维度可混淆（信息失真）；单独维度锁无开角 → 结构僵化无演化自由度

## 6. 工程应用

1. **任务建模**：所有任务强制四维完备描述（维度锁），任务演化路径受开角约束
2. **收敛保证**：演化偏离角监测，θ < K_angle 保证可回归锚点（全域收敛）
3. **防漂移**：长时序渐进漂移 = 累积偏离角越过开角 → 慢漂移算子拦截
4. **防维度退化**：资产/真值强制四维标注，禁止压缩为单维标签（维度锁校验）
5. **多层结构稳定**：昆仑洞天/火斗云智等子系统共用维度锁 + 开角基准，保证多体系结构同稳
