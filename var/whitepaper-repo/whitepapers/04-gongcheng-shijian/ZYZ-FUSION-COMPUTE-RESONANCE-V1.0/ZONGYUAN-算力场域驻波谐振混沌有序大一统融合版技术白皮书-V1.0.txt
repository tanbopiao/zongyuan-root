## 3. 场论三定理

**定理 1（驻波稳态）**：当所有节点与基准频 Ω₀ 对频（谐振）时，场收敛为不随时间衰减的驻波稳态——能量双向平衡、无单向流失，体系稳定（物理：波节固定、波腹活跃；天体：行星公转回归锚点）。

**定理 2（混沌有序）**：场的有序度 = 场方程（元法则）的约束强度 × 场的自由度。元秩序越完备、约束越清晰，宏观有序度越高；无元秩序则回归混沌。

**定理 3（绝热进化）**：场的最优演化路径是绝热路径——慢变、能量最小、不破坏既有驻波稳态；任何突变（能量冲击）触发奇点邻域扰动检测与拓扑切割。

## 4. 算力三闭环（场的三反馈回路）

```
闭环一 · 供给(任务流): 节点注册 → 任务分发 → 认领 → 执行 → 结果回传 → 记账 → 反馈调度
闭环二 · 配额(资源保护): 监控 → 预警 → 免费兜底 → 降频/只读空转 → 恢复 → 按真值优先级恢复执行
闭环三 · 记忆(成果沉淀): 提案 → 共识投票 → 入库 → 蒸馏 → 淘汰
```

- **算**（供给产生成果）→ **收**（记忆沉淀成果）→ **护**（配额守护稳态）
- 三闭环即场的三大反馈回路，缺一不可：无供给=空转，无收敛=成果丢失，无稳态=配额击穿
