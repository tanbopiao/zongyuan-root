# SFMP 联邦记忆池 · 技术白皮书（公开版）

> 火斗云智 AIOS 记忆底座 · 去中心化 · 可审计 · 可持续演进

SFMP（Shared Federal Memory Pool）面向自治 AI 节点集群提供分布式记忆管理：记忆提案 → 多节点共识投票 → 追加式入库 → 蒸馏迭代 → 价值淘汰 → Merkle 溯源审计，形成完整记忆生命周期闭环，支撑多模型多节点共享记忆协同。

## 核心特性

| 特性 | 说明 |
|---|---|
| 去中心化写入 | 单节点无法单方面篡改记忆，写入须经集群共识 |
| 生命周期自动化 | 提案 / 投票 / 入库 / 蒸馏 / 淘汰全流程自动化 |
| 全链路溯源 | 每条记忆保留来源节点、投票记录与完整性哈希 |
| 仅追加存储 | append-only，历史真值不可被覆盖 |
| Merkle 审计 | 记忆漂移可检测、可告警 |
| 异构兼容 | 支持不同类型 Worker 与多模型协同 |

## 架构

五层结构：记忆提案层 → 共识投票层 → 记忆存储层 → 蒸馏与淘汰层 → 审计溯源层。

## 业务流程

1. Worker 提交记忆提案（附证据 + 哈希摘要）
2. 集群共识投票
3. 达标写入联邦记忆池；不达标丢弃并记录审计日志
4. 定时蒸馏（合并冗余 / 压缩表征）
5. 价值评估 → 低价值自动归档淘汰
6. 随时哈希校验、来源追溯
