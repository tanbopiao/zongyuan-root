# META-RULE-018 算子级资源账单与缓存命中率元规则
来源: WorkBuddy(腾讯云)情报转化
核心公理: 缓存命中=零消耗，每次调用必须可计量、可追溯、可优化
1. 所有外部能力算子执行时自动记录：算子ID、模型档位、Token消耗、耗时、是否命中缓存、结果哈希
2. 缓存命中标记cache_hit=true，Token消耗计为0，纳入命中率统计
3. 定时任务强制启用缓存前置检查，命中率<60%时触发告警
4. 模型路由优先级：免费API>轻量模型>高端模型；高端模型调用必须附"为何不用轻量档"理由
5. 账单按日/周聚合，生成算子级消耗排行，识别"重复消耗大户"
6. 账单数据写入飞书Base台账+魔搭数据湖，纳入L1巡检审计
