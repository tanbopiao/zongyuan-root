# META-RULE-017 视觉帧快照记忆元规则
来源: VISTA(MIT何恺明团队)情报转化
核心公理: 记忆检索不计操作成本，只有真实环境操作才消耗资源
1. 昆仑洞天视觉流水线生成过程自动保存帧级快照（关键帧+中间帧），本地+魔搭双备份
2. 帧快照附带四维元数据（空间/时序/属性/因果），支持按角色/场景/版本检索
3. 回看/对比/放大属于"记忆检索"，不计入操作步数、不消耗模型额度
4. 用于：分镜质检跨帧对比、角色风格一致性校验、L1巡检可视化看板、短剧成片回溯
5. 遵循"永不删除仅分类备份"铁律，失效帧打archive标记；单帧>5MB转WebP
挂载: 昆仑洞天视觉资产自治流水线V1.7增量项；L1全域巡检可视化增强
