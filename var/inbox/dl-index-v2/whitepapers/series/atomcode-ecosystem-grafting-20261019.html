一、摘要与定位

本白皮书阐述 AtomCode（AtomGit 官方闭源二进制 v5.2.3）作为 "免费编码/蒸馏执行手" 接入 ZONGYUAN-ROOT 元极恒一自治体系的完整嫁接方案。AtomCode 不改闭源本体，一切扩展走配置层、插件层、MCP 层，全部可回滚。

核心定位

AtomCode 在生态中承担本地免费执行节点角色——利用 AtomGit CodingPlan 免费额度（qwen3.8-27b / glm5.3-flash），为自治体系提供零成本的编码辅助、真值蒸馏、算子执行通道，与云端 OCTOP 智能体生态形成本地-云端双通道互备。

1.2 嫁接原则

  • 闭源本体不改：AtomCode 二进制本身零修改，所有扩展通过配置/MCP/插件注入。
  • 全部可回滚：MCP server 注册、cron 调度、插件启用均可一键撤销，恢复至嫁接前状态。
  • 最小额度消耗：优先使用免费 qwen3.8-27b，空闲时 0 消耗跳过，单次批量上限受控。
  • 增量优先：每次只处理最小必要单元，不一次性批量执行高消耗算子。

绑定协议

  1. 任务分流：轻量、高频、免费可覆盖的任务走 AtomCode MCP 通道；重量、跨域、需要联邦编排的任务走 OCTOP skill-packages。
  2. 结果回流：AtomCode 蒸馏结果回写本地 truth.db，同时通过记忆网关上报至云端中枢，保持数据一致性。
  3. 故障切换：当 AtomCode 免费额度耗尽或服务不可用时，自动切换至 OCTOP 对应 skill-package 执行，反之亦然。
  4. 锚定统一：两端输出均锚定 Ω₀⊂⊙∞⊂Ω，DID-BR-000002，确保身份与真值溯源一致。
