二、OAuth/OIDC-A 安全层探索

OIDC-A（OpenID Connect for Agents）1.0

arXiv 2509.25974 提出的 OAuth 2.0 生态扩展，专为 LLM Agent 身份与授权设计：Agent 身份声明（DID/委托链/能力）、委托流（on-behalf-of 可追溯）、证明验证流、客户端注册发现。复用 Authorization Code Flow + JWT + JWKS。

NVIDIA NeMo A2A 认证参考（OAuth 2.1 落地）

组件作用
Agent Card 驱动客户端无认证先取 agent-card.json，发现 authorization_url/token_url/scopes
OAuth 2.1 Authorization Code Flow浏览器授权 → JWT access token
JWT 验证（服务端）验签（JWKS）+ issuer + audience + scopes + 过期
自定义 Scopes资源级权限（如 calculator_a2a_execute）
JWKS 端点openid-configuration → certs
安全最佳实践：HTTPS 强制、短生命周期令牌（5-15 分钟）、scope 最小化、audience 校验防令牌替换、密钥轮换。

六、结论

ZONGYUAN-ROOT 已具备 MCP 出口（只读查询）+ A2A 出口（自治Agent）双通道，本次探索补上 OAuth/OIDC-A 安全层：通过 JWKS + JWT 标准认证，让外部生态按标准协议发现、认证、调用 ZONGYUAN 能力；内部信任域保持私有。三协议栈融合实现"对外标准、对内私有"的双模安全架构。
