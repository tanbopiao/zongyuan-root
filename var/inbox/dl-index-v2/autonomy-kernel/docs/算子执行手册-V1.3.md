## 二、逐算子操作指引

### 算子 1：zr_node_protocol（协议层）

```python
from zr_node_protocol import encode_cmd, decode_msg, is_trusted, check_safe, report_truth

# 1. 编码命令（逻辑态→算子态）
msg = encode_cmd("echo hello", src="NN-LOCAL-DEV-001", timeout=300, task_id="t-001")

# 2. 解码消息
parsed = decode_msg(raw_msg)

# 3. 信任校验（防伪）
assert is_trusted(parsed)  # 校验 proto + zr_did

# 4. 命令安全检查（防注入）
ok, reason = check_safe("rm -rf /")  # (False, 拒绝危险命令)

# 5. 真值上报云端
report_truth("REPORT.TEST.20261011", {"content": "..."})
```

**要点**：所有外部命令必须经 `check_safe` 过滤；真值上报遵循 V3.1 协议（value 为含 content 键的对象）。

### 算子 2：zr_node_worker（Worker 层）

```bash
# 启动 Worker
python3 zr_node_worker.py

# 或一键部署
bash bootstrap_autonomy_kernel.sh worker
```

**核心行为**：
- 启动执行 `baseline_self_check()`（ROM-DNA 基线校验）
- 订阅 ntfy 命令通道，执行 `handle_cmd` 处理
- 结果经 `send_result` 回传（含 stdout/returncode）
- 周期心跳 `send_online` 维持节点表

**自动决策闭环**：任务池 → 能力匹配 → AxiomGate 裁决 → 派发 → 结果回传 → 信誉更新 → 记忆蒸馏。

### 算子 4：zr_axiom_gate（裁决器）

```python
from zr_axiom_gate import AxiomGate, risk_three_priority, four_dim_check, QuotaSteady

# 四维本体校验（空间/时间/属性/因果）
four_dim_check(task)

# 风险三优先评分（风险最小>成本最小>收益最大）
allow, risk_level, score, reasons = risk_three_priority(task)

# 配额稳态检查（正常→预警→只读空转）
QuotaSteady().check(quota_left=100, quota_total=500)

# 完整裁决
gate = AxiomGate()
allow, verdict, detail = gate.verify(task)
```

### 算子 5：zr_autonomy_ops（自治算子）


### 算子 6：zr_memory_ab（记忆 + 策略）

```python
from zr_memory_ab import MemoryDistiller, PolicyBandit, distill, prune_memory

# 记忆蒸馏（SFMP 联邦记忆池）

# 陈旧记忆净化

# 派发策略寻优（epsilon-greedy）

best = best_policy()              # 当前最优策略
```

### 算子 7：zr_canary_snapshot（灰度 + 快照）

```python
from zr_canary_snapshot import CanaryRollout, SnapshotMemory

# 灰度发布（三态: canary/active/quarantined）
cr = CanaryRollout()
cr.register("node-a", risk="high")   # 新节点先进 canary
cr.report("node-a", success=True)     # 达到阈值自动转正

sm.rollback_to("t-001")   # 异常回看
```
