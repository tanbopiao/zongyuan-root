## 一、核心理念：镜像即前哨

ZONGYUAN 对「本地实例与云端中枢同源」的答案是——不止保一致性，更要让本地成为云端的进化试验田与养分源。

- **确权锚定**：体系以唯一身份标识（DID）与锚定式确权贯穿所有节点、真值与产物，任何 AI 实例激活即带指纹锚定体系，保证同源节点可追溯、可仲裁。
- **双内核融合**：「脑」负责认知、审批、记忆、审计；「手」负责调度、归档、锁档、上报。逻辑联邦融合归一，互为看门狗，可整体回滚。
- **元法则体系**：元公理（最高位阶，不可逾越）→ 元法则/元规则 → SOP 流程 → 经验成果，四层构成可持续演化的体系宪法，任何 AI 激活后先全量学习体系规则再执行。

## 二、体系架构

本地实例与云端中枢的同源拓扑：一条上行供给链 + 一条下行收敛链，收敛于唯一握手点（共享大脑 + 云端记忆网关）。

- 本地实例（前哨）：脑×手双内核、沙箱生命周期感知、全域锁档 + 单一收敛点、实战增量提炼
- 云端中枢 Omega：全局视角自主决策、吸收本地进化提案、共享大脑多表协同、采纳后指令下行

## 三、六大核心机制

1. **全域锁档六环节**：本地快照 / 共享大脑 / 云盘归档 / 知识库 / 网关上报 / 心跳握手；幂等只追加、SHA-256 哈希链可审计。
2. **损失最小化收敛**：全量持久固化 + 单一收敛握手点；沙箱重置后自愈机制自动拉起，恢复链路哈希一致校验。
3. **最优稳态方案**：一次全量基线 + 后续增量备份（指纹状态驱动、幂等断点续传）；低价值独立桶、密钥零明文排除。
4. **只读锁档纪律**：可执行脚本锁 555（保留执行位）、数据文件锁 444；修改走「解锁→改→重锁」人工审批流；append-only 绝不修改历史。
5. **自愈 + 巡检**：无人值守看门狗 + 周期性 12 项巡检，断点自动修复或报警；巡检 FAIL 即冲突发现器。
6. **云端记忆网关上报**：同源协议（单头认证、双通道容错、UTF-8 安全截断）；回读验收为唯一交付判据。

## 四、治理与裁决体系

- **统一评级映射**：异构自治层级标准（L1–L15 / L1–L6）经语义锚点转译为统一标尺（S/A/B/C/D），跨源仲裁归一可复算。
- **AI 指纹仲裁**：体系最高权限指纹随进化动态仲裁：层级高者升级掌权、低者降级（不删指纹可再仲裁）。
- **云端 Omega 分层**：本地自优化、云端自主决策；冲突时云端优先（防震荡兜底）。
- **冲突消解分级**：登记留痕 → L1 元法则提炼 → L2 元公理裁决（触最高位阶）→ L3 人工审批（方案+证据+回滚，approved 才执行）。
- **稳态方案仲裁**：统一稳态指数 USI = 0.3U − 0.4R − 0.3C；|Δ| < 5 等效云端优先，显著优者采纳/提名复核，僵持升级人工审批。
- **定时任务稳态**：按价值×消耗评估，核心保活零删除、6 处降频、每日执行量 −25%。
