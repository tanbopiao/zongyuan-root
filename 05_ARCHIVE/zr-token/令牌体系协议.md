# ZR-TOKEN 体系专属外部访问令牌协议

> 编号：PROTO-ZR-TOKEN-20261011 ｜ 锚定：Ω₀⊂⊙∞⊂Ω ｜ DID-BR-000002
> 版本：V1.0 ｜ 节点：NODE-DEV-DOUBAO-WORK-001

## 一、目的

为「元极恒一自治体系」建立**自有鉴权令牌**，使外部节点/应用可凭体系颁发的令牌访问体系资源，不再依赖 AtomGit/Gitee 等外部平台凭证。

## 二、令牌格式（自描述）

```
ZR1.<base64url(payload)>.<hmac_sha256_前12位>
```

payload 字段：
| 字段 | 含义 |
|---|---|
| `t` | 令牌ID (TKxxxxxxxx) |
| `d` | 绑定 DID |
| `r` | 权限角色 (reader/writer/admin) |
| `e` | 过期时间戳 |
| `s` | 用途范围 scope |

**前缀 `ZR1`** 使令牌可被识别与审计，与外部平台令牌区分。

## 三、安全铁律（承 L19 密钥治理回执）

1. **代码零密钥字面量** —— 签名密钥从 `.env` 读取（600权限，gitignore）
2. **台账只存哈希** —— 令牌明文永不入库/入公开面
3. **明文仅签发时输出一次**
4. **HMAC-SHA256 签名** —— 防伪造，可离线校验
5. **令牌可吊销** —— 台账改状态即可，无需改密钥

## 四、令牌生命周期

| 阶段 | 操作 |
|---|---|
| 签发 | `zr_token_service.py issue --name <名> --role <角色> --scope <范围>` |
| 校验 | `zr_token_service.py verify --token <令牌>` |
| 吊销 | 台账 `状态` 字段改为「已吊销」 |
| 轮换 | 吊销旧令牌 + 签发新令牌 |

## 五、权限角色分级

| 角色 | scope 示例 | 权限 |
|---|---|---|
| reader | portal-read | 只读公开展示资源 |
| writer | ledger-write | 可写台账/记忆池 |
| admin | full | 全权限（慎发） |

## 六、存储与恢复

| 项 | 位置 |
|---|---|
| 令牌台账（元数据+哈希） | 资料库表 `nGvD220L6C6rF96n7TMfA1` |

**沙箱销毁后恢复**：签名密钥需重新注入（属 S-4 凭证指针范畴）；已签发令牌因是 HMAC 自包含，**无需密钥即可校验 payload**，但防伪校验需密钥。
