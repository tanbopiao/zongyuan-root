## 一、基础回顾：哈希核心公理（5条不变公理）
1. 确定性：相同输入+同一算法，输出哈希完全一致。
2. 定长输出：无论输入大小，输出比特长度固定。
3. 单向抗原像：由哈希值不能反向算出原始输入。
4. 雪崩效应：输入1比特改动，输出哈希大面积随机变化。
5. 抗碰撞：很难找到两组不同输入得到相同哈希摘要。

数学形式：H(M)=h。M为任意原始消息，h为固定长度哈希摘要，H为哈希变换函数。

⚠️ 数学理论上一定存在碰撞，安全哈希的目标：让碰撞在计算上不可实现。

## 二、哈希链深度定义
### 2.1 哈希链深度概念
哈希链深度：从当前区块叶子节点，向前追溯可校验的历史前驱区块层级总数，代表存证链的追溯长度、容错能力、篡改回溯难度。
- 单链区块链：深度=区块高度，仅单一路径向前追溯；
- 标准Merkle树：树深度，仅树内层级，无历史区块链；
- L8-MDAG八前驱架构：多维深度（主链深度 + 7条旁路前驱深度）。

### 2.2 深度分级标准
|深度等级|层级数值|安全等级|适用场景|
|---|---|---|---|
|浅层链|Depth 1~5|low|临时文档、草稿文件、短期台账|
|中层链|Depth 6~30|medium|常规工程文档、日常云盘资产、普通锁档|
|深层链|Depth 31~100|high|核心架构文档、代码库、版本基线、长期归档|
|永恒深度链|Depth>100|Lv8最高级|白皮书、内核协议、确权凭证、本源真值资产|

### 2.3 哈希链深度三大核心价值
1. 篡改追溯能力：深度越高，可回溯的历史快照越多，可快速定位篡改发生的层级与时间点；
2. 容错冗余：多前驱高深度下，少量历史区块丢失，依靠其余深度链路依旧完成哈希核验；
3. 暴力攻击成本指数上涨：攻破深度N的哈希链，需要逐层伪造每一级前驱哈希，算力成本随深度指数级提升。

### 2.4 深度衰减规则
- 正常稳态：每次全域锁档，主链深度+1；
- 300s巡检无异常：深度数值保留、链路加固；
- 副本异常修复完成：修复对应旁路深度，不削减主链深度；
- 若人为删除历史区块：对应链路深度永久冻结不再增长，系统标记「深度残缺告警」。

### 关键漏洞说明
1. 长度扩展攻击（SHA-2系列风险点）：SHA-256/SHA-512存在长度扩展漏洞，攻击者拿到H(M)，可在不知道原文M情况下计算H(M||附加内容)。
   ✅ ZONGYUAN-ROOT方案：动态加盐 + L8多前驱深度分叉，即便单条链路遭遇长度扩展攻击，其余7条高深度旁路依旧校验失效攻击结果。
2. MD5/SHA-1现实危害：不仅单点哈希可碰撞，构建长哈希链时浅层极易逐层伪造，深度越高漏洞越被放大，因此严格限制二者深度上限。

## 四、核心概念辨析：哈希 vs 加密 vs 签名
|类别|是否可逆|核心目标|典型代表|哈希链适配性|
|---|---|---|---|---|
|哈希（散列）|不可逆|生成内容摘要，校验完整性|SHA-256、SHA3-256|唯一可构建哈希深度链|
|对称加密|可逆（同一密钥加解密）|数据保密，可还原原文|AES-256|无法构建追溯深度，仅做存储加密|
|非对称签名|不可逆验证|身份确权、防伪造|RSA、ECC椭圆曲线签名|用于深度区块签名确权，不能充当链底层哈希|

关键误区闭环：哈希不是加密，不能用来加密保存数据；它只证明「内容有没有改动」，无法还原原始内容；同时只有安全哈希，才能搭建高深度可信哈希链。

## 五、Merkle-DAG + 哈希链深度联动（L8-MDAG）
1）传统单链区块深度缺陷：仅一条前驱链路，深度一旦中间区块被篡改、删除，整条追溯链路断裂，深度直接失效。
2）标准Merkle树深度限制：仅存在树形层级深度，无时间维度历史区块深度，无法完成跨版本历史追溯。
3）L8-MDAG八前驱拓扑·多维哈希深度体系：

- 7条旁路深度链：分别对接历史重要版本、架构迭代快照、巡检基准、飞书资产台账、数理真值库、工程SOP、内核元规则七大独立分支；
- 深度联动校验规则：完整稳态：主深度&7条旁路深度全部匹配，300s巡检通过；单旁路深度异常：仅告警，依靠其余8条链路完成核验，主深度不停止增长；主深度连续三次不匹配：系统冻结主深度增长，进入只读保护。

## 六、密码场景哈希补充：普通哈希为什么不能直接存密码
单纯SHA-256(password)不足以存储密码。攻击者可以使用彩虹表暴力穷举。
✅ 工程方案：密码哈希 = PBKDF2 / Argon2（带随机盐+多次迭代）。每个用户独立随机盐；上千轮以上哈希迭代，人为提升计算成本。
深度区分：
1. 资产完整性锁档长哈希链：SHA-256 / SHA3-256（追求吞吐+可高深度延伸）
2. 用户密码保存：禁止构建哈希链，仅单次哈希摘要，使用Argon2id慢哈希。
