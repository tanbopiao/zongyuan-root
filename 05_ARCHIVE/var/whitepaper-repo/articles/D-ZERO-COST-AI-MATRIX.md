## 为什么要零成本

AI 应用跑起来最贵的不是开发，是**每次调用的 API 账单**。视频生成一秒几毛钱，批量做几百条素材钱就烧完了。

我们的做法：把所有能免费调的 API 整理成一张矩阵，错峰调用，把成本压到零。

## 二、怎么接

**通义万相**：在本地配置文件 model_profiles 里注册 model_profile，统一调用接口。

**Agnes**：
```
POST https://api.agnes-ai.com/v1/videos   创建任务
GET  https://api.agnes-ai.com/agnesapi?video_id=xxx   轮询结果
```
创建后轮询，别同步等，会超时。

**魔搭 API-Inference**：
```
POST https://api-inference.modelscope.cn/v1/chat/completions
```
和 OpenAI 接口兼容，直接套 OpenAI SDK 就行。

## 三、错峰调用策略

免费额度有限，硬塞会打爆。我们的策略：

1. **任务排队**：所有生成任务先进队列，不并发打
2. **按额度调度**：每个服务记当天已用量，到阈值就切下一家
3. **失败降级**：一家报错自动切备用通道（比如通义挂了切 Agnes）
4. **非高峰跑批**：重活放凌晨，白天只跑轻量

## 四、实际效果

- 每天视频/图像/文本生成任务全部跑通
- API 调用成本：0
- 批量素材（关键帧 145 张）零成本产出
- 失败自动切换，不用人工盯

## 五、注意事项

1. **免费额度会变**：定期复查各服务政策，别写死假设
2. **限流要尊重**：到量就停，别硬刷，容易封号
3. **留降级通道**：至少备两家，一家挂了不停摆
4. **记录用量**：每天用量记到真值库，方便复盘
