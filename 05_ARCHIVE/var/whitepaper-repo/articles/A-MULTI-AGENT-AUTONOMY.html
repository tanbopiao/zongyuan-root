一 · 执行前想清楚三件事

① 执行层无状态

本地 Agent 跑完就结束，不依赖本地记忆

② 记忆必须外置

所有重要结论写云端，任何节点都能取

③ 发布必须解耦

内容生产和对外发布走不同通道，互不阻塞

二 · 三层架构

本地执行层 ├─ 任务引擎 指令 → 规划 → 执行 → 验证 → 交付 ├─ 知识网关 上报 / 检索 / 对账 └─ 发布通道 Git 增量 + 开放平台聚合 云端记忆网关（纯 HTTP） ├─ POST /api/report/truth 上报真值 ├─ GET /api/truth/{key} 按 key 取 └─ GET /api/report/status 看水位 元内核 └─ 全局基准快照 + 共识确权

三 · 记忆网关接口

POST /api/report/truth { "truth_key": "REPORT.20260920", "truth_value": "今日量产完成...", "source_node": "local-agent-01", "confidence": 1.0, "truth_type": "DAILY" }
  • 幂等去重：同 key 重复上报不写第二遍
  • 语义前置校验：冲突真值写入前拦截
  • 可追溯：每条带 source_node

实测水位：87,000+ 条真值，无写爆。

四 · 自动发布引擎

  • 全资产索引自动生成
  • Git 增量：clone → 同步 → commit → push
  • 开放平台合集聚合（幂等去重）
  • 媒体走 Git 通道，绕开上传限流

五 · 自适应心跳

  • 握手 → 对账 → 补推 → 健康判定
  • 停滞检测：真值连续多轮不涨即告警
  • 自动调优：健康达标建议降频
