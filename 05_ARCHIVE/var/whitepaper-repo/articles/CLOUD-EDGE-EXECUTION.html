云边分离式AI执行体系
云端中枢 + 本地执行节点工程实践

CLOUD-EDGE AI EXECUTION · 2026.09.20
合规声明：本文含人工智能生成合成内容，已按《人工智能生成合成内容标识办法》（2025.9.1施行）添加显式标识。内容为 ZONGYUAN-ROOT 体系原创工程实践。
摘要：一套生产环境持续运行的云边分离式AI执行体系——云端中枢负责决策/记忆/调度，本地执行节点负责流水线/发布/上报。通过HTTP网关解耦，实现零SSH、零GPU、零付费API的低成本自治运转。

1. 背景与现状

多智能体自动化实践中常见两类极端：逻辑全集中在一台服务器（单点故障），或节点完全自治（缺全局真值）。本体系取平衡：云端做"大脑"，本地做"手脚"，HTTP网关保持弱耦合。

2. 体系架构

云端中枢（决策/记忆） ├─ 记忆网关 HTTP API（读状态 / 写真值） ├─ crontab 定时任务调度 └─ 每日量产任务 ↑↓ HTTP 本地执行节点（手脚） ├─ 心跳引擎（每4小时握手+对账） ├─ 短剧流水线（剧本→关键帧→音频→合流） ├─ 社区发布引擎（git增量推送） └─ 本地文件系统（媒体库/配置/锁档）

3. 工程实现要点

3.1 零SSH约束

  • 本地不SSH云端，所有通信走HTTP网关
  • 免密钥维护、免网络打通、任意沙箱可跑
  • 代价：云端不能主动推指令，只能本地轮询拉取

3.2 真值网关

  • 关键操作POST真值记录，形成不可变审计账本
  • M1真值不变 / M2单调收敛 / M3可追溯

3.3 熔断与降级

  • 网关502：不重试，等下一轮心跳
  • 付费API欠费：降级走免费edge-tts+ffmpeg
  • 上传接口限流：改走git增量推送
