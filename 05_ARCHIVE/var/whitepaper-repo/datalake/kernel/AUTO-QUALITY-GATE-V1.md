# 自动质量门禁 V1.0
> 确权: DID-BR-000002 | Ω₀⊂⊙∞⊂Ω

## 核心定位
产出交付前自动校验质量，不合格自动打回，不把垃圾交付给用户。

## 门禁检查项
| 检查项 | 规则 |
|---|---|
| 完整性 | 该有的内容都有了吗 |
| 准确性 | 数字/事实对得上吗 |
| 一致性 | 前后说法一致吗 |
| 可验证 | 能复现/能验证吗 |
| 格式合规 | 符合交付格式要求吗 |

## 流程
```
产出 → 自动门禁检查 → 合格 → 交付用户
                  ↓ 不合格
                  自动修复 → 重新检查 → 直到合格
```
