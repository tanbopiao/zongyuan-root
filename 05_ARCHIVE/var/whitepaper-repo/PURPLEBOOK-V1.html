1. 系统概述与硬件环境约束

  • 定位：云端中枢（决策/记忆）+ 本地执行节点（流水线/发布/心跳）云边架构
  • 本地实例：2 核 CPU / 3.9G 内存，仅跑 CPU 轻量任务（ffmpeg/edge-tts/git）
  • 云端中枢：记忆网关 HTTP API（读状态/写真值），禁 SSH
  • 资源策略：免费额度优先，零 GPU 零付费 API

2. 组件清单与依赖版本

  • Python 3 + ffmpeg 4.4 + edge-tts 7.2（本地音频/视频处理）
  • git + modelscope 仓库（魔搭 6 仓库增量发布）
  • 定时任务调度：每日 03:00 进化盘点 / 04:00 IP 量产 / 05:00 魔搭发布 / 05:30 短剧流水线 / 每 4 小时心跳

3. 部署与配置说明

  • 根目录：ZONGYUAN-ROOT/，scripts/ 为可执行脚本，config/ 为配置文件
  • 令牌类敏感文件：chmod 600 本地保存，禁止提交 git 仓库
  • 配置文件：pipeline_config.json / quota_strategy.json / heartbeat_profile.json

4. 熔断与异常处理 SOP

  • 网关 502：不重试，记录异常，等下一轮心跳
  • 方舟 API 欠费：自动降级走免费 edge-tts + ffmpeg 通道
  • 魔搭上传接口限流：规避 /files/upload，改用 git 增量推送
  • 本地沙箱重启：从 config/ 恢复持久化状态

5. 运维与真值上报

  • 所有关键操作上报记忆网关 truth_key（M1 真值不变 / M2 单调收敛 / M3 可追溯）
  • 每批次产出 Merkle 哈希确权，写入 manifest
  • 每周定时任务评审（只读建议，不自动改）
