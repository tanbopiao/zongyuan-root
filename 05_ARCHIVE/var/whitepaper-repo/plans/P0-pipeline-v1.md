## 二、真正端到端流水线设计

```
输入：主题 + 标题
  ↓
[1] 剧本生成（智谱GLM-4-Flash，免费）
  → 输入主题
  → 输出：3-5个场景描述 + 旁白
  ↓
[2] 关键帧生成（Agnes image-2.1-flash，免费）
  → 每个场景生成1张关键帧
  → 9:16竖屏，纯东方神女风格
  → 保存到本地 /images/epXX-kfYY.png
  ↓
[3] 视频生成（硅基流动 Wan2.2-I2V，免费）
  → 用第1张关键帧做首帧
  → 5秒视频，9:16
  → 保存到本地 /videos/epXX-TASK-XXX.mp4
  ↓
[4] 作品入库（直接写works.json）
  → 追加新episodes
  → keyframes指向本地路径
  → video指向本地路径
  → status=published
  ↓
输出：作品库自动展示新作品
```

## 三、各环节API选型（全部免费）

| 环节 | 模型 | 理由 |
|---|---|---|
| 剧本 | 智谱 GLM-4-Flash | 永久免费，中文好 |
| 关键帧 | Agnes image-2.1-flash | 免费额度，东方风格 |
| 视频 | 硅基流动 Wan2.2-I2V | 免费额度，图生视频 |

---

## 四、关键设计决策

1. **本地存储，不用COS** — 视频/图片都存服务器本地磁盘，Nginx直接对外
2. **9:16竖屏** — 所有生成严格竖屏
3. **纯东方神女** — 所有prompt注入L0天元法则约束
4. **逐个生成，不批量** — 一次只生成1个，避免消耗额度
5. **失败自动重试1次** — 单环节失败重试1次，再失败标记failed
