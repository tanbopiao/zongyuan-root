## 2. 核心创新

### 2.1 按需供能推理架构（On-Demand Inference）

```
待命态(零进程): 内存~500MB / CPU≈0%
   │  请求到来
   ▼
拉起模型: 加载2.1GB权重(qwen2.5:3b Q4_K_M)
   │  推理执行 (~22s/次)
   ▼
空闲30s自动卸载: 内存回落至~500MB
```

- **最小内存负载**：空闲时仅保留轻量 HTTP 网关（~20MB）+ 推理服务（~480MB）
- **权重按需加载**：请求到来才加载 2.1GB 模型权重，任务完成即释放
- **冷热分层**：`keep_alive=true` 热模型常驻；`false` 冷模型按需（默认）

### 2.2 持久层冷启动与钩子自恢复（Cold-Start & Hook Autostart）

面对易销毁的沙箱环境，全部算力资产（ollama 二进制 + CPU 依赖库 + 模型权重 2.1GB）归档至本地持久层，由自举触发器一键恢复：

```
持久层部署包(2.1GB)
   ↓ bootstrap_llm_power.sh (8秒)
ollama serve → 模型注册 → 按需网关 → 内核算力注入
   ↓ hook_autostart.sh (cron每小时自检)
环境重置 → 钩子检测缺失 → 自动恢复 → 校验通过
```
