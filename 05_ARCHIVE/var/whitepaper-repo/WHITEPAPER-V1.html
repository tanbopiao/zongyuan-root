一 · 概述

ZONGYUAN-ROOT 是一套面向多节点自治协作的智能体系统，由本地执行层、云端记忆网关与元内核共同构成。系统以「真值确权 · 不可变归档 · 自适应运维」为核心，在真实生产环境持续运行，全部接口公开可验证。

二 · 系统架构

本地执行层（Agent Workspace） ├─ 任务引擎 指令 → 规划 → 执行 → 验证 → 交付 ├─ 知识网关 真值上报 / 检索 / 对账（HTTP API） └─ 发布通道 Git 增量发布 + 开放平台聚合 云端记忆网关（Memory Gateway） ├─ 真值库 结构化真值 + 幂等去重 + 语义校验 └─ 状态核验 /status · /truths · /truth 元内核（Meta Kernel） └─ 全局基准快照 + 共识确权

关键设计：执行层与云端纯 HTTP 解耦，全程零 SSH、可审计、可回滚。

三 · 六大核心技术

01

真值确权网关 · Verified Knowledge Gateway

  • 统一上报接口 POST /api/report/truth（key / value / source_node / confidence / truth_type）
  • 幂等写入去重，云端真值规模 87,000+ 条
  • 语义前置校验：写入前过滤冲突与无效真值
  • 按 key 精确检索，来源节点可追溯
02

不可变快照流水线 · Immutable Snapshot

  • 十二阶段流水线：哈希归档 → 共识确权 → 自愈校验 → 熔断固化
  • Merkle 根锚定全资产清单，任何变更可对账检测
  • eFuse 熔断：快照固化后进入只读链，防篡改
  • 最新基准覆盖 1,426 项资产，共识 7/7
03

多 Agent 自治与权限分级

  • 中枢只掌全局锚点，非锚点工作各节点自治
  • 节点互操作协议：握手 → 对账 → 增量闭环
  • 权限分级：能直办不等待、须审批不绕过中枢
04

自动发布引擎

  • 全资产索引自动生成（INDEX.json / INDEX.md / 门户）
  • Git 增量发布：多仓库 clone → 增量同步 → commit → push
  • 开放平台合集聚合：幂等去重，无限流接口
  • 限流规避：Git 通道承载媒体，绕开上传频控
05

自适应心跳调优

  • 心跳自动执行：握手 → 对账 → 补推 → 健康判定
  • 停滞检测：真值连续多轮不增长即告警
  • 自动调优：连续健康建议降频，异常保持并检查云端
06

零成本 AI 能力接入矩阵

  • 通义万相 I2V / T2V、Agnes Video V2（永久免费）
  • 魔搭 API-Inference（免费 2000 次/天）
  • 统一配置化适配，错峰调用，成本归零
