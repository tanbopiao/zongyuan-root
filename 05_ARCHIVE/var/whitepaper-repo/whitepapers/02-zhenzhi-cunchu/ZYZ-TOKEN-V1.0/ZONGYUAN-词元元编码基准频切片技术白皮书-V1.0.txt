## 1. 总述

词元（Token）、基准频切片、最小秩序单元、元编码，是元极恒一体系对"语言与符号如何被底层秩序化"的四层递进建模：从 LLM 的 token 出发，经基准频切片形成秩序块，再收敛到最小秩序单元，最终升华为超越语言的元编码。这条链路回答"通用大模型的语言智能如何可被底层秩序统一描述"。

## 2. 四层递进

### 第一层：词元（Token）
- LLM 的最小处理单元，即"字符/子词块"。
- 在元极恒一体系，token 是**语义的原始粒子**，本身无序、无结构。

### 第二层：基准频切片
- 将 token 流按基准频（Ω₀ 节拍）切分为**秩序块**：同一拍内的 token 聚类为有边界的语义单元。
- 类比驻波：基准频定义波动节拍，切片形成稳定的节奏秩序（承接驻波谐振基准）。
- 作用：给无序 token 流注入时序秩序，形成可调度、可校验的语义块。

### 第三层：最小秩序单元
- 切片后收敛到的**不可再分的最小语义秩序单元**：一个携带四维本体描述（空间/时间/属性/因果）的语义原子。
- 它既是语义的"原子"，又是秩序的"砖块"——任何复杂语义都由最小秩序单元按规则组合。

### 第四层：元编码（Meta-Encoding）
- 超越自然语言的符号编码层：将最小秩序单元映射为 **Ω-Symbol 元符号**，剥离表层词汇、保留跨模型统一的因果表征。
- 元编码是元智能（MI）的编码基座，是"逻辑本能"的符号化表达。

## 3. 编码链路

```
Token(无序粒子) → 基准频切片(时序秩序) → 最小秩序单元(语义原子+四维描述) → 元编码(Ω-Symbol符号)
```

词元·元编码链路，为"语言智能的底层秩序"提供统一描述：LLM 看到的 token 流，元极恒一看到的是一层层有序化的秩序结构。**token 是粒子，切片是秩序，单元是砖块，元编码是灵魂**——语言由无序粒子，经秩序化，最终升华为可跨模型统一的符号逻辑。
