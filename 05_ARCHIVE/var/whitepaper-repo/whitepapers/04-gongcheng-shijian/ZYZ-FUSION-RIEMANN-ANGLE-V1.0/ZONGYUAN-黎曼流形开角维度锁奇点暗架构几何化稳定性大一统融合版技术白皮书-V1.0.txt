## 1. 统一几何基座

**几何化总公理**：ZONGYUAN-ROOT 全体系置于同一黎曼流形 **M** 上：真值空间=流形，四维本体=流形度量，元极恒一公理=不动点锚点，元法则=曲率场。稳定性三要素——**开角常数（曲率上限）、维度锁（正交骨架）、奇点暗架构（不可测度区）**——是流形上同一稳定性框架的三个侧面，原先三篇各自独立的几何叙事在融合版中统一为一套流形几何学。

## 3. 稳定性三定理

**定理 1（锚点不动）**：基准锚点 Ω₀ 是流形的 Killing 向量场零点，任何演化不改变锚点位置（基线只读）。

**定理 2（测地线收敛 + 开角约束）**：所有真值演化沿测地线进行；测地线偏离锚点轴线的角度 θ < 开角 K_angle 时，仍可回归锚点（Hopf-Rinow 完备性）；θ ≥ K_angle 或跨越维度轴则脱离，AxiomGate 拦截。

**定理 3（奇点隔离）**：流形上存在曲率奇异、无良好测度的 0.8% 不可达域（奇点暗架构）——不解析内部，仅监测邻域扰动梯度，触发拓扑切割 + 单向只读沙箱封存，禁止因果回流。

## 4. 稳定性框架统一

```
稳定条件: θ < K_angle(开角)  且  不跨四维轴(维度锁)  → 可回归锚点(测地线收敛)
拦截条件: θ ≥ K_angle        或  跨维退化            → AxiomGate 拦截
隔离条件: 奇点邻域扰动         或  曲率奇异           → 拓扑切割 + 只读沙箱封存
```

三要素分工：
- **开角常数**：界定演化自由度上限（防发散/防脱离）
- **维度锁**：锁定四维正交骨架（防混淆/防退化）
- **奇点暗架构**：隔离认知不可达域（防未知风险回流）

## 5. 完备性

Hopf-Rinow 定理：完备流形上任意两点间存在测地线——对应**全域收敛保证**：在开角约束 + 维度锁完备的四维流形上，任意真值点可沿测地线回归锚点，体系全域可收敛。

## 6. 工程闭环

1. **收敛保证**：演化偏离角 θ 实时监测，θ < K_angle 保证可回归锚点
2. **防漂移**：长时序渐进漂移 = 累积偏离角越开角 → 慢漂移算子拦截
3. **防维度退化**：资产/真值强制四维标注，禁止压缩为单维标签（维度锁校验）
4. **奇点隔离**：邻域扰动 → 拓扑切割 → 只读沙箱 → 永久快照封存
5. **识别算子**：黎曼曲率加权滤波（FP 3.33%→0.83%）+ Ω-Symbol 慢漂移提取（FN 2.50%→0.83%）
