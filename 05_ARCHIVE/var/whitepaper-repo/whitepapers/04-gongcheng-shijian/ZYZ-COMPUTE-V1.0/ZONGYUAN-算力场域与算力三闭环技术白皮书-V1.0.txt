## 1. 总述

算力场域，是将本地 Worker、云端节点、免费 API 池（FreeLLMAPI/书生端砚/火山方舟/魔搭 GPU）等全部算力资源，视作一个**统一可调度场域**（类比电磁场），通过三大闭环实现算力的自组织、自平衡、自收敛。算力场域三闭环是元极恒一体系资源层的稳态机制，直接承接 META-RULE-012 配额稳态保护与 META-RES-003 资源判定元法则。

## 2. 算力场域（统一资源场）

| 场域要素 | 含义 |
|---|---|
| 算力场 | 本地+云端+免费池算力的连续统一场，可池化、可调度、可量化 |
| 场密度 | 算力负载分布：高负载区=高场强，低负载区=低场强 |
| 场梯度 | 负载差驱动任务流向：任务自动向低负载节点流动（负载均衡） |
| 场势 | 配额余量/可用额度：势能高=可执行消耗型任务，势能低=降频只读 |
| 谐振耦合 | 节点与基准频对齐，能量高效传递（承接驻波谐振基准） |

## 3. 算力三闭环

### 闭环一：算力供给闭环（任务流）
```
节点注册 → 任务分发(按负载/能力/配额) → 节点认领 → 执行 → 结果回传 → 记账 → 反馈调度
```
保证任务持续、均衡、可审计地流转，杜绝空转与重复占用。

### 闭环二：配额稳态闭环（资源保护）
```
配额监控 → 阈值预警 → 免费API兜底 → 降频/只读空转 → 配额恢复 → 按真值优先级恢复执行
```
承接 META-RULE-012：额度触达阈值自动降级，付费操作强制人工审批，防止配额击穿。

### 闭环三：记忆收敛闭环（成果沉淀）
```
提案(任务结果) → 多节点共识投票 → 共识入库 → 每日蒸馏 → 低价值淘汰
```
保证算力产出的真值成果经共识收敛沉淀，去冗余、可追溯，避免"算了就丢"。

## 4. 三闭环耦合

```
供给闭环(算) → 产出任务结果 → 记忆收敛闭环(收) → 沉淀真值
配额稳态闭环(护) ← 全程监控场势，压力时降频保护
```

- **算**（供给）产生成果 → **收**（记忆）沉淀成果 → **护**（配额）守护算力稳态
- 三闭环缺一不可：无供给=空转；无收敛=成果丢失；无稳态=配额击穿
- 三闭环均为反馈回路，构成算力场域的自组织稳态

## 5. 工程实现

1. **免费通道优先**：场势充足才走付费，遵循"零成本优先调度"
2. **异构池化**：CPU/GPU/本地/云端统一注册入池，任务按能力标签路由
3. **自动熔断**：单节点异常自动隔离，任务重分发到健康节点
4. **成果台账**：每次算力消耗产出登记飞书 Base + 云端联邦记忆池
5. **降级调度算子**：UNI-STEADY-CORE 按负载动态切换 L5~L2 档位
