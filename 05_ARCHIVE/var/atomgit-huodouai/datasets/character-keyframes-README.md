## 简介

## 数据规格

- 格式：PNG/JPG，立绘 1:1 方形基准（可衍生 9:16 竖屏 / 2.39:1 宽屏）
- 一致性：每角色含多视角/多表情关键帧，用于角色一致性微调
- 确权：每帧右下角 Ω₀⊂⊙∞⊂Ω 溯源标识 + SHA256 哈希锚点
