## 简介

**宗源自治内核·媒体资产湖**收录昆仑洞天 IP 体系的纯东方神话视觉资产，覆盖系列关键帧、五态短视频、剧集片段与角色体系图等内容，是「东方神话 + AI 影视工业化」方向的稀缺数据资产——以**角色一致性**与**国风美学锚定**为核心设计原则，可用于文生图、图生视频、角色一致性微调、风格 LoRA 训练等方向。

## 使用场景

1. **文生图 / 图生视频**：以角色体系图为底图，生成风格一致的连续镜头
2. **LoRA 微调**：用于国风神话角色一致性 LoRA 训练（可配合 AIGC 专区训练）
3. **短剧工业化产线**：作为昆仑洞天短剧流水线的视觉资产底座
4. **风格迁移研究**：玄黑·暗金·淡紫 / 水墨·青绿双色板研究
