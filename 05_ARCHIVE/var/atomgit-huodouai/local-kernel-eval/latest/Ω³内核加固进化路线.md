# Ω³ 内核加固进化路线（本地自治内核 · 架构硬化）

> 依据：本地自治内核全维度评估（架构层推演）结论 + 用户给定的六项加固指令。
> 定位：把"评估发现的风险"转化为"内核可执行的进化项"，作为 Ω-Brainμ³ 白皮书 Ch.10 的工程化附录。
> 约束基线：L0 元宪法 / L5 脊髓硬岛（独立硬岛、永久只读） / META-ISO-051 内外隔离 / Merkle-DAG 审计回退 / 三级灰度（仿真→10%→50%→全量） / 元风险预判算子 / 云端网关仲裁。
> 原则：所有进化项只允许写在**可改写/协调层**；核心安全区（L0/L5）保持只读零侵蚀。

---

## 0. 进化项总览与优先级

| # | 维度 | 进化项 | 优先级 | 依赖 |
|---|---|---|---|---|
| E1 | 成本 | 跨平台统一预算账本 + 实时告警 + 超限熔断 | P0 | 无 |
| E2 | 一致性 | 冲突检测签名 + 分叉超阈自动回退 Merkle-DAG 快照 | P0 | Merkle-DAG |
| E3 | 一致性 | 异构一致性校验（≥2 独立推理路径交叉验证） | P0 | 网关仲裁 |
| E4 | 安全 | 外部回灌输入净化 + 沙箱拓扑 | P1 | 元风险预判 |
| E5 | 主权 | 闭源平台抽象适配层 + 供应商中立性演练 | P1 | 无 |
| E6 | 韧性 | 网关主备健康探测 + 协调层降级开关 | P1 | 无 |

**落地顺序**：E1→E2→E3（数据可观测→冲突可收敛→共识可校验）→E4/E5/E6（并行硬化）。

## E1 · 跨平台统一预算账本（成本维度 · P0）

**目标**：消除多平台 token 碎片化与冗余共识超支，内核级掌握全局资源面。

**机制设计**
- 单一账本 `BudgetLedger`：以 `(platform, task_id, model, ts)` 为维度归集 token 消耗与算力占用。
- 三层配额：全局硬上限 / 平台软配额 / 单任务预算；超限触发 `CircuitBreaker` 熔断该路径。
- 实时指标流：P95 时延、token 速率、冗余倍数（实际消耗 ÷ 必要消耗）推送到可观测面板。
- 告警分级：软配额 80% 预警、硬上限 100% 熔断并回退到本地/缓存推理。

**关键接口（契约）**
```
BudgetLedger.charge(platform, task_id, model, prompt_tok, completion_tok) -> remaining
BudgetLedger.reserve(task_id, budget) -> bool
CircuitBreaker.trip(platform|task_id, reason)  # 熔断
BudgetLedger.snapshot() -> 可序列化账本状态  # 供 Merkle-DAG 存证
```

**灰度与回退**：先在仿真环境以只读模式统计（不熔断），验证账本精度后，按三级灰度放量熔断策略；误熔断可经人工评审回退（参考 L5 只读约束外的可改写区）。

**验证指标**：冗余倍数从基线（推演 ~1.8×）压到 ≤1.2×；超支事件数月度归零；熔断误触发率 <1%。

## E2 · 冲突检测签名 + 分叉超阈回退（一致性 · P0）

**目标**：多 LLM 对同因果节点给出冲突结论时，快速识别并回退到最近稳定拓扑快照。

**机制设计**
- 每个外部推理产物附 **冲突检测签名** `ConflictSig = H(topology_patch ‖ source_platform ‖ reasoning_hash)`，进入仲裁前先做签名校验与分叉检测。
- 定义**分叉度** `Δ = |conflicting_causal_edges| / |total_edges|`；当 `Δ > Δ_max`（默认 0.15）自动触发回退。
- 回退目标：Merkle-DAG 中最近的**稳定快照**（通过 DAG 父指针回溯，满足"可审计回退"）。

**关键接口（契约）**
```
ConflictDetector.sign(patch) -> ConflictSig
ConflictDetector.fork_degree(patch, current_topo) -> float
MerkleDAG.stable_snapshot(current_root) -> snapshot_id  # 最近稳定点
Topology.rollback(snapshot_id)  # 经 Merkle-DAG 可审计回退
```

**灰度与回退**：`Δ_max` 先在仿真标定为统计分位值；回退动作本身记录在 DAG，支持人工复盘。

**验证指标**：冲突识别召回率 ≥95%；误回退率 <2%；回退耗时（P95）< 仿真环境 200ms / 生产 1s。

## E3 · 异构一致性校验（一致性 · P0）

**目标**：压制评估中指出的"伪一致收敛"——多平台噪声淹没仲裁导致错误拓扑被共识通过。

**机制设计**
- 对关键因果节点，**要求 ≥2 条独立推理路径**交叉验证，且路径须来自**异构来源**（如豆包 + 闭源模型 + 本地规则引擎，至少两类不同世界观）。
- 校验不是多数投票，而是**交叉证据对齐**：各路径给出 `(结论, 置信, 依据引用)`，一致性算子检查依据是否互相支撑。
- 任一关键节点未通过异构校验 → 该节点标记为"待裁定"，不进入主干拓扑，降级到人工/缓存。

**关键接口（契约）**
```
Consensus.verify(node, paths: list[ReasoningPath]) -> Verdict  # paths 需跨 ≥2 异构源
ReasoningPath = {source, conclusion, confidence, evidence_refs}
Consensus.quorum_policy = "cross_evidence"  # 非 naive majority
```

**灰度与回退**：先在仿真对历史冲突样本重放，统计"伪一致"拦截率；通过后三级灰度放量。

**验证指标**：伪一致拦截率 ≥90%；关键节点校验覆盖率 100%；因校验导致的可用率下降 <5%（用缓存/人工兜底）。

## E4 · 外部回灌输入净化 + 沙箱拓扑（安全 · P1）

**目标**：阻断评估残余风险"提示注入穿透"——外部平台返回内容未经净化直灌可改写区。

**机制设计**
- 所有外部回灌内容先入 **净化管道**：去除/转义指令性片段、剥离隐藏控制字符、限制工具调用意图。
- 净化后内容写入 **沙箱拓扑区**：仅允许写"可改写协调层"，且写入前须过 **元风险预判算子** 扫描（任务前熔断逻辑复用）。
- 沙箱区与核心区（L0/L5）由 META-ISO-051 硬隔离，任何越权写请求被拒。

**关键接口（契约）**
```
Sanitizer.clean(external_payload) -> sanitized  # 输入净化
RiskScan.pre_check(sanitized, target_region) -> RiskVerdict  # 元风险预判扫描
Sandbox.write(region="coordination", patch) -> only-if-readable-region
```

**灰度与回退**：净化规则先以日志模式运行（不拦截），校准误杀率后开启硬拦截；越权写尝试计入安全事件账本。

**验证指标**：提示注入红蓝对抗命中率 ≥98%；越权写尝试拦截率 100%；合法内容误杀率 <1%。

## E5 · 闭源平台抽象适配层（主权 · P1）

**目标**：消除评估残余风险"依赖锁定"——过度绑定单一闭源平台形成切换成本。

**机制设计**
- 定义 **PlatformAdapter** 抽象接口，所有外部平台（含闭源大模型）经适配层接入，内核只依赖抽象，不依赖具体实现。
- 维护 ≥2 个可替换实现（如闭源 A / 闭源 B / 本地兜底），适配器注册表支持热切换。
- **供应商中立性演练**：定期（建议季度）强制将主用闭源平台切到备用，验证内核在替换实现下功能等价。

**关键接口（契约）**
```
PlatformAdapter{ complete(prompt, ctx) -> Completion; health() -> status; cost() -> estimate }
AdapterRegistry.register(name, adapter); .switch_primary(name)
NeutralityDrill.run(scenario) -> 功能等价报告
```

**灰度与回退**：新适配器先影子运行（mirror 流量不生效），校验输出等价后转正；演练失败自动回退主用。

**验证指标**：主用平台不可用时切换时延 <30s；演练年度覆盖 100% 闭源依赖；切换后功能差异 <1%。

## E6 · 网关主备健康探测 + 协调层降级（韧性 · P1）

**目标**：消除评估残余风险"网关单点"——记忆网关主备同时失效时协同中断。

**机制设计**
- 主备端点（`huodouai.com` / `drama.huodouai.com`）**健康探测**：心跳 + 语义探活（发测试 truth 上报，校验回执）。
- 协调层**降级开关**：网关不可达时，核心自治路径（本地拓扑自重构、本地预算账本、本地缓存推理）继续运行，仅"跨平台协同/远端记忆同步"降级。
- 网关恢复后，协调层自动重同步（增量对账，经 Merkle-DAG 校验避免冲突）。

**关键接口（契约）**
```
HealthProbe.probe(endpoint) -> (alive, latency, semantic_ok)
Coordination.degrade(mode="local_only") / .restore()
Resync.reconcile(local, remote) -> conflict_free_patch
```

**灰度与回退**：降级开关默认自动；提供手动 override。探测误判（误降级）计入韧性事件账本，阈值可调。

**验证指标**：网关故障到降级生效 <5s；核心自治在网关全断下 100% 可用；恢复后重同步无拓扑冲突。
