# 火斗云智AIOS · 大模型自治训练托管架构

> 面向 7B / 13B / 34B 开源大模型，提供 LoRA / QLoRA 轻量化微调全链路自治托管。
> 无人值守式工业化微调，替代传统人工值守的手工训练流程。

---

## 一、体系总览

火斗云智AIOS 自治算力托管体系，由 **六层正交隔离模块** 构成，实现大模型微调从数据准备、训练执行、评估验收、资产归档的全链路自治。

整套架构支持**双算力环境调度**：

- **Linux 云 GPU** 高性能训练环境
- **Windows 本地私有化**训练环境

由统一自治内核完成跨环境任务分发、状态监控、熔断回滚。

```
┌────────────────────────────────────────────────────────────┐
│  客户需求 → 内核解析工单 → 智能体处理数据集 → 算力网关分配   │
│     → 自治引擎执行 LoRA/QLoRA 训练 → 指标监测/异常熔断        │
│     → 自动评估量化 → 模型+评估报告哈希锁档 → 交付全套资产     │
└────────────────────────────────────────────────────────────┘
```

## 二、六层架构拆解

### 1. 元规则调度层（Ω-Brainμ 自治内核）

体系顶层决策中枢，加载 L0 元宪法与训练元规则，负责：

- 训练任务优先级判定、配额稳态保护、风险预判熔断
- 自动选择训练环境：Linux 云 GPU / Windows 本地节点调度分配
- 任务异常自决策：超时回收、失败自动重试、超限自动停机
- 只做决策与约束校验，不参与底层算子计算

### 2. 任务编排层（Octop 多智能体工作流）

基于智能体集群构建训练流水线，把微调拆分为标准化子任务，自动串行/并行执行：

- 数据集自动清洗、格式校验、分词过滤、训练集/验证集自动切分
- 训练超参自动推荐、超参网格小范围寻优
- 训练脚本自动生成、版本锁定
- 进度日志、指标自动采集；多阶段任务自动流转，无需人工介入

### 3. 算力适配层（跨环境兼容网关）

统一抽象异构算力，屏蔽 Linux 与 Windows 底层差异：

- **Linux 云 GPU 链路**：SSH 远程调度、GPU 资源占用监控、显存阈值告警
- **Windows 私有化节点链路**：本地进程托管、资源配额限制、权限风险校验
- 算力状态心跳上报，节点离线自动切换备用链路
- 支持 API 基座兜底方案：无 GPU 时借用外部模型基座做参数仿真验证

### 4. 训练执行层（LoRA / QLoRA 轻量化训练引擎）

轻量化微调核心执行单元，适配 7B / 13B / 34B 基座模型：

- 支持 LoRA 全参数微调、QLoRA 4bit / 8bit 量化微调，降低显存门槛
- 实时采集 loss、验证集准确率、PPL 等量化指标
- 训练断点自动保存；触发异常阈值自动暂停训练
- 原生支持行业知识注入、角色话术风格蒸馏、垂类专项能力优化

### 5. 持久化容灾层（魔搭持久层 + Merkle-DAG 哈希锁档）

训练资产永久存储与版本管理：

- 数据集、LoRA 权重、训练日志、评估报告统一推送魔搭数据湖持久存储
- 每一轮训练快照生成 SHA256 哈希，纳入 Merkle-DAG 链条，全资产可溯源
- 支持一键熔断回滚：训练效果不达标，直接回退至上一稳定版本
- 记忆网关同步台账至飞书 Base，构建训练资产记忆池，成果长期留存

### 6. 验收审计层（量化评估与交付模块）

标准化效果验证：

- 自动运行多维度评估基准：领域问答准确率、风格一致性、幻觉检出率、指令跟随能力
- 自动生成可交付评估报告，指标可视化，效果可量化、可对比
- 审计日志全留存，每一步操作、数据修改、训练参数全部留痕，商用项目可审计

| 轻量化为主 | 聚焦 LoRA/QLoRA，无需全参数大算力消耗，适合中小企业垂类模型定制 |
