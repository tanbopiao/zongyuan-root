## 一、是什么

**短剧产线 SDK** 是一套从创意到大片的全链路自动化短剧生产流水线：分集大纲 → 分镜表 → 关键帧提示词 → 视频生成 → 配音台词 → 元秩序归档，一条命令跑通工业化量产。

## 二、核心能力

| 模块 | 能力 |
|------|------|
| **分集大纲** | 输入主题/IP设定，自动生成分集剧情大纲与情绪曲线 |
| **分镜表** | 逐镜头拆分：镜号/画面/提示词/音效/时长，结构化 JSON 输出 |
| **关键帧提示词** | 9:16 电影级国风关键帧，同角色多轮生成形象/色调/风格零漂移 |
| **视频生成流水线** | 关键帧 → 视频合成，支持 10s 分段拼接（如 5 段共 50s） |
| **配音台词** | 台词自动导出，角色音色锚定 |
| **元秩序归档** | 产物四层结构化 + 九元类归类 + Merkle-DAG 主链追加 + SHA256 确权 |

## 六、快速上手

```bash
# 1. 生成分集大纲
python drama_pipeline.py outline --theme "玄汐归墟" --episodes 8

# 2. 拆分分镜表
python drama_pipeline.py storyboard --outline out/outline.json

# 3. 导出关键帧提示词（含角色一致性锚点）
python drama_pipeline.py keyframes --storyboard out/storyboard.json --role 九天玄女

# 4. 视频生成流水线（10s×5 拼接）
python drama_pipeline.py render --keyframes out/keyframes/ --segments 5

# 5. 配音台词导出
python drama_pipeline.py lines --storyboard out/storyboard.json

# 6. 元秩序归档（确权 + 主链追加）
python drama_pipeline.py archive --output out/
```
