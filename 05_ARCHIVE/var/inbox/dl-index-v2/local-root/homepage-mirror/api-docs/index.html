API文档

火斗云智AIOS开放API接口文档

系统状态接口

GET https://www.huodouai.com/api/report/status

获取系统运行状态，包括真值库记录数、节点数量、审计日志等统计信息。

真值上报接口

POST https://www.huodouai.com/api/report/truth

上报真值记录到系统。需要提供truth_key和truth_value字段。

真值列表接口

GET https://www.huodouai.com/api/report/truths?limit=100

获取最近的真值记录列表。支持limit参数控制返回数量。

单条真值接口

GET https://www.huodouai.com/api/report/truth/{key}

根据key获取单条真值记录详情。

错误码说明

200 - 请求成功
400 - 请求参数错误
500 - 服务器内部错误
