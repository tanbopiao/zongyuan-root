1. 两大机制

宇宙开角常数 K_angle锚点张开的允许最大偏转角：母线（演化方向）在锥内自由偏转，θ<开角仍属锚点域（可收敛回归），θ≥开角即脱离域（拦截/隔离）。
维度锁四维本体（空间/时间/属性/因果）锁死为正交基：任何实体四维完备描述，维度不可混淆、不可隐性降维、不可跨维越权；仅允许显式投影。
开角常数与维度锁为元极恒一体系原创理论概念（非物理常数），用于建模"结构如何长期保持稳定而不崩塌"。元公理 Ω₀⊂⊙∞⊂Ω 中 Ω = 开角边界，⊙∞ = 锚点张开的无限演化增量空间。

2. 耦合稳定条件

稳定: 演化偏离角 θ < 开角 K_angle 且 不跨越四维正交轴
拦截: θ ≥ K_angle（脱离域） 或 跨维（维度退化）
→ 触发 AxiomGate 拦截 / 拓扑切割 / 隔离封存

- 开角 = 能偏转多少（自由度上限） · 维度锁 = 不能跨越哪些轴（结构骨架）
- 有开角无维度锁 → 演化受限但维度混淆（信息失真）
- 有维度锁无开角 → 结构僵化无演化自由度

3. 维度锁机制

机制说明
正交锁定D1~D4 两两正交，属性不可误作空间、因果不可误作时间
完备校验四维联合核验（TRUTH-META-0002），单一维度不能判定全局真值
因果闭环D4 因果必须闭环（"为何成立，结果是什么"），因果链不可断裂
投影降维（显式）可显式投影到低维用于检索/可视化/存储，本体层维度锁保持完整
