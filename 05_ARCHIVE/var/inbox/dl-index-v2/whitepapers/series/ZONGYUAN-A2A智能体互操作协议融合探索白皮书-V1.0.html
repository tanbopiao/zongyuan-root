一、A2A 协议总述

A2A（Agent2Agent）：Google Cloud 发起、Linux Foundation 托管的开放标准，2026-03 v1.0.0 生产就绪。定位"智能体互联网的 HTTP"——让不同厂商/框架（LangGraph/CrewAI/Semantic Kernel/自定义）构建的 Agent 标准化协作。
设计原则说明
拥抱代理能力Agent 对等协作，不共享内存/工具/上下文（黑盒交互）
基于现有标准构建于 HTTP、SSE、JSON-RPC 之上
默认安全企业级身份验证与授权（OAuth2.0/OIDC）
长时任务秒级到数天，实时状态更新
模态无关文本/音频/视频流/表单/iframe

A2A 与 MCP 的分工

协议方向定位
MCP（Model Context Protocol）Agent → 工具垂直：Agent 如何接入工具（USB 口）
A2A（Agent2Agent）Agent → Agent水平：Agent 发现/委派/协作（互联网）
一句话：MCP 让 Agent 能干活，A2A 让 Agent 能组队。

AgentCard 安全签名（JWS）

AgentCard 托管于 /.well-known/agent-card.json，支持 JWS 签名（RFC 7515，ES256/RS256）。验证流程：提取签名 → 取公钥（kid/jku）→ RFC 8785 规范化 → 验签 → 信任。支持多签名与密钥轮换。
