## 1. 摘要

SFMP（Shared Federal Memory Pool，联邦记忆池）是火斗云智 AIOS 的记忆底座子系统，面向自治 AI 节点集群提供分布式、可审计、可持续演进的记忆管理能力。系统实现记忆提案、多节点共识投票、记忆入库、蒸馏迭代、过期淘汰与全链路溯源审计的完整生命周期闭环，支撑多模型、多节点在共享记忆之上协同工作。

## 2. 设计目标

1. **去中心化记忆写入**：单节点无法单方面篡改记忆真值，写入须经集群共识。
2. **记忆生命周期自动化**：记忆从提案、投票、入库到蒸馏、淘汰全流程自动化管理，低价值记忆自动归档。
3. **全链路可溯源**：每一条记忆均保留来源节点、投票记录与完整性哈希，任意时刻可回溯。
4. **异构节点兼容**：支持不同类型 Worker 节点与多模型协同，共享同一记忆语义层。
5. **真值优先**：记忆沉淀遵循信息守恒、因果收敛原则，历史真值不可被覆盖。

## 3. 核心架构

SFMP 由五个逻辑层构成：

```
┌─────────────────────────────────────────────────────┐
│ ⑤ 审计溯源层  ·  Merkle 哈希 · 完整性校验 · 漂移检测  │
├─────────────────────────────────────────────────────┤
│ ④ 蒸馏与淘汰层 · 价值权重评估 · 冗余合并 · 归档淘汰   │
├─────────────────────────────────────────────────────┤
│ ③ 记忆存储层  ·  仅追加 append-only · 快照不可原地改  │
├─────────────────────────────────────────────────────┤
│ ② 共识投票层  ·  节点集群投票 · 阈值判定 · 达成入库    │
├─────────────────────────────────────────────────────┤
│ ① 记忆提案层  ·  Worker 发起提案 · 证据哈希绑定       │
└─────────────────────────────────────────────────────┘
```

- **记忆提案层**：集群内任意 Worker 节点可发起记忆提案，提案必须附带事实证据与内容哈希摘要，防止无依据写入。
- **共识投票层**：集群节点对提案真值进行共识投票，达到预设阈值方可入库；未达标提案丢弃并写入审计日志。
- **记忆存储层**：追加式（append-only）存储，历史记录不可原地修改，仅允许新增快照，保证真值不可覆盖。
- **蒸馏与淘汰层**：定期对存量记忆做信息蒸馏（冗余合并、表征压缩），按价值权重自动归档或淘汰低价值条目。
- **审计溯源层**：每条记忆绑定 Merkle 哈希，支持完整性校验与来源追溯，检测记忆漂移。

## 4. 业务流程

```
Worker 提交记忆提案（含证据 + 哈希摘要）
        │
        ▼
集群节点共识投票 ──不达标──► 提案丢弃 + 审计日志
        │ 达标
        ▼
写入联邦记忆池（append-only 快照）
        │
        ▼
定时蒸馏（合并冗余 / 压缩表征）
        │
        ▼
价值评估 ──低价值──► 自动归档 / 淘汰
        │ 高价值
        ▼
长期留存 · 随时哈希校验 · 来源追溯
```

1. Worker 提交记忆提案，附带事实证据与哈希摘要；
2. 集群节点启动共识投票；
3. 投票达标 → 写入联邦记忆池；不达标 → 提案丢弃，记录审计日志；
4. 定时蒸馏：合并冗余记忆、压缩表征，降低存储冗余；
5. 价值评估：低价值记忆标记并自动淘汰归档；
6. 任意时刻可通过哈希校验记忆完整性，追溯来源节点与投票记录。

## 5. 安全与真值约束

- 遵循**信息守恒**、**因果收敛**等元公理，记忆沉淀不引入无依据信息。
- 存储采用**仅追加（append-only）**模式，防止历史真值被覆盖或篡改。
- 采用 **Merkle 哈希审计**，任一记忆被改动即触发漂移检测与告警。
- 去中心化共识写入，避免单点特权篡改。
- 不确定性显式表达：低置信记忆标记"低确信+边界说明"，不作确定性伪装。

## 6. 适用场景

- 多 AI 节点协同任务：跨节点共享任务上下文与中间结论。
- 长上下文记忆共享：突破单节点上下文窗口限制，跨会话延续记忆。
- 自治智能体持续任务：沉淀长期任务记忆，支持增量学习与经验复用。
- 联邦多租户隔离：仅流通语义单元，原始上下文不出域。
