## 硬性约束（防空间撑爆）

- 单仓总量 **≤ 50MB**（到 40MB 触发瘦身告警）
- 单文件 **≤ 1MB**（超出走外部存储/拒绝）
- **禁止二进制**（图片/视频/zip 一律不入仓）
- **推送白名单**：仅 `*.sh / *.md / *.json / *.yaml`，且只进上述 6 类目录
- **增量优先**：真值只推新增/变更，不推全量
