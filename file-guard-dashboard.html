📡 API接口文档

所有接口（除健康检查外）需要在请求头中添加 Authorization: Bearer ZONGYUAN-FILE-GUARD-2026-SECRET

GET /api/file/health - 健康检查（无需鉴权）
GET /api/file/system-status - 系统状态
GET /api/file/status - 查询修改请求状态
GET /api/file/approvals - 列出审批记录
GET /api/file/tasks - 列出任务
GET /api/file/conflicts - 列出待解决冲突
GET /api/file/audit - 审计日志查询
POST /api/file/submit - 提交修改请求（自动层级处理）
POST /api/file/execute - 直接执行修改（绕过队列）
POST /api/file/approve/{approval_id} - 审批通过并自动执行
POST /api/file/resolve-conflict - 人工裁决冲突
POST /api/file/rollback - 回滚文件
