一、引擎定位

DOC-FORGE 是体系文档生成核心：6 种专业模板 + JSON 内容注入 + Markdown/HTML/JSON 多格式导出 + 自动确权签名（DID + 溯源 + SHA256 哈希），全链路文档锻造。

二、6 种内置模板

模板用途结构
whitepaper技术白皮书title→abstract→background→architecture→implementation→conclusion→references
report分析报告title→executive_summary→methodology→findings→analysis→recommendations→appendix
resume一页纸简历header→summary→experience→skills→education→projects
contract协议文档标准商业协议结构
decision_memo决策备忘录决策结构
truth_card真值卡core_truth→derivation→boundary→hash

三、工作流

templates（模板清单）→ generate（模板+JSON内容注入）→ 多格式导出（Markdown/HTML/JSON）→ 自动确权（DID + Ω溯源 + 内容哈希）。
