一、引擎定位

KNOWLEDGE-RETRIEVER 是体系知识资产读取引擎，与归档引擎（meta-order-archive）形成读写双引擎：archive 负责写入归档，retriever 负责读取检索。

二、核心能力

能力说明
全文检索中英文混合分词，匹配度评分排序
标签聚类资产标签统计与聚类
关联推荐基于标签重叠的相似资产推荐
九大元类过滤公理/定理/方法/数据/案例/决策/创意/风险/协议
索引管理资产入库、清空、列表

三、命令体系

index（list/add/clear）→ search（全文检索+元类/标签过滤）→ related（关联推荐）→ tags（标签统计）。索引默认落盘 ~/.knowledge_retriever/knowledge_index.json。

四、真实运行验证（2026-10-09）

实测记录

入库 3 条资产（元学习引擎 / TCK / 因果奇点内核）→

  • search "真值" → 命中 2 条，匹配度 100%
  • related A2 → A1（共享标签"真值" 50%）、A3（共享标签"因果" 50%）
  • tags → 真值×2、因果×2、进化×1、奇点×1

五、应用场景

  • 启动记忆全量激活后的资产语义检索
  • 同源 AI 节点知识交叉引用
  • 知识库按元类/标签快速定位

六、铁律

  • 检索结果必须真实运行验证，禁止编造命中
  • 资产入库带元类标签，保证可过滤性
  • 产物带 Ω₀⊂⊙∞⊂Ω 溯源 + 三层固化
