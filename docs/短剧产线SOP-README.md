## 一、SOP 定位

本 SOP 定义昆仑洞天短剧从创意到成片的**全链路工业化生产标准**，确保：产出质量稳定、角色不漂移、流程可复用、资产可归档确权。

## 二、生产全链路

```
选题/IP设定 ──→ 分集大纲 ──→ 分镜表 ──→ 关键帧提示词
                          │                 │
                          │                 ▼
                          │            视频生成(10s×N拼接)
                          │                 │
                          └──→ 配音台词 ──→ 合成校验
                                               │
                                               ▼
                                       元秩序归档(四层+九元类+Merkle-DAG)
                                               │
                                               ▼
                                 分发：官网画廊/魔搭/Git双仓/知识库
```

## 三、分集大纲标准

| 项目 | 标准 |
|------|------|
| 剧情结构 | 起承转合 + 每集钩子 + 情绪曲线 |
| 集数 | 按 IP 设定，每集 60-120s 叙事单元 |
| 角色 | 锚定 IP 角色库（九天玄女/女娲/太阴月神等） |
| 世界观 | 昆仑洞天位面规则，禁止跨位面属性泄露 |

## 四、分镜表标准（逐镜头）

| 字段 | 要求 |
|------|------|
| 镜号 | 顺序编号 |
| 画面 | 景别+运镜+构图描述 |
| 提示词 | 正向提示词（含角色锚点） |
| 音效 | BGM/环境音/拟音 |
| 时长 | 每镜 3-8s |

**输出**：结构化 JSON，供关键帧与视频生成直接消费。

## 五、关键帧提示词规范（防漂移核心）

**角色一致性三规则（算子25-27）**：
1. **Lv6 多主体文明仿真约束**：防止个体属性/因果关系无约束随机改变
2. **角色元规则隔离校验**：杜绝武器形变/人设崩坏/跨位面属性泄露，校验输出帧右下角 Ω₀⊂⊙∞⊂Ω 完整性
3. **9:16 电影级国风关键帧一致性**：同角色多轮形象/色调/风格零漂移

**视觉硬约束**：
- 画幅：9:16 竖屏（短视频）/ 2.39:1 宽屏（PV）
- 风格：国风仙侠写实厚涂 · 史诗创世氛围 · 伦勃朗光影
- 色调：黑金暗纹 · 月白玄黑银淡紫
- 确权：右下角镌刻 Ω₀⊂⊙∞⊂Ω

## 六、视频生成流水线

- 单段 10s，多段拼接（如 5 段共 50s）
- 生成后逐帧一致性抽检（角色脸/服饰/色调）
- 不合格镜头重跑，禁止带瑕疵进入合成
- 合成后整体校验：时长、比例、字幕、音画同步

## 七、配音台词标准

- 台词按分镜导出，角色音色锚定
- 口型/情绪与画面匹配
- 输出文件：台词JSON + 音频轨（可替换）

## 八、元秩序归档（每个成品必须）

1. SHA256 哈希确权 + DID-BR-000002 绑定
2. 四层结构化拆分（L1元数据/L2内容/L3关系/L4真值）
3. 九元类归档（创意类/案例类）
4. Merkle-DAG 主链追加校验
5. 三层固化：云盘归档 / 知识库节点 / ZONGYUAN-ROOT 内核快照
6. 台账回写 + 记忆网关上报（字段用 value，禁止 content）

## 九、质量门（发片前 Checklist）

- [ ] 分镜表 100% 覆盖大纲剧情
- [ ] 关键帧角色一致性抽检通过
- [ ] Ω₀⊂⊙∞⊂Ω 溯源标识齐全
