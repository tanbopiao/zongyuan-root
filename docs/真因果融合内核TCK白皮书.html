一、问题背景

单一真值缺乏因果解释力——知道"是什么"但不知道"为什么"
单一因果缺乏真值锚定——知道"链条"但无法确权验证

TCK 在算子级将真值（Truth）与因果（Causal）融合，输出融合真值 + 因果网络 + 融合度 D_TC，让每一条真值自带因果解释，每一条因果链获得真值锚定。

二、核心机制：双相态交替迭代

v_{k+1} = T(v_k, c_k)
c_{k+1} = C(v_{k+1}, c_k)

T 为真值算子（吸收因果信息修正真值），C 为因果算子（吸收真值信息重构因果），两相态交替迭代直至收敛。

迭代收敛判定

  • 相邻迭代 delta 小于阈值（如 0.0）→ 判定收敛
  • 收敛后输出最终融合真值 + 因果网络拓扑

三、融合度 D_TC

D_TC = 1 − I(v;c) / (H(v) + H(c))

基于互信息与熵的归一化融合度。D_TC 越接近 0 表示真值与因果高度融合（互相充分解释）；越大表示融合越浅。

四、输出产物

产物说明
融合真值带因果解释锚定的真值命题（Top-N）
因果网络节点 + 有向边 + 奇点标记
融合度 D_TC本次融合深度量化指标
Mermaid 拓扑可直接渲染的因果拓扑图
