## 一、是什么

决策流水线引擎把**决策**从"拍脑袋"升级为工业化流水线：问题定义 → 数据收集 → 方案生成 → 风险评估 → 三维稳态评估 → 决策备忘录 → 元秩序归档，全链路可复算、可追溯。

## 二、三维稳态决策公式（核心）

```
综合评分 = 利益×40% + 风险反向×35% + 成本反向×25%
```

| 维度 | 权重 | 说明 |
|------|------|------|
| **利益** | 40% | 方案带来的正向收益（价值/效率/增长） |
| **风险** | 35% | 概率×影响，反向计分（风险越低分越高） |
| **成本** | 25% | 资源/时间/金钱消耗，反向计分 |

## 三、决策流水线六段

```
① 问题定义 ──→ 决策目标 + 约束条件 + 验收标准
      │
      ▼
② 数据收集 ──→ 真实数据（禁臆造）· 交叉验证 · 来源锚定
      │
      ▼
③ 方案生成 ──→ 至少 3 套备选方案（≥3，含保守/稳健/进取）
      │
      ▼
④ 风险评估 ──→ 六类风险矩阵（法律/财务/运营/声誉/技术/合规）
      │
      ▼
⑤ 三维稳态评估 ──→ 利益40% + 风险35% + 成本25% → 排序 + 推荐
      │
      ▼
⑥ 决策备忘录 ──→ 结构化文档 + 敏感性分析 + 元秩序归档
```

## 四、方案生成规则

- **每套方案三维独立评估**：利益/风险/成本逐项打分
- **综合评分排序**：由工具现算，禁止手工估分
- **敏感性分析**：权重扰动 ±10% 看排序是否翻转
- **推荐方案**：最高分 + 风险可控 + 成本可承受

## 五、风险识别分级（六类）

| 类别 | 评估 | 分级 |
|------|------|------|
| 法律 | 条款/合规 | 低/中/高/极高 |
| 财务 | 现金流/投入 | 概率×影响 |
| 运营 | 流程/供应链 | 概率×影响 |
| 声誉 | 品牌/舆情 | 概率×影响 |
| 技术 | 可行性/依赖 | 概率×影响 |
| 合规 | 监管/许可 | 概率×影响 |

**Top-N 高风险项**：输出缓解建议 + 溯源至具体条款/节点。

## 六、决策备忘录模板

```markdown
# 决策备忘录
- 决策ID / 日期 / 决策者
## 1. 问题定义
## 2. 备选方案（≥3套）
## 3. 三维稳态评估表（利益40/风险35/成本25）
## 4. 综合评分与排序
## 5. 风险矩阵 + Top-N 高风险
## 6. 推荐方案 + 敏感性分析
## 7. 执行计划 + 回滚预案
## 8. 元秩序归档（哈希/元类/溯源）
```

## 七、铁律

| 规则 | 说明 |
|------|------|
| 数据必须真实 | 禁臆造数字，未取得标"待补充"并写口径 |
| 评分必须工具计算 | 汇总/排序/换算用工具现算 |
| 方案 ≥3 套 | 不足 3 套不算完成 |
| 风险分级必须概率×影响 | 不能凭感觉定级 |
| 敏感决策需审批 | 重大决策走人工确认 |

## 八、应用场景

- 任务认领优先级排序（每小时自治调度）
- 技术方案选型（部署通道/存储后端/模型选型）
- 业务决策（商业化/定价/合作）
- 资源分配（配额/算力/人力）
