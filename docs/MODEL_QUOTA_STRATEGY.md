## 🛡️ 熔断机制

### 三级熔断
| 级别 | 触发条件 | 动作 |
|------|----------|------|
| **LEVEL 1** | 今日累计 ≥ ¥15 | 降级到 Ollama 本地模式 |
| **LEVEL 2** | 本周累计 ≥ ¥100 | 暂停所有付费 API，人工审核 |
| **LEVEL 3** | 本月累计 ≥ ¥350 | 停止所有付费 API，仅本地 |

### 熔断执行
```bash
# 自动触发
check_circuit_breaker() {
    current_cost=$(get_daily_cost)
    
    if [ $current_cost >= 15 ]; then
        # 写降级标记
        echo '{"mode":"ollama_fallback"}' > /tmp/api_circuit_breaker.json
        
        # 通知运维
        notify "🚨 API 熔断触发，切换本地模式"
    fi
}
```
