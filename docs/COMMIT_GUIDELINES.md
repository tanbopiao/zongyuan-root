# ZONGYUAN-ROOT Git提交规范

## 提交信息格式
```
<类型>(<范围>): <简短描述>

[详细描述（可选）]

[关联问题/工单（可选）]
```

## 类型说明
- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档更新
- `style`: 代码格式（不影响功能）
- `refactor`: 重构（既不是新功能也不是修复bug）
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建/工具/依赖管理
- `security`: 安全相关
- `config`: 配置变更

## 示例
```
fix(workflow): 修复工作流中文乱码问题

- 删除损坏的workflows.json数据
- 重启AIOS服务清除内存缓存
- 重新创建3个标准工作流模板

fixes #123
```

## 预提交检查
每次提交前自动运行：
1. Python语法检查
2. 敏感文件检查（禁止提交.env）
3. 服务健康检查

检查不通过将阻断提交。
