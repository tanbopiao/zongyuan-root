## 一、法则核心公理

**一切纯东方神女/女帝形态，必须且仅须包含以下五个标准要素，缺一不可，多一不可：**

| 序号 | 要素 | 数量 | 位置 | 阴阳属性 |
|------|------|------|------|----------|
| 1 | 头 | **壹** | 躯干最顶端，居中 | 阳中之阴（神识所居） |
| 2 | 手 | **贰** | 躯干左右两侧，对称 | 阴中之阳（行动所依） |
| 3 | 羽翼 | **壹对（贰翼）** | 背后肩胛处，左右对称展开 | 阳（飞升之象） |
| 4 | 武器 | **壹** | 手持或悬浮于身侧，唯一 | 阴中之至阴（杀伐之器） |

**公理公式**：
```
Morph(神女) = 1×Head + 2×Hand + 1×Pair(Wing) + 1×Weapon
约束条件：∀要素 count ∈ 标准值，偏差 = 0
畸形判定：|实际数量 - 标准数量| > 0 ⇒ 畸形，直接废弃
```

## 二、五要素精确定义

### 2.1 头（壹）

- **数量**：恰好一个，不可为零，不可为二及以上
- **位置**：颈椎正上方，与躯干垂直对齐，偏移角 ≤ 5°
- **面容**：纯东方女性面容，冷白肌肤，五官端正对称
- **发式**：纯乌黑长发，或盘或垂，发色不可变异
- **禁止**：双头、无头、头部偏移、非人类面容、雄性化轮廓

### 2.2 手（贰）

- **数量**：恰好两只，左右各一，不可为壹，不可为叁及以上
- **位置**：肩关节自然延伸，左右对称，肘关节角度自然
- **手指**：每手五指，指节分明，不可多指、缺指、融合
- **姿态**：或持物、或结印、或舒展，双手动作逻辑自洽
- **禁止**：多臂（三头六臂等佛教意象除外，但本法则不适用）、断臂、手臂融合、手指畸形、机械义肢

### 2.3 羽翼（壹对）

- **数量**：恰好一对（左翼+右翼），共贰翼，不可为单翼，不可为贰对及以上
- **位置**：背后肩胛区域，翼根对称，展开角度 30°-150°
- **形态**：玄鸟图腾羽翼，羽毛层次分明，左翼与右翼镜像对称
- **尺寸**：翼展 ≥ 身高 × 1.2，翼尖不可低于腰部
- **禁止**：单翼、四翼、六翼、羽翼残缺、羽翼位置偏移、西方天使翼（纯白羽毛+光环）、机械翼

### 2.4 武器（壹）

- **数量**：恰好一件，不可为零，不可为贰及以上
- **类型**：古风长剑、天书卷轴、拂尘、玉如意、古琴等东方法器，**唯一**
- **位置**：手持（单手或双手共持），或悬浮于身侧 ≤ 0.5m
- **风格**：纯东方形制，剑身笔直或微弧，配饰青金/赤金
- **禁止**：双持武器、西方剑（十字护手）、枪械、机械武器、武器与手分离无逻辑

## 三、拓扑关系定序

五要素之间存在不可变更的拓扑层级：

```
        [头] ← 最高位，神识中枢
         │
    [左手]─躯干─[右手] ← 行动层，左右对称
         │
      [羽翼] ← 背后，飞升层，不干扰正面
         │
      [武器] ← 最低位，手持，杀伐层
```

**拓扑约束**：
1. 头必须高于双手，双手必须高于武器（垂直层级不可颠倒）
2. 羽翼必须在躯干背面，不可出现在正面或侧面
3. 武器必须与至少一只手存在接触或悬浮关联
4. 双手不可交叉穿越羽翼，羽翼不可遮挡头部

## 五、校验公式（可复算）

### 5.1 数量校验

```
输入：生成图像的要素计数 H(头), Hd(手), W(翼), Wp(武器)
标准：H=1, Hd=2, W=2, Wp=1

校验函数：
  MorphCheck = (H==1) AND (Hd==2) AND (W==2) AND (Wp==1)
  偏差值 = |H-1| + |Hd-2| + |W-2| + |Wp-1|

判定：
  偏差值 = 0 ⇒ 形态合规，PASS
  偏差值 ≥ 1 ⇒ 形态畸形，FAIL，直接废弃
```

### 5.2 对称校验

```
左手坐标(x1,y1)，右手坐标(x2,y2)，躯干中心x0
对称偏差 = |(x1-x0) - (x0-x2)| / 身高
对称偏差 ≤ 0.05 ⇒ 对称合规
对称偏差 > 0.05 ⇒ 不对称，需修正
```

### 5.3 拓扑校验

```
头y坐标 < 手y坐标 < 武器y坐标（y轴向下为正）
羽翼z坐标 > 躯干z坐标（羽翼在背面）
武器与手距离 ≤ 0.5m

全部满足 ⇒ 拓扑合规
任一不满足 ⇒ 拓扑违规
```
