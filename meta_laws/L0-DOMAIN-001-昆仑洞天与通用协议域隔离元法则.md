## 一、法则核心公理

**ZONGYUAN-ROOT 本源体系内存在两个业务域，必须物理隔离、逻辑隔离、命名空间隔离，禁止跨域污染。**

```
ZONGYUAN-ROOT（共享根层：真值基座 + 自治内核 + 元法则）
├── KUNLUN-DOMAIN（昆仑洞天IP域）── 国风神话IP矩阵
└── LOIP-DOMAIN（通用协议域）────── 逻辑本体智能协议商业化
```

**公理公式**：
```
Domain(KUNLUN) ∩ Domain(LOIP) = ∅  （业务资产交集为空）
SharedRoot = {TruthBase, AutoKernel, MetaLaws}  （仅根层共享）
CrossDomainWrite = FORBIDDEN  （禁止跨域写入）
CrossDomainRead = CONTROLLED  （跨域读取需显式授权）
```

## 四、命名空间隔离规范

### 4.1 文件命名

| 域 | 命名前缀 | 示例 |
|----|----------|------|
| KUNLUN | `KUNLUN-`、`KD-`、角色名 | `KD-EP-002-秩序校准.md`、`太阴月神-战斗形态.png` |
| LOIP | `LOIP-`、`loip_` | `LOIP-SDK-v0.3.0.zip`、`loip_baseline.json` |
| 共享根 | `GLOBAL-`、`AUTOKERN-`、`L0-` | `GLOBAL-SNAPSHOT-20260831.json` |

### 4.2 协议/配置命名

- KUNLUN域的配置文件必须包含 `"domain": "KUNLUN"` 字段
- LOIP域的配置文件必须包含 `"domain": "LOIP"` 字段
- 共享根层配置必须包含 `"domain": "SHARED"` 字段
- 缺少domain字段的文件视为**域归属不明**，需补全后才可使用

### 4.3 ID编号

| 域 | ID前缀 | 示例 |
|----|--------|------|
| KUNLUN | `KD-` | KD-EP-002、KD-ROLE-007 |
| LOIP | `LOIP-` | LOIP-SDK-030、LOIP-API-024 |
| 共享 | `GLOBAL-` / `AUTOKERN-` | GLOBAL-SNAP-001 |

## 五、访问控制矩阵

| 操作 | KUNLUN → KUNLUN | KUNLUN → LOIP | LOIP → LOIP | LOIP → KUNLUN | 任意 → 共享根 |
|------|-----------------|---------------|-------------|---------------|--------------|
| 读取 | ✅ 允许 | ⚠️ 需授权 | ✅ 允许 | ❌ 禁止 | ✅ 允许 |
| 写入 | ✅ 允许 | ❌ 禁止 | ✅ 允许 | ❌ 禁止 | ⚠️ 需锁档 |
| 删除 | ✅ 允许 | ❌ 禁止 | ✅ 允许 | ❌ 禁止 | ❌ 禁止 |
| 引用 | ✅ 允许 | ⚠️ 需标注来源 | ✅ 允许 | ❌ 禁止 | ✅ 允许 |
| 复制 | ✅ 允许 | ❌ 禁止 | ✅ 允许 | ❌ 禁止 | ⚠️ 需标注 |

**核心规则**：
1. **LOIP域绝对禁止写入KUNLUN域**——通用协议不得污染IP核心资产
2. **KUNLUN域读取LOIP域需显式授权**——IP产线可调用LOIP治理能力，但需记录调用
3. **共享根层写入必须经过全域锁档**——任何域不得私自修改真值基座和元法则
4. **跨域引用必须标注来源**——引用对方域资产时必须注明域归属

## 六、数据流约束

### 6.1 允许的跨域数据流

```
KUNLUN视觉资产 → LOIP安全护栏检测（只读调用，不修改原资产）
KUNLUN角色设定 → LOIP基线配置（导出为LOIP基线模板，不回写IP域）
LOIP治理结果 → KUNLUN产线质检报告（作为外部参考，不直接修改IP资产）
共享真值基座 → 双域读取（单向，根层→业务域）
```

### 6.2 禁止的跨域数据流

```
LOIP通用模板 → 直接覆盖KUNLUN角色设定 ❌
KUNLUN角色IP → 打包进LOIP对外SDK ❌
LOIP商业化数据 → 写入KUNLUN IP资产目录 ❌
KUNLUN内部设定 → 作为LOIP默认配置对外暴露 ❌
```

### 6.3 数据脱敏要求

LOIP域引用KUNLUN域资产时，必须执行脱敏：
- 角色内部设定值 → 抽象为通用模板参数
- IP专属视觉元素 → 不可作为LOIP默认示例
- 未公开的剧情/设定 → 禁止进入LOIP对外文档

## 七、违规判定与处置

| 违规类型 | 判定条件 | 处置 |
|----------|----------|------|
| 跨域写入 | LOIP进程写入KUNLUN目录 | 立即阻断 + P0告警 + 回滚 |
| 命名空间污染 | KUNLUN目录出现LOIP前缀文件 | 标记隔离 + 迁移至正确域 |
| IP泄露 | KUNLUN内部设定出现在LOIP对外文档 | 立即删除 + 脱敏重发 + 审计 |
| 共享层私改 | 未经锁档修改真值基座/元法则 | 回滚 + P0告警 + 权限审查 |
| 域归属不明 | 文件缺少domain字段 | 暂停使用 + 补全归属后放行 |

**违规检测公式**：
```
Violation(file) = 
  (file.domain == "LOIP" AND file.path starts_with KUNLUN_PATH) OR
  (file.domain == "KUNLUN" AND file.path starts_with LOIP_PATH) OR
  (file.domain IS NULL AND file.path NOT IN SHARED_PATHS)
```
