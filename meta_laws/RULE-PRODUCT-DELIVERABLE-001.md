## 目的

ZONGYUAN-ROOT 体系对外产品化时，所有产物必须是**真正可运行、可交付、可售卖的产品**，禁止以展示页、静态 demo、纸面方案冒充产品。

## 核心法则

### 法则一：真产品原则
- 产品 = 可运行系统（前端/后端/数据/部署链路完整闭环），用户可直接打开、调用、验收。
- 禁止用 HTML 展示页、原型图、PPT、文档、demo 视频代替可交付产品。
- 营销落地页仅作引流物料，必须标注"产品入口/演示"，不得自称产品本体。

### 法则二：真实验收原则（禁纸面交付）
- 每个功能模块交付前必须实测：进程启动日志、API curl 实测、页面 HTTP 200、数据读写回读。
- 说完成必须有验证证据；说数量必须有实际查询结果；禁止"做了个页面就宣称产品完成"。
- 验收标准：主账号（用户）可直接打开/调用验证，验证不过即返工。

### 法则三：交付物完整性
- 每份产品交付必须附：①可运行产物（代码/部署包）②真实验证结果 ③部署/使用说明 ④开源授权说明。
- 代码/资源获取顺序：魔搭 ModelScope → Gitee 国内镜像 → GitHub 仅兜底。
- 产物内统一品牌"火斗云智AIOS"+ 右下角溯源标识 Ω₀⊂⊙∞⊂Ω。

### 法则四：复用与基准迭代
- 动手前先查已有成果（启动记忆/账本/共享大脑/记忆网关），已存在即复用+真实验证，禁止重复开发。
- 迭代必须在已验收基准上进化，禁止推倒重做；改前先备份，不满意可回退。

### 法则五：合规联动
- 遵守 RULE-PRODUCT-COMPLIANCE-001：禁转售大模型 API/Token/代理通道；引擎仅三通道（客户自有账号/开源本地部署/书面商业许可）。
- 付费支出一律走飞书审批；零成本优先。

### 法则六：确权留痕
- 每个产品版本写入 SHA256 + 启动记忆 + 记忆网关 + Git 三端（gitee/github/atomgit），可溯源、可回滚。
