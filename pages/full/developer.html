核心API能力

POST

图像生成

/api/v2/image/generate

基于角色母版和场景描述生成关键帧，支持LoRA模型调用、风格迁移、批量生成。

POST

视频生成

/api/v2/video/generate

从关键帧生成视频片段，支持5-30秒时长、运镜控制、首帧尾帧约束。

POST

语音合成

/api/v2/voice/synthesize

基于角色声线档案合成对白/旁白，支持情绪参数、语速控制、多角色切换。

POST

多模态质检

/api/v2/qc/inspect

对图像/视频/音频进行AI自动质检，检测负面元素、角色崩坏、音画同步，输出结构化报告。

GET

角色查询

/api/v2/character/{id}

查询已锁档角色的完整设定，包括视觉参数、声线档案、LoRA模型ID、出场记录。

POST

内核状态

/api/v2/kernel/status

查询神经内核运行状态，包括激活节点数、自检结果、进化轨迹、锁档事件链。

POST

批量任务

/api/v2/batch/create

创建批量生成任务，支持60集规模并行调度、失败重试、进度追踪、回调通知。

GET

确权验证

/api/v2/provenance/verify

验证数字资产的确权信息，提取水印、校验哈希链、查询三端存证，生成确权报告。

快速开始

Python
import requests

# 初始化客户端
API_KEY = "your-api-key"
BASE_URL = "https://api.huodouai.com/v2"
headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}

# 生成关键帧
response = requests.post(
  f"{BASE_URL}/image/generate",
  headers=headers,
  json={
    "character_id": "JIUTIAN_XUANNV",
    "scene": "昆仑神殿，红裙战神持枪而立",
    "style": "dark_divine_red_gold",
    "num_images": 4
  }
)
result = response.json()
print(result["image_urls"])

  }'
