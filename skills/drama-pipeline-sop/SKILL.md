## 6步标准生产流程

### 步骤1｜分集大纲生成

输入：项目名称、集数范围、核心剧情走向
输出：每集大纲（集号/标题/核心冲突/关键场景/出场角色/结尾钩子）

```
输出格式：
## EP{编号} {标题}
- 核心冲突：...
- 关键场景：场景1 / 场景2 / 场景3
- 出场角色：...
- 结尾钩子：...
```

### 步骤2｜分集剧本撰写

基于大纲，每集生成完整剧本：
- 场景编号 + 场景描述
- 角色台词（含情绪标注）
- 动作指示
- 转场说明

每集控制在3-5个场景，适配竖屏短剧节奏。

### 步骤3｜分镜表拆分（核心交付物）

将剧本拆分为独立分镜表，每个分镜包含：

| 字段 | 说明 |
|---|---|
| 镜号 | S{集号}-{序号}，如 S03-012 |
| 画面 | 画面内容描述（主体/动作/环境/光影） |
| 提示词 | 生图提示词，含风格、构图、光影参数 |
| 音效 | 背景音乐/音效/环境声描述 |
| 时长 | 单镜秒数（默认3-5秒） |
| 角色 | 出场角色及形态 |

```
输出格式（Markdown表格）：
| 镜号 | 画面 | 提示词 | 音效 | 时长 | 角色 |
|---|---|---|---|---|---|
| S03-001 | ... | ... | ... | 4s | 女娲 |
```

### 步骤4｜关键帧提示词优化

对每个分镜的提示词进行专业优化，确保包含7要素：
1. **主体描述**：角色外观、服饰、姿态、表情
2. **环境描述**：场景、天气、时间、氛围
3. **构图参数**：镜头角度、景别、景深、运镜
4. **光影参数**：光源方向、色温、伦勃朗光/逆光/柔光
5. **风格标签**：国风仙侠写实厚涂 / 黑金暗纹 / 史诗创世
6. **质量标签**：8K、UE5.7全局光追、博物馆馆藏质感、浮雕立体感
7. **确权符号**：画面右下角 Ω₀⊂⊙∞⊂Ω

### 步骤5｜配音台词导出

从剧本中提取全部台词，生成配音脚本：

| 字段 | 说明 |
|---|---|
| 镜号 | 对应分镜 |
| 角色 | 说话人 |
| 台词 | 原文 |
| 情绪 | 平静/激动/悲伤/威严/魅惑等 |
| 语速 | 慢/中/快 |
| 音色参考 | 可选，指定声线类型 |

```
输出格式：
[S03-001] 女娲（威严/中速）："天地初开，万物待生。"
[S03-002] 九天玄女（决绝/快速）："魔族犯境，此战必诛！"
```

### 步骤6｜元秩序归档

调用 `meta-lock-sop` 技能，对本次全部产出执行全域锁档：
- 分集大纲、分集剧本、分镜表、关键帧提示词集、配音台词脚本

卷宗命名规范：`SNAP-KUNLUN-EP{集号范围}`

## 交付清单

每集生产完成必须交付：
1. 分集大纲（Markdown）
2. 分集剧本（Markdown）
3. 分镜表（Markdown表格）
4. 关键帧提示词集（按镜号索引）
5. 配音台词脚本（纯文本，可直接导入TTS）
6. 元秩序锁档回执（调用meta-lock-sop）

## 批量生产模式

当用户指定多集（如"生成EP003-EP005"）时：
1. 并行生成各集大纲
2. 逐集执行步骤2-5
3. 最后统一执行步骤6归档
4. 输出总索引文件 `_INDEX.md`，汇总各集交付物链接

- [ ] 9:16竖屏适配（提示词中明确vertical/9:16）
