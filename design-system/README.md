# 元极恒一 · 设计系统（DESIGN-SYSTEM-V1）

复杂项目的设计系统不是"一套 UI 稿"，而是**可被机器校验、可被版本追溯、可跨终端复用的规则集合**。本仓库是它的单源真值载体。

## 五条铁律

1. **Token 唯一源头**：`tokens/tokens.json` 是全部视觉值的唯一来源。组件、前端、AIGC 提示词、文档一律从它派生，禁止在组件里写死色值与像素。
2. **语义优先**：组件只能引用语义 Token（`text.primary`、`bg.surface`），不得直接引用原始色值（`ink.900`），这样才能一键换主题。
3. **受控扩展**：新增 Token 或组件必须走 `governance/` 的提案流程，附用途与影响范围，人工审批后合并。
4. **变更即记账**：每次合并生成新版本号，记录 SHA256、时间戳、审批人，对齐 ZONGYUAN-ROOT 归档规则。
5. **文档与代码同源**：组件 `.md` 与 story 是规格的一部分，缺文档的组件视为未完成，不得进入交付。

## 落地顺序（不要一次性全铺）

| 阶段 | 动作 | 产出 | 门槛 |
|---|---|---|---|
| 第一周 | 抽取 Token + 5 个基础组件 | tokens.json、button/input/tag/table/modal | 单页能拼出来 |
| 第二周 | 页面模板 + 业务组件 | 列表页、任务卡、回执卡 | 新页面复用率≥60% |
| 第三周 | 治理与巡检 | lint、审计脚本、CI 门禁 | 硬编码零新增 |
| 持续 | 按需扩展 + 废弃归档 | 版本演进 | 复用率≥80% |

## 与体系其他部分的连接

- **前端 / 低代码面板**：由 `tokens/build/` 生成 CSS 变量与 TS 常量，构建期注入。
- **AIGC 视觉资产**：`aigc/prompt-tokens.json` 由 Token 派生，保证官网与生成图同源同调（黑金、勃艮第红、冷蓝青黑）。
- **审计链**：版本变更写入 ZONGYUAN-ROOT 锁档回执，DID-BR-000002 确权。

## 常用命令

```bash
bash scripts/scaffold.sh          # 生成完整目录树（幂等，可重复执行）
npm run tokens:build              # token.json → css/ts
npm run lint:hardcode             # 扫描组件里的硬编码色值/px
npm run audit:tokens              # 校验组件引用的 token 是否存在
```

## 禁止清单

- 在组件里写 `#D4AF37`、`padding: 13px` 这类硬编码；
- 为单个页面新增"只此一处"的组件；
- 直接修改 `tokens/build/` 下的生成物；
- 未经提案就重命名或删除已有 Token（会打断所有下游）。

> 本目录全部资产为 META-003 只读锁档，修改须人工审批解锁。
