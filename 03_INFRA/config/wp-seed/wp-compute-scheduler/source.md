# 全域算力调度引擎

## 一、技能定位

元极恒一自治体系的算力操作系统，统一管理双基座引擎（Seedance 2.0 Mini + MiniMax H3）及多模态生成算力，实现任务的智能路由、负载均衡、成本优化与并发控制，确保高价值任务优先执行、整体算力利用率最大化。

## 二、核心架构

### 2.1 双基座引擎
| 引擎 | 定位 | 优势任务 | 成本等级 |
|------|------|----------|----------|
| Seedance 2.0 Mini | 视频生成主力 | 短剧/创意视频/关键帧动画 | 中 |
| MiniMax H3 | 通用多模态 | 文本/图像/音频/复杂推理 | 中高 |

### 2.2 调度层级
```
┌─────────────────────────────────────┐
│         任务接入层 (API/队列)        │
├─────────────────────────────────────┤
│         优先级排序引擎               │
│    P0(紧急) > P1(高) > P2(中) > P3(低) │
├─────────────────────────────────────┤
│         智能路由引擎                 │
│    基座选择 / 模型选择 / 参数优化    │
├─────────────────────────────────────┤
│         并发控制层                   │
│    令牌桶 / 并发数 / 超时控制        │
├─────────────────────────────────────┤
│         执行层 (双基座)              │
│    Seedance 2.0 Mini | MiniMax H3   │
└─────────────────────────────────────┘
```

## 三、核心能力

### 3.1 任务优先级管理
- **P0 紧急**：用户即时请求、关键路径任务（<30s响应）
- **P1 高**：批量生产主任务、交付截止任务（<5min响应）
- **P2 中**：常规生成任务、预处理任务（<30min响应）
- **P3 低**：后台批量、探索性生成（空闲时执行）

### 3.2 智能路由
- 基于任务类型自动选择最优基座
- 基于当前负载动态调整路由
- 基于成本预算选择性价比最优方案
- 失败自动重试与降级路由

### 3.3 并发控制
- 全局并发数限制（可配置）
- 单用户并发限制
- 令牌桶速率限制
- 超时自动回收与重试

### 3.4 成本优化
- 任务合并（小任务批量执行）
- 闲时调度（低优先级任务移至闲时）
- 参数优化（分辨率/步数/时长的成本权衡）
- 缓存命中（相似任务复用结果）

### 3.5 监控与统计
- 实时队列状态监控
- 任务成功率/平均耗时统计
- 基座利用率统计
- 成本消耗统计与预算告警

## 四、执行流程

### 步骤1：任务接入
- 接收生成任务（图像/视频/音频/文本）
- 任务元数据提取（类型/参数/优先级/预算）
- 入队登记

### 步骤2：优先级排序
- 按P0-P3优先级排序
- 同优先级按FIFO + 截止时间排序
- 紧急任务插队机制

### 步骤3：智能路由
- 任务类型→基座映射
- 负载状态检查
- 成本预算校验
- 路由决策

### 步骤4：并发控制
- 令牌获取
- 并发槽位分配
- 超时计时器启动

### 步骤5：执行与监控
- 调用对应基座API
- 实时状态更新
- 进度回调
- 异常捕获与重试

### 步骤6：结果交付
- 结果校验（完整性/质量）
- 缓存写入（可复用任务）
- 统计更新
- 回调通知

## 五、任务类型与路由规则

| 任务类型 | 首选基座 | 备选基座 | 典型参数 |
|----------|----------|----------|----------|
| 图像生成 | MiniMax H3 | - | 2048×2048, seedream_4.5 |
| 视频生成 | Seedance 2.0 Mini | MiniMax H3 | 10s/段, 9:16 |
| 音频生成 | MiniMax H3 | - | T2A/TA2A, WAV |
| 文本生成 | MiniMax H3 | - | 按任务配置 |
| 批量图像 | MiniMax H3 | - | 并发批量 |
| 短剧视频 | Seedance 2.0 Mini | - | 多段拼接 |

## 六、输入格式

```json
{
  "task_id": "唯一任务ID",
  "task_type": "image|video|audio|text",
  "priority": "P0|P1|P2|P3",
  "payload": {
    "prompt": "生成提示词",
    "params": {"width": 2048, "height": 2048}
  },
  "budget": {"max_cost": 1.0, "max_time": 300},
  "callback_url": "可选回调地址"
}
```

## 七、输出格式

### 7.1 任务提交响应
```json
{
  "task_id": "TASK-20260818-001",
  "status": "queued",
  "priority": "P1",
  "position": 3,
  "estimated_wait": "2min",
  "assigned_engine": "Seedance 2.0 Mini"
}
```

### 7.2 任务完成响应
```json
{
  "task_id": "TASK-20260818-001",
  "status": "completed",
  "result_url": "https://...",
  "engine_used": "Seedance 2.0 Mini",
  "duration": "45s",
  "cost": 0.15,
  "quality_score": 92
}
```

## 八、与其他技能联动

- **上游**：drama-pipeline（短剧视频任务）、collection-card-generator（藏品卡图像任务）、research-pipeline（图表生成任务）
- **下游**：直接调用image_gen/image_to_video/text_to_audio等基础工具
- **监控**：任务状态可触发meta-order-archive归档

## 九、配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| max_concurrent | 5 | 全局最大并发数 |
| max_per_user | 2 | 单用户最大并发数 |
| token_rate | 10/min | 令牌桶速率 |
| task_timeout | 300s | 单任务超时时间 |
| retry_count | 2 | 失败重试次数 |
| cache_ttl | 3600s | 结果缓存时间 |

## 十、执行脚本

任务提交使用 `scripts/submit_task.py`：
```bash
python3 scripts/submit_task.py --task task.json --priority P1
```

队列状态查询：
```bash
python3 scripts/queue_status.py
```
