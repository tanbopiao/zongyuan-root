# Decision Pipeline｜决策工业化流水线

基于三维稳态决策公式的结构化决策支持系统。

## 核心决策公式

**三维稳态决策 = f(利益最大化, 风险最小化, 成本最小化)**

每个方案在三个维度上打分，加权求和得出稳态值，最高者为最优解。

## 核心流程（7步决策流水线）

1. **问题定义**：明确决策目标、约束条件、时间范围、决策主体
2. **方案枚举**：列出所有可行方案（包括"不行动"方案）
3. **数据收集**：调用相关技能收集每个方案的关键数据
4. **三维评估**：对每个方案在利益/风险/成本三个维度打分
5. **敏感性分析**：测试关键变量变化对决策结果的影响
6. **决策备忘录**：生成结构化决策文档，含推荐方案和依据
7. **元秩序归档**：调用meta-order-archive，归档到wiki M8行业知识层

## 三维评估标准

### 利益维度（权重可配置，默认40%）

| 评分 | 标准 |
|---|---|
| 5分 | 显著超额收益，超出预期 |
| 4分 | 达到预期收益，有额外 upside |
| 3分 | 基本达到预期收益 |
| 2分 | 收益低于预期 |
| 1分 | 无明显收益或负收益 |

### 风险维度（权重可配置，默认35%，分数越高风险越低）

| 评分 | 标准 |
|---|---|
| 5分 | 极低风险，有多重防护 |
| 4分 | 低风险，可控可承受 |
| 3分 | 中等风险，需监控 |
| 2分 | 高风险，可能造成实质损失 |
| 1分 | 极高风险，可能造成不可逆损失 |

### 成本维度（权重可配置，默认25%，分数越高成本越低）

| 评分 | 标准 |
|---|---|
| 5分 | 极低成本，几乎无投入 |
| 4分 | 低成本，在预算内 |
| 3分 | 中等成本，需权衡 |
| 2分 | 高成本，超出预算 |
| 1分 | 极高成本，不可承受 |

## 敏感性分析

对排名前2的方案，测试以下变量变化±20%时的排名变化：
- 关键假设变量
- 外部环境变量
- 时间窗口变量

如果排名发生反转，标注为"临界决策"，需额外谨慎。

## 决策备忘录标准结构

1. **决策问题**（一句话定义）
2. **约束条件**（预算、时间、资源、合规）
3. **方案列表**（所有可行方案简述）
4. **决策矩阵**（三维评分+加权总分）
5. **敏感性分析**（关键变量测试结果）
6. **推荐方案**（最优方案+核心理由）
7. **风险提示**（推荐方案的主要风险和应对措施）
8. **执行路径**（下一步行动、里程碑、检查点）
9. **复盘机制**（何时、如何评估决策效果）

## 执行脚本

决策矩阵自动计算使用 `scripts/decision_matrix.py`：

```bash
python3 scripts/decision_matrix.py --input <方案JSON> --weights 0.4,0.35,0.25
```

输入：各方案的三维评分JSON
输出：加权总分、排名、敏感性分析结果

## 决策约束

1. 必须枚举至少3个方案，包括"不行动"方案
2. 每个维度的评分必须有具体依据，不能拍脑袋
3. 权重必须根据决策场景调整，不默认使用
4. 必须做敏感性分析，不能只看静态排名
5. 必须区分"确定性结论"和"概率性判断"
6. 重大决策必须标注"建议人工复核"
7. 禁止给出绝对化建议，始终保留不确定性
