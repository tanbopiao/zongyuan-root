所有网页/系统轻量化、可视化、风格统一
借鉴外部技术但必须自进化融合超越，形成自有技术体系

<1s

页面体积

响应式自适应

🛠 技术栈规范

✅ 强制标准

  • 单文件HTML自包含 — CSS/JS内联，不拆外部文件
  • 原生JS无框架 — 不用React/Vue/构建工具
  • CSS Columns瀑布流 — 作品库/图库标准布局
  • 视频preload=none — hover才加载播放
  • 图片loading=lazy — IntersectionObserver
  • AVIF/WebP优先 — JPG/PNG兜底

🔬 探索前沿

  • WebAssembly 3.0 — 64位内存/GC/向量加速，流式编译
  • CSS分层渲染 — 首屏提速300%
  • Critical CSS内联 — 首屏必需CSS内联head
  • HTML Streaming — 服务端流式渲染
  • 延迟实例化 — 非关键函数按需加载
  • Wasm图像处理 — 比JS快5-8倍

🎨 全域视觉统一

  • 主题色 — 深色背景#0a0a0f + 金色强调#d4af37
  • 字体 — Noto Serif SC标题 + Noto Sans SC正文
  • 组件 — 统一卡片/导航/按钮/灯箱/瀑布流规范
  • 响应式 — 桌面4列 / 平板3列 / 手机2列 / 超小屏1列
  • 导航 — 8大分类固定，新页面归入对应下拉，禁止新增主分类

📊 飞书妙塔/多维表格集成

  • 仪表盘嵌入 — 飞书多维表格仪表盘分享链接 → iframe嵌入官网对应页面
  • 应用场景 — 真值库可视化大屏 / 资产统计仪表盘 / 节点状态监控面板 / 审批流程看板
  • 数据实时同步 — 多维表格数据更新，官网仪表盘自动更新
  • 移动端限制 — 移动端iframe不可用，用链接跳转方式打开
  • 零成本 — 利用飞书免费多维表格能力，无需自建可视化后端

🧬 自进化创造原则

超越原创形成自有
  • 核心原则 — 外部技术仅作参考，自进化融合超越的才是真正的资产
  • 鼓励创造 — 挖掘新技术、创造新代码、适配体系功能，不局限于现有技术
  • 来源标注 — 自进化得到的技术标注自研来源，区分借鉴与原创
  • 案例 — 作品库2.0融合ArtStation瀑布流+B站懒加载+抖音悬停预览，形成自有展示体系

📦 交付标准

  • 可点击链接 — 所有交付物必须提供可直接点击的markdown链接，禁止纯文本URL
  • 交付前验证 — 必须验证HTTP 200可访问，双root同步完成
  • 自动集成 — 新页面自动加入官网导航，不用再下命令
  • 轻量化检查 — evolution_scanner每日扫描页面性能，超标自动标记优化
