## 三、P0级任务详解（立即执行）

### P0-1: 服务持久化与自恢复

**问题**: 当前FastAPI服务和进化循环在环境重启后丢失，诊断显示"未运行"。

**目标**: 实现7×24持久运行，异常自动恢复，环境重启后自动拉起。

**执行路径**:
```
第1天:  systemd/supervisor配置编写
        ├─ omega-brain.service (FastAPI)
        ├─ evolution-loop.service (进化循环)
        └─ mwp-coordinator.service (MWP协调者)
第2天:  健康检查与自动重启
        ├─ /health端点监控
        ├─ 失败3次自动重启
        └─ 重启上限5次/小时（防崩溃循环）
第3天:  环境启动钩子
        ├─ @reboot cron任务
        ├─ 容器ENTRYPOINT配置
        └─ 启动后自检脚本
第4-5天: 持久化验证
        ├─ 模拟进程杀死→自动恢复
        ├─ 模拟环境重启→自动拉起
        └─ 72小时稳定性测试
```

**预期产出**:
- 3个systemd service文件
- 1个启动自检脚本
- 1份持久化运行报告
- 服务可用性≥99.5%

**衡量指标**:
- 服务连续运行时间 ≥ 72小时
- 异常恢复时间 ≤ 30秒
- 环境重启后自动拉起成功率 = 100%

**价值**: 所有其他任务的基础。服务不持久，一切功能都是"一次性"的。

### P0-2: 多模态产线真实接入

**问题**: 当前multimodal_pipeline只生成prompt文件，不真正生成图像/视频/音频。

**目标**: 实现1输入→14真实资产（3文本+5图像+3视频+3音频），全部通过API真实生成。

**执行路径**:
```
第1周: 图像生成接入
       ├─ 接入image_gen工具（seedream_4.5）
       ├─ 5个关键帧自动生成
       ├─ 暗印自动镌刻（调用image_watermark.py）
       └─ 质量校验（分辨率/内容/暗印）

第2周: 视频生成接入
       ├─ 接入image_to_video工具（seedance_2.0）
       ├─ 3个场景视频生成（10秒/个）
       ├─ 关键帧→视频一致性校验
       └─ 视频暗印（片尾溯源符号）

第3周: 音频生成+全链路联调
       ├─ 接入text_to_audio（BGM/配音/音效）
       ├─ 14资产自动锁档（SHA256+Merkle）
       ├─ 产线端到端测试
       └─ 失败重试与降级机制
```

**预期产出**:
- multimodal_pipeline_v3.py（真实生成版）
- 1套产线配置模板（角色/场景/情绪）
- 1份产线质量报告
- 日产能力：1角色→14真实资产

**衡量指标**:
- 图像生成成功率 ≥ 90%
- 视频生成成功率 ≥ 80%
- 音频生成成功率 ≥ 95%
- 14资产全链路耗时 ≤ 30分钟
- 资产锁档率 = 100%

**价值**: 体系从"文档/配置生产者"升级为"真实媒体资产生产者"，能力指数+500。

### P0-3: Function Call与豆包基座深度集成

**问题**: 8个工具已注册但未接入豆包模型的Function Call机制，模型无法自主调用工具。

**目标**: 实现"模型理解意图→自动选择工具→执行→返回结果"的完整闭环。

**执行路径**:
```
第1周: 工具Schema标准化
       ├─ 8个工具的OpenAI function格式导出
       ├─ 参数验证与类型约束
       ├─ 工具描述优化（提升模型选择准确率）
       └─ 工具调用日志与审计

第2周: 模型集成与闭环测试
       ├─ 接入豆包API的function_call参数
       ├─ 模型返回function_call→自动执行
       ├─ 执行结果回传模型→生成最终回答
       └─ 多轮工具调用（链式调用）支持
```

**预期产出**:
- function_call_gateway.py（工具调用网关）
- 8个工具的标准化Schema
- 1套工具调用测试用例
- 模型自主调用工具演示

**衡量指标**:
- 工具选择准确率 ≥ 85%
- 工具调用成功率 ≥ 95%
- 多轮链式调用支持 ≥ 3轮
- 平均调用延迟 ≤ 5秒

**价值**: 模型从"只能说话"升级为"能动手干活"，是Lv5元认知的基础。
