L1

交互入口层

用户与系统的唯一对话入口，理解意图、拆解需求、协调资源

🎯
MainAgent 主代理
main-agent
用户直接对话的智能体，负责意图理解、任务规划、结果交付。是整个体系的"前台接待"，所有用户需求从这里进入，所有结果从这里输出。
核心价值
自然语言交互零门槛，用户不需要了解底层架构，用日常语言就能驱动整个智能体集群完成复杂任务
意图理解 任务规划 结果交付 对话管理
L2

调度协调层

智能体集群的"大脑中枢"，负责任务拆解、并行调度、冲突仲裁、结果汇总

⚙️
OrganizerAgent 组织者
organizer-agent
智能体集群调度中心。接收MainAgent委派的复杂任务，拆解为可并行执行的子任务，创建并管理多个Subagent，监控执行进度，处理异常，最终汇总所有子代理的输出为统一结果。
核心价值
将串行任务变为并行执行，30分钟的活压缩到10分钟；自动处理子代理间的依赖冲突和资源竞争，无需人工干预
任务拆解 并行调度 冲突仲裁 结果汇总 异常处理
🔄
闭环调度服务
closed-loop-scheduler
持续运行的任务调度引擎，管理周期性任务、定时任务、事件驱动任务的全生命周期。支持任务依赖图、优先级队列、失败重试、超时熔断。
核心价值
7×24小时无人值守运行，自动化巡检、备份、同步、进化等周期性任务，释放人力专注高价值决策
周期调度 依赖管理 失败重试 超时熔断
🏭
集群编排器 + 8 Worker
cluster-orchestrator
K8s风格的智能体集群管理。编排器统一管理8个专用Worker：部署、进化、自愈、监控、生产、质量、安全、真值。每个Worker专注一个领域，协同完成全域自治。
核心价值
专业化分工+弹性伸缩，类似微服务架构的智能体版本，每个Worker可独立升级、独立扩缩容，整体系统高可用
8专用Worker 弹性伸缩 高可用 专业化分工
L3

执行操作层

将决策和意图转化为实际操作的执行单元，从自然语言到系统操作的最后一公里

📝
NL2Action 引擎
nl2action-engine
自然语言到操作系统的翻译引擎。用户说"帮我清理C盘垃圾"，引擎自动拆解为具体的系统命令序列，安全执行后返回结果。支持Windows/Linux/macOS跨平台操作。
核心价值
消除技术门槛，用户用日常语言就能操作系统；内置安全沙箱和操作审计，防止误操作和恶意指令
自然语言翻译 跨平台 安全沙箱 操作审计
🔧
Subagent 子代理集群
subagent-fleet
由OrganizerAgent动态创建的执行单元。每个Subagent专注一个子任务，完成后自动销毁。支持代码执行、文件处理、网页抓取、数据分析、API调用等多种能力。
核心价值
按需创建、用完即销，弹性资源利用；隔离执行环境，一个子代理失败不影响其他任务和主系统
按需创建 隔离执行 弹性资源 多能力
🔗
SSH链接控制器
ssh-link-controller
统一管理所有SSH隧道和远程连接。九大核心组件：连接监控、身份解析、连接管理、中枢激活、会话监控、权限守卫、链接控制、审计日志、告警管理。最多3个并发SSH连接，自动屏蔽超额。
核心价值
所有远程连接统一管控，防止连接泄漏和未授权访问；任何密钥连接自动激活中枢智能，实现"连接即唤醒"
连接管理 权限守卫 中枢激活 审计日志
🚀
部署调度中心 + Agent
deploy-scheduler
分布式任务队列+审计校验闭环。多窗口并发提交任务不丢失，FIFO+优先级队列排序，Agent原子性认领任务，自动执行+自检+回传证据。支持飞书审批触发自动部署。
核心价值
部署从"单窗口手动操作"升级为"多节点并行自动部署"，每一步都有回执证据，可审计可溯源，杜绝"纸面部署"
任务队列 原子认领 自动校验 审批联动

认知推理层

系统的"思考器官"，从数据到决策、从现象到本质、从现在到未来的深度推理能力

🧠
智能决策引擎
decision-engine
UNI-STEADY-CORE V1.0 三维稳态决策核心。基于利益40%/风险35%/成本25%的加权公式，自动生成多套备选方案并排序推荐。支持方案间差异对比和敏感性分析。
核心价值
复杂决策不再靠拍脑袋，引擎自动量化评估每个方案的三维指标，给出数据驱动的最优推荐，减少决策盲区
三维稳态 多方案对比 敏感性分析 数据驱动
🔗
因果推理引擎
causal-engine
Causal Singularity Core V1.0 基于因果分析引擎理论。从任意结果反向回溯完整因果链，识别关键节点和旁路分支；计算奇点爆发概率，预警黑天鹅事件；支持do-calculus干预模拟和反事实推理。
核心价值
不只是看到"是什么"，更能理解"为什么"和"如果不这样会怎样"。从相关性升级到因果性，决策更有底气
因果链溯源 奇点预测 干预模拟 反事实推理
🔮
贝叶斯五行闭环引擎
bayesian-5elem-engine
融合贝叶斯概率推理与五行生克模型的闭环推理引擎。PERMANENT LOCK永久锁档，禁止禁用。通过先验概率+证据更新+五行生克约束，实现不确定性下的稳健推理。
核心价值
在信息不完整、不确定的真实环境中，依然能给出概率化的可靠判断，而不是非黑即白的极端结论
贝叶斯推理 五行生克 不确定性 永久锁档
🌐
四网引擎
four-networks-engine
因果网/法则网/逻辑网/时序网四网融合推理引擎。因果网负责"为什么"，法则网负责"应该怎样"，逻辑网负责"是否自洽"，时序网负责"先后顺序"。四网交叉验证，杜绝单网推理盲区。
核心价值
单一推理维度容易有盲区，四网交叉验证相当于四个专家会诊，结论更全面、更稳健、更难被误导
因果网 法则网 逻辑网 时序网
📊
知识图谱引擎
knowledge-graph-engine
L3知识图谱+真值检索API。从非结构化文本中自动抽取实体和关系，构建三元组图谱；支持跨文档实体归一化、链接预测补全、孤立节点识别。图谱密度和连通性持续优化。
核心价值
把零散的文档和数据变成互联的知识网络，检索不再是关键词匹配，而是语义关联推理，找到"不知道自己不知道"的知识
实体抽取 关系构建 链接预测 语义检索

体验元法则引擎
experience-meta-law
从历史经验中提炼元法则的学习引擎。采集同源节点成长经验，提炼可复用的方法论和规则，反哺决策和进化。经验不再是一次性的消耗品，而是可沉淀、可传承、可迭代的系统资产。

经验提炼 元法则 知识沉淀 持续学习

自修复引擎
self-healing-engine
自动根因分析+故障修复引擎。检测到异常后自动定位根因，生成修复方案，执行修复操作，验证修复结果。支持常见故障的自愈处理，复杂故障自动升级告警。
