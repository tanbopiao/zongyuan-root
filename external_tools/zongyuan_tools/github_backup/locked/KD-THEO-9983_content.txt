## 一、基础背景公理
### 1.1 威胁来源
经典Shor量子算法：可多项式时间破解RSA、ECC椭圆曲线这类基于大数分解、离散对数的公钥密码。
Grover算法：对哈希/对称密码进行平方根加速，n比特安全强度下降为n/2。
- 哈希算法（SHA-2、SHA-3）：不被Shor算法直接攻破，仅受Grover降阶影响；
- 对称加密AES：密钥长度翻倍即可抵御Grover；
- RSA/ECC：量子时代彻底失效，必须替换为NIST标准化后量子密码(PQC)。

### 1.2 后量子密码四大技术路线（NIST标准）
|路线|数学困难问题|代表算法|用途|
|---|---|---|---|
|格密码|Module-LWE模块学习错误|CRYSTALS-Kyber|密钥封装KEM（通用密钥协商）|
|格密码|Module-LWE|CRYSTALS-Dilithium|数字签名|
|基于哈希|多哈希一次性签名|SPHINCS+|无状态哈希签名，不依赖格|
|基于编码|线性码译码困难|Classic-McEliece|KEM，密钥体积大|

ZONGYUAN-ROOT选型公理：
1. 主线路：CRYSTALS-Kyber-768/1024（密钥协商）+ CRYSTALS-Dilithium-3/5（签名）；
2. 备份冗余线路：SPHINCS-SHA2-256，作为哈希基签名兜底，不依赖格密码假设；
3. 不优先启用Classic-McEliece，公钥尺寸过大不适合云盘/自治内核高频归档场景。

### 1.3 安全强度映射（对抗量子敌手）
|目标安全等级|经典安全|量子等效安全|选型|
|---|---|---|---|
|Level-2|128bit|64bit|Kyber-768 / Dilithium-3|
|Level-5|256bit|128bit|Kyber-1024 / Dilithium-5 / SPHINCS-256|

2. 签名层（原有ECC/RSA）：Shor算法可破解，不能继续用于未来区块签名确权，需要替换为PQC签名。
3. L8-MDAG多维哈希深度本身结构：DAG拓扑、深度计数、多旁路校验逻辑数学架构不受量子影响；仅底层密码原语需要替换。

## 三、风险边界真值（不可忽略约束）
1. PQC不是"绝对安全"：格密码是计算困难假设，尚未获得数学证明；所以必须保留SPHINCS+哈希签名作为第二独立假设兜底。
2. 过渡期风险：算法实现漏洞 > 量子威胁。后量子密码库代码较新，实现bug、侧信道攻击是现实主要风险，内核需要增加侧信道防护开关。
3. 向后兼容约束：历史旧哈希链区块（已经用ECC签名）不能篡改；系统只能做校验兼容，不能重写历史签名；新生成锁档全部启用PQC。
4. 性能代价：Dilithium-5签名体积更大；SPHINCS+签名尺寸大、签名速度慢。工程权衡：永恒深度归档允许高开销；高频临时业务不强制SPHINCS+兜底签名。
