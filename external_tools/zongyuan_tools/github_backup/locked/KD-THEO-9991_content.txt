## 二、语义核心层（不可约简真值内核）

数学基础的三大前沿方向——范畴论、类型论/同伦类型论、量子计算理论——从三个不同维度重新定义了"数学结构"与"计算"的本质：

**范畴论**（Category Theory, Eilenberg-Mac Lane, 1945）将数学的研究对象从"集合与元素"提升到"对象与态射"，通过泛性质（universal property）刻画数学结构的本质，而不依赖于具体的内部构造。范畴论的核心工具——函子、自然变换、伴随函子、极限、单子——提供了一种跨数学分支的统一语言，使得代数、拓扑、逻辑、计算之间的深层对应得以显现。范畴论不是某个数学分支的理论，而是"数学的数学"（mathematics of mathematics）。

**类型论与同伦类型论**（Type Theory / Homotopy Type Theory, HoTT, Voevodsky 2006; HoTT Book 2013）将"命题即类型，证明即程序"的Curry-Howard同构推向极致，提出了一种全新的数学基础框架。同伦类型论将类型解释为同伦空间，等式解释为路径，高阶等式解释为高阶同伦，从而在类型论内部重建了同伦论。一元公理（Univalence Axiom）断言"等价即相等"，使得同构的数学结构可以被视为相同，这符合数学家的实际实践但在集合论基础中不成立。同伦类型论/单值基础（Univalent Foundations）被视为继集合论之后最有潜力的数学基础新方案，且天然适合计算机形式化（证明助手Coq/Agda/Lean）。

**量子计算理论**（Quantum Computation, Deutsch 1985; Feynman 1982）将计算的物理基础从经典物理扩展到量子力学，利用量子叠加、纠缠、干涉等现象实现经典计算无法高效完成的任务。量子计算不改变可计算性边界（所有量子可计算函数都是经典可计算的），但深刻改变了计算复杂性——Shor算法在多项式时间内分解大整数（经典未知多项式算法），Grover算法实现无序搜索的平方根加速。量子计算理论的核心是量子电路模型、量子算法、量子复杂性类（BQP/QMA）、量子信息论，以及量子纠错与容错。

这三大前沿的统一内核是**结构主义与等价不变性**：范畴论通过泛性质刻画"在等价下不变的结构"，同伦类型论通过一元公理将"等价"提升为"相等"，量子计算通过酉演化保持量子态的等价结构。三者共同指向一种新的数学观：**数学的本质不是集合的元素，而是结构之间的态射与等价关系。**

## 三、逻辑推导层

### 模块A：范畴论

#### A.1 范畴的定义

**范畴（Category）C** 由以下数据组成：
1. **对象类** Ob(C)：范畴的对象集合（不一定是集合，可能是真类）
2. **态射类** Hom(C)：对每对对象A,B∈Ob(C)，有态射集Hom_C(A,B)（或写为C(A,B)）
3. **恒等态射**：对每个对象A，有id_A ∈ Hom(A,A)
4. **复合运算**：对任意f∈Hom(A,B), g∈Hom(B,C)，有g∘f∈Hom(A,C)

**公理：**
- **结合律**：对任意f:A→B, g:B→C, h:C→D，有h∘(g∘f) = (h∘g)∘f
- **单位律**：对任意f:A→B，有id_B∘f = f = f∘id_A

**态射的特殊类型：**
- **同构（Isomorphism）**：f:A→B是同构，如果存在g:B→A使得g∘f=id_A且f∘g=id_B。记作A≅B。
- **单态射（Monomorphism）**：f:A→B是单态射，如果对任意g,h:C→A，f∘g=f∘h ⟹ g=h。（左可消）
- **满态射（Epimorphism）**：f:A→B是满态射，如果对任意g,h:B→C，g∘f=h∘f ⟹ g=h。（右可消）
- 在Set中，单态射=单射，满态射=满射，同构=双射。但在一般范畴中，单+满不一定是同构。

#### A.2 重要范畴示例

| 范畴 | 对象 | 态射 |
|------|------|------|
| **Set** | 集合 | 函数 |
| **Grp** | 群 | 群同态 |
| **Ab** | 阿贝尔群 | 群同态 |
| **Ring** | 环 | 环同态 |
| **Vect_k** | 域k上的向量空间 | 线性映射 |
| **Top** | 拓扑空间 | 连续映射 |
| **Hask** | Haskell类型 | 函数（严格来说是Hask的理想化） |
| **Cat** | （小）范畴 | 函子 |
| **Rel** | 集合 | 关系 |
| **Pos** | 偏序集 | 保序映射 |

#### A.3 函子（Functor）

**协变函子（Covariant Functor）F: C→D：**
1. 对象映射：对每个A∈Ob(C)，F(A)∈Ob(D)
2. 态射映射：对每个f:A→B∈C，F(f):F(A)→F(B)∈D
3. 保持恒等：F(id_A) = id_{F(A)}
4. 保持复合：F(g∘f) = F(g)∘F(f)

**逆变函子（Contravariant Functor）F: C→D：**
- 态射映射反转：F(f:A→B): F(B)→F(A)
- 保持复合：F(g∘f) = F(f)∘F(g)
- 等价于协变函子C^op→D（C^op是C的对偶范畴，态射方向反转）

**自函子（Endofunctor）：** F: C→C，定义域和值域相同的函子。

**重要函子示例：**
- 幂集函子P: Set→Set（协变：P(f)(A)=f(A)；逆变：P(f)(B)=f^{-1}(B)）
- 自由群函子F: Set→Grp
- 遗忘函子U: Grp→Set（忘记群结构，只记住底层集合）
- 对偶空间函子(-)*: Vect_k→Vect_k（逆变）

#### A.4 自然变换（Natural Transformation）

**自然变换α: F⇒G**（F,G: C→D是函子）：
1. 对每个对象A∈C，有态射α_A: F(A)→G(A)（称为α在A处的分量）
2. **自然性条件**：对任意f:A→B∈C，有G(f)∘α_A = α_B∘F(f)
   - 即以下方块交换：
   ```
   F(A) --α_A--> G(A)
    |             |
   F(f)         G(f)
    |             |
    v             v
   F(B) --α_B--> G(B)
   ```

**自然同构（Natural Isomorphism）：** 每个分量α_A都是同构的自然变换。记作F≅G。

**函子范畴（Functor Category）[C,D]或D^C：**
- 对象：C→D的函子
- 态射：函子之间的自然变换
- 自然变换可以垂直复合（α:F⇒G, β:G⇒H，则β∘α:F⇒H）和水平复合

#### A.5 米田引理（Yoneda Lemma）

**米田引理：** 对任意函子F: C→Set和对象A∈C，存在双射
$$\text{Nat}(\text{Hom}_C(A,-), F) \cong F(A)$$
即从可表函子Hom(A,-)到F的自然变换集合与F(A)一一对应。

**证明核心：** 自然变换α: Hom(A,-)⇒F完全由α_A(id_A)∈F(A)决定。给定x∈F(A)，定义α_B(f)=F(f)(x)，这给出一个自然变换。

**推论：**
1. **米田嵌入（Yoneda Embedding）：** 函子y: C→Set^{C^op}，A↦Hom(-,A)，是完全忠实的（full and faithful），即C(A,B)≅Nat(Hom(-,A),Hom(-,B))。
2. **可表函子的唯一性：** 如果Hom(A,-)≅Hom(B,-)，则A≅B。
3. 米田引理是范畴论中最重要的定理之一，它表明对象由它的"可观测性质"（到其他对象的态射）完全决定。

#### A.6 泛性质与极限

**泛性质（Universal Property）：** 通过对象与其他对象的态射关系来刻画对象，而不描述其内部构造。满足同一泛性质的对象在同构意义下唯一。

**初始对象（Initial Object）：** 对象0∈C，使得对每个A∈C，存在唯一态射0→A。
- 在Set中：空集∅
- 在Grp中：平凡群
- 初始对象在同构下唯一

**终对象（Terminal Object）：** 对象1∈C，使得对每个A∈C，存在唯一态射A→1。
- 在Set中：单元素集合
- 在Grp中：平凡群（既是初始也是终对象，称为零对象）

**积（Product）：** 对象A和B的积是对象A×B，配有投影π₁:A×B→A, π₂:A×B→B，满足泛性质：对任意对象C和态射f:C→A, g:C→B，存在唯一⟨f,g⟩:C→A×B使得π₁∘⟨f,g⟩=f, π₂∘⟨f,g⟩=g。
- 在Set中：笛卡尔积
- 在Grp中：直积

**余积（Coproduct）：** 积的对偶。A+B配有内射ι₁:A→A+B, ι₂:B→A+B，满足泛性质：对任意f:A→C, g:B→C，存在唯一[f,g]:A+B→C。
- 在Set中：不交并
- 在Ab中：直和（=直积，因为Ab是加法范畴）

**等化子（Equalizer）：** 平行对f,g:A→B的等化子是对象E配有e:E→A，使得f∘e=g∘e，且对任意h:C→A满足f∘h=g∘h，存在唯一k:C→E使得e∘k=h。
- 在Set中：{a∈A | f(a)=g(a)}

**拉回（Pullback）：** cospan f:A→C, g:B→C的拉回是对象A×_C B配有p₁:A×_C B→A, p₂:A×_C B→B，使得f∘p₁=g∘p₂，且满足泛性质。
- 在Set中：{(a,b)∈A×B | f(a)=g(b)}

**极限（Limit）：** 上述构造（终对象、积、等化子、拉回）的统一推广。图J:C的极限是一个锥（cone），满足泛性质（所有其他锥都唯一因子通过它）。
- 有限完备范畴（finitely complete / lex）：有所有有限图极限（等价于有终对象、积、等化子）
- 完备范畴（complete）：有所有（小）图极限

**余极限（Colimit）：** 极限的对偶（初始对象、余积、余等化子、推出）。

#### A.7 伴随函子（Adjunction）

**伴随函子 F ⊣ G：** F: C→D是左伴随，G: D→C是右伴随，如果存在自然同构
$$\text{Hom}_D(F(A), B) \cong \text{Hom}_C(A, G(B))$$
自然于A∈C, B∈D。

**等价刻画：**
1. **Hom集同构**：如上定义
2. **单位-余单位**：存在自然变换η: id_C⇒G∘F（单位）和ε: F∘G⇒id_D（余单位），满足三角恒等式：
   - G(ε_B)∘η_{G(B)} = id_{G(B)}
   - ε_{F(A)}∘F(η_A) = id_{F(A)}
3. **泛性质**：对每个A，η_A:A→G(F(A))是A到G的泛态射（universal morphism）

**重要伴随示例：**
- 自由群函子F: Set→Grp ⊣ 遗忘函子U: Grp→Set
- 自由幺半群 ⊣ 遗忘
- 积函子(-×B) ⊣ 指数函子(-)^B（笛卡尔闭范畴）
- 幂集函子P: Set→Set^op（逆变）是自伴随
- 存在量词∃ ⊣ 弱化 ⊣ 全称量词∀（在超学说中）

**伴随函子定理：**
- **特殊伴随函子定理（SAFT）**：完备良幂范畴之间的保持极限的函子有左伴随
- **一般伴随函子定理（GAFT）**：满足解集条件的保持极限的函子有左伴随

#### A.8 单子（Monad）

**单子（Monad）** 在范畴C上是三元组(T, η, μ)：
1. 自函子T: C→C
2. 单位自然变换η: id_C⇒T
3. 乘法自然变换μ: T∘T⇒T
4. **结合律**：μ∘Tμ = μ∘μT（即T(T(T(X))) → T(T(X)) → T(X)两条路径相等）
5. **单位律**：μ∘Tη = id_T = μ∘ηT

**单子与伴随的关系：** 每个伴随F⊣G生成一个单子T=G∘F，η是伴随的单位，μ=G(ε_F)。
- 反之，每个单子可以通过Kleisli范畴或Eilenberg-Moore范畴分解为伴随

**Kleisli范畴（C_T）：**
- 对象：C的对象
- 态射：A→B在C_T中是A→T(B)在C中
- 复合：f:A→T(B), g:B→T(C)，则g*f = μ_C∘T(g)∘f
- 恒等：η_A:A→T(A)

**编程中的单子（Haskell）：**
- return = η（将纯值包装为单子值）
- join = μ（将嵌套单子展平）
- >>=（bind）：m >>= f = join(fmap f m)
- 单子提供了"带副作用的计算"的抽象：Maybe（可能失败）、[]（非确定性）、IO（输入输出）、State（状态）、Reader（环境）、Writer（日志）

**重要单子示例：**
- Maybe单子：可能失败的计算
- 列表单子：非确定性计算
- State单子：带状态的计算
- Reader单子：读环境的计算
- Writer单子：写日志的计算
- 延续单子（Continuation monad）：(a→r)→r
- 幂集单子P: Set→Set（非确定性）

#### A.9 范畴论与逻辑/计算的对应

**笛卡尔闭范畴（CCC, Cartesian Closed Category）：**
- 有终对象、积、指数（函数空间）的范畴
- 指数B^A配有求值态射eval: B^A×A→B，满足泛性质
- CCC是简单类型λ演算的范畴模型
- 例子：Set、（小）范畴范畴、偏序集（Heyting代数）

**Curry-Howard-Lambek对应：**
- 简单类型λ演算 ↔ 笛卡尔闭范畴 ↔ 直觉主义命题逻辑
- 类型 ↔ 对象 ↔ 命题
- 项 ↔ 态射 ↔ 证明
- 函数类型A→B ↔ 指数B^A ↔ 蕴含A⇒B
- 积类型A×B ↔ 积 ↔ 合取A∧B
- 和类型A+B ↔ 余积 ↔ 析取A∨B
- 单位类型 ↔ 终对象 ↔ 真
- 空类型 ↔ 初始对象 ↔ 假

**Topos理论：**
- 初等topos是有限完备、笛卡尔闭、有子对象分类器的范畴
- 子对象分类器Ω: 真值对象，配有泛子对象true:1→Ω
- Set是topos的典范
- topos内部有直觉主义高阶逻辑
- 层范畴（sheaf topos）是几何与逻辑的交汇
- Grothendieck topos: 层范畴，等价于几何理论的分类topos

#### A.10 范畴论的哲学意义

1. **结构主义数学观：** 数学对象由其与其他对象的关系（态射）决定，而非其内部构造（元素）。米田引理是这一观点的数学表达。
2. **等价不变性：** 范畴论关心的是在同构（或等价）下不变的性质，而非集合论意义上的"相等"。这预示了同伦类型论的一元公理。
3. **跨分支统一：** 范畴论提供了统一语言，使得代数、拓扑、几何、逻辑、计算之间的深层对应得以发现和表达。
4. **反对基础主义：** 范畴论不追求将所有数学还原为某个基础（如集合论），而是强调数学结构之间的关系和态射。这被视为对集合论基础主义的替代。
5. **计算的抽象：** 单子、函子、自然变换等概念为函数式编程提供了数学基础，使得"副作用"、"非确定性"、"状态"等计算概念获得了统一的范畴论解释。

### 模块B：类型论与同伦类型论

#### B.1 类型论基础

**类型论（Type Theory）** 是一种将"类型"作为基础概念的数学基础框架，最早由罗素（1908）为解决集合论悖论而提出，后经邱奇（简单类型λ演算, 1940）、Martin-Löf（直觉类型论, 1972）等人发展。

**简单类型λ演算（STLC, Simply Typed Lambda Calculus）：**
- **类型**：基本类型（如Bool, Nat）+ 函数类型A→B
- **项**：变量x、λ抽象λx:A.t、应用t u
- **类型规则**：
  - 变量：Γ, x:A ⊢ x:A
  - 抽象：Γ, x:A ⊢ t:B ⟹ Γ ⊢ λx:A.t : A→B
  - 应用：Γ ⊢ f:A→B, Γ ⊢ a:A ⟹ Γ ⊢ f a : B
- **β归约**：(λx.t)u → t[x:=u]
- **强规范化**：所有归约序列都终止（STLC是强规范化的）
- **Church-Rosser性质**：归约合流（结果唯一）

#### B.2 Curry-Howard同构

**Curry-Howard同构（Curry-Howard Correspondence, 1958/1969）：** 命题与类型之间、证明与程序之间的精确对应。

| 逻辑 | 类型论 |
|------|--------|
| 命题A | 类型A |
| 证明A | 项t:A |
| 蕴含A→B | 函数类型A→B |
| 合取A∧B | 积类型A×B |
| 析取A∨B | 和类型A+B |
| 真⊤ | 单位类型1 |
| 假⊥ | 空类型0 |
| 证明规范化 | β归约 |
| 证明恒等 | 外延等价 |

**深层意义：** 逻辑证明就是计算机程序，命题就是程序的类型规范。构造性数学的证明可以直接提取为可执行程序。这是证明助手（Coq/Agda/Lean）和程序验证的理论基础。

#### B.3 依赖类型论（Martin-Löf类型论）

**依赖类型（Dependent Type）：** 类型可以依赖于项。例如，长度为n的向量类型Vec(A,n)依赖于自然数n。

**核心类型构造：**

1. **Π类型（依赖函数类型）**：(x:A)→B(x)或Π(x:A)B(x)
   - 项是函数f，对每个a:A，f(a):B(a)
   - 逻辑对应：全称量词∀x:A, B(x)

2. **Σ类型（依赖对类型）**：(x:A)×B(x)或Σ(x:A)B(x)
   - 项是对(a,b)，其中a:A, b:B(a)
   - 逻辑对应：存在量词∃x:A, B(x)
   - 第一投影π₁，第二投影π₂

3. **等式类型（Identity Type）**：Id_A(a,b)或a=b
   - 项是a等于b的证明
   - 构造子refl_a : a=a（自反性）
   - 等式类型是依赖类型论最深刻的构造，它开启了同伦类型论的大门

4. **宇宙（Universe）**：类型的类型U
   - 为避免悖论，使用宇宙层级U₀:U₁:U₂:...
   - 累积性：Uᵢ ⊆ Uᵢ₊₁

5. **归纳类型（Inductive Type）：** 通过构造子定义的类型，带有归纳原理
   - 自然数：Nat = zero | succ Nat
   - 列表：List A = nil | cons A (List A)
   - 等式类型本身也是归纳类型（只有refl一个构造子）

**归纳原理：** 对归纳类型，要证明性质P对所有元素成立，只需证明P对每个构造子保持。这对应于结构归纳法和递归函数定义。

#### B.4 同伦类型论（HoTT）的核心思想

**同伦类型论（Homotopy Type Theory, HoTT）** 由Voevodsky（2006年左右）和Awodey/Warren独立提出，2013年《HoTT Book》系统化。其核心思想是将类型论解释为同伦论：

| 类型论 | 同伦论 |
|--------|--------|
| 类型A | 空间A |
| 项a:A | 空间中的点a |
| 等式类型a=b | 从a到b的路径空间 |
| 等式的证明p:a=b | 路径p |
| 等式之间的等式p=q | 路径同伦（路径之间的连续变形） |
| 高阶等式 | 高阶同伦 |
| 函数f:A→B | 连续映射f |
| 函数应用cong f | 路径的像 |

**关键洞察：** 等式类型a=b不是一个命题（至多一个证明），而是一个空间——可以有多个不同的"等式证明"（路径），这些路径之间又可以有同伦（高阶等式）。这与传统类型论/集合论中"等式是命题"的假设根本不同。

#### B.5 一元公理（Univalence Axiom）

**一元公理（Voevodsky, 2006）：** 对任意类型A,B，等式类型(A=B)等价于等价类型(A≃B)：
$$(A = B) \simeq (A \simeq B)$$

**等价（Equivalence）：** f:A→B是等价，如果它有同伦逆（homotopy inverse）g:B→A，使得g∘f∼id_A且f∘g∼id_B（这里∼是同伦，即点态路径）。等价是同伦意义上的"双射"。

**一元公理的推论：**
1. **等价即相等：** 如果两个类型等价（同伦等价），则它们相等。这意味着可以在任何上下文中将一个类型替换为其等价类型。
2. **函数外延性（Function Extensionality）：** 对任意f,g:A→B，如果对所有x:A，f(x)=g(x)，则f=g。这在传统Martin-Löf类型论中不可证明，但由一元公理推出。
3. **命题外延性：** 逻辑等价的命题相等。
4. **同构不变性：** 数学结构的性质在同构下不变。这符合数学家的实际实践（我们不区分同构的群/环/空间），但在集合论基础中不严格成立（同构的集合作为集合不一定相等）。

**一元公理的哲学意义：** 它将"等价"提升为"相等"，实现了数学家"同构的结构就是相同的"这一非正式实践的形式化。这是结构主义数学观的极致表达。

#### B.6 高阶归纳类型（HIT）

**高阶归纳类型（Higher Inductive Type, HIT）：** 归纳类型的推广，构造子不仅可以生成点（项），还可以生成路径（等式）和高阶路径（高阶等式）。

**经典HIT示例：**

1. **区间I（Interval）：**
   - 点构造子：0_I, 1_I : I
   - 路径构造子：seg : 0_I = 1_I
   - 区间是"有两个点和一条路径连接它们"的类型
   - 区间的存在推出函数外延性

2. **圆S¹（Circle）：**
   - 点构造子：base : S¹
   - 路径构造子：loop : base = base
   - 圆是"一个点和一条以该点为基点的环路"
   - S¹的基本群是整数（π₁(S¹)=ℤ），这可以在HoTT内部证明

3. **球面Sⁿ（Sphere）：**
   - S⁰ = 2（两个点）
   - S¹ = 圆
   - S² = 一个点base + 一个2-环路surf : refl_base = refl_base（高阶路径）
   - 同伦群可以在类型论内部计算

4. **悬浮（Suspension）ΣA：**
   - 点构造子：N, S : ΣA（北极、南极）
   - 路径构造子：merid : A → (N = S)（对每个a:A，有一条从N到S的经线）
   - 悬浮是同伦论中的悬挂构造
   - S^{n+1} = ΣSⁿ

5. **商类型（Quotient Type）A/~：**
   - 点：A的元素
   - 路径：对每个a,b∈A且a~b，有路径quot(a)=quot(b)
   - 商类型是HIT的特例，实现了类型论中的商构造

**HIT的意义：** HIT使得同伦构造（区间、圆、球面、悬浮、商）可以在类型论内部直接定义，而不需要从集合论/拓扑学导入。这是HoTT作为"综合同伦论"（synthetic homotopy theory）的核心。

#### B.7 同伦n-类型与截断

**同伦n-类型（Homotopy n-Type）：** 按高阶同伦群的平凡性对类型分类。

| 层级 | 名称 | 定义 | 例子 |
|------|------|------|------|
| (-2)-类型 | 可缩类型（Contractible） | 存在一个点，所有其他点都与它有路径相连 | 单位类型1、区间I |
| (-1)-类型 | 纯命题（Mere Proposition） | 任意两个元素都相等（路径空间可缩） | 真、假、等式类型（在命题截断后） |
| 0-类型 | 集合（Set） | 任意两个元素之间的等式是命题 | 自然数、集合（在集合论意义上） |
| 1-类型 | 广群（Groupoid） | 等式是集合（路径空间是集合） | 群、基本广群 |
| n-类型 | n-广群 | 等式是(n-1)-类型 | n阶广群 |

**命题截断（Propositional Truncation）||A||：**
- 将类型A"截断"为命题：如果A有元素（非空），则||A||为真；否则为假
- ||A||是(-1)-类型
- 构造子：|a| : ||A||（对每个a:A）
- 截断原理：对任意命题P，(A→P) → (||A||→P)
- 命题截断实现了"存在"的逻辑意义（不关心具体证据），与Σ类型的"存在"（保留证据）形成对比

**集合截断（Set Truncation）||A||₀：** 将类型A截断为0-类型（集合），即识别所有高阶路径。

**n-截断：** 一般地，||A||ₙ将A截断为n-类型。

#### B.8 立方类型论与计算解释

**问题：** 一元公理作为公理加入类型论后，破坏了正规性（canonicity）——闭项的范式不一定是构造子形式。这意味着HoTT中的证明不一定能直接计算。

**立方类型论（Cubical Type Theory, CTT）：**
- 由Cohen, Coquand, Huber, Mörtberg（2015）提出
- 引入区间对象I（有端点0,1和连接运算）
- 路径类型Path A a b = I→A，满足端点条件（i=0时为a，i=1时为b）
- 一元公理成为**定理**（不需要作为公理加入），通过胶合（glue）构造证明
- 具有正规性（canonicity）：闭项的范式是构造子形式
- 具有可计算的语义

**实现：**
- **Cubical Agda**：Agda证明助手的立方类型论扩展
- **redtt**：实验性立方类型论证明助手
- **cubicaltt**：最小立方类型论实现
- **Arend**：支持HoTT的证明助手

**意义：** 立方类型论使得HoTT从"理论上优雅但计算上有问题"变为"既优雅又可计算"，为HoTT的实际应用（数学形式化、程序验证）铺平了道路。

#### B.9 单值基础与数学形式化

**单值基础（Univalent Foundations, UF）：** Voevodsky提出的数学基础新方案，以同伦类型论+一元公理为核心。

**与集合论基础的比较：**

| 方面 | ZFC集合论 | 单值基础（HoTT） |
|------|-----------|-------------------|
| 基本对象 | 集合（∈关系） | 类型（依赖类型） |
| 相等 | 外延相等（元素相同） | 路径/等价（一元公理） |
| 同构处理 | 同构不等于相等 | 等价即相等（一元公理） |
| 高阶结构 | 需要显式构造（范畴、广群） | 内建于类型（等式类型=路径空间） |
| 计算性 | 非计算性（选择公理等） | 计算友好（立方类型论） |
| 形式化 | Metamath, Mizar | Coq, Agda, Lean（HoTT库） |

**已形式化的数学（HoTT）：**
- 基本同伦论：π₁(S¹)=ℤ，Seifert-van Kampen定理
- 范畴论：HoTT中的范畴（预范畴、范畴、严格范畴）
- 代数：群论、环论、模论
- 实数：柯西实数、戴德金实数
- 综合同伦论：大量同伦论结果

**Voevodsky的愿景：** 建立一个完整的数学形式化库，使得所有数学定理都可以在计算机上验证，且数学结构在等价下自然不变。

#### B.10 类型论的哲学意义

1. **命题即类型：** 逻辑不是数学的基础，而是类型论的一个侧面（命题是特殊的类型）。证明是数学对象（程序），可以计算和操作。
2. **构造性数学：** 类型论天然是构造性的——存在性证明必须提供证据（Σ类型的第一个投影）。这与直觉主义数学一致，但通过一元公理和HIT获得了经典数学无法表达的新内容。
3. **等价不变性：** 一元公理实现了"同构即相等"，这是数学家实际实践的形式化。数学真理应该在等价下不变，这是结构主义的核心。
4. **高阶相等：** 等式不是命题而是空间，这开启了高阶结构的内建处理。传统集合论/范畴论需要显式处理高阶范畴，而HoTT中高阶等式是内建的。
5. **计算与数学的统一：** 类型论既是数学基础又是编程语言，证明即程序。这消除了"纯数学"与"计算"之间的鸿沟，使得数学形式化和程序验证成为同一活动的两个侧面。

### 模块C：量子计算理论

#### C.1 量子力学基础

**量子态（Quantum State）：** 量子系统的状态由希尔伯特空间中的单位向量（态矢）描述。
- **狄拉克记号**：|ψ⟩（右矢/ket）表示态矢，⟨ψ|（左矢/bra）表示其共轭转置
- 内积：⟨φ|ψ⟩
- 概率幅：复数α，测量概率为|α|²

**量子比特（Qubit）：**
- 二维希尔伯特空间中的量子态
- 计算基：|0⟩ = (1,0)^T, |1⟩ = (0,1)^T
- 任意量子比特态：|ψ⟩ = α|0⟩ + β|1⟩，其中|α|²+|β|²=1
- α,β是复数（概率幅）

**布洛赫球（Bloch Sphere）：**
- 单量子比特态的几何表示
- |ψ⟩ = cos(θ/2)|0⟩ + e^{iφ}sin(θ/2)|1⟩
- θ∈[0,π]（极角），φ∈[0,2π)（方位角）
- 布洛赫球面上的点对应纯态
- 球心对应最大混合态（完全不确定）

**测量（Measurement）：**
- 对量子比特在计算基测量：得到|0⟩的概率|α|²，得到|1⟩的概率|β|²
- 测量后态坍缩：测量得到|0⟩后态变为|0⟩，得到|1⟩后变为|1⟩
- 测量是不可逆的（除非测量结果与态正交/平行）

**演化（Evolution）：**
- 封闭量子系统的演化由酉变换（幺正变换）描述
- |ψ(t)⟩ = U|ψ(0)⟩，其中U是酉矩阵（U†U=I）
- 薛定谔方程：iℏ d|ψ⟩/dt = H|ψ⟩，H是哈密顿量
- 酉演化是可逆的、保内积的、保概率的

#### C.2 多量子比特与纠缠

**复合系统：** n量子比特系统的希尔伯特空间是2^n维的，由各量子比特空间的张量积构成。
- 计算基：|x₁x₂...xₙ⟩ = |x₁⟩⊗|x₂⟩⊗...⊗|xₙ⟩
- 任意n量子比特态：|ψ⟩ = Σ_{x∈{0,1}^n} α_x |x⟩，Σ|α_x|²=1

**纠缠（Entanglement）：**
- 如果复合系统的态不能分解为各子系统态的张量积，则称为纠缠态
- 可分态：|ψ⟩ = |φ⟩⊗|χ⟩
- 纠缠态：不能这样分解

**Bell态（EPR对）：**
- |Φ⁺⟩ = (|00⟩+|11⟩)/√2
- |Φ⁻⟩ = (|00⟩-|11⟩)/√2
- |Ψ⁺⟩ = (|01⟩+|10⟩)/√2
- |Ψ⁻⟩ = (|01⟩-|10⟩)/√2
- Bell态是最大纠缠态

**EPR佯谬与Bell不等式：**
- Einstein-Podolsky-Rosen（1935）：纠缠似乎暗示"幽灵般的超距作用"，质疑量子力学的完备性
- Bell（1964）：提出可实验检验的不等式，区分量子力学和局域隐变量理论
- 实验验证（Aspect 1982, Zeilinger等）：Bell不等式被违反，局域隐变量理论不成立
- 纠缠不能用于超光速通信（不可通信定理/No-communication Theorem）

**不可克隆定理（No-Cloning Theorem）：**
- 未知量子态不能被完美复制
- 证明：如果存在酉U克隆|ψ⟩，则U|ψ⟩|0⟩=|ψ⟩|ψ⟩。对|0⟩和|1⟩成立，但对(|0⟩+|1⟩)/√2，U作用后得到(|00⟩+|11⟩)/√2 ≠ (|0⟩+|1⟩)/√2 ⊗ (|0⟩+|1⟩)/√2 = (|00⟩+|01⟩+|10⟩+|11⟩)/2。矛盾。
- 不可克隆是量子密码学的基础

#### C.3 量子门与量子电路

**量子门（Quantum Gate）：** 作用于量子比特的酉变换。

**单比特门：**

| 门 | 矩阵 | 作用 |
|----|------|------|
| **X（NOT/Pauli-X）** | [[0,1],[1,0]] | |0⟩↔|1⟩（经典NOT） |
| **Y（Pauli-Y）** | [[0,-i],[i,0]] | |0⟩→i|1⟩, |1⟩→-i|0⟩ |
| **Z（Pauli-Z/相位翻转）** | [[1,0],[0,-1]] | |0⟩→|0⟩, |1⟩→-|1⟩ |
| **H（Hadamard）** | (1/√2)[[1,1],[1,-1]] | |0⟩→(|0⟩+|1⟩)/√2, |1⟩→(|0⟩-|1⟩)/√2（创建叠加） |
| **S（相位π/2）** | [[1,0],[0,i]] | |1⟩→i|1⟩ |
| **T（相位π/4）** | [[1,0],[0,e^{iπ/4}]] | |1⟩→e^{iπ/4}|1⟩ |
| **R_x(θ)** | cos(θ/2)I - i sin(θ/2)X | 绕x轴旋转θ |
| **R_y(θ)** | cos(θ/2)I - i sin(θ/2)Y | 绕y轴旋转θ |
| **R_z(θ)** | cos(θ/2)I - i sin(θ/2)Z | 绕z轴旋转θ |

**双比特门：**

| 门 | 作用 |
|----|------|
| **CNOT（受控NOT）** | 控制比特为|1⟩时翻转目标比特：\|00⟩→\|00⟩, \|01⟩→\|01⟩, \|10⟩→\|11⟩, \|11⟩→\|10⟩ |
| **CZ（受控Z）** | 控制和目标都为\|1⟩时施加相位-1 |
| **SWAP** | 交换两个量子比特的状态 |
| **受控U** | 控制比特为\|1⟩时对目标比特施加U |

**通用门集合（Universal Gate Set）：**
- {H, T, CNOT} 是近似通用的（可以任意精度逼近任意酉变换）
- {H, S, CNOT, Toffoli} 精确实现经典可逆计算 + 叠加
- Solovay-Kitaev定理：任何通用门集合可以以O(log^c(1/ε))个门逼近任意酉变换到精度ε

**量子电路（Quantum Circuit）：**
- 由量子比特线（水平）和量子门（方块）组成
- 从左到右表示时间演化
- 测量用仪表符号表示
- 量子电路模型是量子计算的标准模型

#### C.4 量子算法

**Deutsch-Jozsa算法（1992）：**
- 问题：判断函数f:{0,1}^n→{0,1}是常数（全0或全1）还是平衡（恰好一半0一半1）
- 经典：最坏需要2^{n-1}+1次查询
- 量子：1次查询
- 意义：第一个展示量子加速的算法，虽然是黑盒模型

**Bernstein-Vazirani算法（1993）：**
- 问题：找隐藏字符串s∈{0,1}^n，已知f(x)=s·x mod 2
- 经典：n次查询
- 量子：1次查询
- 意义：展示量子查询复杂性的指数优势（黑盒模型）

**Simon算法（1994）：**
- 问题：找周期s，已知f(x)=f(y)⟺x⊕y∈{0,s}
- 经典：指数次查询
- 量子：多项式次查询
- 意义：Shor算法的前身，展示了周期发现的量子加速

**量子傅里叶变换（QFT, Quantum Fourier Transform）：**
- 离散傅里叶变换的量子版本
- 经典FFT：O(N log N) = O(2^n · n)
- 量子QFT：O(n²)个门（指数加速！）
- QFT是Shor算法、量子相位估计、HHL等算法的核心
- QFT本身不直接加速经典问题（因为不能直接读出所有傅里叶系数），但作为子routine提供加速

**量子相位估计（QPE, Quantum Phase Estimation）：**
- 问题：给定量子门U和本征态|ψ⟩（U|ψ⟩=e^{2πiφ}|ψ⟩），估计相位φ
- 核心：QFT + 受控U操作
- 精度：t个辅助比特得到t位精度，成功概率常数
- QPE是Shor算法、HHL算法、量子模拟的核心

**Shor算法（1994, Peter Shor）：**
- **整数分解**：给定合数N，找其素因子
  - 经典：未知多项式时间算法（数域筛法sub-exponential exp(O(n^{1/3}))）
  - 量子：多项式时间O((log N)^3)
- **离散对数**：给定a,b,p，找x使得a^x ≡ b mod p
  - 同样多项式时间量子算法
- **核心步骤**：
  1. 选随机a，计算gcd(a,N)（如果非平凡则完成）
  2. 用量子算法找函数f(x)=a^x mod N的周期r
  3. 如果r偶数且a^{r/2}≠-1 mod N，则gcd(a^{r/2}±1, N)给出因子
  4. 周期发现使用QPE + QFT
- **意义**：对RSA、ECC、Diffie-Hellman等公钥密码系统构成威胁，推动了后量子密码学的发展

**Grover算法（1996, Lov Grover）：**
- 问题：在N个无序元素中搜索目标
- 经典：O(N)次查询（平均N/2）
- 量子：O(√N)次查询（平方根加速）
- 核心：振幅放大（amplitude amplification）——通过反射操作放大目标态的概率幅
- 最优性：BBBV定理证明量子搜索不能快于Ω(√N)
- 意义：对对称密码（AES等）的暴力搜索提供平方根加速（256位安全→128位安全），但不构成根本性威胁

**HHL算法（Harrow-Hassidim-Lloyd, 2009）：**
- 问题：解线性方程组Ax=b（A是稀疏Hermitian矩阵）
- 经典：O(N)（共轭梯度等，对稀疏矩阵）
- 量子：O(log N · κ² · s)（κ是条件数，s是稀疏度）——指数加速！
- 但输出是量子态|x⟩，不能直接读出所有分量（只能求期望值等）
- 意义：量子机器学习、量子数据分析的基础算法之一

**量子模拟（Quantum Simulation, Feynman 1982）：**
- 问题：模拟量子系统的演化
- 经典：一般量子系统的模拟需要指数资源（希尔伯特空间维度指数增长）
- 量子：多项式资源（用量子比特直接模拟量子系统）
- 应用：化学模拟（分子能级、反应路径）、材料科学（高温超导、催化剂）、粒子物理
- 被认为是量子计算机最有前景的近期应用之一（NISQ时代）

#### C.5 量子复杂性类

**BQP（Bounded-error Quantum Polynomial time）：**
- 量子计算机在多项式时间内、有界错误概率（≤1/3）可解决的问题类
- 量子版的BPP
- 已知包含：P ⊆ BPP ⊆ BQP
- 已知包含于：BQP ⊆ PP（Adleman-de Marrais-Huang, 1997）⊆ PSPACE
- 因此P ⊆ BPP ⊆ BQP ⊆ PP ⊆ PSPACE
- BQP vs NP：未知（广泛猜测NP⊄BQP，即量子不能有效解决NP完备问题）
- BQP vs P：未知（Shor算法表明BQP可能包含不在BPP中的问题，但整数分解未知是否在P中）
- BQP-完备问题：量子电路的输出概率估计、近似Jones多项式等

**QMA（Quantum Merlin-Arthur）：**
- 量子版的NP（MA）：证明者（Merlin）提供量子证书，验证者（Arthur）用量子计算机验证
- NP ⊆ QMA（经典证书是量子证书的特例）
- QMA ⊆ PP（Kitaev-Watrous）
- **QMA-完备问题**：
  - 局部哈密顿量问题（k-Local Hamiltonian, k≥2）：给定k-局部哈密顿量H和能量阈值a,b，判断基态能量≤a还是≥b（promise problem）
  - 这是QMA的第一个完备问题（Kitaev, 1999），量子版的Cook-Levin定理
  - 其他QMA-完备问题：量子可满足性（QSAT）、量子稀疏矩阵秩等

**其他量子复杂性类：**
- **QIP**（Quantum Interactive Polynomial）：量子交互式证明，=PSPACE（Jain-Ji-Upadhyay-Watrous, 2010，重大结果）
- **QCMA**（Quantum Classical Merlin-Arthur）：经典证书+量子验证
- **QMA(2)**：两个不可通信证明者的QMA
- **PQP**：无界误差量子多项式时间，=PP
- **EQP**：精确量子多项式时间（零错误）

**量子复杂性与经典复杂性的关系图：**
```
P ⊆ BPP ⊆ BQP ⊆ PP ⊆ PSPACE
         ⊆ NP ⊆ MA ⊆ QMA ⊆ PP
                 ⊆ QCMA
```

#### C.6 量子信息论

**冯诺依曼熵（Von Neumann Entropy）：**
- 量子态ρ（密度矩阵）的熵：S(ρ) = -Tr(ρ log ρ)
- 经典香农熵的量子推广
- 纯态S=0，最大混合态S=log d（d是维度）

**量子互信息：** I(A:B)_ρ = S(ρ_A) + S(ρ_B) - S(ρ_AB)
- 可以超过经典极限（纠缠态的互信息可以很大）

**Holevo定理（Holevo's Theorem, 1973）：**
- 从n量子比特中最多可以提取n经典比特的信息
- 即使量子比特可以处于无限多个态（连续参数），可访问的信息仍受限于量子比特数
- 这是"量子比特不能简单替代经典比特"的信息论基础

**量子信道容量：**
- 量子信道是保迹完全正映射（CPTP map）
- 经典容量：通过量子信道传输经典信息的最大速率（Holevo-Schumacher-Westmoreland定理）
- 量子容量：传输量子信息（保持相干性）的最大速率（Lloyd-Shor-Devetak定理），涉及相干信息
- 私密容量：传输私密经典信息的速率

**量子纠错码（Quantum Error Correction）：**
- 不可克隆定理使得经典纠错（复制+多数表决）不能直接应用
- **Shor码（1995）**：9量子比特码，可纠正任意单量子比特错误
- **Steane码（1996）**：7量子比特码，CSS码的典范
- **表面码（Surface Code）**：2D格点上的量子比特，只需要局部测量，阈值~1%（最高的容错阈值之一），是当前最有前景的容错架构
- 稳定子码（Stabilizer Code）：量子纠错的统一框架

**量子容错阈值定理（Fault-Tolerance Threshold Theorem）：**
- 如果量子门的错误率低于某个阈值（表面码~1%），则可以通过量子纠错实现任意长的量子计算，错误率任意小
- 这是大规模量子计算可行性的理论基础

**量子密钥分发（QKD, Quantum Key Distribution）：**
- **BB84协议（Bennett-Brassard, 1984）**：利用单光子偏振态分发密钥，窃听必然被发现（测量干扰量子态）
- **E91协议（Ekert, 1991）**：利用纠缠对和Bell不等式检测窃听
- 信息论安全（不依赖计算复杂性假设），是量子密码学的核心应用
- 已商业化（中国"墨子号"卫星实现星地QKD）

#### C.7 量子计算模型

**量子电路模型（Quantum Circuit Model）：**
- 标准模型，由量子比特初始态+量子门序列+测量组成
- 等价于量子图灵机

**量子图灵机（Quantum Turing Machine, Deutsch 1985）：**
- 经典图灵机的量子推广，转移振幅是复数
- 与量子电路模型多项式等价

**绝热量子计算（Adiabatic Quantum Computation, AQC）：**
- 利用量子绝热定理：系统初始在简单哈密顿量的基态，缓慢演化到目标哈密顿量，最终态是目标哈密顿量的基态
- 等价于量子电路模型（多项式等价）
- D-Wave系统使用量子退火（quantum annealing），是AQC的近似/特殊情况
- 适合优化问题（将目标函数编码为哈密顿量）

**测量基量子计算（Measurement-Based Quantum Computation, MBQC / One-Way Quantum Computer）：**
- 初始制备大的纠缠态（团簇态/cluster state）
- 通过单量子比特测量实现计算（测量基和顺序决定计算）
- 与量子电路模型等价
- 适合光量子计算（纠缠态制备后只需测量）

**拓扑量子计算（Topological Quantum Computation）：**
- 利用二维系统中的任意子（anyon，既非玻色子也非费米子的准粒子）的编织（braiding）实现量子门
- 量子信息存储在拓扑自由度中，对局域噪声天然免疫
- 容错性极高（不需要主动纠错）
- Microsoft Station Q专注于此方向
- 物理实现：分数量子霍尔效应、拓扑超导体（马约拉纳零模）

#### C.8 物理实现与量子优越性

**主要物理实现路线：**

| 路线 | 代表机构/公司 | 量子比特 | 优点 | 缺点 |
|------|--------------|---------|------|------|
| **超导量子比特** | Google, IBM, 中科大 | 数百 | 工艺成熟、门速度快、可扩展 | 需要mK级低温、相干时间有限、串扰 |
| **离子阱** | IonQ, Honeywell, 中科大 | 数十 | 相干时间长、门保真度高、全连接 | 门速度慢、扩展困难 |
| **光量子** | 中科大（九章）, Xanadu | 数十 | 室温运行、天然适合MBQC | 光子相互作用弱、纠缠制备困难、概率性 |
| **中性原子** | QuEra, ColdQuanta | 数百 | 可扩展、全连接、相干时间中等 | 门保真度待提升 |
| **拓扑量子比特** | Microsoft | 0（实验中） | 天然容错 | 物理实现尚未验证 |
| **硅自旋量子比特** | Intel, 代尔夫特 | 数十 | 与CMOS工艺兼容、可扩展 | 操控困难、低温 |

**量子优越性/量子优势（Quantum Supremacy/Advantage）：**
- 定义：量子计算机在某个明确任务上超越任何经典超级计算机
- **Google Sycamore（2019）**：53量子比特超导处理器，在随机电路采样任务上，200秒完成，经典超算估计需1万年（后被改进到数天，但仍展示了优势）
- **中国科学技术大学"九章"（2020）**：76光子光量子计算机，高斯玻色采样任务，200秒完成，经典超算估计需25亿年
- **"九章二号"（2021）**：113光子，进一步提升
- **"祖冲之二号"（2021）**：66量子比特超导，随机电路采样
- 注意：量子优越性是在特定任务上（通常是采样问题），不意味着通用量子计算已经实现

**NISQ时代（Noisy Intermediate-Scale Quantum, 2018-现在）：**
- 50-数百量子比特，没有（或只有有限）量子纠错
- 噪声是主要限制
- 研究重点：变分量子算法（VQE、QAOA）、量子近似优化、量子机器学习、量子模拟
- 目标：在NISQ设备上找到实际有用的量子优势（beyond classical）

#### C.9 量子计算的本质与局限

**量子计算不改变可计算性边界：**
- 所有量子可计算函数都是经典可计算的（BQP中的问题都是可判定的）
- 量子计算不解决停机问题、不计算不可计算函数
- 量子计算的优势在于**复杂性**（某些问题量子比经典快），不在于**可计算性**

**量子计算的已知局限：**
1. **不能有效解决NP完备问题**（广泛猜测，未证明）：Grover只提供平方根加速，不能指数加速NP完备问题
2. **测量限制**：量子态的信息不能直接读出，测量会坍缩态，只能获得统计信息
3. **不可克隆**：未知量子态不能复制，限制了某些经典技术的应用
4. **退相干**：量子态与环境耦合导致相干性丢失，是物理实现的主要障碍
5. **纠错开销**：容错量子计算需要大量物理量子比特编码逻辑量子比特（表面码~1000:1）

**量子计算与经典计算的关系：**
- 量子计算是经典计算的推广（酉演化包含经典可逆计算）
- 量子计算的能力介于P和PSPACE之间（精确位置未知）
- 量子计算的本质是利用量子叠加和干涉进行并行计算，但测量限制了可访问的信息
- 量子加速的来源：量子傅里叶变换（Shor类）、振幅放大（Grover类）、量子模拟（直接模拟量子系统）

#### C.10 量子计算的哲学意义

1. **计算的物理基础：** 量子计算表明计算的本质不是抽象的图灵机，而是物理定律。不同的物理定律（经典vs量子）支持不同的计算能力。这是"计算是物理的"这一观点的深刻表达。

2. **丘奇-图灵论题的扩展：** 经典丘奇-图灵论题说任何有效可计算函数都是图灵可计算的。量子计算不违反这一点（量子可计算=经典可计算）。但"扩展丘奇-图灵论题"（任何物理计算都可以被图灵机多项式时间模拟）可能被量子计算违反——如果BQP≠BPP，则量子物理不能被经典计算机多项式模拟。

3. **多世界与量子计算：** 量子计算的"并行性"有时被通俗解释为"在多个平行宇宙中同时计算"。这是对多世界诠释的误用——量子加速的真正来源是量子干涉（不同路径的概率幅相干叠加），不是简单的并行。多世界诠释是量子力学的一种诠释，不影响量子计算的数学和物理。

4. **信息与物理：** 量子信息论表明信息不是抽象的，而是物理的——信息的存储、传输、处理都受物理定律约束。Landauer原理（擦除信息需要耗散能量）、不可克隆定理、Holevo定理都体现了信息的物理性。

5. **实在论与量子态：** 量子态（波函数）的本质是哲学争论的焦点——是认识论的（描述我们的知识）还是本体论的（描述物理实在）？量子计算的成功（量子态可以被操控和利用）支持了量子态的实在性，但争论仍在继续。

## 四、应用边界层

### 4.1 直接应用
1. **函数式编程**：范畴论概念（函子、单子、自然变换）直接应用于Haskell/Scala等函数式语言
2. **证明助手与形式化数学**：类型论是Coq/Agda/Lean的基础，HoTT提供了新的数学形式化框架
3. **程序验证**：依赖类型论可以表达复杂的程序规范，Curry-Howard同构使得证明=程序
4. **量子密码学**：QKD（BB84/E91）提供信息论安全的密钥分发
5. **量子模拟**：量子计算机模拟化学/材料系统，是近期最有前景的应用
6. **优化与机器学习**：变分量子算法（VQE/QAOA）、量子机器学习在NISQ时代探索
7. **数据库理论**：范畴论的函子/极限概念用于数据库视图、数据集成
8. **语言学**：组合范畴语法（CCG）、分布式语义（张量范畴）

### 4.2 非应用领域（明确排除）
1. **通用人工智能的保证**：范畴论/类型论/量子计算都不直接保证AGI的实现
2. **破解所有密码**：Shor算法只对基于分解/离散对数的公钥密码有效，对称密码只受Grover平方根加速（可通过加倍密钥长度应对）
3. **解决不可计算问题**：量子计算不改变可计算性边界，停机问题等仍不可解
4. **任意数学的自动化**：HoTT/证明助手可以验证证明，但不能自动生成所有数学证明（受不完备定理限制）
5. **经典问题的普适量子加速**：不是所有问题都有量子加速，许多问题量子与经典等价

### 4.3 常见误区澄清
1. ❌ "范畴论只是抽象的数学游戏" → 错误。范畴论在函数式编程、数据库理论、量子场论、拓扑量子场论、逻辑基础中有深刻应用。
2. ❌ "单子就是副作用" → 不准确。单子是范畴论概念（自函子+单位+乘法），副作用是单子的一种应用（IO/State单子）。Maybe/列表单子不涉及副作用。
3. ❌ "同伦类型论只是类型论的小修改" → 错误。一元公理和HIT从根本上改变了类型论的性质——等式从命题变为空间，等价变为相等，高阶结构内建。这是数学基础的新范式。
4. ❌ "一元公理说所有同构的东西都相等" → 需要限定。一元公理说类型的**等价**（同伦等价）等于**相等**。不是任意同构（如集合的双射在HoTT中是等价，但群同构不一定是类型等价）。
5. ❌ "量子计算机只是更快的经典计算机" → 错误。量子计算机利用叠加和纠缠，计算模型本质不同。某些问题（如Shor分解）有指数加速，不是简单的"更快"。
6. ❌ "量子计算机可以解决NP完备问题" → 未证明且广泛猜测为假。Grover只提供平方根加速，没有已知的量子算法能指数加速NP完备问题。BQP vs NP是开放问题。
7. ❌ "量子比特可以存储无限信息" → 错误。虽然量子比特态由连续参数（α,β）描述，但Holevo定理证明从n量子比特最多提取n经典比特。测量坍缩限制了可访问信息。
8. ❌ "量子优越性意味着通用量子计算" → 错误。量子优越性是在特定采样任务上超越经典，不意味着可以运行任意量子算法（如Shor需要数千逻辑量子比特+容错）。当前是NISQ时代。

### 4.4 真值边界条件
1. 范畴论的结果（米田引理、伴随函子定理等）是严格证明的定理，不依赖于未证明假设。
2. 同伦类型论的一元公理目前作为公理加入（在立方类型论中成为定理），其一致性相对于标准类型论+某些大基数公理。HoTT的一致性是活跃研究领域。
3. 量子计算的算法结果（Shor/Grover等）是严格证明的，在量子电路模型下成立。
4. BQP vs NP、BQP vs BPP等是开放问题，本文陈述的是已知包含关系和专家共识，不是确定结论。
5. 量子计算的物理实现是工程问题，本文描述的是理论模型和已知实验进展，不预测具体时间表。
6. 所有"不可判定"、"不完备"的陈述都是相对于特定形式系统/计算模型的。
