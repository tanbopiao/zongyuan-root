## 系统约束摘要
1. MD5、SHA-1禁止用于确权锁档，仅允许内部快速去重，强制深度上限；
2. 普通锁档优先 SHA-256+动态盐；Lv8永恒深度链强制 SHA3-512；
3. 永恒深度资产启用双哈希；后量子时代永恒链强制 Dilithium-5 + SPHINCS-256双签名；
4. 用户密码哈希使用 Argon2id / PBKDF2，禁止接入哈希链深度累加；
5. 300s巡检校验集合：哈希匹配、深度匹配、算法白名单、PQC签名合规校验；
6. 存量历史ECC签名仅做校验兼容，禁止新生成区块继续使用ECC/RSA签名。
