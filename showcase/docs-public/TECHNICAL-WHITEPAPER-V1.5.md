## 概述
ZONGYUAN-ROOT 面向多节点自治协作，以「真值确权 + 不可变归档 + 自适应运维 + 元进化闭环」为核心。V1.5 将 12 个蓝图内核工程化为可执行算子，建立逻辑态→执行态→推动态三层融合模型。

## 系统架构
```
本地执行层：算子引擎(12算子) + 知识网关 + 发布通道
云端网关：真值库(结构化+幂等去重) + 状态核验
元内核：全局基准快照 + 共识确权
```
