## 一、治理目标

所有定时任务与自动化脚本在保证功能闭环前提下，最小化额度消耗：不做无效调用、不产生无限膨胀、不空转。

## 二、消耗点画像（改造前）

| 任务/脚本 | 消耗点 | 等级 |
|---|---|---|
| 元极恒一全自动上报（每4h） | 记忆网关每次新key(inserted无限膨胀) | 高 |
| 同上 | drama 上报无条件调用（502期间空耗） | 高 |
| 轮询执行（每小时） | 空转无任务仍高频触发 | 中 |
| 全链路 | 各脚本非幂等重复写入 | 中 |

## 三、轻量化改造清单（已落地）

### 1. 记忆网关幂等（key 固定）
- 改造前：`key=AUTO-REPORT.{时间戳}` → 每次 inserted 新记录，真值库无限膨胀
- 改造后：`key=AUTO-REPORT.STATUS.{日期}` → 每日固定 key，同 key 自动 update 幂等
- 验证：二次执行 `action=unchanged` ✅

### 2. drama 网关条件上报
- 改造前：无条件调 drama report（truths 502 期间仍空耗）
- 改造后：`gw_status=healthy 且 truths 可用` 才上报；否则跳过并标记
- 验证：truths 502 时输出「跳过(不空耗请求)」✅

### 3. 空转自适应暂停（轮询任务内）
- 连续 3 次无新任务 → schedule 降为每日 1 次（暂停空转）
- 次日有任务 → 自动恢复阶段档位

### 4. 频率阶段降档
- 今天每小时 → 明天每 4 小时 → 后天每 8 小时（内置自切换）

### 5. 既有幂等（此前已落地，保持）
- 真值提炼：按文件 SHA256 指纹，无变更不提炼
- 任务执行：按 record_id 精确更新，绝不新增记录
- 算力池/心跳：update 不 create
- 凭据登记：按名称磁盘查重

## 四、验收标准

- 记忆网关同类状态记录不无限新增（同 key 幂等）
- 网关不可达期间无空耗请求
- 无任务期间自动降频，不空转
- 所有写操作幂等可重入
