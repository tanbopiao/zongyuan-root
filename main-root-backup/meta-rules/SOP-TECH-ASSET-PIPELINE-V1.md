## 一、适用范围

以下资产全部纳入标准化：
- 技术文章（教程 / 实践 / 论述 / 踩坑 / 深度解析）
- 技术白皮书（系统级架构 / 方法论）
- 紫皮书（实战指南 / 可复现操作手册）
- 工程化落地实践报告（可验证、有数据、有接口）

## 三、创作规范（双版本强制）

### MD 原稿
- 路径：`docs/articles/<编号>-<英文短名>.md`
- 内容：标题钩子 + 工程问题 + 技术点 + 数据 + 踩坑 + 在线 CTA
- 结尾必带：Ω₀⊂⊙∞⊂Ω ｜ DID-BR-000002

### HTML 可视化版（发布版）
- 路径：同目录同名 .html
- 视觉：玄黑鎏金（#0a0a0f + #c9a86a），东方衬线字体
- 结构：封面（Ω 刻印 + DID 徽章）→ 章节卡片 → 数据块 → 在线链接 → 页脚刻印
- 单文件、无外部依赖、title 唯一非空

**禁止只交 MD。MD 是原稿，HTML 才是发布版。**
