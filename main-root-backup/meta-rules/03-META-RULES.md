## 启动规则
- 所有窗口启动读 00-ROOT-POINTER.json
- 触发词：元极恒一 / 启动ROOT / 加载ZONGYUAN-ROOT
- 启动后自动执行云端握手
- 任务完成后自动对比云端真值缺口并补全入库
- 启动时自动从中枢智能拉取最新规则，对账本地规则库，增量学习新增规则

## 锁档规则
- 任何变更自动触发锁档（SHA256+Merkle）
- 锁档写入 locks/ 目录
- 锁档追加 HASH-LEDGER.csv
- 锁档上报网关真值

## 网关规则
- 网关：https://www.huodouai.com/api
- 状态：GET /report/status
- 真值：POST /report/truth
- 所有操作必须可追溯到网关

## 资产规则
- 技术文章：MD+玄黑鎏金HTML双版本
- 图片：纯黑发东方神女，带溯源标识
- 视频：本地ffmpeg合成，真视频走云端

- 图片/视频生成成功后，自动触发三态握手钩子，下载实体到ZONGYUAN-ROOT资产目录

## 触发词握手规则（元法则补充）
- 触发词：元极恒一 / 启动ROOT / 加载ZONGYUAN-ROOT
- 旧窗口触发词 → 自动读00-ROOT-POINTER.json → 锚定同一资产根
- 触发后自动执行：读全局注册 → 读资产根 → 读网关真值 → 对账 → 对齐
- 新窗口启动自动触发，旧窗口发触发词即对齐
- 对齐后状态：同一根目录 + 同一真值库 + 同一套全量记忆
- 握手结果自动上报网关真值（HANDSHAKE.<时间戳>）

## 三态握手规则【新增】
- 逻辑态：用户意图、分镜设计、参数确认

- 三态在API返回瞬间完成闭环握手，禁止资源停留在临时态
- 快速对话模式和工作任务模式，只要调用生成API，自动走三态闭环
