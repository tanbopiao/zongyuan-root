## 一、法则真值定位

本法则为 ZONGYUAN-ROOT 协议族**真值哈希口径的最高约束**，解决"协议件自我哈希不可复现、审计结论不可信"的核心缺陷。

**核心定论**：哈希字段不得自指；`self_sha256` 必须按 `RESIGN-CONVENTION-V1.0` 计算；不可复现的哈希一律不得作为完整性或确权依据。

**缺陷事实（实测）**：

| 项 | 实测值 |
|---|---|
| 普查范围 | `autonomous_kernel_protocol/` 84 件 JSON |
| 含 `self_sha256` | 66 件 |
| 修复前可复现 | **0 / 66** |
| 检验口径数 | 10 种（整文件/LF/去尾/缩进/压缩/sort_keys × 中英） |
| 根因假设 | **自指缺陷**——原口径将 `self_sha256` 自身纳入取值对象，写入即令该值失效 |
| 生成口径一致性 | 不一致（66 件中 1 件大写 HEX、65 件小写） |
| 定性 | `undetermined`——**不能定性为伪造**（66 值互不重复、无复用、无占位特征） |

## 二、唯一计算口径（RESIGN-CONVENTION-V1.0）

```
self_sha256 = sha256( utf8( JSON{ obj 去掉 self_sha256, 键排序, 紧凑分隔符 } ) )
```

| 条款 | 定义 |
|------|------|
| 算法 | SHA-256 |
| 取值对象 | 协议 JSON 顶层对象**剔除 `self_sha256` 字段**后的剩余对象 |
| 序列化 | `json.dumps(sort_keys=True, ensure_ascii=False, separators=(',',':'))` |
| 编码 | UTF-8，**不含**尾随换行 |
| 唯一性 | 该口径为协议族内**唯一合法口径**；旧口径不再合规 |

**为何剔除自身字段**：若把哈希值本身纳入取值对象，则任何一次写入都会立即让该值失效，导致永不可复现——此为自指缺陷的根因，必须从口径层面消除。

## 三、铁律约束

### 铁律1：新增与修订一律按新口径
协议族任何**新增**或**修订**的协议件，其 `self_sha256` 必须按 `RESIGN-CONVENTION-V1.0` 计算。
违反后果：该件哈希不予采信，审计权重计 0。

### 铁律2：禁止自指
计算 `self_sha256` 时**必须剔除该字段自身**。禁止将自身哈希值纳入取值对象。
违反后果：产生不可复现哈希，等同于无哈希，须重签。

### 铁律3：哈希字段变更必须走备份链
任何对哈希字段的写操作，**变更前必须逐件备份**并记录备份 SHA256；**无备份即拒绝执行**。
违反后果：操作拦截，不得落盘。

### 铁律4：不可复现的哈希不得作为确权依据
凡 `self_sha256` 不能按口径复算通过者，其**审计权重为 0**，**不得**作为完整性证明、确权凭证或审计通过依据，直至重签并复验通过。
违反后果：据此得出的审计结论无效。

### 铁律5：改哈希不得改语义
哈希字段修复**只允许改变哈希字段本身**；业务语义、`truth_type`、`efuse_state` 等一律保持原样，且必须经字节级逆向校验（V3）证明。
违反后果：视为内容篡改，须回滚。

### 铁律6：校验必须独立复核
生成脚本的自检**不构成通过依据**，必须由**独立复核**（另行读盘重算，不复用生成进程内存态）确认。
违反后果：自证结论不予采信。

### 铁律7：跨系统互验须完整 JCS
当协议需与外部系统互验时，须将近似口径**替换为完整 RFC8785(JCS)** 实现后再行互验。
违反后果：互验结果不成立。

## 四、校验流程（四重）

| 编号 | 校验项 | 判据 |
|------|--------|------|
| V1 | 口径复算 | `sha256(剔除字段后的规范化 JSON) == 落盘值` |
| V2 | 语义不变 | 除哈希字段外，对象与原件完全相同 |
| V3 | 字节逆向 | 将新值换回旧值后，字节流与原件**完全相同**（证明仅该字段变化） |
| V4 | 独立复核 | 由独立进程从磁盘重算，结论一致 |

四项全过方为 `PASS`。任一项不过即判定 `FAIL`，须回滚至备份。

## 六、边界与限制

- 本口径为 **RFC8785(JCS) 的近似实现**，未实现数字规范化（`1.0` vs `1`）、UTF-16 码点排序、严格转义表。
- 因此仅供**体系内部**自校验使用；跨语言/跨系统互验须先替换为完整 JCS（见铁律7）。
- 本法则不改变任何既有协议的业务语义；修复为**纠错性**而非重构。
