## 关键风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 云端 API 限流/变更 | 同步失败 | 双网关 fallback + 本地状态缓存 + 告警 |
| Gitee 429 / 配额超限 | 三镜像不同步 | 退避重试 + AtomGit/GitHub 主同步 + 定期 GC |
| AHOLO 等生成 API 失效 | 模板包内容产出中断 | 模板包预生成 + 本地模型兜底 |
| 多节点冲突激增 | 用户体验下降 | 冲突三级消解 + MANUAL 仲裁面板 |
| 用户数据隐私质疑 | 合规风险 | 企业版私有化 + 签名密钥本地保管 |
