## 强集成执行规则
### S2.5 分镜审核门控
- 审核项: 钩子明确 / 角色卡完整 / 分幕节拍符合情绪逻辑(铺垫→发展→爆点→转折→收尾) / 镜头顺序可执行
- 通过(APPROVED) → S3；驳回(REJECTED) → 回S2修订
- 目的: 打破"单提示词生成"黑箱，创作流程可控、阶段可判断

### S2 StoryPack 标准产物
- 字段: hook(故事钩子) / character_cards(角色卡) / beats(分幕节拍) / dialogue_cues(台词提示) / shot_order(镜头顺序)
- 替代原"关键帧+旁白金句"单一输出，升级为完整创作包

### S6 连续性检查算子
- 角色一致性(外形/服饰跨镜头不漂移)
- 关键帧sha256指纹比对(防角色漂移/混用)
- 场景/风格一致性
- StoryPack节拍与成片对齐
- 一致性未过 → 仅回S3重渲对应镜头，不重渲全片（省额度）
