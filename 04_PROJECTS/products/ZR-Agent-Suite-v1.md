## 一、产品定位

**一句话**：不是"卖模型 API"，而是卖"会自我进化、可溯源确权的自治系统"。

客户购买的是 ZONGYUAN-ROOT 体系的**自治能力**（长期记忆、任务调度、SOP 治理、确权溯源、IP 产线），大模型只是系统内部引擎，不向客户开放模型访问权。

**差异化锚点**（火山/同行给不了的）：
- 长期记忆 + 全量启动记忆激活（850+ 条目）
- 真值提炼/漂移巡检/27算子十层拓扑（可输出每日巡检报告）
- Merkle 哈希确权 + 溯源标识 Ω₀⊂⊙∞⊂Ω
- 任务台账 + 共享大脑（飞书 Base 化运营）
- 三层固化（本地/云端/双远端 Git）

## 三、套餐档位与功能

### Starter · 免费引流版（¥0）
- 自治内核接入指引（豆包/千问/GLM 上叠轻量微内核）
- 启动记忆模板 + 任务台账模板（飞书 Base 共享）
- 元法则/SOP 文档库访问（魔搭公开数据集）
- 社区支持

### Pro · 标准版（¥199/月起，按项目或年付）
- Starter 全部 +
- 本地自治内核部署（部署包 + 一键脚本 + 启动记忆激活）
- 每日自治巡检报告（27算子轻量模式，HTML 交付）
- 记忆网关接入（真值上报/漂移告警）
- 飞书共享大脑搭建（任务台账/节点状态/真值共识区 3 表）
- 双远端 Git 固化（Gitee/GitHub 自动推送）
- 交付物：部署包 + 文档 + 30 天远程支持

### Enterprise · 私有化版（¥4999/项目起，评估报价）
- Pro 全部 +
- 联邦记忆池部署（多节点记忆同步 + 容灾备份）
- 私有化服务器部署（开源模型本地推理，数据不出内网）
- 昆仑洞天 IP 产线接入（角色锚点表 + 一致性约束）
- 定制化：SOP 体系搭建、专属算子开发
- SLA 99% + 运维支持 + 年度升级

### 可选增值包
- 产品站/作品库部署：¥999/站（手机自适应 + 画廊 + API 文档页）
- 知识库 SOP 化咨询：¥1500/项目
- LoRA 定制：¥2000/模型起（Qwen 底座，自有数据）

> 定价为估算值，正式商务报价需走审批后由主账号确认；对标参考：火山 Agent Plan Medium 49.9元/月（纯API）、魔搭 offering 服务单价。

## 四、模型引擎合规策略（核心）

| 场景 | 引擎来源 | 合规依据 |
|---|---|---|
| 客户自己的系统 | 引导客户开通火山方舟/其他平台自有账号 | 客户与平台直接签约 |
| 私有化部署 | 开源模型（魔搭 Qwen 等，本地/内网部署） | 开源协议，无转售 |
| 我方运营的服务 | 我方自用豆包额度（内部引擎）或开源模型 | 我方账号自用，不向客户提供 API 访问 |

**绝对禁止**：向客户出售/转售任何大模型 API 访问权、Token、代理通道。详见 RULE-PRODUCT-COMPLIANCE-001。
