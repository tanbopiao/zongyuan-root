## 一、调研结论：全系大厂的六层产品分层

所有头部厂商不约而同按同一骨架排兵布阵：

| 层 | 内容 | 大厂代表 |
|---|---|---|
| ① 模型/API 层 | 自研模型+按量计费+免费额度 | GPT-5.6 三档定价、Claude Opus/Sonnet、火山方舟、百炼、DeepSeek |
| ② Agent 平台/编排层 | Agent 构建+模板市场+插件/MCP 生态 | Agents API、Copilot Studio、AgentCore、扣子三层商店、腾讯元器 |
| ③ 开发工具/编程类 | 代码助手+agentic 编码 harness | Codex、Claude Code、GitHub Copilot、Trae、Comate |
| ④ 办公协作集成层 | 套件内嵌 AI+席位订阅 | M365 Copilot $30/席、Gemini in Workspace、WPS 365、飞书 AI 点、钉钉 365 |
| ⑤ 记忆/知识管理层 | 跨会话记忆+知识库（订阅粘性来源） | ChatGPT Memory（带来源）、Gemini 个性化、腾讯 ima 算力、NotebookLM |
| ⑥ 消费级 App/硬件生态 | 免费引流+会员分档+硬件/社交捆绑 | 豆包 68-500 元档、元宝免费、Meta 眼镜、xAI 捆绑 Cursor+X |

**七条定价/商业规律**：
1. 免费层引流 + 分层会员变现（C 端 68-199 元/月主流档）
2. **积分/点数计费成标配**（token 成本包装为可视额度：扣子资源点、ima 算力、飞书点、Manus 积分）
3. 纯席位制正转向「席位费+用量 credits」混合计费（GitHub AI Credits、Copilot Studio 信用包）
4. Agent 平台必配「模板市场+插件市场+企业内部商店」三层生态
5. 私有化交付是政企标配（一体机/本地部署）
6. 开源引流、闭源变现（Llama/GLM/Qwen/Gemma）
7. 全家桶互嵌导流（豆包↔即梦↔Trae、千问↔夸克↔钉钉）

## 二、我们的占位判断：不做模型层，做「AI 稳态治理基础设施」

**关键洞察：六层中 ①③④ 属红海且非我方禀赋；②⑤⑥ 及「层间治理」是差异化战场。**
大厂产品全部解决「AI 能做什么」，**没有一家系统解决「AI 如何不失控、不漂移、不失忆、可审计」**——这正是元极恒一内核的全部资产所在（四层阈值防线+三级熔断、真值锁档、Merkle 存证、算子自愈）。

我们不自研基础模型（走 Octop 多模型混合池路由），产品线全部落在**治理与记忆层**，对外遵循 META-ISO-051 内外隔离（脱敏交付、内核自留）。

## 三、产品线规划（四线并行）

### 产品线 P1 · 稳态治理线（旗舰，核心护城河）
| SKU | 对标大厂空白 | 现状 | 分层 |
|---|---|---|---|
| **联邦记忆内核**（已定 L1/L2/L3 三档） | ChatGPT Memory/ima 的企业级超集 | 产品技术文档完整版 ✅ | L1 种子资产包(引流) / L2 私有化+工具链+看板(主力) / L3 托管迭代(高客单) |
| **意图漂移防控中间件 intent-drift-guard** | 无直接对标（Agent 安全护栏） | 源码+自测 100%/0%+三文档 ✅ 可直接产品化 | 独立轻量 SKU（≤5% 误报），亦可并入 L2 |
| **GEO 晶格稳态校验**（脱敏版：扰动扫描+秩序分） | 大厂监控只抓报错，不抓隐性漂移 | 内核锁档 ✅ | 作为内核能力随 L2/L3 交付 |

**计费架构**：免费层=脱敏种子资产包+接入文档（对标大厂引流层）；主体=私有化订阅（年付）；深度=托管迭代（按节点/算力增购包）——完全复用「平台费+资源增购」双轨，但**独有卖点是积分最小消耗元规则**（最小额度消耗已上报为全局元规则，天然契合客户降本诉求）。

## 四、对标定价参考带（仅策略参考，正式定价另行决策）

- C 端/轻量：免费层 ← 68-199 元/月（国内主流带）
- B 端席位：对标 WPS 199-599 元/人/年、M365 Copilot $30/席/月 → L2 落 299-599 元/人/年带
- 私有化/企业：对标腾讯 ADP 4880 元/月、扣子企业 490 元/月 → L3/DataGate/SSH 网关按「部署年费+增购包」双轨，一体机另议
- 用量计费：全部 SKU 预留积分/credits 口径（行业标配），并以「最小消耗」作差异定价（同等额度更少浪费）

## 五、路线图

1. **近期（已就绪可售）**：联邦记忆内核 L1 发布（脱敏资产包+接入文档）→ intent-drift-guard 打包入 L2 → SSH 网关 SDK 版开源引流
2. **中期**：DataGate 补齐适配器实装（CDC/API）→ 联邦记忆小程序上线（飞书入口）→ 积分计量与看板打通
3. **远期**：Ω-Refer 脱敏规范对外（协议卡位）→ 模板市场（稳态治理模板包）→ 一体机形态（政企）

## 六、一句话战略

**大厂卷「AI 能做什么」，我们卖「AI 如何不失控」——以联邦记忆内核为底座、稳态治理为旗舰、数据网关与 SSH 网关为工业触手、办公小程序为分发入口，四线卡位六层分层中唯一无人防守的治理层。**
