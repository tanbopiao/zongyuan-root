# 简易版共享大脑 · 协作契约（shared-brain-lite）

> 定位：轻量化共享台账底座——单源真值、多节点同步、版本确权、冲突可追溯。
> 不含 Lv11 自治 / GEO 晶格 / L5-Organizer 复杂调度；合并一律人工确认放行。
> 核心原则：**Gitee 冷存确权，在线表格业务读写前台，sandbox 先行，converge 收敛。**

## 目录规范（固定结构，直接照搬）

```
shared-brain/
├── converge/            # 【唯一权威分支基线，只读源】所有真值台账最终收敛目录
│   ├── truth-ledger.csv # 真值账本：哈希、时间戳、变更说明、变更节点ID
│   ├── rule/            # 协作元规则、字段定义、字典（只读，修改需要审批）
│   └── asset-index.md   # 资产索引清单
├── sandbox/             # 沙箱目录：节点临时草稿、测试变更，不影响主真值
├── archive/             # 归档目录：历史快照、过期版本，只读锁档
└── README.md            # 本仓库协作契约（必读）
```

强制约定：**converge = 唯一真值源**，所有节点默认只读，不允许直接推送覆盖。

## 最简协作元公理（六条，所有人遵守）

1. **单源真值**：一切真值以 converge 分支内账本为准；本地节点修改前，必须先拉取最新远端基线。
2. **沙箱先行**：任何新增、修改内容，先放到 sandbox 测试验证，验证通过后才合并进入 converge。
3. **账本留痕**：每一次并入 converge 的变更，必须在 truth-ledger.csv 登记：时间戳、操作人/节点标识、变更摘要、文件 SHA256 哈希。
4. **冲突判定**：出现内容冲突，以账本时间戳+哈希指纹为准，禁止强行覆盖；解决冲突后重新提交。
5. **固化资产保护**：archive 归档目录内容设置只读，修改必须人工评审。
6. **准入边界**：沙箱内允许自由试错；converge 是共识基准，不允许未经核验的内容流入。

## 使用模式

### 模式 A：纯手动（不用写代码）

1. 主台账放在在线多维表格（飞书 Base），所有人在表格读写业务数据
2. 定期（每日/每次重要变更）：导出表格台账文件，放到 sandbox
3. 核对变更内容，确认无误，手动合并至 converge
4. 手动计算文件哈希，往 truth-ledger.csv 追加一条记录
5. Git 提交+推送到 Gitee，形成带哈希的版本快照，支持随时回滚

### 模式 B：半自动脚本版

```bash
# 默认 dry-run（只报告差异，不落账不提交）
python3 sync_shared_brain.py --export path/to/base_export.csv

# 人工核对差异后放行（写账本 + commit + push）
python3 sync_shared_brain.py --export path/to/base_export.csv --apply
```

脚本只做 4 件轻量任务：① 拉取远端 converge 基线 ② 导入表格数据到 sandbox
③ 对比差异并计算 SHA256 ④ 有差异时写账本、提交推送（`--apply` 才执行）。

⚠️ 与高阶版本的区别：脚本只做同步、存证，**没有稳态打分、自动评审、自主进化逻辑**；
所有内容合并需要人工确认放行（默认 dry-run 即人工确认闸门）。

## 多维表格（Base）最简表结构

只建 3 张基础表：

1. **真值主表**：业务台账、事实记录、参数配置（业务读写入口）
2. **变更审批表**：记录待合并的沙箱变更、核验状态、处理人
3. **资产索引表**：记录外部资源链接、文件路径、对应 Gitee 提交哈希

## 能力边界

✅ 可以实现：
- 多个人/多个 AI 节点共享一套统一台账
- 每一次变更都有版本、哈希、历史记录，随时回滚
- 区分草稿沙箱和正式共识真值，减少乱改冲突
- 离线本地节点，联网后再同步收敛

❌ 这个简易版不自带：
- L5-Organizer 顶层调度、自动派单巡检
- GEO 晶格稳态校验、自治进化打分
- A2A 全链路内核互通、云端内核比对
- 自动熔断、快照回滚、DID 确权体系

## 升级路线（简易版 → 完整版）

1. **第一阶段**：跑通这套手动/半自动共享大脑，稳定运行一段时间
2. **第二阶段**：接入轻量调度脚本，增加定时巡检、差异告警
3. **第三阶段**：引入算子契约、稳态评估规则，逐步往 Lv11 自治体系演进
