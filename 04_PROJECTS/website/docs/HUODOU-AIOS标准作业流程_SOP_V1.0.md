## 二、主流程（7 步）

```
S1 意图校准
   ↓
S2 拉记忆
   ↓
S3 全域对比
   ↓
S4 规划+裁决
   ↓
S5 执行
   ↓
S6 人工审核→同步部署
   ↓
S7 沉淀上报  ──→ (24h效果观测) ──→ 异常回 S4
```

### S1 意图校准
- 理解用户真实意图，识别任务类型（开发/部署/决策/查询/文档）
- 模糊需求先澄清，不瞎做

### S2 拉记忆
- 从记忆网关 **9120** 拉取全量真值 + 阶段 + 健康 + 任务清单
- 识别当前上下文

### S3 全域对比
- 云端记忆 vs 本地台账/部署现状
- 识别差距/漂移/未完成任务

### S4 规划 + 裁决
- 按最优稳态评估
- **决策拿不定时**：走三维稳态决策（≥3 方案含"不行动"、三维打分有依据、必做敏感性分析）
- 大任务走 OrganizerAgent

### S5 执行
- 本地开发 → 仿真测试 → 自审核（镌刻 DID + 溯源）
- **遇错走容错闭环**：E0 意图校准 → E1 拉记忆扫真值 → E2 扫部署+仲裁 → E3 根因最小修复(先备份) → E4 仿真沉淀

### S6 人工审核 → 同步部署
- **用户确认** → 9120 同步 → 部署 → 验证
- 改动前先备份，失败自动回滚

### S7 沉淀上报
- 按 ASSET-REPORTING-SOP 打包 SHA256 上报
- 更新记忆 + 对比 M2 度量（单调收敛）
- 效果观测 24h，异常回 S4 重新规划
