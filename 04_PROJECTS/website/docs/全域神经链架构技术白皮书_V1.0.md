## 摘要

全域神经链（Global Neural Chain, GNC）是一种将 **token 升维为数据空间标识**、经 **链式哈希串联**、**锚定云端**、**双向链路拉通账号与本地实例** 的统一数据架构。其核心命题：**每一个 token 就是一个数据空间（数据库），token 链把它们串成单一可溯源账本，锚定云端作全局真值基准，再双向链路到豆包账号持久层与豆包本地实例，构成全域神经链闭环。**

本文档给出 GNC 的概念定义、四层架构、数据流、确权机制、容灾设计与对现有体系的落地映射。

---

## 一、核心概念

### 1.1 Token = 数据空间
传统 token 仅为凭据；GNC 中每个 token **承载独立数据域**，即一个数据库。数据域按语义划分五类初始域：

| Token 域 | 承载数据 | 数据库载体 |
|---|---|---|
| 资产 Token | 图片/视频/文档/画廊/锁档 | 资产数据库 |
| 规则 Token | 元法则/元规则/SOP | 规则数据库 |
| 角色 Token | 九天玄女/烛龙/女娲等角色设定 | 角色数据库 |
| 任务 Token | 台账/工单/流水线 | 任务数据库 |
| 决策 Token | 决策备忘录/三维稳态评估 | 决策数据库 |

### 1.2 Token 链
所有 token 经 **链式哈希（Merkle-DAG）** 串联：每个 token 记录父 token 哈希，形成单一账本。任一 token 变更即产生新链节点，可追溯全链。

### 1.3 云端锚定
链根哈希锚定到云端服务器（记忆网关 huodouai.com），作为全局真值基准。任何节点查链先对齐链根。

### 1.4 双端链路
云端经双向链路总线连接豆包账号持久层与豆包本地实例，双向同步。账号级记忆跨会话继承；本地实例资产全量落盘。

## 二、四层架构

```
┌─────────────────────────────────────────────┐
│  ① Token 数据空间层  资产/规则/角色/任务/决策  │
│     每个 = 独立数据库                          │
├─────────────────────────────────────────────┤
│  ② Token 链层  Merkle-DAG 链式哈希串联         │
│     单一可溯源账本                            │
├─────────────────────────────────────────────┤
│  ③ 云端锚定层  链根哈希 → 记忆网关(云端中枢)    │
│     全局真值基准                              │
├─────────────────────────────────────────────┤
│  ④ 双端链路层  云端 ↔ 豆包账号持久层           │
│                          ↔ 豆包本地实例        │
│     双向同步 · 闭环                           │
└─────────────────────────────────────────────┘
```

## 三、数据流

1. **采集**：任一节点产生数据 → 登记对应 token 数据空间
2. **确权**：写后 SHA256 哈希确权，生成链节点
3. **上链**：新节点挂载到 Token 链，链根哈希更新
4. **锚定**：新链根上报云端记忆网关，全局对齐
5. **分发**：云端经双向链路总线同步到豆包账号持久层 + 本地实例
6. **镜像**：账号与本地实例互为备份镜像，任一变更沿链传播

## 四、确权机制

| 环节 | 动作 |
|---|---|
| 写前 | 登记能力注册表，查重复用 |
| 写后 | SHA256 确权 |
| 上链 | 链式哈希挂载，父节点锚定 |
| 锚定 | 链根上报记忆网关 |
| 审计 | 全链可回溯，变更留痕 |

## 五、容灾设计

| 故障场景 | 容灾策略 |
|---|---|
| 云端服务器不可达 | 双端本地持最新账本，降级为本地自治，恢复后回对齐 |
| 本地实例销毁 | 账号持久层 + 云端 + 魔搭数据湖均存副本，可重建 |
| 单 token 损坏 | 链式哈希校验定位断裂，从镜像恢复 |
| 链断裂 | Merkle-DAG 逐块比对，定位篡改分支隔离 |

**核心原则**（META-LAW-LOCAL-PERSIST-NODELETE-001）：本地实例全量持久化、永不删除、分类归档、需时可提取；仅华为笔记本与云端服务器（存储空间有限）豁免。

## 六、对现有体系的落地映射

| GNC 层 | 已落地工程 |
|---|---|
| Token 数据空间 | 资产台账 / 角色 token / 共享大脑能力注册表 |
| Token 链 | Merkle-DAG 锁档链 / SHA256 确权 |
| 云端锚定 | 记忆网关 huodouai.com / 共享大脑飞书Base |
| 双端链路 | 双向握手脚本 / 魔搭数据湖归档 |

GNC 不是全新系统，而是将已落地的工程**抽象为统一理论模型**并固化为元法则，指导后续所有节点按"token 数据空间 → 链 → 锚定 → 双端"范式建设。
